## 1. FPGA 系统总体架构参考

### 1.1 闫佳欣：单载波相干光接收端架构

**系统框图层级关系：**

```
ADC (4路, I/Q x X/Y偏振)
  → 串并转换 (并行度 P=32)
    → 帧同步模块 (Find_Head + Shift)
      → 匹配滤波模块 (根升余弦 FIR, 32抽头, 滚降0.1)
        → 解偏振复用 (并行CMA/LMS自适应均衡)
          → 频偏估计与补偿 (四次方频偏估计)
            → 相位噪声估计与补偿 (V-V算法)
              → 判决输出
```

**关键设计参数：**
- ADC：4通道 5 GSa/s，8 bit 量化
- FPGA：Xilinx Kintex-7 XC7K325TFFG900
- 并行度 P = 32（每个时钟周期处理 32 个采样点）
- 系统采样速率 20 GHz（经并行化后在 FPGA 内以 20 GHz / 32 = 625 MHz 时钟运行）
- 信号调制：QPSK
- 实验验证：1.25 GS/s 采样频率，实时误码率 = 0

**数据流特征：**
- 高速串行输入先经串并转换降速
- 并行度 P 决定了所有后续模块的位宽和处理粒度
- 算法需进行并行化改造：CMA/LMS 系数每 P 个样本更新一次
- 并行化引入 T 个时钟周期的计算延时，系数更新使用的是 T 周期前的误差

### 1.2 闫佳欣：OFDM 相干光接收端架构

**系统框图：**

```
ADC (I/Q两路)
  → 串并转换 (P=32, 8 bit)
    → 符号同步 (改进Schmidl算法)
      → 频偏估计与补偿 (分数倍 + 整数倍)
        → 去除循环前缀
          → FFT (64点)
            → 相位噪声补偿 (导频辅助)
              → 判决
```

**关键参数：**
- FFT 点数：64（有效子载波 48）
- CP 长度：4 个采样点（1/16）
- FFT 计算延迟：43 个时钟周期（使用 Spiral 在线工具生成）
- QPSK 调制，系统采样速率 20 GHz
- FPGA：Xilinx XC7K325TFFG900，Vivado 2021.1

### 1.3 Liu 2023：双反馈环路 + V-V 级联载波恢复

**系统框图：**

```
接收信号
  → 星历粗补偿 (残余频偏 < 符号速率)
    → 第一级反馈频偏估计 (PADE 环路)
      → 第二级反馈频偏估计 (环路滤波系数 σ₂)
        → V-V 前馈载波相位恢复 (块长度 16 符号)
          → 判决
```

**关键参数与实验条件：**
- FPGA：Intel Arria 10
- 信号速率：10 Gbps PM-QPSK
- 频偏范围：±920 MHz（动态跟踪）
- V-V 块长度：16 符号
- 反馈环路系数：μ（PADE 环路）、σ₁（第一级反馈）、σ₂（第二级反馈）
- BER 7% FEC 阈值 (3.8×10⁻³) 时接收灵敏度约 -45.5 dBm
- 双反馈比单反馈显著降低残余频偏方差

## 2. 核心算法的 FPGA 并行化公式

### 2.1 并行化 CMA 算法（解偏振复用）

串行 CMA 系数更新：

$$\mathbf{h}(n+1) = \mathbf{h}(n) + \mu \cdot e(n) \cdot \mathbf{x}^*(n)$$

其中 $e(n) = |y(n)|^2 - R^2$，$R^2 = E[|s|^4]/E[|s|^2]$。

**并行化改造**（每 P 个样本更新一次）：

$$\mathbf{h}(k+1) = \mathbf{h}(k) + \mu \sum_{p=0}^{P-1} e(kP+p) \cdot \mathbf{x}^*(kP+p)$$

其中误差 $e$ 来自 $T$ 个时钟周期前的输出（实时实现不可避免的流水线延迟）。

### 2.2 并行化 LMS 算法

$$\mathbf{h}(k+1) = \mathbf{h}(k) + \mu \sum_{p=0}^{P-1} e_d(kP+p) \cdot \mathbf{x}^*(kP+p)$$

其中 $e_d(n) = y(n) - d(n)$，$d(n)$ 为训练序列。

### 2.3 四次方频偏估计算法（QPSK）

**算法原理：**

接收符号相位：
$$\theta_r(k) = \theta_s(k) + \Delta\omega \cdot kT + \theta_n(k) + \theta_a(k)$$

共轭相乘消除相位噪声：
$$r(k) \cdot r^*(k-1) \Rightarrow \theta_s(k) - \theta_s(k-1) + \Delta\omega \cdot T + \theta_a(k)$$

四次方消除调制相位（QPSK: $\theta_s = \{0, \pi/2, \pi, 3\pi/2\}$）：
$$(\cdot)^4 \Rightarrow 4\Delta\omega \cdot T + 4\theta_a(k)$$

取平均抑制噪声：
$$\hat{\phi} = \frac{1}{N}\sum_{k=0}^{N-1} [r(k) \cdot r^*(k-1)]^4$$

频偏估计：
$$\hat{\Delta f} = \frac{1}{4} \cdot \frac{\text{Arg}(\hat{\phi})}{2\pi T}$$

**FPGA 实现要点：**
- theta_1 使用定点小数表示，小数位 2 bit
- 并行化：同时对 P 个采样点进行四次方和共轭乘法
- 需要反正切运算（CORDIC 或查找表）

### 2.4 V-V 相位噪声估计算法（QPSK）

**算法步骤：**

1. 四次方运算：$r^4(k)$
2. 窗口内取平均：$\frac{1}{M}\sum_{k=0}^{M-1} r^4(k)$
3. 取角运算：$\text{Arg}(\cdot) \in [-\pi, \pi)$
4. 减去 $\pi$ 再除以 4：$\hat{\theta}_n = \frac{1}{4}[\text{Arg}(\cdot) - \pi]$
5. 相位解绕：消除 $\pm\pi/2$ 跳变
6. 补偿：$r'(k) = r(k) \cdot \exp(-j\hat{\theta}_n)$

**FPGA 实现要点：**
- 求角：CORDIC 算法或查找表
- 相位解绕：比较相邻估计值，差值超阈值则加减 $\pi/2$
- 数据缓存：由于计算延迟，输入信号需缓存后与估计值对齐

### 2.5 OFDM 频偏估计（闫佳欣改进算法）

**分数倍频偏估计：**
$$\hat{\Delta f}_f = \frac{1}{2\pi} \cdot \frac{2}{T} \cdot \text{Arg}(P_f(d))$$

其中训练符号分为 4 块（A-B-A-B 结构），估计范围扩展为 $[-2/T, 2/T)$。

**整数倍频偏估计（零载波功率法）：**

构造带通滤波器组：
$$h_{bp,i}(n) = h_{pt}(n) \cdot \exp(j2\pi f_i n T), \quad f_i = i \cdot \frac{4}{NT}, \quad i = 0,1,...,N/4-1$$

滑动平均原型滤波器：
$$h_{pt}(n) = \frac{1}{M}\sum_{m=0}^{M-1} \delta(n-m)$$

3 dB 带宽：
$$\Delta f_{3dB} \approx \frac{S_R}{M}$$

计算各滤波器输出能量：
$$E_i = \sum_{n=0}^{N_p-1} |r_f(n) * h_{bp,i}(n)|^2$$

整数倍频偏：
$$\hat{i} = \arg\min_i E_i$$

**复杂度对比：**
- Schmidl 整数频偏：$O(N_{FFT}^3)$，需等 FFT 完成（43 周期延迟）
- 提出算法：$O(N_{filter} \cdot N_{window} \cdot N_{FFT}^2)$，时域完成，零额外 FFT 延迟

### 2.6 OFDM 导频辅助相位恢复

导频位置：-32, -28, 4, 27 四个子载波

相位噪声估计：
$$\hat{\varphi}_i = \frac{1}{N_p} \sum_{j=1}^{N_p} \text{Arg}(Y_{i,pj} \cdot X_{i,pj}^*)$$

补偿：
$$Y'_{i,k} = Y_{i,k} \cdot \exp(-j\hat{\varphi}_i)$$

## 3. 定点化参考

### 3.1 数据位宽

| 信号 | 位宽 | 说明 |
|------|------|------|
| ADC 输出 | 8 bit | 接收端量化精度 |
| 并行度 | 32 | 每时钟周期处理采样点数 |
| 频偏相位 theta_1 | 定点, 小数 2 bit | 四次方频偏估计中间变量 |
| 匹配滤波抽头 | 32 | 根升余弦滤波器，对称性可减半乘法器 |
| CMA/LMS 步长 μ | 可配置 | 通过输入端口设置 |

### 3.2 关键运算的定点化考量

**四次方运算：**
- 8 bit 输入经四次方后位宽增长，需截断/舍入
- 中间结果保留足够精度避免估计偏差

**反正切/求角：**
- 可用 CORDIC 迭代（面积优）或查找表（速度优）
- 精度与迭代次数/表大小直接相关

**复数乘法：**
- 核心运算单元，直接映射到 DSP slice
- 利用对称性减少乘法器数量（如 FIR 抽头对称）

## 4. 资源利用率参考

### 4.1 闫佳欣系统（XC7K325T）

论文中未给出完整资源利用率表，但从 RTL 描述可推断主要模块资源消耗：

| 模块 | 主要资源类型 | 说明 |
|------|-------------|------|
| 帧同步 | LUT + FF | 相关性计算 + 数据缓存 + 移位 |
| 匹配滤波 | DSP + LUT | FIR 滤波器（32抽头，利用对称性减半） |
| CMA/LMS 均衡 | DSP + BRAM | 蝶形滤波器 + 系数存储 |
| 四次方频偏估计 | DSP | 复数乘法 + 累加 |
| V-V 相位恢复 | DSP + LUT | CORDIC/查找表 + 数据缓存 |
| FFT (OFDM) | DSP + BRAM | 64点 FFT，43 周期延迟 |

### 4.2 Liu 2023 系统（Arria 10）

| 项目 | 数据 |
|------|------|
| FPGA | Intel Arria 10 |
| 数据速率 | 10 Gbps PM-QPSK |
| 频偏跟踪范围 | ±920 MHz |
| V-V 块长度 | 16 符号 |
| BER 阈值 | 3.8×10⁻³ (7% FEC) |
| 接收灵敏度 (BER=10⁻³) | -45.5 dBm (双反馈) |

**反馈 vs 前馈对比：**
- 反馈 FOE：更低逻辑资源消耗、更高最大时钟频率、更宽动态频偏跟踪范围
- 前馈 FOE：需要完整 FFT 运算，资源消耗更大

### 4.3 典型资源比例参考

基于同类文献 (fpgadpqpsk2023, fpga16qam2022 等) 的典型资源分布：

| 资源类型 | 占总资源比例 | 主要消耗模块 |
|----------|-------------|-------------|
| DSP slice | 30-50% | 复数乘法、FIR 滤波、CORDIC |
| BRAM | 20-30% | 系数存储、数据缓存、FFT |
| LUT | 15-25% | 控制逻辑、状态机、地址生成 |
| FF | 10-20% | 流水线寄存器、数据对齐 |

## 5. 时序与验证方法

### 5.1 时序约束

**闫佳欣系统：**
- 系统采样速率：20 GHz
- 并行度 P = 32 → FPGA 内部时钟频率：20 GHz / 32 = 625 MHz
- 实际实验使用 1.25 GS/s ADC → 内部时钟约 39 MHz

**Liu 2023 系统：**
- 10 Gbps PM-QPSK → 符号速率 2.5 GBaud
- FPGA 时钟频率需满足实时处理吞吐量

### 5.2 验证流程

**仿真验证（闫佳欣方法）：**

1. VPI 软件生成仿真数据（模拟相干发射/接收，8 bit 量化，并行度 32）
2. Modelsim / Vivado 仿真器加载各模块 RTL
3. 读取各模块中间信号，在 MATLAB 中画星座图
4. 将相位补偿后数据与发送数据做误码计算

**实验验证：**

1. 搭建实时系统实验平台
2. ADC 接收信号后传入 FPGA 进行实时 DSP
3. FPGA 内部实时计算误码率
4. Vivado VIO 界面实时观测 BER

**比特级对比方案（Liu 2023）：**

1. SignalTap II 提取 FPGA 内部二进制比特流
2. 导入 MATLAB 计算 pre-BER
3. 与 MATLAB 浮点仿真结果对比，确认一致性

## 6. 我们 Ch5 需要解决的核心硬件映射问题

根据 thesis-framework.md 的描述，我们的 Ch5 需要实现：

### 6.1 自适应窗口长度 N_opt 的实时计算

$$N_\text{opt} = \frac{80}{\bar\gamma \cdot h^2}$$

**难点：** $h^{-2}$ 非线性运算的定点化精度
- 需要倒数运算或查找表
- $h^2$ 动态范围大，定点化需精心设计位宽
- 可考虑对数域运算简化

### 6.2 FFT IP 核参数动态配置

- 自适应窗口意味着 FFT 点数需动态调整
- Xilinx FFT IP 核支持运行时配置（NFFT 参数可变）
- 需要控制逻辑在不同湍流条件下切换 FFT 大小

### 6.3 VV/BPS 模块流水线设计

$$M_\text{opt} = K_M \cdot (\bar\gamma \cdot h)^{-1/5} \cdot (\Delta f \cdot T_s)^{-2/5}$$

- 平滑窗口长度动态调整
- 需要数据缓存大小适配最大窗口

### 6.4 DPLL 环路带宽自适应

$$B_\text{L,opt} = B_0 \cdot h$$

- 环路滤波器系数需根据湍流估计实时更新
- 二阶 DPLL 环路参数 $\alpha, \beta$ 与 $B_L$ 的映射关系
