## 1. 级联误差传播的理论模型

### 1.1 信号处理链与误差注入点

本系统的级联结构为：

```
信道 h (真值) → 信道估计 ĥ (有噪声) → MMSE 均衡 → 载波恢复 (FOE+DPLL+VV) → BER
```

误差从 h_est 注入，依次影响两级：(A) MMSE 均衡，(B) 载波恢复（通过自适应参数）。

### 1.2 第一级：h_est 误差 → MMSE 均衡

**噪声模型**（代码 L59-64）：

```
ĥ = |h + n_ε|,  n_ε ~ N(0, h^2 · 10^(-NMSE/10))
```

等价于乘性噪声模型：**ĥ ≈ h · (1 + ε)**，其中 ε ~ N(0, NMSE_linear)。

**MMSE 均衡公式**（代码 L201）：

```
rx_mmse = rx · conj(√ĥ) / (ĥ + 1/γ̄) · amp_limit(·, 3.0)
```

将 ĥ = h(1+ε) 代入，均衡后的信号可分解为：

- **理想项**：s · exp(jφ) · h / (h + 1/γ̄)（当 ε=0 时）
- **失真项**：由 ε ≠ 0 引起的幅度和相位偏差

**误差性质：乘性。** MMSE 均衡器以 ĥ 为权重，估计误差 ε 直接进入分子和分母，形成乘性失真。具体地：

```
有效SNR偏移 = γ_eff / γ_ideal = (1+ε)²·(h + 1/γ̄)² / ((1+ε)·h + 1/γ̄)²
```

在 20dB（γ̄=100）时，h 的中位数约 1.0（弱湍流）或 0.5（强湍流），1/γ̄ = 0.01 相对 h 可忽略，因此：

```
γ_eff / γ_ideal ≈ 1  （当 1/γ̄ << h 时）
```

**关键结论**：在 20dB 高 SNR 下，MMSE 均衡分母中 h >> 1/γ̄，使得估计误差对均衡后 SNR 的影响被自然抑制。这是第一级误差不爆炸的根本原因。

### 1.3 第二级：h_est 误差 → 载波恢复（自适应 DPLL）

自适应载波恢复使用 ĥ 调整 DPLL 环路带宽（F4.10）：

```
B_L = B_0 · ĥ = B_0 · h · (1+ε)
```

DPLL 线性化模型的相位误差方差为（F3.18 上下文）：

```
σ_φ² ≈ B_L · T_s / (2 · γ̄ · h)
```

代入 B_L = B_0·h·(1+ε)：

```
σ_φ² ≈ B_0·h·(1+ε)·T_s / (2·γ̄·h) = B_0·(1+ε)·T_s / (2·γ̄)
```

**核心发现（F3.21）**：h 在分子分母中精确对消！σ_φ² 仅与 (1+ε) 成正比，与信道状态 h 无关。

**误差性质：加性（对 σ_φ² 的一阶修正）。**

- NMSE = -10 dB → ε ~ N(0, 0.1) → σ_φ² 波动 ±√0.1 ≈ ±0.32 → σ_φ 相对变化约 ±16%
- NMSE = -5 dB → ε ~ N(0, 0.316) → σ_φ² 波动 ±56% → σ_φ 相对变化约 ±25%

由于 DPLL 有积分器（二阶环路），瞬时带宽偏差会被环路积分平滑，实际影响进一步减小。

### 1.4 VV 窗口自适应（次要影响）

VV 窗口 M_opt 依赖 h（F4.9, h^(-1/5) 依赖）：

```
M_opt = K_M · (γ̄·ĥ)^(-1/5) · (Δf·T_s)^(-2/5)
```

h^(-1/5) 是 5 次根号，极其温和。NMSE = -10 dB 时，M_opt 偏差仅约 (1+ε)^(-1/5) ≈ 1 - ε/5，即 2% 量级。

### 1.5 综合级联模型

```
总BER恶化 ≈ BER_ideal · [1 + f(NMSE)]
```

其中 f(NMSE) 的各分量贡献：

| 误差源 | 依赖形式 | NMSE=-10dB 贡献 | NMSE=-5dB 贡献 |
|--------|---------|-----------------|----------------|
| MMSE 均衡失真 | 乘性（被 h>>1/γ̄ 抑制） | <1% | ~3% |
| DPLL 带宽偏差 | 加性（h 对消后仅 ε 残留） | ~2% | ~8% |
| VV 窗口偏差 | h^(-1/5) 极温和 | <1% | ~2% |
| **总 BER 恶化** | **以加性修正为主** | **<5%** | **<15%** |

**理论结论：误差以加性修正为主（h 对消是关键机制），不发散，随 NMSE 单调恶化但无尖锐阈值。**

## 2. 六个测试场景的 PASS 标准

### 2.1 场景定义

仿真定义 6 个场景 = 3 湍流强度 x 2 仰角（多普勒条件）：

| # | 场景 | 湍流 | α,β | 多普勒率 | 物理场景 |
|---|------|------|-----|---------|---------|
| 1 | weak_low | 弱 | 4.0, 3.0 | 150 MHz/s | 夜间低仰角 |
| 2 | weak_high | 弱 | 4.0, 3.0 | 30 MHz/s | 夜间高仰角 |
| 3 | moderate_low | 中 | 2.5, 1.8 | 150 MHz/s | 白天低仰角 |
| 4 | moderate_high | 中 | 2.5, 1.8 | 30 MHz/s | 白天高仰角 |
| 5 | strong_low | 强 | 1.5, 0.8 | 150 MHz/s | 恶劣天气低仰角 |
| 6 | strong_high | 强 | 1.5, 0.8 | 30 MHz/s | 恶劣天气高仰角 |

### 2.2 PASS 标准：自适应 vs 固定增益 > 0.5 dB

PASS 条件：自适应方案的 BER < 固定方案 BER，增益 > 0.5 dB。

**物理依据**：

1. **自适应 DPLL 的本质优势**：B_L = B_0·h 使环路带宽与瞬时信道状态匹配。高 SNR 块（h 大）用大带宽快速跟踪相位变化，低 SNR 块（h 小）用小带宽抑制噪声。固定带宽无法同时兼顾两种情况。

2. **增益来源的定量分析**：
   - 弱湍流（h 方差小）：固定与自适应差距小，增益主要来自 DPLL 的微调。预期增益 0.5-1.5 dB。
   - 中等湍流（h 方差中等）：自适应优势开始显现。预期增益 1-3 dB。
   - 强湍流（h 方差大，深衰落频繁）：固定带宽在深衰落块严重过调（噪声爆炸）或正常块跟踪不足。自适应增益最大。预期增益 2-5 dB。

3. **0.5 dB 阈值的工程意义**：0.5 dB SNR 增益等效于发射功率提升约 12%，在卫星激光通信链路预算中属于有意义的改善量级。低于 0.5 dB 的改善在工程上难以与实现复杂度权衡。

### 2.3 各场景预期 BER 恶化范围（量化锚点）

基于 SPEC.md §6.1 的已验证 BER 数据和上述级联模型：

**锚点 1：NMSE = -15 dB（高质量估计）**

| 场景 | 预期 BER (oracle h) | 预期 BER (NMSE=-15dB) | 预期恶化 | 自适应增益 |
|------|--------------------|-----------------------|---------|-----------|
| weak_low | ~0.015% | ~0.016% | +7% | 0.5-1.0 dB |
| moderate_low | ~0.15% | ~0.17% | +13% | 1.0-2.0 dB |
| strong_low | ~1.9% | ~2.2% | +16% | 1.5-3.0 dB |

**锚点 2：NMSE = -10 dB（中等质量估计）**

| 场景 | 预期 BER (oracle h) | 预期 BER (NMSE=-10dB) | 预期恶化 | 自适应增益 |
|------|--------------------|-----------------------|---------|-----------|
| weak_low | ~0.015% | ~0.018% | +20% | 0.5-1.5 dB |
| moderate_low | ~0.15% | ~0.20% | +33% | 1.0-2.5 dB |
| strong_low | ~1.9% | ~2.5% | +32% | 2.0-4.0 dB |

**锚点 3：NMSE = -5 dB（低质量估计，接近失败边界）**

| 场景 | 预期 BER (oracle h) | 预期 BER (NMSE=-5dB) | 预期恶化 | 自适应增益 |
|------|--------------------|-----------------------|---------|-----------|
| weak_low | ~0.015% | ~0.025% | +67% | 0-1.0 dB |
| moderate_low | ~0.15% | ~0.28% | +87% | 0-2.0 dB |
| strong_low | ~1.9% | ~3.5% | +84% | 0.5-2.0 dB |

> 注：NMSE=-5dB 时估计噪声极大（ε 标准差 ~0.56），自适应参数 B_L 偏差达 ±56%。此时 h 对消机制虽然仍成立（不发散），但增益可能不足以超过 0.5 dB PASS 阈值。

### 2.4 H006 判定标准

```
Strong PASS: >= 4/6 场景 PASS at NMSE=-10dB
PASS:        >= 4/6 场景 PASS at NMSE=-15dB
WEAK PASS:   2-3/6 场景 PASS at NMSE=-15dB
FAIL:        全崩 at NMSE=-15dB
```

**理论预测**：基于 h 对消机制，自适应方案在 NMSE=-10dB 应仍有 >= 4/6 PASS（Strong PASS），因为：
- 弱/中湍流 4 个场景增益来自带宽自适应，不严重依赖 h 精度
- 强湍流 2 个场景增益最大，即使 NMSE=-10dB 仍有 1.5-3 dB 余量

## 3. 文献先例

### 3.1 灵敏度级联分析的文献传统

**通信系统级联灵敏度分析**是一个成熟但分散的研究范式，主要有以下几条线索：

**(a) RF 接收机链路预算的级联噪声系数**

I 通信教科书中对超外差接收机的级联噪声分析（Friis 公式）是级联灵敏度分析的鼻祖。每级模块的噪声系数按级联公式传播，前级增益抑制后级噪声。本论文的 h_est -> 均衡 -> 载波恢复 链路在结构上与之同构。

参考文献：B. Sklar, *Digital Communications: Fundamentals and Applications*, Ch. 2 (Noise Figure and Cascade Analysis).

**(b) OFDM 系统信道估计误差传播**

OFDM 文献中大量研究信道估计误差对均衡、解码的级联影响。典型分析框架：

1. 信道估计误差 Δh 引起均衡后 SINR 恶化
2. SINR 恶化传播至 BER，通过指数函数放大

例如：M. Morelli and U. Mengali, "A comparison of pilot-aided channel estimation methods for OFDM systems," IEEE Trans. Signal Process., 2001. 该文建立了 LS/MMSE 估计误差 -> 均衡 SINR -> BER 的完整级联模型。

**(c) 相干光通信的相位恢复灵敏度分析**

相干光通信文献中，载波恢复（特别是 Viterbi-Viterbi 和 DPLL）对信道估计误差的灵敏度是一个已知问题：

- **Liu 2023**（本论文已引用）：分析了 VV-CPR 在不同窗口长度下的相位 MSE，但未考虑 h 估计误差对窗口参数的影响。
- **Fernandes 2023**（本论文已引用）：分析了湍流强度对载波恢复性能的影响，但假设 h 已知（oracle）。
- **Zhao 2025**（本论文已引用）：提出了自适应载波恢复框架，同样假设 h 已知。

**文献空白**：在 FSO 湍流信道下，**将信道估计误差与载波恢复自适应参数联合分析**的工作目前未见。现有文献要么假设 h 已知分析载波恢复，要么分析 h 估计精度但不考虑对下游载波恢复的影响。

### 3.2 本论文的级联分析定位

本论文的级联分析在以下方面区别于现有文献：

| 维度 | 传统分析 | 本论文分析 |
|------|---------|-----------|
| 误差源 | 信道估计噪声 | 信道估计噪声 + 估计器类型 |
| 传播路径 | h_est -> 均衡 -> BER | h_est -> 均衡 -> 自适应参数 -> 载波恢复 -> BER |
| 关键机制 | SINR 恶化 | **h 对消**（B_L ∝ h 与 γ ∝ h 抵消） |
| 结论 | 误差放大 | 误差被抑制（加性修正，不发散） |

**h 对消机制（F3.21）** 是本文的独特发现：自适应 DPLL 的 B_L ∝ h 设计使得 σ_φ² 与 h 无关，估计误差仅通过 ε 项残留。这在 FSO 文献中未见报道，但数学上是"显而易见"的（H002 定位为设计洞察而非理论创新）。

## 4. 理论模型总结

### 4.1 误差传播链的数学描述

```
级联 BER = f(NMSE) ≈ BER_ideal · (1 + α·NMSE_lin)

其中：
  BER_ideal = BER(oracle h, 固定或自适应参数)
  NMSE_lin = 10^(-NMSE_dB/10)
  α ≈ 0.1~0.3（取决于湍流强度和场景）
```

这是一个**线性化近似**，在 NMSE < -5 dB 时有效（误差 <20%）。NMSE > -5 dB 时非线性效应（深衰落块的噪声爆炸、幅度限制器触发频率增加）使模型失效。

### 4.2 不发散的数学保证

1. **MMSE 均衡**：分母 ĥ + 1/γ̄ 中 ĥ > 0（取绝对值），无除零风险
2. **DPLL 带宽**：B_L = clip(B_0·ĥ, 0.5MHz, 20MHz)，物理约束保证有限
3. **h 对消**：σ_φ² ∝ (1+ε)，不依赖 h 的具体值，无深衰落爆炸
4. **幅度限制器**：|rx| > 3.0 时截断，防止极端噪声放大

### 4.3 量化锚点汇总

| 条件 | BER 恶化预期 | 自适应增益预期 | PASS 预测 |
|------|-------------|---------------|----------|
| NMSE=-20dB, 弱湍流 | <2% | 0.5-1.0 dB | PASS |
| NMSE=-15dB, 中湍流 | 10-15% | 1.0-2.5 dB | PASS |
| NMSE=-10dB, 强湍流 | 25-35% | 1.5-3.0 dB | PASS |
| NMSE=-5dB, 弱湍流 | 50-70% | 0-1.0 dB | 边界 |

## 5. 对论文写作的指导

1. **§3.4 应重点描述 h 对消机制**：这是解释"为什么估计误差不致命"的核心论据。数学推导简单（3 行代数），但物理意义深刻。
2. **量化锚点用于仿真验证**：上述 4 个锚点应在 `sim_cascade_robustness.py` 的实验结果中得到确认（偏差 <30% 视为一致）。
3. **文献定位**：级联分析本身不是创新点（有大量先例），但"FSO 信道下 h 估计误差对自适应载波恢复的级联影响"这一具体分析未见报道，可作为设计洞察（design insight）写入 §3.4。
