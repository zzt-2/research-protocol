## 调研问题

## 文献/理论发现

### 发现 1：outage 概率作为 BER 下界的数学依据——Markov 不等式

**来源**: 自推（基于 F3.13-F3.17）; Simon & Alouini, "Digital Communication over Fading Channels" Ch.5; Proakis, "Digital Communications" Ch.14

**核心逻辑**：

对于块衰落信道（块内 h 恒定），平均 BER 定义为：

```
P_b^{avg} = E_h[E_φ[P_b(γ̄·h, φ)]]
          = ∫₀^∞ f_GG(h) · P_b^{phase-avg}(γ̄·h, σ_φ) dh
```

其中 `P_b^{phase-avg}(γ, σ_φ)` 是相位平均 BER，关于 γ 单调递减。

**Markov 不等式推导**：

定义事件 A = {γ < γ_th}，即 outage 事件。在 outage 区域内：

- 当 γ → 0（极深衰落），BER → 1/2（QPSK 随机猜测）
- 更精确地：P_b^{phase-avg}(γ, σ_φ) ≥ P_b^{phase-avg}(γ_th, σ_φ) = P_target，对所有 γ ≤ γ_th

因此：

```
P_b^{avg} = ∫₀^∞ f_GG(h) · P_b^{phase-avg}(γ̄·h) dh
          ≥ ∫₀^{h_th} f_GG(h) · P_b^{phase-avg}(γ̄·h) dh   （取积分下限部分）
          ≥ ∫₀^{h_th} f_GG(h) · P_target dh                  （γ ≤ γ_th → BER ≥ P_target）
          = P_target · F_GG(h_th)
          = P_target · P_out
```

即 **P_b^{avg} ≥ P_target · P_out**。

**等号条件**：
- 当且仅当 γ ≤ γ_th 时 P_b = P_target（阶梯函数近似）时等号成立
- 实际上 P_b^{phase-avg}(γ) 从 P_target（在 γ = γ_th）到 1/2（在 γ = 0）连续变化
- 因此下界 P_target · P_out 始终严格小于实际 BER

**另一种更粗糙但直觉清晰的下界**：

当 γ → 0 时 P_b → 1/2，所以：

```
P_b^{avg} ≥ (1/2) · P(γ = 0) = 0   （连续分布 P(γ=0)=0，无用）
```

更实用的近似：对极深衰落（h < h_min，例如 h_min = 0.01）：

```
P_b^{avg} ≈ (1/2) · P(h < h_min) + E_{h≥h_min}[BER]
          ≥ (1/2) · P(h < h_min)
```

这个下界更松，但物理含义明确：深衰落事件中系统等效于随机猜测，贡献至少 (1/2)·P(h < h_min) 的 BER。

### 发现 2：P_target · P_out 下界的紧致度分析

**来源**: 数值分析（F3.13-F3.17 参数）; Simon & Alouini Ch.5.1 (outage-based bounds)

下界与实际 BER 的比值取决于：

1. **SNR 范围**：低 SNR 时 P_out 大（接近 1），下界接近实际 BER；高 SNR 时 P_out 小，下界远小于实际 BER
2. **湍流强度**：强湍流下深衰落频发，P_out 大，下界更紧
3. **P_target 的选择**：P_target 越大 → γ_th 越小 → P_out 越大 → 下界越紧，但 P_target 本身也越大

**量化紧致度**（γ̄ = 20 dB，σ_φ = 0，无相位误差，P_target = 10⁻³）：

| 湍流 | P_out = F_GG(h_th) | 下界 = P_target·P_out | 实际 BER（近似） | 下界/实际 | 松弛倍数 |
|------|---------------------|----------------------|-----------------|-----------|---------|
| 弱 (4,3) | 1.36% | 1.36×10⁻⁵ | 1.6×10⁻⁴ | 8.5% | ~12x |
| 中 (2.5,1.8) | 6.04% | 6.04×10⁻⁵ | 1.6×10⁻³ | 3.8% | ~26x |
| 强 (1.5,0.8) | 21.5% | 2.15×10⁻⁴ | 1.8×10⁻² | 1.2% | ~84x |

**结论**：
- outage-based 下界在**中-高 SNR** 下典型松弛 **10-100 倍**
- 强湍流下 P_out 大但实际 BER 也大，下界占比反而更小（松弛更多）
- 这是因为实际 BER 主要来自 h 附近的"正常衰落"贡献，而非极深衰落区域

**关键量化锚点 1**：outage-based 下界 P_target · P_out 在 20 dB、中湍流下松弛约 **26 倍**（P_target = 10⁻³）。这是一个相对松的下界。

### 发现 3：本论文的下界定义分析

**来源**: F3.11-F3.17（formulas-master.md）; sim_ch3_ber_bounds.py

本论文涉及两种"下界"概念，需要区分：

**A) BER floor（F3.11）——高 SNR 渐近下界（非 outage-based）**

$$P_{b,floor} = Q(\pi/(4σ_φ))$$

- 这是 γ̄ → ∞ 时 BER 的**极限值**，由 σ_φ 唯一决定
- **不是** outage 概率，而是相位噪声的固有 BER 下限
- 数学性质：对任意 γ̄，P_b^{avg}(γ̄, σ_φ) ≥ Q(π/(4σ_φ))（因为 P_b^{phase-avg}(γ, σ_φ) ≥ Q(π/(4σ_φ)) 对所有 γ）
- **这是一个严格的、参数无关的下界**

**B) 中断概率 P_out（F3.13-F3.17）——统计性能指标**

$$P_{out} = F_{GG}(h_{th})$$

- 这不是 BER 的下界，而是"信道质量不达标"的概率
- P_out 衡量的是 h < h_th 的概率，与 BER 的关系是间接的
- P_target · P_out 可以作为 BER 的一个下界，但如发现 2 所示，这个下界较松

**C) 更紧的下界：Jensen 不等式**

由于 Q(√(2γ)) 关于 γ 是凸函数（在 γ > 0 的 BER 相关范围内），由 Jensen 不等式：

```
E_h[Q(√(2γ̄·h))] ≥ Q(√(2γ̄·E[h])) = Q(√(2γ̄))    （因为 E[h] = 1）
```

这给出 AWGN BER 作为 GG 衰落下 BER 的**下界**（无相位误差时）。这在低 SNR 时较紧（衰落影响小），高 SNR 时较松（衰落惩罚增大）。

**关键量化锚点 2**：本论文的 BER floor Q(π/(4σ_φ)) 是一个**紧致渐近下界**——在高 SNR 区域（γ̄ > 30 dB），实际 BER 收敛到此下界的 **5% 以内**（MC 验证，见 V-02）。而 outage-based 下界在同条件下松弛 **10-100 倍**。

### 发现 4：不同湍流和 SNR 下的下界紧致度预期

**来源**: F3.11 数值计算; V-02 数据

**BER floor 下界（F3.11）的紧致度**：

紧致度取决于实际 BER 多快收敛到 floor。由 V-02 的数据：

| 条件 | BER @ SNR | BER floor | 收敛比 | 紧致度 |
|------|-----------|-----------|--------|--------|
| 弱湍流, σ_φ=10°, 20 dB | ~3.4×10⁻⁶ | 3.4×10⁻⁶ | ~1.0 | 极紧（已收敛） |
| 中湍流, σ_φ=10°, 20 dB | ~3.5×10⁻⁶ | 3.4×10⁻⁶ | ~1.03 | 极紧（已收敛） |
| 强湍流, σ_φ=10°, 20 dB | ~3.6×10⁻⁶ | 3.4×10⁻⁶ | ~1.06 | 紧（已收敛） |
| 弱湍流, σ_φ=5°, 20 dB | ~1.6×10⁻⁴ | 1.1×10⁻¹⁹ | ~1.4×10¹⁵ | 极松（远未收敛） |
| 强湍流, σ_φ=0°, 20 dB | ~1.8×10⁻² | 0 | N/A | 无下界（floor=0） |

**规律**：
1. σ_φ 越大 → floor 越高 → 越早收敛 → 下界越紧
2. 湍流越强 → BER 曲线越平坦 → 对 floor 收敛越慢 → 但差异不大（floor 与湍流无关）
3. σ_φ = 0 时 floor = 0，BER floor 下界退化为"BER ≥ 0"（平凡下界，无信息量）

**Outage-based 下界（P_target · P_out）的紧致度**：

| 条件 | P_out | P_target·P_out | 实际 BER | 松弛倍数 |
|------|-------|----------------|---------|---------|
| 弱, 20dB, P_t=10⁻³ | 1.4% | 1.4×10⁻⁵ | 1.6×10⁻⁴ | 12x |
| 弱, 30dB, P_t=10⁻³ | ~0% | ~0 | ~0 | N/A |
| 中, 20dB, P_t=10⁻³ | 6.0% | 6.0×10⁻⁵ | 1.6×10⁻³ | 27x |
| 强, 20dB, P_t=10⁻³ | 21.5% | 2.2×10⁻⁴ | 1.8×10⁻² | 84x |
| 中, 20dB, P_t=10⁻⁴ | 9.9% | 9.9×10⁻⁶ | 1.6×10⁻³ | 162x |

**关键量化锚点 3**：outage-based 下界的松弛倍数在 10-160x 之间，取决于 P_target 选择。松弛随 SNR 增大而急剧增加（因为 P_out → 0 但实际 BER 下降更慢）。

### 发现 5：上界/下界之比的合理范围

**来源**: F3.10（精确 BER）; F3.11（floor 下界）; 经典 BER 界文献

**本论文可用的界**：

| 界 | 表达式 | 性质 |
|----|--------|------|
| 下界 1（floor） | Q(π/(4σ_φ)) | 渐近紧（高 SNR），低 SNR 时无用 |
| 下界 2（outage） | P_target · F_GG(h_th) | 较松（10-100x） |
| 下界 3（Jensen） | Q(√(2γ̄)) | 低 SNR 较紧，高 SNR 时松（在 GG 衰落下） |
| 精确值 | F3.10 | 精确 |
| 上界 | 0.5（平凡）或 F3.9（P_s/2 近似，略高） | 较紧 |

**上界/下界比值的合理范围**：

1. **BER floor 作为下界 + P_s/2 作为上界**：
   - 在高 SNR 区域（γ̄ > 25 dB, σ_φ ≥ 10°）：比值约 1.0-1.5（极紧）
   - 在中 SNR 区域（γ̄ ~ 15-20 dB）：比值约 10-100（松）
   - 在低 SNR 区域（γ̄ < 10 dB）：比值可达 1000+

2. **Jensen 下界 + 实际 BER**：
   - 弱湍流 20 dB：BER_Jensen / BER_actual = 7.8×10⁻⁴ / 1.6×10⁻⁴ ≈ 4.9（Jensen 反而更大——说明 Q(√γ) 在 GG 的高阶矩区域不满足凸性条件，Jensen 方向可能反转）

   **修正**：Q(√(2γ)) 关于 γ 在 γ > 0 的二阶导数为正（凸函数），所以 Jensen 给出 E[Q(√(2γ̄h))] ≥ Q(√(2γ̄E[h])) = Q(√(2γ̄))。但 E[h]=1，所以 Jensen 下界 = AWGN BER。然而实际 GG-BER > AWGN-BER（衰落恶化），所以 Jensen 下界成立但方向正确。弱湍流 20 dB 时 Jensen 下界 = 7.8×10⁻⁴，实际 = 1.6×10⁻⁴，Jensen 下界 > 实际 BER——**矛盾！**

   **原因**：Q(√(2γ)) 在 γ > 0 不是全局凸函数。在 γ 较大时二阶导数为负。因此 Jensen 不等式方向取决于 GG 分布的支撑区域。对弱湍流（高 α,β），h 集中在 1 附近，但 h < 1 的区域贡献更大 BER（指数级增长），导致 E[Q] < Q(E)，即 Jensen 方向反转。**结论：Jensen 不等式在本场景下不直接适用作为下界。**

### 发现 6：下界的正确实现验证

**来源**: sim_ch3_ber_bounds.py; F3.11

当前 `sim_ch3_ber_bounds.py` 实现的是：
- `ber_floor_theory(sigma_phi)` = Q(π/(4σ_φ)) → BER floor 渐近下界
- MC 仿真验证此下界在高 SNR 下收敛

**实现正确性判断**：
- F3.11 的推导正确：γ → ∞ 时 P_b(γ,φ) 退化为 0 或 1/2 的阶梯函数
- MC 实现正确：`ber_qpsk_conditional` 实现了精确条件 BER
- BER floor 下界的物理含义正确：纯相位误差导致的高 SNR 不可消除误码

**注意**：当前代码中没有显式实现 outage-based 下界（P_target · P_out）。如果需要 outage-based 界，需要额外实现。

### 发现 7：文献中的下界紧致度基准

**来源**: Simon & Alouini, "Digital Communication over Fading Channels"; Petkovic 2023; Trivedi & Joshi 2021

经典文献中的 BER 界紧致度基准：

1. **Simon & Alouini**：对 Nakagami-m 衰落，MGF 方法的精确 BER 与近似 BER 在 10⁻⁴ 以上 BER 区域误差 < 5%。在 10⁻⁶ 以下可能发散。

2. **Petkovic 2023** 的 Fourier 级数法（FSM）：截断误差 |E_N| ≤ q_{N+1}，N=100 时对 σ_φ ≥ 5° 达到 5 位有效数字精度。这是精确方法，不是界的近似。

3. **Outage 近似**：经典结论是 outage probability 作为 BER 代理在高 SNR 下提供了 diversity order 的正确预测（BER ~ SNR^{-d}），但常数因子（prefactor）差异大（典型 3-10 dB 偏移），对应 BER 比值约 10-1000 倍。

4. **BER floor 作为下界**：在 σ_φ 足够大（≥ 8°）时，floor 与精确 BER 在高 SNR 区域（BER < 10⁻⁵）匹配到 < 10% 以内。这是非常紧的下界。

**关键量化锚点 4**：文献基准表明 outage-based 下界的典型松弛因子为 **10-100 倍**（中等 SNR），而 BER floor 下界在收敛区域松弛因子 < **1.1 倍**（10% 以内）。

**判断标准**：
- 上界/下界比 < 3x → 优秀（界可用于工程设计）
- 上界/下界比 3-10x → 良好（界可用于趋势预测）
- 上界/下界比 10-100x → 可接受（界可用于量级估计）
- 上界/下界比 > 100x → 过松（界仅用于定性分析）

## 结论

1. **outage-based 下界 P_target · P_out 是合法但较松的 BER 下界**（典型松弛 10-100 倍）。理论依据是 Markov 不等式（更精确地，非负函数在截断区域上的积分下界）。

2. **本论文的 BER floor Q(π/(4σ_φ)) 是更紧、更实用的渐近下界**——在 σ_φ ≥ 8° 且 SNR 足够高时，与实际 BER 差距 < 10%。这本质上不是 outage-based 界，而是相位噪声的固有下界。

3. **outage 概率本身不是 BER 下界**——它是系统性能的独立指标。P_target · P_out 只是 Markov 不等式给出的一个松下界。

4. **上界/下界比 < 10x 算良好**，< 3x 算优秀。在 σ_φ ≥ 8° 的高 SNR 区域，BER floor 下界可达到优秀水平。
