# V-08: 信道估计误差与 BER 恶化的理论关系

> 关联仿真: sim_ch3_strengthening.py (Strengthening 2) | Phase: 1a | 批次: B1
> 状态: 完成 | 发现锚点数: 6

## 调研问题

h 估计 NMSE 如何影响下游 BER？建立估计误差 → BER 恶化的理论模型，为 Ch3 鲁棒性仿真提供量化预期。具体问题：

1. NMSE → BER 恶化的传导路径是什么？（一阶近似 vs SNR loss）
2. NMSE=10% 时 BER 恶化应在什么范围？
3. 不同估计方法（LS/MMSE/KF）的典型 NMSE 对应什么 BER 影响？
4. 深衰落（h 很小）时估计误差影响更大还是更小？

## 文献/理论发现

### 发现 1：估计误差影响 BER 的传导机制——两条独立路径

**来源**: F3.18, F3.21 (formulas-master.md); SPEC.md §1.1; sim_ch3_strengthening.py §2.2

估计误差 ĥ = h(1+ε), ε ~ N(0, NMSE) 通过两条路径影响 BER：

**路径 A——载波同步参数失配**（Ch3 核心关切）：

载波同步算法（DPLL/VV）需要 ĥ 来设置同步参数。估计误差导致参数偏离最优值，进而影响 σ_φ 和 BER。

- **DPLL 路径**：自适应带宽 B_L = B_0·ĥ，σ_φ² = B_L·T_s/(2γ̄·h)
  - 代入：σ_φ² = B_0·h(1+ε)·T_s / (2γ̄·h) = B_0·T_s/(2γ̄) · (1+ε)
  - **关键发现**：h 在分子分母精确对消，σ_φ² 仅乘以 (1+ε)
  - 取期望：E[σ_φ²] = σ_φ²(perfect) · E[1+ε] = σ_φ²(perfect) · 1（因为 E[ε]=0）
  - **结论：DPLL 的平均 σ_φ 对估计误差完全鲁棒**

- **VV 路径**：窗口长度 M = K_M·(γ̄·ĥ)^{-0.2}·Δf^{-0.4}，σ_φ² = 1/(2M·γ̄·h)
  - 代入：σ_φ² ∝ (ĥ)^{0.2} / (γ̄^{0.8}·h) = h^{0.2}·(1+ε)^{0.2} / (γ̄^{0.8}·h) ∝ h^{-0.8}·(1+ε)^{0.2}
  - 估计误差贡献：(1+ε)^{0.2} ≈ 1 + 0.2ε + O(ε²)
  - **结论：VV 的 σ_φ 对估计误差的灵敏度仅为 0.2 次方**

**路径 B——MMSE 均衡器失配**（影响极小）：

MMSE 均衡器使用 ĥ 设置均衡系数。但 SPEC.md §7 明确说明"当前所有仿真假设 MMSE 均衡用 oracle h（20dB 下影响可忽略）"。这条路径在当前系统参数下不构成主要影响。

**综合传导模型**：

```
BER_mismatch ≈ BER_ideal × (1 + f(NMSE))
```

其中 f(NMSE) 来自载波同步参数失配，而非 SNR loss。这是与"ΔSNR_effective = g(NMSE)"不同的模型——估计误差不直接改变有效 SNR，而是通过改变 σ_φ 间接影响 BER。

### 发现 2：DPLL 场景下 NMSE 对 BER 的影响可忽略（ratio ≈ 1.000）

**来源**: F3.21 (formulas-master.md); sim_ch3_strengthening.py §2.2 MC 仿真; sim_cascade_robustness.py 6/6 PASS

**数学证明**（DPLL 纯场景）：

```
σ_φ²(mismatch) / σ_φ²(perfect) = 1 + ε
BER ∝ Q(π/(4σ_φ))
E_ε[Q(π/(4σ_φ√(1+ε)))] ≈ Q(π/(4σ_φ)) + O(Var(ε))
```

对于 NMSE = -5 dB (ε 方差 0.316)，E[ε]=0，Var(ε)=0.316：
- σ_φ 的一阶扰动：δσ_φ/σ_φ ≈ ε/2（Taylor 展开）
- BER 是 σ_φ 的指数灵敏函数（BER floor = Q(π/(4σ_φ))），但对 ε 的**期望值**几乎不变

**仿真验证**（sim_ch3_strengthening.py §2.2, moderate turb, SNR=20dB, DPLL+VV 联合）：

| NMSE (dB) | NMSE (线性) | BER | BER ratio vs perfect |
|-----------|------------|-----|---------------------|
| perfect | 0 | baseline | 1.000 |
| -25 | 0.003 | ~baseline | 1.000 |
| -20 | 0.01 | ~baseline | 1.000 |
| -15 | 0.032 | ~baseline | ~1.001 |
| -10 | 0.1 | 轻微变化 | ~1.005 |
| -7 | 0.2 | 轻微变化 | ~1.01 |
| -5 | 0.316 | 轻微变化 | <1.03 |

**核心结论**：自适应载波同步（DPLL）对信道估计误差天然鲁棒。原因是 B_L ∝ h 与 γ ∝ h 的精确对消——这是系统设计的数学性质，不是巧合。

### 发现 3：VV 场景下估计误差影响同样很小（(1+ε)^{0.2} 效应）

**来源**: sim_ch3_strengthening.py §2.1; F4.9 (formulas-master.md)

VV 的 σ_φ² 对 ĥ 的依赖为 (ĥ)^{0.2} 次方：

```
σ_φ²(VV, ε) / σ_φ²(VV, perfect) = (1+ε)^{0.2}
```

对 ε ~ N(0, NMSE)：
- E[(1+ε)^{0.2}] ≈ 1 + 0.2·E[ε] + (-0.08)·E[ε²] = 1 - 0.08·NMSE
- NMSE = -10 dB (0.1)：E[ratio] ≈ 1 - 0.008 = 0.992（实际上 σ_φ 略微**减小**）
- NMSE = -5 dB (0.316)：E[ratio] ≈ 1 - 0.025 = 0.975

**反直觉发现**：估计误差在 VV 场景下**略微降低**平均 σ_φ，因为 (1+ε)^{0.2} 是凹函数，Jensen 不等式保证 E[(1+ε)^{0.2}] < (1+E[ε])^{0.2} = 1。

**物理含义**：VV 窗口长度 M ∝ ĥ^{-0.2}——高估 h 时窗口略短（σ_φ 略增），低估 h 时窗口略长（σ_φ 略减）。凹函数效应使平均 σ_φ 略降。这个效应非常小（<3%），在实际 BER 中不可观测。

### 发现 4：深衰落条件下估计误差对 BER 的条件影响

**来源**: sim_ch3_strengthening.py §2.3; GG 分布尾部分析

深衰落（h << 1）时：
- **DPLL**：σ_φ 与 h 无关（h 对消），估计误差不影响 σ_φ → **深衰落中无额外 BER 恶化**
- **VV**：σ_φ ∝ h^{-0.3}（原已很大），估计误差 (1+ε)^{0.2} 的相对影响不变但绝对 σ_φ 已在高位 → **BER 由 SNR 极低主导，σ_φ 变化是次要项**

**深衰落 BER 分解**（h < 0.2, moderate turb, SNR=20dB）：

| NMSE (dB) | h<0.2 区域 BER | h≥0.2 区域 BER | 全局 BER |
|-----------|---------------|---------------|---------|
| perfect | ~0.25-0.35 | ~baseline | baseline |
| -10 | ~0.25-0.35 | ~baseline | ≈ baseline |
| -5 | ~0.25-0.35 | ~baseline | ≈ baseline |

**结论**：深衰落中 BER ≈ 0.5（随机猜测水平）由 γ = γ̄·h << 1 主导，σ_φ 变化的影响被淹没。估计误差在深衰落中不产生额外 BER 恶化。

### 发现 5：不同估计方法的 NMSE 典型水平与对应 BER 影响

**来源**: F3.24, F3.26 (formulas-master.md); sim_prototype.py; sim_ch4_kf_pilot_h.py

各方法在 SNR=20dB 下的典型 NMSE 范围：

| 方法 | NMSE 典型值 | NMSE (dB) | BER 恶化倍数 | 备注 |
|------|-----------|-----------|-------------|------|
| Oracle h | 0 | -∞ | 1.000 | 理想基准 |
| MMSE (多导频) | 0.01~0.03 | -15~-20 | ~1.000 | 高 SNR 接近 oracle |
| KF (稳态) | 0.01~0.05 | -13~-20 | ~1.001 | 利用时间相关性 |
| MMSE (单导频) | 0.05~0.1 | -10~-13 | ~1.005 | 弱/中湍流 |
| LS (多导频) | 0.03~0.1 | -10~-15 | ~1.005 | 无统计先验 |
| LS (单导频) | 0.1~0.3 | -5~-10 | ~1.01 | 强湍流时最差 |

**关键推论**：即使是最差的 LS 估计（NMSE = -5 dB），BER 恶化也不超过 3%。这是因为自适应载波同步的 B_L∝h 与 γ∝h 对消机制将估计误差"隔离"在了载波同步之外。

### 发现 6：NMSE → BER 的理论模型总结

综合以上发现，NMSE → BER 恶化的理论模型为：

**模型（DPLL 主导场景）**：

```
BER(NMSE) ≈ BER(perfect) × [1 + α · NMSE]
```

其中 α 的量级：

| 载波同步方法 | α (理论) | α (仿真) | BER 恶化 @ NMSE=10% |
|------------|---------|---------|-------------------|
| DPLL only | ≈ 0 | ~0 | 1.000× (无恶化) |
| DPLL + VV | ~0.05 | ~0.05 | ~1.005× |
| VV only | ~0.08 | ~0.08 | ~1.008× |

**与 SNR loss 模型的区别**：

NMSE 不直接转化为 SNR loss。传统无线通信中 NMSE → ΔSNR 的模型（如 `ΔSNR = 10·log10(1+NMSE)` dB）假设估计误差直接恶化均衡器输出 SINR。但在本系统中，估计误差的传导路径是载波同步参数失配，而非均衡器失配。由于 DPLL 的 h 对消特性，传导效率极低。

### 关键结论

1. **NMSE ≥ -5 dB → BER 恶化 < 3%**：自适应载波同步天然鲁棒，无需完美估计
2. **DPLL 的 h 对消是核心机制**：B_L ∝ h 与 γ ∝ h 精确抵消，使 σ_φ 与 h 无关
3. **深衰落不放大估计误差影响**：BER 由低 SNR 主导，σ_φ 变化是次要项
4. **传统 NMSE→ΔSNR 模型不适用**：传导路径是载波同步参数而非均衡器 SINR
