# V-17: FFT-FOE 理论精度与仿真参数验证

> 2026-06-01 | 调研 | DONE
> 关联: SPEC.md §2, F4.4-F4.6, common.py `fft_foe`

## 目标

建立 FFT-FOE 的理论精度极限，验证仿真参数（N_fft=1024, ZP=8192）是否合理，评估残余频偏 1 MHz 的估计精度。

---

## 1. FFT-FOE 原理回顾

### 1.1 算法流程（代码验证）

`common.py` 的 `fft_foe` 实现（L122-141）：

1. 取前 N_fft=1024 个符号
2. 四次方运算：r4 = rx**4（QPSK 调制信息消除，s^4=-1）
3. Hanning 窗加权：r4w = r4 * win（减少频谱泄漏）
4. FFT 并 zero-padding 到 8192 点
5. 找峰值 + 抛物线插值
6. 频率估计除以 4（四次方恢复）

### 1.2 公式对应

- F4.4：R4(f) = FFT{r[k]^4 * w_Hann[k]}，f_hat = argmax|R4(f)| / 4
- F4.5：四次方 SNR 退化 = gamma_bar*h / 8（h=1 时 SNR4 = 12.5 = 11 dB）
- F4.6：自适应窗口 N_opt = 80/(gamma_bar * h^2)（固定参数用 N=1024）

## 2. 理论精度分析

### 2.1 频率分辨率

| 参数 | 值 | 物理含义 |
|------|-----|---------|
| 观测窗口 T_obs | 1024 * 400ps = 409.6 ns | 积分时间 |
| Rayleigh 分辨率 | 1/T_obs = **2.44 MHz** | 不加窗的基本分辨率 |
| FFT bin 间距（N_fft=1024） | R_SYM/1024 = 2.44 MHz | 无 ZP 的离散频率间隔 |
| ZP bin 间距（8192 点） | R_SYM/8192 = 305 kHz | ZP 后的插值间隔 |
| FOE 实际分辨率（/4） | 305/4 = **76.3 kHz** | 四次方除以 4 后 |

**结论**：Zero-padding 将插值间隔从 2.44 MHz 降到 76.3 kHz，但 Rayleigh 分辨率仍为 2.44 MHz。ZP 提高的是**插值精度**（找到峰值的精确位置），而非**分辨率**（区分两个靠近的频率）。抛物线插值进一步提升精度至约 bin 的 1/8-1/10。

### 2.2 Cramer-Rao 下界（CRB）

对于复单音信号的白噪声频率估计，CRB 为：

```
var(f_hat) >= 6 / (4*pi^2 * T_s^2 * N * (N^2 - 1) * SNR)
```

对于四次方 FOE：
- 频率变为 4*f，方差除以 16（var(f) = var(4f)/16）
- SNR 退化 8 倍（F4.5）

**系统参数下（h=1, SNR=20dB）的 CRB**：

| 量 | 值 |
|----|-----|
| SNR4（四次方后） | 12.5 (11 dB) |
| CRB(4*f_hat) 标准差 | 8.41 kHz |
| CRB(f_hat) 标准差 | **2.1 kHz** |

**注意**：CRB 假设无偏估计器和高斯白噪声。实际 FFT-FOE 使用离散频率网格 + 窗函数 + 抛物线插值，不满足 CRB 的理想条件。

### 2.3 Monte Carlo 验证（5000 次试验）

| 场景 | 标准差 | 最大误差 | 相对 CRB |
|------|--------|----------|---------|
| 纯音 + 噪声 (h=1) | 4.71 kHz | 19.0 kHz | 2.24x CRB |
| QPSK + 噪声 (h=1) | 4.64 kHz | 16.6 kHz | 2.21x CRB |

Monte Carlo 标准差约为 CRB 的 2.2 倍。差距原因：
1. Hanning 窗降低等效观测长度（相干增益损失）
2. 离散频率网格限制了插值精度
3. 抛物线插值不是最优估计器
4. 四次方引入信号-噪声交叉项（非纯单音）

### 2.4 湍流对 FOE 精度的影响

| h 值 | 等效 SNR4 | FOE 标准差 | 最大误差 |
|------|----------|-----------|---------|
| h=1.0 | 11.0 dB | 4.7 kHz | 14.8 kHz |
| h=0.5 | 8.0 dB | 6.6 kHz | 20.1 kHz |
| h=0.1 | 1.0 dB | 17.9 kHz | 64.4 kHz |

深衰落（h<0.1）时 FOE 精度退化显著，但仍为数十 kHz 量级（远小于 DPLL 捕获范围）。

### 2.5 FOE 失败率 vs SNR

| SNR | 标准差 | 失败率（错峰） |
|-----|--------|---------------|
| 5 dB | 43.5 kHz | 40.2% |
| 10 dB | 18.5 kHz | 4.7% |
| 15 dB | 8.8 kHz | 0% |
| **20 dB** | **4.8 kHz** | **0%** |
| 25 dB | 2.6 kHz | 0% |
| 30 dB | 1.4 kHz | 0% |

**在 20 dB 工作点，FOE 失败率为 0%，标准差 4.8 kHz。**

## 3. 仿真参数合理性验证

### 3.1 1 MHz 残余频偏估计

| 检查项 | 结果 | 判定 |
|--------|------|------|
| 频率范围 | 4*f_res = 0.0016（归一化），远小于 0.5 | OK |
| 估计精度 | 标准差 4.7 kHz，相对误差 0.47% | 优秀 |
| 离峰距离 | 1 MHz / 76.3 kHz = 13.1 个 bin | 精确定位 |

**结论：1 MHz 残余频偏可被准确估计，相对误差 < 0.5%。**

### 3.2 Doppler 漂移在观测窗内

- Doppler 变化率：150 MHz/s
- 观测窗 T_obs = 409.6 ns
- 频率漂移：150e6 * 409.6e-9 = **61.4 Hz** = 0.061 kHz

漂移量 / Rayleigh 分辨率 = 0.0025%，**完全可忽略**。

### 3.3 激光相位噪声影响

- 四次方后线宽：4 * 10 kHz = 40 kHz
- 相干时间：1/(pi*40e3) = 8.0 us
- T_obs / t_coh = 0.052（观测窗仅占相干时间的 5.2%）

相位噪声导致的频谱展宽约 40 kHz，**与 FOE 精度（4.7 kHz）同量级但不主导**。在 20 dB SNR 下，热噪声是主要误差源。

## 4. FOE 误差的下游传播

### 4.1 残余频偏对 DPLL 的影响

FOE 补偿后残余频偏标准差 ~5 kHz。DPLL 的闭环带宽：

| omega_n | B_L | FOE 残余 / B_L | 判定 |
|---------|-----|---------------|------|
| 8 MHz (默认) | 4.24 MHz | 0.11% | 完全可跟踪 |
| 20 MHz (最优) | 10.6 MHz | 0.044% | 完全可跟踪 |

DPLL 捕获范围远大于 FOE 残余，**FOE 误差对 DPLL 无影响**。

### 4.2 残余频偏对 KF 的影响

KF 状态向量包含频偏分量 x[1] = df。FOE 残余 ~5 kHz 远小于 KF 初始化不确定度（默认 100 kHz），且 KF 会通过观测逐符号修正频偏估计。

每块（100 符号）由 FOE 残余导致的相位漂移：

```
delta_phi = 2*pi * 5e3 * 100 * 400e-12 = 0.0012 rad = 0.07 deg
```

**完全可忽略**。KF 不受 FOE 残余影响。

### 4.3 传播链总结

```
FOE 误差 ~5 kHz
  --> 相位漂移 0.07 deg/block（可忽略）
  --> DPLL/KF 均可轻松跟踪
  --> 对最终 BER 无可测量影响
```

## 6. 仿真参数合理性结论

### 6.1 参数合理性判定

| 参数 | 当前值 | 判定 | 说明 |
|------|--------|------|------|
| N_fft = 1024 | 合理 | 在 20 dB 下精度 4.7 kHz，0% 失败率 |
| ZP = 8192 | 合理 | 8x 插值将精度从 bin 级（2.44 MHz）提升到 sub-bin 级（76 kHz），配合抛物线达 ~5 kHz |
| Hanning 窗 | 合理 | 减少频谱泄漏，代价是 2x CRB（可接受） |
| 抛物线插值 | 合理 | 简单有效，精度接近 CRB 的 2.2 倍 |

### 6.2 无需修改的依据

1. **精度充足**：FOE 是粗补偿步骤，精度 5 kHz 远小于后续 DPLL/KF 的跟踪范围
2. **失败率为零**：20 dB 下 Monte Carlo 验证零失败
3. **计算效率**：N_fft=1024 已足够，增大到 2048 仅在 h<0.5 时有边际改善
4. **F4.6 自适应窗口**：在深衰落时自动增大 N_fft，覆盖了 h<1 的退化场景

### 6.3 已知限制

- h<0.1（深衰落）时精度退化到 ~18 kHz，但 F4.6 自适应窗口会增大 N_fft 补偿
- SNR<10 dB 时失败率急剧上升（5 dB 时 40%），但系统设计工作点在 20 dB
- CRB 差距 2.2x 是窗函数 + 离散网格的固有代价，无法消除

## 7. 对论文写作的意义

1. **FOE 是可靠的前置步骤**：20 dB 下精度 ~5 kHz，对所有载波恢复方法提供一致的粗补偿
2. **FOE 不是系统瓶颈**：误差远小于后续跟踪范围，仿真中 FOE 误差不构成 BER 差异的来源
3. **自适应窗口有价值但非必需**：固定 N_fft=1024 在 20 dB 下已足够；自适应主要改善低 SNR 和深衰落场景
4. **公平性保障**：FOE 对所有方法使用相同参数（N_fft=1024 或 4096），不引入对比偏差
