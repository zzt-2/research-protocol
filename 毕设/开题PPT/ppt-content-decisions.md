## 通用规则

### 学术事实性底线（最高优先级）

PPT 上每一句话都必须经得起学术审查。具体要求：

1. **事实准确性**：每一句、每个词、每个时间、每个技术归属都不能错。有不确定的地方必须查证（子 agent 验证或查原文），不能凭印象写。
2. **无领域常识错误**：不能出现该领域专家一眼看出的错误（如把模型建立说成估计、把方法应用场景搞错）。
3. **学术措辞严谨**：动词强度匹配内容性质（引用现有方法用"介绍"不用"提出"；仿真结果用"表明"不用"证明"；未做的工作用"拟"不用"已"）。程度词必须有数据支撑，无数据禁用"显著/大幅/远"。
4. **经得起追问**：PPT 上写的每个事实性声明，都要能回答评委"这个说法的依据是什么"。写之前想好出处（论文/教材/标准），写不出处就不写。
5. **术语统一**：全文用 TERMS.md 规定的术语，同一概念不混用不同称呼。

> 来源：用户多次强调。"具体叙述必须准确。每一句，每个词，每个时间都不能错""必须保证学术上的严谨、正确、合适"。上一轮时间线事实性验证派了 3 个子 agent 纠正了 7 处错误。

**验证流程**：讨论措辞时发现的事实性疑问，必须派子 agent 检索确认，不能凭印象定稿。验证范围包括：年份、作者归属、方法描述准确性、方法在某场景中的主流程度、论文的具体贡献定位。验证结果记录在对应页面章节中。

### 内容规则

1. 不放具体仿真结果数字（开题阶段数字可能变）
2. 可以提"初步验证已完成"证明可行性
3. 创新点用"拟提出/拟建立"不用"提出了"
4. 不用禁忌词（首次/填补空白/显著鸿沟/oracle CSI）
5. h = 归一化辐照度，ω_n 单位 rad/s，FPGA 用"设计分析"
6. 不在 PPT 上写公式（除非关键的一个信号模型）

### 文字写作规则（2026-06-03 补充，来源：3 agent 调研）

| 规则         | 标准                                           |
| ------------ | ---------------------------------------------- |
| 每页总字数   | 50-100 字，上限 150 字                         |
| 要点数       | 3-5 条，最多 6 条                              |
| 每行         | 中文 15-25 字                                  |
| 每页核心信息 | 只传达一个核心观点                             |
| 标题         | 完整陈述句（Assertion-Evidence），不用话题短语 |
| 引导语       | 告诉听众"为什么看这页"，不是"这页讲什么"       |
| 过渡         | 口头完成，不写 slide 上                        |
| bullet       | 短语/关键词展开，不用完整长句；并行结构        |
| 检验标准     | 站 3 米外一眼抓到核心信息                      |

**Assertion-Evidence 方法**：每页标题是本页核心论点的完整陈述句，slide body 是支撑证据（图表/数据/关键词），而非话题短语（如"研究背景""技术路线"）。

**"拟"字强度梯度**：拟提出（强，有明确方法思路）> 拟建立（中，有框架思路，形态不绑定）> 拟研究/探索（弱，方向级承诺）。越确定用越强。

**bullet 写法**：每条只含一个信息点；并行结构（每条开头词性一致）；量化优先（用数字替代"显著/良好"）。

**口述稿写法**：口述稿必须写成完整、能照着念的段落（不是要点列表），控制在每页 100-150 字（对应 20-40 秒）。PPT 上是骨架，口述稿是完整叙述。文献支撑、路径区分、过渡衔接等细节全部放在口述稿中，PPT 上不放。

### P8：研究空白

**标题（Assertion-Evidence）**：

> 信道估计与载波同步在 FSO 湍流场景中均存在研究空白

**空白①**：CE→CPR 级联影响未被定量分析

- CE 精度与下游 CPR 性能缺乏定量关联
- 不同同步方法对估计误差灵敏度差异大
- → **设计者无法确定估计精度做到多少才能满足同步需求**

**空白②**：载波同步湍流适配设计准则缺失

- 经典设计公式多基于白噪声假设，湍流下准则不完善
- 系统性分析仅涉及少数方法，未将 CE 误差纳入
- → **缺乏分湍流条件的方法选择和参数配置指导**

- 两个空白**上下排列**，中间用一条粗箭头连接，箭头旁标注"估计误差级联约束同步设计"，视觉上强调因果链而非并列

> 信道估计方法本身已相当成熟，但估计精度与下游载波同步性能之间缺乏定量关联——这就是 CE→CPR 的级联分析空白。已有框架对误差建模较简化，没区分不同同步方法对误差的灵敏度差异。GG 湍流下当衰落较强时，前馈方法的统计最优性前提不再成立，不同调制格式对误差的容忍度差异也很大——所以设计者无法确定精度做到多少才够用。这个问题直接导致第二个空白：载波同步在湍流场景下缺乏适配的设计准则。经典公式多基于白噪声，湍流下的系统性分析仅涉及少数方法，且未考虑信道估计误差的影响。两个空白不是独立的，而是同一条信号处理链上的上下游关系。

### P25：初步验证 — 前馈方法参数敏感性

> 关键在于前馈方法的平均窗口长度。湍流越强，所需的最小窗长越大（弱湍流 Nw≥16，中等 Nw≥36，强湍流 Nw≥128）。重要的是，当窗长足够时，VV 的 BER 可以逼近 DPLL（强湍流 Nw=256 时 BER≈0.018，与 DPLL 几乎一致）——这说明性能差异不是方法本身的优劣，而是参数配置的敏感度不同。前馈方法不是不能用，是参数门槛更高。

- 口述要点：前馈方法不是不能用，是参数门槛随湍流升高

> DPLL 的环路带宽也有设计空间。弱和中等湍流下参数宽容度很高，BER 在很宽的 ωn 范围内波动很小（弱/中等湍流 2-100 Mrad/s 稳定）。但强湍流下 ωn 过大会导致周期跳跃（ωn>70M 时 BER 从 0.018 跳到 0.13 以上）。结合前两张图可以得出核心结论：不同方法在不同湍流条件下参数敏感度不同，这正是第四章设计方法的研究动机。
