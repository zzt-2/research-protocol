# 逐节写作合同

> 用途：全质量章节稿的唯一目录、范文、证据和段落职责入口。
>
> 状态含义：`FULL`＝现有材料足以写成完整正文；`PARTIAL`＝只能完整写证据已闭合的部分；`BLOCKED`＝只能保留标题与证据缺口，不得写成完成态。

## 全局写法

1. 技术章第一节统一命名为“引言”，不用“本章引言”。
2. Ch3、Ch4 的引言采用夏兆宇稳定三段式：任务价值 → 现有瓶颈 → 本章方法链；结果数字不放在引言。
3. 方法型二级节采用“机制/对象 + 技术动作”命名，不用“方法介绍”“结构约束思路”等汇报式标题。
4. 每节正文先完成本节论证职责，再引出公式、算法或图表；不从参数、公式或验证回执起笔。
5. 正文顺序为 Ch3/Ch4 → Ch2 → Ch1 → Ch5 → Ch6；摘要性章节在承重正文稳定后回写。
6. 对外稿删除内部编号、材料包、验证门和流程语言；内部事实边界继续由本合同控制。
