# 第二章 星地激光通信系统与信道模型

## 2.1 本章概述

相干检测星地激光通信系统的性能受到大气信道效应的影响。为实现后续章节中载波同步算法的性能分析，需要给出完整的信号模型和信道模型，明确系统参数与接收信噪比之间的定量关系。本章围绕这一目标展开，内容安排如下。

§2.2介绍正交相移键控（Quadrature Phase Shift Keying, QPSK）相干检测星地激光通信系统的端到端组成，推导接收信号的数学模型，并给出噪声模型和信噪比的定义。§2.3分析大气信道的传输特性，依次介绍大气衰减的确定性模型和湍流效应的统计模型，采用Gamma-Gamma湍流衰落模型对归一化辐照度的概率分布进行建模。§2.4将系统参数、链路几何和信道模型统一纳入链路预算框架，推导接收端平均信噪比的闭合表达式，定量分析仰角和湍流强度对链路性能的影响。

## 2.2 星地激光通信系统模型

本节给出相干检测星地激光通信系统的信号模型，为后续载波同步算法的分析提供数学基础。首先介绍系统端到端组成与相干混频原理，在此基础上推导QPSK信号模型，最后给出噪声模型和信噪比的定义。

### 2.2.1 相干检测系统组成

星地激光通信系统的接收灵敏度是制约长距离链路性能的关键因素。与直接检测相比，相干检测利用本振光（Local Oscillator, LO）对微弱信号光进行光域混频放大，能够提高接收灵敏度、抑制背景光干扰，并支持高阶调制格式。正交相移键控（Quadrature Phase Shift Keying, QPSK）相干检测星地激光通信系统的端到端框图如图2-1所示。

【图2-1: QPSK相干检测星地激光通信系统端到端框图。发射端（激光器→QPSK调制器→光学天线）→自由空间光（Free Space Optical, FSO）信道（大气衰减+湍流）→接收端（光学天线→90°光混频器+本振激光器→平衡探测器→ADC→DSP）】

如图2-1所示，信号从发射端经大气信道到达接收端的传输过程可分为三个阶段。发射端激光器产生连续光载波，经QPSK调制器将数据信号加载到光载波相位上，随后通过光学天线向空间辐射。信号光经大气信道传输后，由地面站光学天线接收并送入相干接收机。在接收机内，信号光与本振光经90度光混频器进行相干混频，再通过平衡探测器完成光电转换，输出同相（In-phase, I）和正交（Quadrature, Q）两路基带电信号。基带信号经模数转换（Analog-to-Digital Converter, ADC）后送入数字信号处理（Digital Signal Processing, DSP）模块进行后续解调。表2-1列出了本文仿真所采用的星地激光通信系统主要参数。

【表2-1: 系统参数表（工作波长λ=1550nm、发射功率Pt、收发孔径Dt/Dr、光学效率η_t/η_r、量子效率η、探测器响应度$\mathcal{R}$、卫星高度H、符号速率Rs、本振功率P_LO等）】

相干检测的核心在于信号光与本振光的混频过程。接收信号光场可表示为：

$$E_s(t) = A_s \exp[-j(\omega_s t + \varphi_s)] \tag{2.1}$$

本振光场为：

$$E_{LO}(t) = A_{LO} \exp[-j(\omega_{LO} t + \varphi_{LO})] \tag{2.2}$$

式中，$A_s$和$A_{LO}$分别为信号光和本振光的振幅，$\omega_s$和$\omega_{LO}$分别为信号光和本振光的角频率（单位rad/s），$\varphi_s$和$\varphi_{LO}$为初始相位。两束光经90度光混频器后分为四路，相位分别为0°、90°、180°和270°，四路光信号两两进入平衡探测器，分别输出I路和Q路电信号。

本文系统采用内差（Intradyne）检测方式，即收发激光器中心频率近似相等（中频$\omega_{IF} \approx 0$）。该方式兼具零差检测的高灵敏度与外差检测对频率偏差的容忍能力[ref]。

模数转换后的离散信号仍携带频偏、相位噪声及偏振串扰等非理想因素，需要依次经过若干数字信号处理模块加以消除。图2-2给出了接收端数字信号处理链的框图，主要包括定时同步、偏振解复用、载波频偏估计（Frequency Offset Estimation, FOE）与补偿、载波相位恢复（Carrier Phase Recovery, CPR）以及符号判决等模块。

【图2-2: 接收端数字信号处理链框图。ADC输出→定时同步→偏振解复用→FOE与补偿→CPR→符号判决。标注FOE对应§4.3，CPR对应§4.4】

FOE和CPR作为载波同步的核心环节，将在第四章详细讨论。在实际系统中，由于收发端激光器中心频率存在偏差且激光器存在有限线宽，接收信号中包含残余频偏和激光相位噪声。此外，信号经大气信道传输后还受到湍流效应的影响。上述非理想因素需要在后续的数字信号处理模块中加以估计和补偿。

### 2.2.2 QPSK信号模型

在明确了系统端到端组成之后，下面推导接收信号的数学模型。本文系统采用QPSK调制格式。假设定时同步已由前端模块完成，以下聚焦于载波同步相关的信号建模。第$m$个QPSK发射符号定义为：

$$s_m = \exp\!\left(j\frac{(2m-1)\pi}{4}\right), \quad m = 1, 2, 3, 4 \tag{2.3}$$

即四个星座点的相位分别为$\pi/4$、$3\pi/4$、$5\pi/4$和$7\pi/4$，每个符号携带2比特信息。这一星座结构满足$s_m^4 = -1$，该性质是部分载波相位恢复算法的理论基础。

发射信号经大气信道传输后，第$k$个符号周期内的接收信号可以表示为：

$$r[k] = \sqrt{h}\,s[k]\exp(j\varphi[k]) + n[k] \tag{2.4}$$

其中，$s[k]$为第$k$个发射符号；$h$为归一化辐照度，表示大气湍流引起的光强起伏，满足$h \geq 0$且$E[h] = 1$，为实值标量而非复信道系数，其统计特性服从Gamma-Gamma分布，详见§2.3；$\varphi[k]$为联合载波相位误差，包含残余频偏引入的线性相位旋转和激光相位噪声的贡献；$n[k]$为复加性高斯白噪声，服从$\mathcal{CN}(0, \sigma_n^2)$分布。由于$h$为归一化辐照度而非电场强度，接收信号中$\sqrt{h}$对应电场幅度的衰减，而非功率的线性衰减。

噪声项$n[k]$的统计特性和信噪比的定义尚未给出，下一小节将对此进行分析。此外，归一化辐照度$h$的统计建模将在下一节展开，$\varphi[k]$的估计与补偿将在第四章讨论。

### 2.2.3 接收端噪声模型与信噪比定义

本节首先分析噪声的来源与统计特性，进而给出信噪比的定义。星地激光通信接收端的噪声主要来源于散粒噪声和热噪声。散粒噪声由光电探测过程中的光子统计特性引起，其功率与入射光功率成正比；负载电阻中载流子的热运动则产生热噪声，其功率取决于温度和等效噪声带宽。

光电探测器的响应度定义为单位光功率所产生的光电流：

$$\mathcal{R} = \frac{e\eta}{h_P \nu} \tag{2.5}$$

式中，$e$为电子电荷，$\eta$为量子效率，$h_P$为普朗克常量，$\nu$为光频率。在此基础上，散粒噪声方差和热噪声方差分别写为：

$$\sigma_{\text{shot}}^2 = 2e\bigl(i_D + \mathcal{R}(P_S + P_{LO} + P_B)\bigr)\Delta f \tag{2.6}$$

$$\sigma_{\text{th}}^2 = \frac{4k_B T_K \Delta f}{R_L} \tag{2.7}$$

式中，$i_D$为暗电流，$P_S$为信号光功率，$P_{LO}$为本振光功率，$P_B$为背景光功率，$\Delta f$为噪声等效带宽，$k_B$为玻尔兹曼常数，$T_K$为工作温度，$R_L$为负载电阻。

在本振光功率远大于信号光功率的典型条件下（$P_{LO} \gg P_S$），本振光散粒噪声在总噪声中起主导作用，此时相干接收机的噪声性能逼近散粒噪声极限。

平衡探测器输出的中频信号功率为：

$$P_{\text{IF}} = 2\mathcal{R}^2 P_S P_{LO} \tag{2.8}$$

该式表明，中频信号功率与本振功率和信号功率之积成正比，本振光对微弱信号光起到了光域放大作用。据此，相干检测信噪比（Signal-to-Noise Ratio, SNR）定义为中频信号功率与总噪声功率之比：

$$\text{SNR} = \frac{P_{\text{IF}}}{\sigma_{\text{shot}}^2 + \sigma_{\text{th}}^2} = \frac{2\mathcal{R}^2 P_S P_{LO}}{2e\bigl(i_D + \mathcal{R}(P_S + P_{LO} + P_B)\bigr)\Delta f + 4k_B T_K \Delta f / R_L} \tag{2.9}$$

当本振光功率足够大（$P_{LO} \gg P_S$）且本振散粒噪声远大于热噪声时，上式可简化为$\text{SNR} \approx \eta P_S / (h_P \nu \Delta f)$，此时相干检测信噪比逼近量子极限[ref]，接收灵敏度仅取决于信号光功率和量子效率。

在大气湍流信道下，接收信号光功率随归一化辐照度$h$随机波动，瞬时信噪比也随之变化。计入湍流效应后，瞬时信噪比可写为：

$$\gamma = \bar{\gamma} \cdot h \tag{2.10}$$

其中，$\bar{\gamma}$为平均信噪比，$h$为归一化辐照度。由于$h$为实值标量，瞬时信噪比与辐照度之间呈线性关系（而非$h^2$），这与射频通信中SNR与$|h|^2$成正比的形式不同。噪声模型和信噪比定义给出了接收端信号质量与系统参数之间的定量关系。然而，归一化辐照度$h$的统计特性尚未建模，下一节将分析大气信道对光信号传输的影响，并对$h$进行概率建模。

## 2.3 大气信道传输特性

在实际星地激光通信链路中，归一化辐照度$h$受到大气衰减和湍流起伏的联合影响，其统计特性对系统性能分析至关重要。本节依次介绍大气衰减的确定性损失模型和湍流效应的概率统计模型，最终给出$h$的Gamma-Gamma湍流衰落模型描述。

### 2.3.1 大气衰减

激光信号穿过大气层时，大气分子和气溶胶粒子会对光信号产生吸收和散射，导致信号功率发生确定性衰减。根据Beer-Lambert定律[ref]，光信号经大气传输后的接收光强为：

$$I(H) = I_0 \exp\!\bigl(-(\sigma_a + \sigma_s)\, H \sec\theta\bigr) \tag{2.11}$$

式中，$I_0$为发射光强，$I(H)$为经大气传输后的接收光强，$\sigma_a$为大气吸收系数，$\sigma_s$为大气散射系数，$H$为大气信道垂直高度，$\theta$为天顶角。吸收和散射系数可进一步分解为分子和气溶胶分量：

$$\sigma_a = \sigma_{a,\text{mol}} + \sigma_{a,\text{ae}}, \quad \sigma_s = \sigma_{s,\text{mol}} + \sigma_{s,\text{ae}} \tag{2.12}$$

其中，$\sigma_{a,\text{mol}}$和$\sigma_{a,\text{ae}}$分别为分子吸收和气溶胶吸收系数，$\sigma_{s,\text{mol}}$和$\sigma_{s,\text{ae}}$分别为分子散射和气溶胶散射系数。分子散射以Rayleigh散射为主，其系数与波长的四次方成反比（$\sigma_{s,\text{Rayleigh}} \propto \lambda^{-4}$）；气溶胶散射以Mie散射为主，其系数与能见度和波长有关[ref]。

通信波长的选择需要综合考虑衰减特性和器件可用性。在1550nm波长窗口，大气衰减系数较低（晴朗天气下典型值约0.2 dB/km[ref]），且该波长与光纤通信系统兼容，可采用成熟的商用器件。因此，本文系统选取1550nm作为工作波长。

### 2.3.2 大气湍流效应与Gamma-Gamma分布模型

上述Beer-Lambert定律描述了信号功率经过大气时的确定性衰减。然而，大气湍流引起的折射率随机起伏会导致接收信号的随机光强起伏，这种随机效应无法用确定性衰减模型描述，需要引入概率统计方法进行分析。

大气湍流源于大气中温度、压强和风速的不均匀分布所引起的折射率随机空间变化。为定量描述折射率的统计起伏特性，Kolmogorov理论表明，在惯性子区（$l_0 < r < L_0$，$l_0$为湍流内尺度，$L_0$为湍流外尺度）内，折射率结构函数满足2/3定律[ref]：

$$D_n(r) = C_n^2\, r^{2/3} \tag{2.13}$$

式中，$C_n^2$为折射率结构常数（单位m$^{-2/3}$），是表征湍流强度的核心物理参数。对应的空间功率谱密度为Kolmogorov谱：

$$\Phi_n(\kappa) = 0.033\, C_n^2\, \kappa^{-11/3}, \quad 2\pi/L_0 < \kappa < 2\pi/l_0 \tag{2.14}$$

上式中，$\kappa$为空间波数（单位rad/m）。在此基础上，Tatarskii谱和Von Karman谱分别引入了内尺度和外尺度修正，其中修正Von Karman谱适用于全波数域，是仿真中最常用的功率谱模型[ref]。本文后续推导基于Kolmogorov谱。

利用上述功率谱模型，可以推导出衡量湍流对光传播影响程度的量化指标。Rytov方差是刻画光传播路径上累积湍流效应的核心参数[ref]，定义为：

$$\sigma_R^2 = 1.23\, C_n^2\, k^{7/6}\, d_{\text{link}}^{11/6} \tag{2.15}$$

式中，$k = 2\pi/\lambda$为光波波数，$d_{\text{link}}$为星地传播距离。Rytov方差是湍流强度的量化指标：$\sigma_R^2 < 1$对应弱湍流，$\sigma_R^2 \approx 1$对应中等湍流，$\sigma_R^2 > 1$对应强湍流。与之相关的闪烁因子定义为归一化光强方差$\sigma_I^2 = \langle I^2 \rangle / \langle I \rangle^2 - 1$，在弱湍流条件下近似等于Rytov方差。

以上参数从宏观上刻画了湍流强度。下面从统计角度，确定接收端光强的概率分布模型。对数正态分布在弱湍流条件下（$\sigma_I^2 < 1$）能够较好地描述光强起伏，但随着湍流强度增大，实测数据与对数正态分布的偏差逐渐显著。K分布在强湍流条件下具有较好的拟合效果，但无法覆盖弱至中等湍流范围。为此，需要一种能够统一描述各湍流强度条件的统计模型。

Gamma-Gamma（GG）湍流衰落模型通过分别建模大尺度和小尺度湍流效应，能够实现从弱到强湍流条件的统一描述[ref]。该模型将归一化辐照度$h$分解为大尺度Gamma分量$X$和小尺度Gamma分量$Y$的乘积：

$$h = X \cdot Y, \quad X \sim \text{Gamma}(\alpha, 1/\alpha), \quad Y \sim \text{Gamma}(\beta, 1/\beta) \tag{2.16}$$

式中，$X$和$Y$相互独立，$\alpha$和$\beta$分别为大尺度和小尺度湍流参数。基于上述因子化结构，$h = XY$的无条件概率密度函数可通过积分消去条件变量得到[ref]：

$$f(h) = \frac{2(\alpha\beta)^{(\alpha+\beta)/2}}{\Gamma(\alpha)\Gamma(\beta)}\, h^{(\alpha+\beta)/2-1}\, K_{\alpha-\beta}\!\left(2\sqrt{\alpha\beta\, h}\right), \quad h > 0 \tag{2.17}$$

其中，$\Gamma(\cdot)$为Gamma函数，$K_{\alpha-\beta}(\cdot)$为第二类修正Bessel函数。参数$\alpha$和$\beta$通过Rytov方差和孔径平滑参数$d = \sqrt{kD^2/(4d_{\text{link}})}$（$D$为接收孔径直径）确定[ref]：

$$\alpha = \left[\exp\!\left(\frac{0.49\,\sigma_R^2}{(1+0.18\,d^2+0.56\,\sigma_R^{12/5})^{7/6}}\right)-1\right]^{-1} \tag{2.18a}$$

$$\beta = \left[\exp\!\left(\frac{0.51\,\sigma_R^2}{(1+0.9\,d^2+0.62\,d^2\,\sigma_R^{12/5})^{5/6}}\right)-1\right]^{-1} \tag{2.18b}$$

由式(2.18)可知，$\alpha$主要受大尺度湍流（折射率起伏的低频分量）影响，$\beta$主要受小尺度湍流（高频分量）影响。当$\beta = 1$时，Gamma-Gamma分布退化为K分布。

【图2-3: Gamma-Gamma分布概率密度函数（Probability Density Function, PDF）曲线。三档湍流（弱/中/强）下归一化辐照度h的概率密度函数，标注α/β参数值。弱湍流PDF集中在h≈1附近，强湍流PDF尾部极长】

图2-3展示了弱、中、强三档湍流条件下Gamma-Gamma分布的概率密度曲线。弱湍流时PDF集中在$h \approx 1$附近，深衰落概率极低；强湍流时PDF尾部延长，表明接收光强出现深度衰落的概率大幅增加。

### 2.3.3 Gamma-Gamma模型参数推导

上述GG分布模型给出了湍流强度参数与信道衰落统计之间的联系。为将该模型应用于后续链路预算和仿真分析，需要根据实际链路物理参数确定$\alpha$和$\beta$的具体取值。将链路参数（波长$\lambda$、星地传播距离$d_{\text{link}}$、接收孔径$D$、折射率结构常数$C_n^2$）代入式(2.15)和式(2.18)，即可计算出对应湍流条件下的GG参数。

【表2-2: Gamma-Gamma湍流模型参数表。列：湍流强度 | $C_n^2$ (m$^{-2/3}$) | $\sigma_R^2$ | $\alpha$ | $\beta$ | $\min(\alpha,\beta)$。行：弱($C_n^2 \approx 10^{-16}$) / 中($C_n^2 \approx 5\times10^{-15}$) / 强($C_n^2 \approx 10^{-14}$)】

确定了湍流信道模型参数后，下一节将其代入链路预算分析，给出系统参数与接收SNR之间的定量关系。

## 2.4 星地链路预算分析

相干检测信噪比以接收端信号光功率$P_S$为输入，尚未建立$P_S$与发射端参数之间的定量关系。本节将系统参数、链路几何和信道模型统一纳入链路预算框架，首先给出各损耗分量的物理模型，在此基础上推导接收端信噪比的闭合表达式。

### 2.4.1 链路损耗模型

接收端光信号功率受到三类因素的联合影响：自由空间传播引入的几何扩散损耗，大气分子和气溶胶引入的确定性衰减，以及湍流引起的随机光强起伏。前两项为确定性因素，在链路设计阶段即可计算；湍流引起的归一化辐照度$h$为随机变量，其统计特性已由Gamma-Gamma湍流衰落模型描述。对于低地球轨道（Low Earth Orbit, LEO）卫星（以下简称低轨卫星），星地链路的几何距离随卫星运动和地面站仰角持续变化，自由空间损耗也随之波动。地面站仰角为$\theta$时，星地斜距为：

$$d(\theta) = \sqrt{(R_E + H)^2 - (R_E \cos\theta)^2} - R_E \sin\theta \tag{2.19}$$

式中，$R_E$为地球半径（取6371 km），$H$为卫星轨道高度，$\theta$为地面站仰角（仰角90°对应卫星位于天顶，与§2.3.1中的天顶角互补）。由式(2.19)可知，仰角越大（卫星越接近天顶），斜距越小，自由空间损耗也越低。以$H = 500$ km的低轨卫星为例，天顶方向（$\theta = 90°$）斜距为500 km，而低仰角（$\theta = 10°$）时斜距增至约1700 km，对应的自由空间传播损耗相差约10.7 dB（$20\log_{10}(1700/500)$）。此外，低仰角时信号穿过大气的路径更长，由§2.3.1的Beer-Lambert定律可知大气透过率更低，进一步恶化接收信号质量。基于上述损耗模型，下一小节推导接收端信号光功率与信噪比。

### 2.4.2 接收功率与信噪比预算

在明确了各损耗分量的物理模型后，可推导接收端信号光功率。对于衍射极限圆孔径天线，发射天线增益为$G_t = \eta_t(\pi D_t / \lambda)^2$，接收天线增益为$G_r = \eta_r(\pi D_r / \lambda)^2$。结合自由空间传播因子$(\lambda / 4\pi d)^2$和大气透过率$T_{atm}$，接收端信号光功率为：

$$P_R = P_t \eta_t \eta_r \left(\frac{\pi D_t D_r}{4 d \lambda}\right)^{\!2} T_{atm} \cdot h \tag{2.20}$$

式中，$P_t$为发射光功率，$D_t$和$D_r$分别为发射和接收孔径直径，$\eta_t$和$\eta_r$分别为发射和接收光学效率（含孔径效率和光学传输损耗），$d$为由式(2.19)确定的星地斜距，$T_{atm}$为大气透过率，$h$为归一化辐照度。式(2.20)中$P_R$即接收端信号光功率$P_S$。该式将确定性链路传输因子与随机湍流衰落统一于同一表达式：确定性部分仅与系统参数和链路几何有关，而湍流衰落由$h$单独表征。

将式(2.20)代入相干检测信噪比定义，在本振散粒噪声主导、热噪声可忽略的量子极限近似条件下（$P_{LO} \gg P_R$），平均信噪比为：

$$\bar{\gamma} = \frac{\eta P_t \eta_t \eta_r}{h_P \nu R_s}\left(\frac{\pi D_t D_r}{4 d \lambda}\right)^{\!2} T_{atm} \tag{2.21}$$

式中，$\eta$为量子效率，$h_P$为普朗克常量，$\nu$为光频率，$R_s$为符号速率（对于Nyquist滤波，噪声等效带宽$\Delta f \approx R_s$）。瞬时信噪比$\gamma = \bar{\gamma} \cdot h$与式(2.10)的形式一致，表明湍流衰落通过归一化辐照度$h$线性影响瞬时信噪比。

## 2.5 本章小结

本章围绕星地激光通信系统的信号建模与信道建模展开分析。首先介绍了QPSK相干检测系统的端到端信号模型，推导了接收信号$r[k] = \sqrt{h}\,s[k]\exp(j\varphi[k]) + n[k]$，明确了瞬时信噪比与归一化辐照度之间的线性关系$\gamma = \bar{\gamma} \cdot h$。在此基础上，采用Beer-Lambert定律和Gamma-Gamma湍流衰落模型分别描述了大气衰减的确定性损耗和湍流效应的统计特性。进而通过链路预算分析，将系统参数、链路几何与信道模型统一纳入同一框架，推导了接收端平均信噪比的闭合表达式，定量分析了仰角和湍流强度对链路性能的影响。

上述模型为后续章节中载波频偏估计与载波相位恢复算法的性能分析和仿真验证提供了信号模型基础和链路参数依据。
