# 检索 + 初筛（gw-search）

## 入参
- 用户的研究方向描述
- `search-archive/` 目录下已有的搜索结果（如有）

## 出参
- `search-archive/{date}/{slug}.json`（脚本自动存档）
- 面向用户的候选列表（用 `--format markdown` 生成可读表格）

## 操作

1. 根据用户的研究方向，构造搜索关键词（≥3 组不同角度）
2. 用 `tools/search` 脚本检索（参见 `tools-guide.md` §2）
   - 推荐参数：`--mode academic`、`--preset scenario-method` 或 `--preset problem-driven`
   - 多源搜索，每源 ≥15 条
   - **中文检索**：中文文献用 `tools/blit --source cnki`（详见 `tools-guide.md` §5 中文检索策略），不依赖 API 管线
3. 去重 + 合并 + 按相关性排序（脚本自动完成）
4. **AI 候选审查**（[MUST] Agent 执行，不能用脚本的 relevance_score 替代）
   - 读取脚本输出的 `search-archive/{date}/{slug}.json`
   - 对每条候选，综合 title + abstract + venue + year + citation_count + publication_status，判断与研究方向的真实语义相关性
   - 为每条标注 `priority` 和 `priority_reason` 字段：
     - **必读**：近 3 年 + 正式发表（期刊/会议）+ 与研究方向直接相关
     - **建议读**：近 5 年 + 正式发表 + 方法可借鉴
     - **待确认**：预印本 + 与研究方向直接相关（优先检查是否有正式版本）
     - **备选**：较早文章但有基础性贡献
     - **排除**：与研究方向无关（即使关键词命中，也需明确排除）
   - 审查完成后，将标注结果保存回原 JSON 文件
   - 输出统计：各优先级数量分布
5. 基于 AI 审查结果，确认候选列表满足质量门槛
6. **二轮定向检索**（[MUST] 初筛通过后执行）
   - 从一轮审查结果中识别 **≥2 个候选研究方向**（基于论文密度、方法聚类、空白区域等信号）
   - 为每个候选方向，构造方向专属关键词（≥2 组不同角度），用 `tools/search` 做定向深搜
   - 定向深搜的目的是**验证方向本身**：确认论文池规模、创新空白是否真实存在、竞争态势是否有变化
   - 将新结果合并到已有候选列表，重新执行 AI 审查（步骤 4）和覆盖度评估
   - **通过条件**：每个候选方向都有独立的定向检索支撑，且至少 1 个方向的验证检索确认了创新空白的真实性
   - 如果某个候选方向在定向检索后被推翻（如发现竞争已饱和），记录判断理由并从候选中移除，可补充探索新方向
7. 基于一轮 + 二轮检索的综合结果，产出最终候选方向列表

### 复用已有搜索结果

如果 `search-archive/` 中已有相关搜索结果（如前次对话产出），可以复用，但必须额外检查：

1. **数量门槛**：已有结果 ≥20 条（同下方质量门槛）
2. **覆盖度门槛**（必须通过）：
   - 结果是否覆盖 ≥2 个不同子方向/技术路线？
   - 是否存在与研究主题明显相关但完全未出现的方向？
   - 如有明确的方向空洞 → 必须针对缺失方向做补充搜索（即使总量已达标）

> 试跑教训：已有 30 条搜索结果时 agent 直接判定通过，但 30 条全部集中在单一技术路线，遗漏了重要的替代方案。覆盖度不够时必须补充搜索，不能只看数量。

## 质量门槛

- 去重后 ≥20 条候选（通信细分领域论文池可能只有 20-30 篇，这个量级即可）
- **路径合规**：搜索结果存放在 `search-archive/{date}/{slug}.json`，不在其他位置创建检索结果文件
- 覆盖 ≥3 个搜索源
- "必读"类 ≥5 篇
- **覆盖度**：结果必须覆盖 ≥2 个不同子方向/技术路线，无明显方向空洞
- **正式发表文献占比 ≥50%**（如预印本占主导，需补充正式发表文献检索，可用 `tools/blit --source ieee`）
- publication_status 为 unknown 的论文视为"待确认"，计入总数但不计入正式发表占比。执行时可优先对 unknown 论文做 DOI 查询确认发表状态

## 不达标时

- 候选总数 <15 → 用 `--mode broad` 或 `--preset problem-driven` 扩大范围重搜
- 必读 <3 → 检查关键词是否过于狭窄，换角度重搜
- 搜索结果与研究方向偏差大 → 重新对齐研究方向描述，再搜
- 覆盖度不足 → 针对缺失方向构造新关键词组，做补充搜索
- 预印本占比过高 → 用 S2 API（`tools/search --citations` 或直接 Semantic Scholar API）逐篇检查预印本是否有正式发表版本，更新 `publication_status` 和 venue 信息
- 学位论文场景缺中文文献 → 用 `tools/search --doc-types chinese_journal` 或 `tools/blit --source wanfang` 补充中文学术期刊检索
