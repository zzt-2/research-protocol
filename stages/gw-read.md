# 精读 + 提取（gw-read）

## 入参
- `papers/{arxiv|doi}/{id}/content.md`（已下载论文全文）

## 出参
- `literature_notes.md`

## 操作

**必须读 content.md，不允许只读搜索元数据。**

对每篇已下载的论文，读其 `content.md` 的 method + experiment 部分（introduction 和 related work 可跳过，这些信息已从搜索元数据获得），按以下结构提取（模板见 `templates.md`）：

```
### [L01] {论文标题}
- DOI/来源：{实际 DOI / arXiv ID / "无 DOI（来源：{数据源名}）"}
- **发表状态**：{正式发表 | 预印本 | 已录用待刊 | 未知}
- **发表渠道**：{期刊名/会议名 + 等级，如 "IEEE JSAC (SCI Q1)"}
- 年份/会议：{年份 + 出版 venue}
- 核心贡献：{从 content.md 提取，≥2 句，包含方法层面细节}
- 方法概述：{从 method 部分提取，2-3 句}
- 实验设置：{从 experiment 部分提取的关键配置}
- 使用的 Baseline 方法：
  - {方法名}: {简述，标注论文内是自实现还是引用}
  - （如论文无对比实验，标注"无对比实验"）
- 关键结论：{从 result/conclusion 提取}
- 与本研究关系：{直接相关 / 方法可借鉴 / 对比 baseline 候选 / 仅供参考}
- 实现关键细节：{从 method 提取影响复现的工程细节：奖励归一化方式/具体数值、观测空间归一化、动作空间处理。[MUST] 包含具体数值，不允许"标准处理"}
- 开源代码：{有（链接）/ 无 / MATLAB / 仅伪代码}
- 验证状态：{已通过学术搜索工具验证}
```

### 结构化提取（[MUST]）

自由文本的"实现关键细节"不可跨对话复用。以下 5 个子表必须在精读时以结构化形式提取：

1. **状态空间**：维度名 | 范围/取值 | 归一化方法
2. **动作空间**：类型（离散/连续/混合）| 维度 | 合法动作约束
3. **奖励函数**：完整公式（内联 LaTeX，不允许散文描述）| 归一化方式 | 各项权重值
4. **建模假设**：假设内容 | 论文位置（章节/公式）| 对仿真器的影响
5. **网络架构**：层类型 | 维度 | 激活函数 | 归一化 | 优化器设置

> 为什么这样要求：精读时如果只留自由文本描述，跨对话恢复时仿真器构建者无法获得足够的 MDP 定义。奖励公式丢失归一化细节是最常见的返工原因。

领域专属的额外提取要求见领域定制文件（通信领域见 `domain-comms.md`）。

### 综合分析（精读完成后撰写）

1. **现有方法分类**：按技术路线分类，每类 2-3 句（包含具体方法名，不是泛泛而谈）
2. **已知局限**：现有方法的共同不足（从论文的 conclusion/future work 部分提取）
3. **2-3 年趋势**：该方向的发展趋势（从精读论文的发表年份和方法演进中推断）

### 浅读流程（可选）

当候选论文数量超过精读范围时（如大论文场景），可将部分论文标记为"浅读"：

1. 标记标准：搜索结果中相关性为"建议读"且非核心方法的论文
2. 操作：从搜索结果的 abstract 和元数据中提取，不要求读 content.md
3. 产出：在 literature_notes.md 中使用浅读条目模板（见 templates.md）
4. 浅读论文不计入精读数量门槛（≥5 篇精读的门槛仅计算精读论文）

精读和浅读的关系：
- 精读（读 content.md）→ 用于核心对比、Baseline 选择、方法细节提取
- 浅读（读 abstract）→ 用于 Related Work 覆盖面、引用定位
- 不需要为小论文（<30 篇引用）启用浅读流程

## 质量门槛

- ≥5 篇论文完成精读提取
- 每篇的"使用的 Baseline 方法"不为空（无对比实验的除外）
- 每篇的"核心贡献"≥2 句，不是搜索摘要的复制粘贴
- 综合分析三个小节都有实质内容
- **路径合规**：`literature_notes.md` 在 `projects/{name}/` 下，不在根目录

## 不达标时

- 精读 <5 篇 → 回 gw-acquire.md 补下载
- Baseline 提取为空 → 检查是否漏读了 experiment 部分
- 综合分析泛泛而谈 → 用更多论文的具体内容支撑
- 结构化提取缺少完整公式 → 回论文对应章节重新提取，不允许用散文替代公式
