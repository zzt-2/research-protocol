# PROMPT: 评估 6 个候选研究方向

## 背景

学位论文攒材料，通信领域（LEO卫星/DRL/GNN），导师方向模糊（大致是"LEO卫星通信"）。现有 5 个活跃项目 + 1 个归档项目，需要找一个新方向。

## 前置阅读

1. `directions-registry.md` — 所有已探索方向全记录（必读，避免重复）
2. `projects-overview.md` — 跨项目状态汇总和教训
3. `domain-comms.md` §1 — 文献检索规范
4. `tools-guide.md` — 检索工具用法

## 任务

对以下 6 个候选方向，逐一用 `tools/search` 做初步检索，评估可行性和新颖性。

按顺序评估（每完成一个再评估下一个，根据前一个的结果调整后续策略）：

1. **ISAC 通感一体化 + 卫星** — 5/11 有过浅检索（~15篇），未深入
2. **Digital Twin + RL + 卫星网络** — 5/11 有过浅检索（~10篇），未深入
3. **联邦学习 + 卫星路由/资源管理** — 作为辅助方法出现，非主攻，可独立
4. **通导遥一体化** — 5/14 综述性检索，可能有空间
5. **LEO 星座抗毁/故障恢复** — 5/14 综述性检索，未评估
6. **频谱共享/干扰协调（LEO+GEO 共存）** — ISL 子主题，可独立

## 每个方向的评估流程

### Step 1: 检索（用 tools/search）

每个方向搜 2-3 组关键词（中英文各一组），每组返回 ≤30 条。记录检索结果到 `search-archive/{today}/`。

检索前先检查 `directions-registry.md` 和 `search-archive/` 已有记录，避免重复搜同样的关键词。

### Step 2: 快速评估

对每个方向，基于检索结果回答：

```
方向: xxx
论文总量: ~N篇（近3年）
ML/DRL/GNN渗透率: X% (N篇中N篇用ML)
最接近的竞品: 1-2篇关键论文（标题+年份+方法）
蓝海判断: 真（<5篇ML）/ 伪（已有成熟方案）/ 待定
导师方向匹配: 高/中/低
与现有项目冲突: 无 / 与项目X重叠
MVE可行性: 可快速验证 / 需要复杂仿真 / 不适合
综合推荐: ★★★/★★/★
```

### Step 3: 汇总排名

6 个方向全部评估完后，给出推荐排名（1-6），说明推荐理由。

## 约束

- 每个方向的检索+评估控制在 1-2 轮，不精读论文，只看标题/摘要判断
- 不创建项目目录，不写正式报告
- 发现明显红海（>20篇ML论文）立即跳过，记录排除原因即可
- 如果某个方向在检索过程中激发了新的候选方向，也记录下来
- 总时间控制在单对话内（3个步骤上限前完成）
- 如果 6 个都评估不完，优先完成排名靠前的候选；只有确认需要开新对话继续时才写 handoff，不要顺手写一个
