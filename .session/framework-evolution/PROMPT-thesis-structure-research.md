# PROMPT: 研究硕博论文结构 — 验证"1方向→3问题"的实际形态

## 背景

导师要求学位论文结构为"1 个大方向 → 3 个互相关联的问题 → 3 章主体"，但我们不确定：
1. "互相关联"的具体标准是什么？是方法统一？场景统一？逻辑递进？还是别的？
2. 3 个问题之间的"距离"应该多远？太近被说同一件事做三遍，太远被说不连贯
3. 每章的独立性要求多高？能否共享仿真平台/数据集？

## 任务

### Step 1: 检索通信方向硕博论文

用 `tools/search --source cnki` 检索 985 高校通信方向的硕博论文。

检索关键词（每组 ≤30 条）：
- 高级检索：学科=信息与通信工程，学位级别=博士，学校级别=985，年份=2023-2026
- 关键词组合：卫星通信 + 深度学习/强化学习/图神经网络（优先找与我们领域最接近的）
- 备选关键词：无线通信 资源分配 + 深度强化学习（博士论文）
- 再搜一组：低轨卫星 + 算法/优化（博士论文）

重点找的论文类型：
- **最相关**：卫星通信 + ML/DRL/GNN 的博士论文
- **次相关**：无线通信 + ML 的博士论文（看结构就行）
- **参考**：通信领域经典博士论文（高引用）

### Step 2: 分析论文结构

对找到的论文，重点看**目录和章节结构**，不需要读全文。提取：

```
论文标题: xxx
学校: xxx
年份: xxx
大方向（一句话）: xxx
章1问题: xxx（一句话）
章2问题: xxx
章3问题: xxx
三者的关联方式: 方法统一 / 场景统一 / 逻辑递进 / 问题分解 / 其他
关联强度: 强（有依赖关系）/ 中（共享场景或方法）/ 弱（只是同领域）
评论: 这篇的结构是否值得参考？为什么？
```

### Step 3: 归纳模式

从 5-10 篇论文中归纳出常见的"3 章结构"模式，例如：

- **方法迁移型**：同一方法（如 GNN）应用到同一场景的 3 个不同子问题
- **问题分解型**：一个大问题拆成 3 个递进步骤（如建模→优化→验证）
- **场景拓展型**：同一问题在不同场景/约束下分别求解
- **层次递进型**：从单点到局部到全局的递进
- **其他模式**

对每种模式评估：
- 这种"关联"答辩时是否被认可
- 哪种模式最适合我们的情况（LEO 卫星 + GNN/DRL）

### Step 4: 对照我们的方案

用归纳出的模式，对照我们的两个候选方案：

**方案 A: 路由 + ISL 调度 + 抗毁**
**方案 B: 频谱共享拆 3 个子问题**

判断哪个更符合"标准答案"，或者是否需要调整。

## 约束

- **严禁在主对话中使用 WebSearch 或 webReader**，会导致上下文爆炸
- 检索只能用 `tools/search --source cnki`（知网论文检索）或 `tools/search`（Semantic Scholar）
- 如果实在需要 web 查询某篇论文的目录，**必须在子 agent 中执行**，子 agent 消化后返回 ≤500 词摘要
- 只看目录/摘要/结论，不精读全文
- 优先找博士论文（结构更完整），硕士论文作为补充
- 找不到卫星通信方向的就放宽到无线通信/移动通信
- 重点看 985 学校（清华、北邮、上交、东南、成电、西电、哈工大、北航、中科大等通信强校）
- 单对话内完成；只有确认需要开新对话继续时才写 handoff
