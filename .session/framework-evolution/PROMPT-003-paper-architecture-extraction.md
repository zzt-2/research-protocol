# 提示词：新增论文写作架构提取步骤

## 任务

在 Groundwork Step 3 精读中增加"论文写作架构提取"能力，让 agent 在精读技术内容的同时学习竞品论文的写作模式。

## 背景

当前 `gw-read.md` 的结构化提取只关注技术维度（状态空间/动作空间/奖励函数/网络架构），没有提取写作架构维度。这导致后期写论文/毕业论文时缺乏参考：
- 不知道该领域论文的标准章节结构
- 容易遗漏审稿人期望看到的关键参数、公式、图表
- 叙述风格和实验对比方法缺乏参照
- 后期补做会导致大量返工

## 要读的文件

1. `stages/gw-read.md` — 当前精读流程和结构化提取模板
2. `templates.md` — literature_notes 模板
3. `stages/paper-materials-workflow.md` — 理解后期的素材提取流程（避免重复）
4. `stages/thesis-materials.md` — 学位论文材料准备要求
5. 2-3 篇已精读论文的 content.md（如 `papers/` 下任意 2 篇），理解论文结构

## 具体改动

### 1. `stages/gw-read.md` — 增加写作架构提取模板

在 Step 3 的结构化提取部分（当前 6 个子表之后），增加第二个提取维度：

**论文写作架构提取**（对 2-3 篇标杆论文执行，非全部论文）：

```markdown
### 写作架构提取

**选文标准**：选择 2-3 篇与当前方向最接近、发表在目标期刊/会议上的论文。

#### A. 章节结构
- 各级标题列表（到三级）
- 核心章节的页数/段落分布
- 是否有独立的 System Model / Problem Formulation / Algorithm Design 章节

#### B. 关键参数展示方式
- 参数是用表格集中展示还是散落在正文中
- 参数符号定义的位置（单独的 Notation 节？脚注？行内？）
- 是否有参数敏感度分析

#### C. 图表模式
- 核心图表类型和数量（系统模型图、算法框图、架构图、实验曲线、对比表格）
- 图表的典型 caption 风格
- 是否有 3D 可视化/热力图/收敛曲线

#### D. 实验组织
- Baseline 选择和数量（3-5 个？是否包含传统方法？）
- 消融实验的组织方式
- 评价指标的选择和数量
- 是否有复杂度分析/收敛性分析

#### E. 叙述模式
- Introduction 的论证结构（背景 → 问题 → 空白 → 贡献）
- 贡献列表的条目数和粒度
- Related Work 的组织方式（按方法/按问题/按时间）
```

### 2. `templates.md` — literature_notes 模板增加写作架构节

在 literature_notes 模板的"综合分析"之后增加：

```markdown
## 写作架构参考（选做）

> 从精读论文中选择 2-3 篇标杆论文提取写作架构。

### 标杆论文选择
- [论文 ID]：选择原因

### 共性模式总结
- 标准章节结构：...
- 必要图表清单：...
- 关键参数展示方式：...
- 实验组织模式：...
```

### 3. `stages/groundwork.md` — 编排查表更新

在 Step 3 的描述中增加：**对 2-3 篇标杆论文完成写作架构提取**。

## 约束

- 写作架构提取只在 2-3 篇标杆论文上做，不在全部精读论文上做
- 与 `paper-materials-workflow.md` 的素材提取不重复——本步骤关注"竞品怎么写"，素材提取关注"我要写什么"
- 保持改动最小化，不引入新文件
- 这个提取可以在 Step 3 精读时顺便做，不需要单独开一步
