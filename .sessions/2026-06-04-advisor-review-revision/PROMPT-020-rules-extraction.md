# PROMPT-020: 规则提取与写作质量规范更新

> 创建: 2026-06-04 | 优先级: P4（收尾步骤） | 批次: 全部完成后
> 依赖: P-001 至 P-019 全部执行完成 | 复杂度: 中等

## 目标

全部 20 条导师批注的修订批次完成后，回顾所有 PROMPT（P-001 至 P-019）的实际执行结果，从中提取新发现的写作规范规则，更新 `毕设/写作质量规范.md`。这是方案 A（预装+只读）的收尾步骤：P-001 已预装 B1-B10 共 10 条规则作为基线，本 PROMPT 负责从执行过程中发现预装未覆盖的新规则。

## 必读文件（按优先级）

1. **`毕设/写作质量规范.md`** — 当前版本（含 P-001 预装的 B1-B10），规则写入目标
2. **`.sessions/2026-06-04-advisor-review-revision/S001-review-planning.md`** — 执行记录，含各 PROMPT 完成状态
3. **各 PROMPT 执行产出** — 逐个回顾 P-002 至 P-019 的实际修改记录（每个 PROMPT 末尾的"附录"段落或执行日志）

## 工作步骤

### Step 1: 逐个 PROMPT 回顾

按编号顺序回顾 P-002 至 P-019 的实际修改内容。对每个 PROMPT：

1. 读取该 PROMPT 文件中的修改记录/附录
2. 记录修改中体现的写作模式或教训
3. 标注该模式是否已被 P-001 预装规则（B1-B10）覆盖

按以下维度分类记录：

| 维度 | 对应 PROMPT 范围 | 关注点 |
|------|-----------------|--------|
| AI 痕迹改写 | P-003, P-007, P-008, P-010 | 改写过程中发现的 B1 未覆盖的新模式 |
| 表格改造 | P-006 | 表格学术性改造中发现的标准细节 |
| 参考文献替换 | P-004, P-012 | 期刊质量判断经验、格式修正中的常见错误 |
| 术语替换 | P-011, P-016 | 用词规范、术语一致性要求 |
| 格式修正 | P-002, P-013, P-014, P-015, P-017, P-018 | 常见格式错误模式 |
| 图表修正 | P-005, P-009 | 图表设计中发现的可复用规范 |
| 结构调整 | P-007, P-008, P-010, P-018 | 段落/章节组织中发现的原则 |

### Step 2: 提取新规则

从 Step 1 的记录中，提炼可复用的写作规范规则。每条新规则必须满足：

- **有执行证据**：能指明源自哪个 PROMPT 的哪处具体修改
- **可复用**：不是本次修改的特殊情况，而是未来写作也适用的通用规范
- **可操作**：用祈使句表述，明确"做什么"或"不做什么"
- **不重复**：与 B1-B10 预装规则无重叠

### Step 3: 与预装规则对比去重

将 Step 2 提取的新规则逐条与 B1-B10 对照：

- B1（AI 痕迹判定标准）：覆盖了"机器语言"的宏观识别
- B2（逐句改写纪律）：覆盖了改写流程要求
- B3（教学与科研区分标准）：覆盖了实验方案定位
- B4（表格学术性标准）：覆盖了表格基本要求
- B5（泛话黑名单）：覆盖了 10 个泛话短语
- B6（模板残留扫描）：覆盖了模板文字清理
- B7（标题用词规范）：覆盖了"概况"类问题
- B8（图表设计三规则）：覆盖了图表基本要求
- B9（参考文献质量门槛）：覆盖了期刊质量标准
- B10（引用格式 GB7714-87）：覆盖了引用格式要求

如果新规则只是已有规则的细化或实例，归入已有规则的补充说明而非新建规则。

### Step 4: 写入写作质量规范.md

将通过去重的新规则写入 `毕设/写作质量规范.md`：

1. 确定每条新规则的最佳插入位置（归入现有章节 or 新建章节）
2. 每条新规则格式：编号（B11 起）+ 祈使句标题 + 说明段落 + 来源标注（`[来源: P-0XX, 批注#N]`）
3. 保持文档整体结构不变，不调整已有规则的位置或编号

### Step 5: 验证

1. 通读更新后的写作质量规范.md，确认新规则与已有规则无矛盾
2. 确认每条新规则都有明确的来源 PROMPT 编号
3. 确认新规则措辞为祈使句且可操作

## 约束

- **不修改预装规则**：B1-B10 的内容、编号、位置保持不变
- **新规则必须有执行证据**：每条规则标注来源 PROMPT 编号和具体修改位置
- **不重复已有规则**：与 B1-B10 重叠的发现归入补充说明，不新建规则
- **不预设规则**：只从实际修改中提取，不凭理论预设
- **措辞用祈使句**：规则表述为"做 X""避免 Y"，不用描述性语气
- **不改动 kaiti-report.md**：本 PROMPT 只更新规范文档，不修改开题报告本身
