## 发现

### 一、四种主流画法

#### 类型A：系统端到端框图（中文论文最常见）

典型布局：左→右三段式（发射端 / 信道 / 接收端），每段内模块串联。

```
┌── 发射端 ──┐    ┌── 信道 ──┐    ┌── 接收端 ──┐
│ 激光器     │    │           │    │ 光学天线   │
│ → QPSK调制 │──→│ 自由空间  │──→│ → 混频器   │
│ → 光学天线 │    │ 大气衰减  │    │ → 平衡检测 │
└────────────┘    │ 湍流衰落  │    │ → DSP      │
                  └───────────┘    └────────────┘
```

视觉特点：
- 三段用竖虚线或底色区分
- 信道段常画云状/渐变表示大气
- 关键参数在模块旁或箭头旁标注（dB值或符号）
- 虚线可表示反馈/控制路径

#### 类型B：功率预算方程图（瀑布/链式）

将链路预算公式 P_r = P_t · G_t · G_r · L_fs · L_atm · h 可视化为水平链式图。

两种子类型：

**B1：纯链式（加减dB瀑布）**
```
P_t ──(+G_t)──(-L_fs)──(-L_atm)──(×h)──(+G_r)──→ P_r
发射功率  发射增益  空间损耗   大气损耗  湍流  接收增益   接收功率
```
- 增益用向上箭头，损耗用向下箭头
- dB值标注在各节点旁

**B2：乘法节点信号流图（本项目已尝试，被拒5次）**
```
[发射功率] → (×) → (×) → (×) → (×) → (×) → [接收功率] → (÷) → [SNR]
              ↑      ↑      ↑      ↑      ↑                         ↑
            天线增益 空间损耗 大气衰减 湍流衰落 接收增益              噪声功率
```
- 使用乘法圆圈节点（×或⊗），因子从垂直方向接入
- 数学关系明确，但视觉效果单调（一排圆圈不好看）

参考：
- **赵云综述 3.1节**：链路功率预算方程 P_r = P_t * G_t * η_ot * L_s * η_s * L_APT * G_r * η_or，配套表2给出数值
- **Stotts et al., Applied Optics 2010**：链路预算估算方法

### 二、各画法适用场景

| 画法 | 适用场景 | 在中文论文中的出现频率 |
|------|---------|---------------------|
| A: 系统框图 | 展示系统架构，"有什么模块" | 最高（几乎每篇都有） |
| B: 方程图 | 展示功率计算关系，"功率怎么算" | 中等（系统设计类论文常用） |
| C: 表格/曲线 | 展示数值结果，"算出来多少" | 高（表格几乎都有，曲线常见） |
| D: 几何图 | 展示物理场景，"链路长什么样" | 高（信道建模章节常用） |

## 结论

1. 链路预算的数学关系（乘法链）在学术论文中通常用**表格**（类型C1）或**公式+文字**呈现，而非专门的信号流图
2. 如果需要画"图"来表示链路预算，最常见的做法是**系统框图**（类型A）——发射端/信道/接收端三段，功率参数作为模块标注
3. 类型B（方程图/乘法节点图）在教学中常见，但正式论文中较少作为独立图出现——通常公式+表格就够了
4. 本项目的 fig_link_budget.drawio 五次被拒的根本原因可能是：**这个图的功能可以由公式+表格替代，不需要单独画信号流图**
