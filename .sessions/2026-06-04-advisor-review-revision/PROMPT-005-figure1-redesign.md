## 子 Agent 策略

### Agent 1：范文图表模式分析（独立执行）

- 精读 3 篇范文（闫佳欣、曾嘉、张岱）中的系统图/框图
- 提取每篇范文中系统图的设计模式：

  - 模块粒度（到什么级别停止分解）
  - 标注内容（参数值、信号类型、频率/速率、坐标轴等）
  - 连接关系（箭头类型、信号流方向、数据流 vs 控制流）
  - 布局方式（从左到右 / 从上到下 / 层次嵌套）

- 产出：图的文字规格文档

## 工作步骤

### Step 1：范文图表模式提取 [检查点：模式对比表完成]

Agent 1 执行：

1. 逐一精读 3 篇范文的 content.md，定位所有系统图/框图
2. 对每张系统图，提取以下信息：

| 维度 | 提取内容 |
|------|---------|
| **图的层次** | 场景层（如卫星-地面站）？子系统层（如发射端/信道/接收端）？模块层（如载波同步模块内部）？ |
| **模块粒度** | 分解到什么级别？如"数字信号处理"→"载波恢复""均衡"→具体算法？ |
| **标注内容** | 有无参数值（如"10 Gbps""1550 nm"）？信号类型标注（如"电信号""光信号""数字信号"）？坐标轴？ |
| **连接关系** | 箭头类型（实线/虚线/双向）？信号流方向？有无反馈环路？ |
| **布局方式** | 水平（左→右）？垂直（上→下）？层次嵌套？分栏？ |
| **图注/图例** | 有无单独图例区域？图注内容？ |
| **与正文关系** | 图前引导句写什么？图后分析句写什么？ |

3. 产出模式对比表（Markdown 表格，7 维度 × 3 篇范文）
4. 提炼可复用的设计模式（哪些设计元素适合图 1-1 采用）

**检查点**：3 篇范文全部提取完成，对比表完整，设计模式提炼有明确结论。

### Step 2：确认图 1-1 需要支撑的正文内容 [检查点：支撑点清单完成]

1. 读 `kaiti-report.md` 图 1-1 周边段落（L1-50），确认：
   - 图前引导句的内容和指向
   - 图后分析句的内容和指向
   - 图需要支撑的核心论点是什么
2. 读 kaiti-report.md 中研究内容（§1.2 或 §2）和研究方案（§3）的框架性描述，确认：
   - 系统边界：哪些子系统在研究范围内、哪些不在
   - 信号处理链路的起点和终点
   - 需要在图中突出的关键模块（对应论文三个研究问题的模块）
3. 产出支撑点清单（图需要表达的内容要素列表）

**检查点**：支撑点清单完整，图的"必须包含"和"不应包含"边界明确。

### Step 3：设计新图 1-1 规格 [检查点：规格文档完成]

Agent 2 执行，基于 Step 1 的设计模式 + Step 2 的支撑点清单：

1. **确定图的层次结构**

   图 1-1 作为开题报告的首张图，定位是"系统场景图 + 信号处理链路总览"。建议采用双层结构：
   - 上层：星地链路场景（卫星 → 大气信道 → 地面站），标注距离、波长、速率等关键参数
   - 下层：信号处理链路框图（从发射端光调制 → 信道传输 → 接收端信号处理），按模块展开

   具体层次选择需基于范文分析结果确定。

2. **列出模块清单**

   按信号流顺序列出所有模块，每个模块标注：
   - 模块名称（中英文）
   - 输入信号类型和参数
   - 输出信号类型和参数
   - 是否为本论文的研究重点（标注★）
   - 对应 kaiti-report.md 哪个章节/研究问题

3. **定义连接关系**

   - 模块间的信号流方向（箭头）
   - 信号类型标注（光信号/电信号/数字信号）
   - 关键参数标注（速率、波长、调制格式等）
   - 反馈环路（如有）

4. **定义布局方案**

   - 整体布局方向（推荐左→右，符合信号流阅读习惯）
   - 分区方式（发射端 / 信道 / 接收端三区，或其他）
   - 研究重点模块的视觉强调方式（加粗边框/底色/★标注）

5. **写出引导句和分析句草稿**

   - 引导句（图前 1 句）：指向图的内容和阅读重点
   - 分析句（图后 2-3 句）：从图中提炼关键信息，衔接正文论述

**检查点**：规格文档完整覆盖以上 5 项，任何人拿到规格都能画出目标图。
