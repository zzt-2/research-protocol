# PROMPT-003: AI 痕迹判断标准建立 + 全文 AI 痕迹定位

> 创建: 2026-06-04 | 优先级: P1（第一轮结构性问题，与 P-002 并行）
> 依赖: P-001（预装规范 B1/B2 已就绪，子 agent 可直接引用）
> **警告: 产出将被多个后续 PROMPT 引用，质量必须过关**

## 目标

建立"什么样的语言是机器语言"的判断标准，然后对 kaiti-report.md 全文做 AI 痕迹定位扫描。产出是一份**AI 痕迹定位报告**（标记问题段落 + 问题类型 + 严重度 + 改写方向），供后续 PROMPT-007/008/010/011 执行实际改写时使用。

注意：本 PROMPT **不做改写**，只做定位和分类。改写由后续 PROMPT 负责。

## 子 Agent 策略

本 PROMPT 工作量较大（精读范文 + 全文扫描），建议拆分为 3 个子 agent：

### 子 Agent A：范文精读 — 提取正常学术写作特征

**输入**: 闫佳欣和曾嘉两篇范文
**任务**:
1. 精读两篇范文的绪论和研究方案部分（与 kaiti-report.md 对应的章节）
2. 提取"正常学术写作"的以下特征：
   - 句式结构特征（平均句长、并列句式频率、从句嵌套深度）
   - 衔接手段特征（衔接词密度、语义承接比例、段首句接法分布）
   - 动词/措辞特征（有力动词使用频率、AI 高频词出现次数）
   - 段落节奏特征（论断-展开-收束的比例、先扬后抑的使用频率）
   - 研究方案写法特征（方向之间的区分度、技术细节密度、与绪论的呼应方式）
3. 按 R011 的句子功能标注体系（DEF/FACT/CLAIM/EVAL/TRANS/GAP/NEED/CITE）标注范文中的典型段落
**输出**: 一份"正常学术写作特征清单"（≤1500 字），含具体示例行号和量化数据
**时间限制**: 12 分钟

### 子 Agent B：AI 痕迹全文扫描

**输入**: kaiti-report.md 全文 + B1 规则 + R011 §7-§8 + 子 Agent A 产出的正常特征清单
**任务**:
1. 逐段扫描 kaiti-report.md 全文（L1 至文末），用 B1 的 5 类标准逐段判定
2. 每个有问题的段落记录：
   - 行号范围
   - 所属章节
   - 问题类型（翻译腔/清单体/元叙述/数据堆砌/平行罗列，可多选）
   - 严重度（重度/中度/轻度）
   - 具体问题句子摘录（1-3 句）
   - 改写方向（一句话说明应如何改写）
3. 已知重点段落必须特别仔细扫描：
   - L117-492（整个研究方案）
   - L406-430（§3.4.4 三个方向）
   - L651 附近（可行性分析末尾）
   - L23 附近（长并列句式）
   - L41-62（研究概况段）
**输出**: AI 痕迹定位报告（表格形式，见产出格式）
**时间限制**: 12 分钟

### 子 Agent C：交叉验证

**输入**: 子 Agent B 的扫描报告 + kaiti-report.md 原文
**任务**:
1. 抽查子 Agent B 报告中的 30% 条目（至少覆盖每个严重度等级各 2 条）
2. 验证判定是否准确（问题类型是否匹配、严重度是否合理、改写方向是否可行）
3. 检查是否有遗漏的严重段落（B 未标记但实际有 AI 痕迹的段落）
4. 如发现误判或遗漏，修正报告
**输出**: 验证通过的报告 + 修正意见（如有）
**时间限制**: 10 分钟

## 工作步骤

### Step 1: 启动子 Agent A（范文精读）

- 派子 Agent A 精读闫佳欣和曾嘉范文
- 指令中包含 R011 的句子功能标注体系和段落节奏公式
- 明确要求：只读与 kaiti-report.md 对应的章节（绪论、研究现状、研究方案），不读实验结果和结论

### Step 2: 启动子 Agent B（全文扫描）

- 子 Agent A 完成后（或与 A 并行，但 B 需要在最终判定时参考 A 的产出）
- 读取 `毕设/写作质量规范.md` 中 B1/B2 规则
- 按 B1 的 5 类标准逐段扫描 kaiti-report.md
- 对已知重点段落（L23, L41-62, L406-430, L651）做放大镜式逐句分析

### Step 3: 交叉验证

- 子 Agent C 抽查 B 的报告
- 重点验证：重度段落的判定是否准确、改写方向是否可执行
- 如 B 漏标了明显问题段落，补充

### Step 4: 汇总产出

- 整合子 Agent B 和 C 的结果，形成最终的"AI 痕迹定位报告"
- 按严重度排序（重度优先）
- 为每个后续 PROMPT 标注其需要关注的条目

## 质量检查

以下检查项必须全部通过，否则迭代：

- [ ] **覆盖全部 5 类 AI 痕迹**（翻译腔/清单体/元叙述/数据堆砌/平行罗列），每类至少定位 2 处实例
- [ ] **重度段落不少于 8 处**（导师说"通篇"，如果只有 3-4 处重度说明扫描不够仔细）
- [ ] **已知被点名段落全覆盖**：§3.4.4 L406-430、可行性分析 L651、L23 长并列必须标记为重度
- [ ] **改写方向可执行**：每条的改写方向必须具体到"用什么模式替代"（如"用先扬后抑替代平铺罗列"），不能只说"改写"
- [ ] **与范文对比有据**：至少 3 处改写方向引用范文的具体段落作为参照
- [ ] **无遗漏严重段落**：子 Agent C 的抽查未发现 B 漏标的重度段落（或漏标的已补充）
- [ ] **严重度分级合理**：被导师点名的段落必须是重度；有明显问题但未被点名的段落标中度；轻微倾向标轻度

## 不要做什么

- **不做任何改写**：本 PROMPT 只定位和分类，不改写任何段落。改写由 P-007/008/010/011 负责
- **不扩展 B1 规则**：B1 的 5 类标准已在 P-001 冻结，本 PROMPT 引用不改
- **不讨论"是否用 AI 写的"**：导师已定性为 AI 痕迹过重，不需要讨论，直接定位问题
- **不在报告中写大段分析**：每条记录控制在 3-5 行（行号 + 类型 + 严重度 + 摘录 + 改写方向），不写段落
- **不跳过任何章节**：导师说"通篇"，全文每个段落都必须扫描到，包括看起来"还行"的段落
