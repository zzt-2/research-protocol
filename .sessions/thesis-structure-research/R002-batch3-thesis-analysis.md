# 第二批博士论文结构分析（4篇）

## 低轨卫星宽带光控毫米波相控阵关键技术研究_夏师懿

**（中科院微小卫星创新研究院，2023年，导师：李国通）**

### 与卫星网络/资源管理/路由的相关性

**弱相关。** 该论文研究的是低轨卫星天线/相控阵硬件技术（光控波束成形、RF-OAM、降维相控阵），属于射频/光学硬件层，不涉及网络层路由或资源调度算法。对我们"LEO路由→ISL调度→抗毁"3章结构的参考价值有限，但仍有结构模式可供借鉴。

### 1. 章节结构

| 章节 | 主题 |
|------|------|
| Ch1 | 绪论：LEO卫星天线发展现状、光控相控阵挑战、RF-OAM、降维相控阵文献综述 |
| Ch2 | 基于用户差异性的低轨互联网卫星波束覆盖方式分析（系统级仿真论证灵活波束的必要性） |
| Ch3 | 宽带相控阵波束成形及光控相控阵在透传卫星网络的应用（AWGR架构+实验验证） |
| Ch4 | 基于低轨通信卫星的矢量光控毫米波波束成形（矢量合成原理+实验验证） |
| Ch5 | 光子射频轨道角动量生成和波束合成与转向（集成芯片方案+实验验证） |
| Ch6 | 降维相控阵（矩阵映射理论+SVD压缩+PSO/Transformer优化+实验验证） |
| Ch7 | 总结与展望 |

主体章节：5章（Ch2-Ch6），每章一个独立技术问题。

### 2. 章间衔接方式

绪论1.5节明确说明各章内容，但**无章节关系图**。各章之间没有显式的逻辑递进关系——Ch2是系统级分析（论证需求），Ch3-Ch6分别解决不同的技术挑战（宽带斜视、矢量合成、RF-OAM、降维）。衔接方式为"并列并列"，仅在绪论中用"挑战1→第3章、挑战2→第4章..."的方式做了对应。

### 3. 共享元素

- **系统模型**：Ch2建立了低轨卫星波束覆盖模型（OneWeb/SpaceX对比），但Ch3-Ch6不再使用该模型，各自独立建模
- **方法论**：不统一。Ch2是仿真分析，Ch3-Ch5是"原理+实验验证"模式，Ch6是"理论推导+仿真+实验"
- **仿真/实验平台**：不统一。Ch2用系统仿真，Ch3-Ch5各自搭建光控实验平台，Ch6设计电路板实验

### 4. 各章独立性

| 章节 | 独立问题建模 | 独立算法/方法 | 独立实验 | 可独立发表 |
|------|-------------|-------------|---------|-----------|
| Ch2 | 有（用户-波束覆盖模型） | 有（性能对比仿真） | 有 | 是 |
| Ch3 | 有（AWGR原理） | 有（光控波束成形） | 有（实验平台） | 是 |
| Ch4 | 有（矢量合成原理） | 有（光功率控制波束扫描） | 有（实验平台） | 是 |
| Ch5 | 有（RF-OAM原理） | 有（双波长集成芯片） | 有（实验平台） | 是 |
| Ch6 | 有（矩阵映射理论） | 有（SVD压缩+PSO/DL优化） | 有（电路板实验） | 是 |

每章完全独立，可各自发表。

### 5. 结构模式归类

**问题分解型（并列式）。** Ch2论证需求，Ch3-Ch6分别解决4个独立的技术挑战。章节之间无递进依赖，是同一方向下不同技术点的并列展开。

### 6. 对我们的启发

- **借鉴**：该论文的"绪论→需求论证章→多个并列技术章"结构清晰，绪论中将挑战与章节一一对应的写法值得学习
- **避免**：该论文各章方法论不统一（仿真/实验混合），缺乏统一的数学框架。我们计划用GNN+DRL统一框架贯穿3章，这在方法论连贯性上会显著优于这种并列式
- **注意**：该论文5个主体章偏多，每章篇幅相对较短。我们3章结构更集中，每章可以做更深

## 低轨卫星星座网络IP路由技术研究_晏坚

**（清华大学电子工程系，2010年，导师：曹志刚）**

### 与卫星网络/资源管理/路由的相关性

**高度相关。** 这是LEO卫星星座网络路由方向的经典博士论文，直接研究IP路由技术，与我们的LEO路由章节高度对应。

### 1. 章节结构

| 章节 | 主题 |
|------|------|
| Ch1 | 绪论：LEO卫星星座通信系统背景、我国发展需求、卫星IP组网技术 |
| Ch2 | 低轨卫星星座网络路由问题分析与建模（网络模型+路由解耦+仿真平台） |
| Ch3 | 低轨卫星星座拓扑结构特征分析（最小跳数 vs 最短延时路径的理论+仿真验证） |
| Ch4 | 低轨卫星星座网络静态路由算法（快照序列分析+RDBR算法提出+仿真） |
| Ch5 | 低轨卫星星座网络动态路由算法（业务负载建模+RDBAR算法提出+QoS扩展） |
| Ch6 | 总结 |

主体章节：3章（Ch3-Ch5），加上建模基础章Ch2共4章。

### 2. 章间衔接方式

**递进式衔接，非常紧密。** 绪论1.5节详细说明各章关系：
- Ch2建立网络模型和仿真平台（基础设施）
- Ch3分析拓扑特征，得出"最小跳数可替代最短延时"的关键结论（理论基础）
- Ch4基于Ch3结论设计静态路由算法RDBR（理论→算法）
- Ch5在Ch4基础上扩展为动态路由算法RDBAR，并增加QoS机制（算法→增强）

Ch3的结论直接支撑了Ch4/Ch5的算法设计——正是因为"最小跳数路径集合中各路径延时差别不大"，才可以放心地在RDBR/RDBAR中使用跳数而非延时作为路由度量。

### 3. 共享元素

- **系统模型**：统一。Ch2建立的网络模型（N/P/F:h:i:theta星座参数、曼哈顿网络描述）被Ch3-Ch5共享使用
- **方法论**：统一。各章均采用"理论/算法分析 → 仿真验证"的研究范式
- **仿真平台**：统一。Ch2.5设计了完整的仿真平台（网络模型、卫星节点模型、终端模型、信关站模型），后续章节均在此平台上进行仿真
- **路由度量**：统一。Ch3确立"跳数代替延时"的度量基础，Ch4/Ch5一致使用
- **算法家族**：统一。RDBR（Ch4）和RDBAR（Ch5）属于同一"反向探测"算法族，后者是前者的增强版

### 4. 各章独立性

| 章节 | 独立问题建模 | 独立算法/方法 | 独立实验 | 可独立发表 |
|------|-------------|-------------|---------|-----------|
| Ch2 | 有（统一模型） | 有（路由解耦方案） | 有（仿真平台） | 部分（基础性工作） |
| Ch3 | 有（拓扑分析） | 有（遍历仿真验证） | 有 | 是（理论结论型论文） |
| Ch4 | 依赖Ch3结论 | 有（RDBR算法） | 有 | 是 |
| Ch5 | 依赖Ch4 | 有（RDBAR算法+QoS） | 有 | 是 |

Ch3-Ch5各自可以独立发表，但它们之间存在理论依赖关系（Ch3→Ch4→Ch5），构成递进链。

### 5. 结构模式归类

**层次递进型。** 典型的"建模→理论分析→算法1→算法2（增强版）"递进链。每一步都是上一步的自然延伸，章节之间有明确的逻辑因果关系。

### 6. 对我们的启发

- **强烈推荐借鉴**：
  - **统一仿真平台**：Ch2一次建好仿真平台，后续所有章节共享使用，避免各章重复搭建。我们应在第1个主体章（或准备章）中统一建立LEO星座模型+仿真环境
  - **递进式章节关系**：先建立理论基础（如我们的GNN建模方式、ISL拓扑特征），再依次展开各章算法
  - **统一算法族**：RDBR→RDBAR属于同一算法族，后章是前章的增强。我们3章虽然问题不同（路由/调度/抗毁），但可以用统一的GNN+DRL框架串联，形成"方法族"
  - **Ch3的理论支撑写法**：该论文用一整章做拓扑特征分析，为后续算法设计提供理论依据。我们可以考虑在第一个主体章中先做ISL网络拓扑特征分析，为后续调度和抗毁策略设计提供基础

- **需注意**：
  - 该论文只有3个核心贡献章（Ch3-Ch5），与我们的3章结构完美对应
  - 2010年的论文，仿真基于离散事件仿真器，没有DRL/ML方法。我们的方法论比它复杂，需要额外说明GNN+DRL框架的统一性

## 低轨卫星移动通信系统中的信道分配策略研究_董燕

**（华中科技大学，2007年，导师：黄载禄/王宏远）**

### 与卫星网络/资源管理/路由的相关性

**相关。** 研究LEO卫星系统中的信道分配和切换管理，属于无线资源管理范畴。与我们的资源调度主题有关联（都是卫星资源管理），但侧重物理层/链路层的信道分配，不是网络层的路由/调度。

### 1. 章节结构

| 章节 | 主题 |
|------|------|
| Ch1 | 绪论：LEO卫星移动通信背景、无线资源管理、信道分配研究概况 |
| Ch2 | 基础与概论：LEO卫星通信系统概述、优缺点分析、网络仿真模型 |
| Ch3 | 基于全局业务量预测和随机控制的动态信道分配（PSCCA策略） |
| Ch4 | 基于效用函数的多业务卫星通信系统自适应信道分配模型（数学建模） |
| Ch5 | 基于智能计算的多业务自适应信道分配算法（GA+PSO求解Ch4的模型） |
| Ch6 | 低轨卫星-地面综合通信系统的体系结构研究（卫星+地面Ad Hoc综合） |
| Ch7 | 总结与展望 |

主体章节：4章（Ch3-Ch6）。

### 2. 章间衔接方式

**混合式衔接。** Ch3-Ch5有递进关系（Ch3解决单业务场景→Ch4建模多业务场景→Ch5求解Ch4的优化问题），Ch6相对独立（体系结构层面的问题）。绪论1.5节用一段话简要说明各章安排，没有章节关系图。

关键递进链：Ch4提出数学模型（有约束非线性规划）→ Ch5设计智能计算算法（GA、PSO）来求解该模型。这是一个典型的"建模→求解"两章递进结构。

### 3. 共享元素

- **系统模型**：统一。Ch2建立了SFC（Satellite-Fixed Cells）波束覆盖模型和仿真平台，Ch3-Ch5共享
- **方法论**：部分统一。Ch3-Ch5都是"策略/模型提出 → 仿真验证"，但具体方法不同（随机控制/非线性规划/智能计算）
- **仿真平台**：统一。Ch2描述的仿真模型被后续章节共享
- **问题域**：Ch3-Ch5共享"信道分配"这一核心问题，只是场景不同（单业务→多业务，策略→求解算法）

### 4. 各章独立性

| 章节 | 独立问题建模 | 独立算法/方法 | 独立实验 | 可独立发表 |
|------|-------------|-------------|---------|-----------|
| Ch3 | 有（PSCCA策略） | 有（随机控制） | 有 | 是 |
| Ch4 | 有（效用函数模型） | 有（非线性规划建模） | 部分（模型提出，求解在Ch5） | 部分（需要Ch5配合） |
| Ch5 | 依赖Ch4模型 | 有（GA+PSO算法） | 有 | 部分（与Ch4联合发表） |
| Ch6 | 有（综合体系结构） | 有（负荷分担机制） | 有（协议设计） | 是 |

**注意**：Ch4+Ch5构成一个整体（建模+求解），不能分开独立发表。Ch3和Ch6各自独立。

### 5. 结构模式归类

**混合型。** Ch3-Ch5是"问题深化+方法递进"（单业务→多业务→智能求解），Ch6是独立的体系结构研究。整体上是递进型与并列型的混合。

### 6. 对我们的启发

- **借鉴**：
  - Ch2"基础与概论"章的写法：将系统模型、仿真平台、评价指标统一在一章中介绍，后续章节直接引用
  - Ch4+Ch5的"建模→求解"两步走结构：如果我们的某章涉及复杂的优化问题，可以分为"问题建模"和"算法设计"两部分
  
- **避免**：
  - Ch4和Ch5过度拆分导致两章都不能独立成文。如果我们3章中的某一章内容特别多，可以在同一章内分节处理，不必拆成两章
  - Ch6与前面章节的主题关联度较弱（从信道分配跳到体系结构），让人感觉像拼凑。我们3章应保持主题的紧密关联（路由→调度→抗毁都是网络层问题）

- **对比**：该论文4个主体章，但Ch4+Ch5实质是一个贡献，Ch6是另一个方向，实际独立贡献只有2.5个。我们3章每章一个独立贡献，比它更紧凑

## 低轨卫星网络中的路由策略研究_金骥丰

**高度相关，最强参考。** 该论文直接研究LEO卫星网络路由策略，包含负载均衡、抗毁、日凌应对三大主题，与我们的"LEO路由→ISL调度→抗毁"结构高度对应。且该论文来自同一导师（李国通），与夏师懿同组。

|------|------|

### 5. 结构模式归类

**场景拓展型。** 核心结构是：同一网络中的不同场景（正常→意外故障→可预测故障→地面站优化）。每个场景有独立的挑战和算法，但共享网络模型和理论基础。这是典型的"1个方向→N个场景→N个算法"结构。

### 6. 对我们的启发

- **强烈推荐借鉴**：
  - **"场景拓展"结构模式**：该论文用3章分别处理3种路由场景（负载均衡/意外故障/日凌），与我们"路由→调度→抗毁"3个问题/场景的结构完美对应
  - **每章独立的仿真平台设计**：虽然共享基础模型，但每章有自己的仿真平台小节，使得每章完全自包含。我们可以在共享LEO星座模型的前提下，每章独立设计仿真场景
  - **绪论中的论文组织结构图**：图1-8用流程图展示了各章的逻辑关系，非常直观。我们应在绪论中加入类似的结构图
  - **统一的理论基础章（Ch2）**：将星座构型、链路模型、流量模型、路由模型统一放在一章中，后续各章直接引用
  
- **需注意的差异**：

## 本批共性发现

### 1. "理论基础/基础模型"章的普遍性

4篇论文中，有3篇（晏坚、董燕、金骥丰）都设置了独立的"基础与概论"章（通常为Ch2），用于：
- 定义系统模型（星座构型、链路类型、网络拓扑）
- 描述仿真平台设计
- 建立评价指标体系

这已经成为该领域博士论文的标准结构。我们应在第一个主体章之前或之内，建立统一的LEO星座模型+GNN+DRL框架。

### 2. 主体章节数量：3-4章为主流

- 夏师懿：5章（但该论文是硬件技术，问题较碎）
- 晏坚：3章（Ch3-Ch5）
- 董燕：4章（Ch3-Ch6，但Ch4+Ch5实质是一个贡献）
- 金骥丰：4章（Ch3-Ch6，但Ch6是附加贡献，核心3章）

**核心贡献章3章是主流选择**，与导师要求的"1个方向→3个互相关联问题→3章主体"完全吻合。

### 3. 章节关系：场景拓展型和层次递进型最常见

- 晏坚：**层次递进型**（理论→静态算法→动态算法），章节之间有强依赖
- 金骥丰：**场景拓展型**（负载均衡→抗毁→日凌），章节之间独立但共享模型
- 董燕：**混合型**（递进+独立混合）
- 夏师懿：**问题分解型**（并列独立）

对我们而言，**场景拓展型+层次递进型的混合**可能最合适：
- Ch2 统一框架（GNN+DRL理论基础）
- Ch3 LEO路由（负载均衡场景）
- Ch4 ISL调度（资源分配场景，可复用Ch3的拓扑理解）
- Ch5 抗毁（故障场景，可复用Ch3/Ch4的算法+增加容错机制）

这样既保持每章独立性（可独立发表），又有方法论和模型的统一性。

### 4. 论文组织结构图的价值

金骥丰的论文在绪论中配有"论文组织结构图"，直观展示各章关系。在4篇中效果最好。**建议我们在绪论中加入类似的章节关系图。**

### 5. 仿真平台策略的差异

| 论文 | 仿真平台策略 | 优缺点 |
|------|-------------|--------|

### 6. 对我们3章结构的具体建议

综合4篇论文的经验，我们"LEO路由→ISL调度→抗毁"3章结构建议：

1. **设置统一的理论基础章**（Ch2）：包含LEO星座模型、ISL拓扑特征分析、GNN建模方法、DRL训练框架、仿真平台描述
2. **3个核心章按场景展开**（Ch3-Ch5）：路由（正常场景）→调度（资源分配场景）→抗毁（故障场景），每章有独立的问题定义+算法+实验
3. **统一的GNN+DRL框架贯穿3章**：这是我们的方法论优势，比以上4篇论文的方法论统一性都强
4. **绪论中加入章节关系图**：参考金骥丰的图1-8
5. **每章结尾显式引出下一章**：参考晏坚的递进式衔接，让3章形成"正常→优化→容错"的逻辑链
