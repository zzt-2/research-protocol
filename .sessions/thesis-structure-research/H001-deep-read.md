# PROMPT: 精读博士论文目录与章节衔接，细化我们的论文结构

## 背景

导师要求学位论文结构为"1个大方向 → 3个互相关联的问题 → 3章主体"。我们已完成博士论文结构调研，找到 5 篇卫星/空间网络方向的中国博士论文并提取了全文目录。

调研结论：**方案 A（路由+ISL调度+抗毁）**是最优选择，与通信方向博士论文主流结构高度吻合。

现在需要精读这 5 篇论文的全文 markdown，重点看：
1. 每篇的章节间如何衔接（章末有没有"本章结果为下一章提供基础"的显式衔接）
2. 共享的系统模型/技术栈具体是什么
3. 各章的独立性如何体现（能否独立发表）
4. 对我们的 3 章结构（路由→ISL调度→抗毁）有什么具体启发

## 任务

### Step 1: 精读 P0 论文（冷涛 + 刘晔祺）

对每篇论文，用子 agent 精读全文 markdown，提取：

```
论文标题: xxx
学校/作者: xxx

## 章节间衔接分析
- 第N章末尾如何过渡到第N+1章？（引用原文）
- 各章之间有没有共享的变量/结果？

## 共享元素
- 系统模型: 各章是否用同一星座/拓扑？
- 技术栈: 各章是否用同一算法框架？
- 仿真平台: 各章是否共享仿真参数？

## 各章独立性
- 每章能否独立投稿？（有自己的问题建模+算法+实验）
- 各章对应的期刊/会议发表情况（如能从致谢/参考文献推断）

## 对我们的启发
- 哪些写法值得借鉴？
- 哪些结构要避免？
```

### Step 2: 精读 P1 论文（万莹）

同上格式，重点看"场景拓展型"的3章如何设计递进的约束条件。

### Step 3: 综合分析

基于精读结果，为我们的论文设计具体的 3 章结构：

```
第1章(主体): 标题 + 一句话描述 + 对标哪篇论文的哪一章
第2章(主体): 标题 + 一句话描述 + 如何与第1章衔接
第3章(主体): 标题 + 一句话描述 + 如何与前两章衔接

共享元素:
- 系统模型: xxx
- 技术栈: xxx
- 仿真平台: xxx

章间衔接设计:
- 第1章→第2章: xxx
- 第2章→第3章: xxx
```

## 约束

- **全文精读必须在子 agent 中执行**，主对话只接收结构化摘要（每篇 ≤800 词）
- 优先精读 P0（冷涛+刘晔祺），有剩余精力再读 P1（万莹）
- P2 两篇可跳过，除非 P0/P1 的信息不足以支撑结论
- 最终输出：更新 `.session/thesis-structure-research/analysis-report.md` 中的"五、最终建议"部分
