## 调研问题

H002 提出的核心问题（用户原话"总感觉咱们思路不太对。要不先看看别人在这个领域硕士毕业都是做的什么工作？"）拆成 5 个校准问题：

1. 硕士论文的方法章典型形态是什么？（一个方法+仿真？方法对比？解析+仿真？纯FPGA？）
2. 他们选的物理问题，和我们撞不撞？（撞了人家毕业了 → 问题不在"做不出来"）
3. 有没有我们完全没想到的角度？
4. 工作量量级（多少仿真/多大对比/几个场景）——校准我们是不是把标准定太高了
5. 推翻 vs 验证：若别人做的就是我们试过的家族 → 问题在执行/包装；若完全不同 → 跟着换路径

### F3. 路径1 决定性证据：换形态真能避开 A3 死法

精读 4 篇 CPE 硕士论文（张思齐/丁爽/董凡/李明洋）的物理设定/信道模型/参数溯源。**全文检索 `自适应光学/Greenwood/Paillier/159Hz/300kHz/1885/gain_fill/MVE/AO 残余/变形镜/波前传感器` 全部 0 命中**。

- **4 篇里 0 篇用 AO**。前序 A3 把"AO 残余参数（Greenwood 时延/高阶残差带宽 300kHz）"作为方法可行性核心变量，是前序独有的过严设定，这个赛道里别人根本不这么玩
- **主流可毕业设定**：湍流直接灌进 DSP、无 AO 校正（张思齐明说"FOE 不考虑光强闪烁"；董凡用 D<<r0 点接收假设绕开波前校正）
- **关键逃生通道**：丁爽/董凡把线宽做成 `Δν·Ts` 无量纲乘积扫描，规避了绝对线宽/绝对 AO 残余带宽的物理溯源压力——这正好是前序 A3 缺的招
- **Cn²=10⁻¹⁶ 弱湍流是行业惯例值**，4 篇里只有董凡标了公式来源，3 篇数值都不标文献——TL-26/FR-20 在别人硕士论文里**普遍没被执行**。前序 A3 死在参数溯源，不是这个赛道的普遍风险点
- **A3 和张岱 4.6 聚类 M-DPSK 是直接同源对照工作**：同任务（相位恢复），一个导频、一个盲聚类。前序 A3 的国内同期对照基线

**结论**：换"算法改进 + 仿真/FPGA"形态做 CPE 在星地 FSO 下，**能避开前序 AO 残余膨胀 1885× 的死法**。前序 A3 死在"自设过严物理前提（AO 残余）+ 该前提参数没溯源"的复合死法，不是"CPE 在湍流下不可行"。

### F4. 路径3 决定性证据：张岱方法章是"链式兜底"，不是单点突破

张岱博士论文（国防科大 2018，标题几乎一字不差贴合开题）的 4 个方法章组织逻辑：

**物理问题顺序**（偏振→波前→多径→编码）背后是**信号处理链路顺序**（光学损伤→探测→均衡→纠错），不是单纯物理影响层级。每章前置是结构性需要，不是物理重要性排序。

**两条串联机制**（都是设计的，非偶然）：
1. **物理信号链串联**（第 4-5 章）：4.2 相位屏造畸变 → 4.4/4.5 校正 → 4.6 相位恢复 → 5.4 均衡 → 6.3 纠错。每个子方法都是上游方法输出再处理
2. **物理量串联**（第 3-5 章）：退偏振比。3.3 产出"退偏比↔光学厚度"对应 → 5.3 消费做"退偏比→速率"查表。摘要/小结/引言六处反复强调

**最值得借鉴的范式**："**绕开一个解法 → 必然产生新代价 → 配一个兜底方法**"（4.5 自差 DPSK 绕开 AO/CPE → 4.6 聚类补自差残留畸变）。**这是"一选一弃，弃的代价要新方法补"**——和前序"单点突破反复试错"完全相反。

**硕士级可单做的子方法**（去掉博士广度）：
- 4.6 聚类 M-DPSK 相位恢复（仿真门槛最低）
- 6.3 交织方案 + post-FEC BER 分析式（**最契合 FPGA 背景**）
- 4.2 子频带相位屏（纯数字仿真）
- 5.4 SM-BNMCMA（有现成 CMA 代码可改）

**方法章组织模式（综合张岱博士+吴志航硕士）**：
- 标杆方法章 = "**DSP 流水线综述章 + 1-2 个核心创新章**"，不是单点突破
- 吴志航写法尤其值得借鉴：第3章把"时钟恢复→均衡→频偏→相位估计"4 个标准 DSP 模块做综述，A3 自然嵌入这条流水线，不再孤立
- 物理问题高频排序：**波前畸变 > 相位恢复 > 信道均衡 > 偏振/多径/编码**

### F5. 完全没碰过的新角度（0 撞前序）

- **信道估计/均衡**（B 组 4 篇）：惠佳欣（EM/GMM/CRB 统计估计）、高悦（CNN 深度学习联合估计）、夏煜（CMA/DDLMS + FPGA + 板级）、佟欣（变步长 CMA-LMS）。**0 撞前序**。注意"信道估计用导频"和前序"导频辅助 CPE"不是一回事，要区分
- **分集补湍流**（C 组 3 篇）：孙晶（空间分集 MRC/EGC/SC 解析）、尹涵（少模光纤模式分集 + MIMO 均衡，OSNR 节省 1.8-3dB）、王敏艳（MIMO+EGC+自适应MPSK）。**尹涵是 C6（多模/阵列分集 piston）最直接先例**——但尹涵补的是"模态能量回收"，不是严格的 piston 项补偿，孙晶/王敏艳补的是辐照度衰落

### F6. FPGA 背景是优势不是劣势

闫佳欣/曾嘉/董凡/夏煜/丁爽证明：**"算法创新 + FPGA 验证"是 viable 毕业路**，配方是"选 DSP 子问题 → 对比经典算法 → 提低复杂度/并行变体 → RTL + 板级 BER"。算法创新和 RTL 工作量各占一半。

**可毕业配方（闫佳欣+曾嘉+董凡+丁爽归纳）**：选定一个相干光 DSP 子问题（如 OFDM 整数倍频偏 / IQ 失衡补偿 / 定时同步 / QPSK 载波恢复）→ 对比 2-3 种经典算法 → 提并行化/低复杂度/低时延变体（核心创新点，必须独立于硬件，用复杂度公式 O(·) 量化）→ FPGA RTL 实现（并行度、位宽、流水线级数）→ 联合仿真 → 可选板级实时实验（真链路 BER）

**指标提升典型量级**：复杂度从 O(N³)→O(N²)、估计错误率 ≤1×10⁻⁴、可校正相位偏差 ±30°、可校正定时频偏 200ppm、SNR/OSNR 损失 <0.2-0.5dB、速率 1.25-25 GBaud、BER 0~<1×10⁻⁹。

**反例（白佳俊）**：纯离线经典算法应用 + 室内短距实验，算法创新点几乎为零（仅算法选择），正是 C5 Killed 的死法。但 GSOP/FFT 频偏/松尾环/Gardner 这套经典算法链是 QPSK 解调标准件，后续工作都在这上做并行化/低复杂度变体——**不要复制白佳俊的形态，但可复制他的"标准件选择"作为 baseline**。

### F7. 工作量量级校准

硕士论文级指标提升**不需要很大**（dB 级即可），重点在方法闭环和对比充分：
- SNR/灵敏度 dB 级：0.15–0.76 dB（张思齐、丁爽），多为个位零点几 dB
- 复杂度下降 %：13.7%–83%
- 实时速率：2.5–12.16 GBaud
- 误码率量级：10⁻⁵–10⁻⁷（板级实测）

**前序 MVE/FR 门控标准偏严**——前序把硕士论文当成博士级物理可行性论证在做（FR-21 oracle 上界 <0.5dB 即 Kill，TL-26 参数溯源强制执行）。这套纪律本身没错，但用在"硕士论文方法章"这个尺度上太重了。

### F8. 路径2 决定性证据：新角度方法空间量化 + C6 piston 物理可行

深挖 5 篇信道估计/均衡/分集类论文（惠佳欣/高悦/夏煜/佟欣/尹涵）的**方法空间饱和度 + 已做烂子问题 + C6 piston 物理差异**。

**方法空间饱和度地图**：

| 子方向 | 代表 | 饱和度 | 剩余空间 |
|---|---|---|---|
| GG 分布参数估计（EM/GMM/N-R 三件套）| 惠佳欣 | **高** | 几乎做烂，MSE 逼近 CRB 已是天花板 |
| 探测噪声联合估计 | 高悦 | 中 | SISO 已占；MIMO+时序 DL 未做 |
| CMA 盲均衡算法变体 | 佟欣/夏煜 | **高** | 纯算法层无新空间，新算法只能算调参 |
| 盲均衡 FPGA 并行实现 | 夏煜 | 中 | 10Gbps/高阶调制/+LDPC 是明确扩展 |
| 模式分集（少模光纤）| 尹涵 | 高 | 物理增量小（作者自留"最优模式数+ML均衡"）|
| **阵列分集补 piston** | （5 篇无先例）| **低（空白）** | **5 篇全无触及 piston 相位补偿** |

**已做烂的子问题（避坑）**：
- **GG 分布参数 EM/N-R/GMM 三件套 + CRB 标尺**：惠佳欣+高悦连用，套路雷同，再做的增量只在"换噪声模型/换 DL 网络"
- **CMA 类盲均衡算法变体**（变步长、CMA+DDLMS、CMA+LMS）：佟欣+夏煜覆盖，纯算法无新空间
- **少模光纤 LP01+LP11 + LMS-MIMO 蝶形**：尹涵已验证 1.8-3dB 增益，复刻同等价于"换湍流强度重跑仿真"

**C6 piston 物理差异——能讲清（决定性）**：
- **尹涵补的是辐照度（幅度域 GG 模型），piston 是 Zernike Z₀⁰ 整孔径常数相位（相位域）——不同物理量**
- **piston 作为公共相位，不可被 MIMO 矩阵求逆消除**（LMS-MIMO 蝶形均衡器消不掉秩-1 公共相位子空间）→ C6 有独立物理基础，**不沦为尹涵复刻**
- 三重正交差异化：**阵列分集 vs 模式分集 / 补 piston vs 补模态能量 / 相位域 vs 幅度域**
- **风险点（C6 物理前提）**：阵列孔径需 > piston 相干长度，否则 piston 退化为全公共相位、阵列分集也失效。这是 C6 必须在论文中论证的前提

**还有真创新空间的子问题（机会点）**：
1. **piston 相位补偿 + 阵列分集**（5 篇空白，C6 方向）
2. **盲均衡 FPGA 工程化扩展**（夏煜自述 32 路/5Gbps 已达极限，10Gbps+高阶调制+LDPC 资源协同未做，**天然适配 FPGA 背景**）
3. **联合估计 MIMO 扩展 + 时序建模**（高悦自述仅 SISO，MIMO+RNN/LSTM 未做）
4. **均衡/估计的硬件闭环验证**（5 篇里仅夏煜有 FPGA 板级实测，"算法+硬件实现"组合仍稀缺）

**最强组合信号**：5 篇里 FPGA 实现仅夏煜 1 篇、piston 补偿 0 篇、阵列分集 0 篇——"**阵列分集 piston 补偿 + FPGA 实现**"是同时满足"方法空间低饱和 + 物理可讲清差异 + FPGA 背景可发挥"三条件的**空白交叉点**。但有风险：无直接先例可抄，需自建物理模型。

**对"新角度能否当主线"的综合判断**：
- **C6（阵列分集补 piston）**：方法空间低饱和、物理可讲清差异，但 FPGA 实现证据为零。若结合 FPGA 背景（"阵列分集 piston 补偿的 FPGA 实时实现"）可形成差异化主线；纯仿真则方法章偏薄
- **盲均衡 FPGA 扩展（夏煜路线）**：方法空间中饱和但有明确扩展点，FPGA 工作量证据最充分，硕士方法章+实现章最稳，但创新偏工程非物理
- **联合估计 MIMO+时序 DL（高悦路线）**：方法空间中饱和，无 FPGA 成分，适合算法导向
- **GG 参数估计（惠佳欣路线）**：高饱和，**不建议**作为新主线

### F9. 路径4 决定性证据：C6 空白性经涂奕聪强化（21 篇总量）

补样本 2 篇验证趋势：涂奕聪（华科 2020 硕士）《多孔径相干光接收机设计方法研究》+ 曹明华（中国激光 2020 期刊）《GG 湍流下超奈奎斯特光通信系统性能》。**本地累计精读 21 篇**。

**涂奕聪（C6 直接对照，最关键）**：
- 做的是**辐照度分集**（幅度域 GG）+ 各孔径独立载波相位对准（φ_n），4 路 EGC 合并增益 4.50dB
- **明确采用"点接收机模型"**抹掉孔径内波前结构，**全文 0 命中 piston/Zernike/r0/Fried 长度**
- 相位对准章（3.3）对准的是各孔径**独立载波相位延迟**，不是 piston（Z₀⁰ 公共相位）
- **作者自述缺陷**："未考虑接收天线孔径大小的影响，未考虑孔径平均效应"——**这恰好是 C6 要补的物理前提**
- DSP 用 V-V 算法（撞 CPE 家族），但是合并后的载波恢复，与 C6 物理层 piston 是两件事

**曹明华（FTN 超奈奎斯特，正交新角度）**：
- FTN 是脉冲成型/频谱效率维度（加速因子 τ<1 人为引入 ISI），**与前序 CPE/PCS/MCS/导频四家族物理层正交**
- 纯解析+MC 仿真，工作量轻，**对 C6/piston 主线无直接价值**（解决"带宽受限提速"非"低 SNR/相位损伤恢复"）
- 是 19 篇调研漏掉的新角度，但**不改变候选排序**

**路径4 核心结论**：补这 2 篇后，路径1/2/3 的结论**被强化而非修正**。C6 的"空白交叉点"判断经涂奕聪（辐照度分集）/尹涵（MIMO 模式分集）/曹明华（FTN）三个补样本**确认为真空白**——piston（相位域 Z₀⁰）× 阵列分集（多孔径 > r0）这个交叉点，在所有已读 21 篇里**无人触及**。涂奕聪的点接收机假设 + 自述缺陷，恰好印证 C6 必须显式建模"孔径尺寸 vs r0"的物理前提。

### F10. 首期调研误判修正（2026-06-18，用户质疑触发）

用户对首期调研（§F1-F9）提出三个质疑，核实后**首期 2 个候选方向被撤回**，根因是**首期未核对前序已有筛子**：

**误判 1：盲均衡 FPGA 扩展（方向2）被撤回**
- 前序 `R001-multi-dimension-direction-scan.md` 明确判定"**均衡 | LOW（GG flat fading）| LOW**"——星地 GG 湍流在典型带宽下近似平坦衰落，相干带宽 >> 信号带宽，ISI 不显著，均衡缺乏物理动机
- 夏煜（盲均衡 FPGA 样板）做的是**空空信道**（20km 航空多径），**不是星地**——题目不匹配
- 首期被"夏煜 FPGA 形态好看"带偏，**没核对物理基础和题目匹配**

**误判 2：C6 阵列分集补 piston（方向1）被撤回**
- 前序 `decisions.md` D 排除列#2：需专用/非通用硬件（光电硬件/非手上 FPGA 板）
- C6 物理本质需要**多个空间分离的接收孔径**（光电硬件），不是 FPGA 能模拟的

### F12. 第二轮精读决定性发现（第一批 5 篇）

**发现 1：前序"均衡 LOW"判断——部分成立，需限定边界**
- 赵远帆《空间相干激光通信信道均衡算法研究》（2024，青岛大学）的均衡**不是针对 GG 平坦衰落**——他**明确回避了大气湍流**（5.2 节："本文暂未考虑大气湍流"）
- 做的是 **(a) 接收机 I/Q 硬件不平衡均衡** + **(b) RF/NTN 卫星多径信道**（3GPP NTN-TDL，非光波 GG）
- **结论**：前序"GG 下均衡 LOW"仍对。但若绝对化为"空间激光通信均衡一律 LOW"则过窄——**I/Q 不平衡 + RF 多径场景下均衡有物理动机**。不过 I/Q 均衡偏"硬件补偿"，和题目"湍流信道"贴合度存疑

**发现 2：码型切换——作为主线风险高，但物理事实可借用**
- 陈亚玲《BPSK/QPSK 码型切换》（2024，长春理工）明确是**自适应反馈式**（收端估计 Rytov→阈值→反馈发端→切换），关键词自证"自适应调制格式切换"，**撞前序 ③ MCS + TL-03/04**
- **修正判断**（用户质疑触发）：不该说"码型切换这条线排除"。准确说法是——"**自适应反馈式**调制调度"撞 ③，但"码型切换"大类还有开环/静态形态理论上不撞。**只是任何有意义的"切换"都带自适应味道**（切换的物理动机就是信道变差时降阶），去掉自适应后退化为"固定选一个码型"，不再算"切换"
- 陈亚玲揭示的"BPSK/QPSK 在不同湍流下性能差异"这个**物理事实**可被其他方向借用（如编码层根据湍流强度选码）

**发现 3：4b 编码层——确认能做，是目前证据最强的方向**
- 唐承茂《空空抗突发错误交织编码+FPGA》（2025，电子科大）：编码层（Polar+卷积交织）+ FPGA 完整 RTL + 板级验证，**直接样板**。物理问题=湍流时变突发误码（Markov 双状态链+LCR/AFD，与张岱第6章同根）
- 王秋悦《LDPC 星地光通信》（2020，武大）：星地场景最贴，但编码层方法无创新（标准 LDPC 应用对比），真正贡献在星地三层功率谱闪烁模型
- **编码层评估**：能做硕士方法章（唐承茂样板）+ 不撞 CPE/PCS/MCS/导频（前提不做闭环自适应）+ FPGA 天然匹配 + 物理基础扎实（突发误码不依赖 AO/相干前提，不撞 Paillier 框）
- **方法创新空间**：纯算法新意薄（FEC 理论成熟），创新必须靠"**编码×湍流信道耦合设计**"（交织方案×湍流联合、突发错误定制编码）或"**编码×FPGA 工程创新**"（低时延高吞吐结构）。已做烂：标准码型选型对比、静态参数扫描、标准译码器 FPGA 重实现

**发现 4：张学锋《损伤抑制》（2023）——CPE 家族的 FPGA 形态参考**
- 做 FOE+CPE，撞前序 CPE 家族，但给完整"算法→MATLAB→FPGA 实时→资源量化"硕士级工作模板
- 核心贡献：反馈式 FOE 挑战前馈成见（±920MHz 跟踪范围 vs 前馈 ±312.5MHz）
- 对 FPGA 背景调研者：硬件实现经验可迁移，方法新意薄

**证据不支持"完全推翻前序思路"，但支持"调整方法形态 + 收窄单点突破策略"。**

- **A3 家族赛道是对的**——8 篇撞且是主流。前序 A3 死在 AO 残余参数 1885× 膨胀（TL-26/27），**不是赛道错，是参数溯源没做 + 物理可行解空间倒推路子太窄**。同样的 CPE 子问题，别人用"算法+仿真/FPGA"形态毕业了（路径1 决定性证据）
- **N1/③ 该放弃**——PCS 是光纤支流（星地 FSO 硕士论文 0 篇用），MCS 只能当辅助子模块
- **新候选该纳入**：信道估计/均衡（0 撞）、分集补湍流（C6 有尹涵先例）、DSP 流水线架构（吴志航式综述+创新）、张岱式"链式兜底"组织范式

### F13. 4b 编码层"编码×湍流耦合"创新空间深挖（2026-06-18，3 篇子 agent 精读）

三篇关键文献一手精读（唐承茂 2025 空空交织 FPGA / 张岱 2018 第6章 post-FEC BER / 王秋悦 2020 多元 LDPC 展望），回答 4 个子问题。

**关键证据（已逐条核对原文行号）**：

1. **唐承茂 L2053 自留"交织器开关"展望**（原话）："后续可以考虑设计交织器开关，对于特定湍流条件才使用交织器，以此减小传输时延"——本质即"信道感知条件性启用交织"，作者仅展望未实现
2. **唐承茂 L448-468 LCR/AFD 框架已建但未用于参数自适应**：突发长度 Lburst≈800 静态估算（L1082），交织深度 B=27/D=38 静态固定（L1247）。LCR/AFD 框架与交织参数间未建立动态映射
3. **张岱第6章解析式 5 条明确局限**：① "一个交织周期内仅有一次集中突发误码"假设过强（L2709）；② 突发码组内误码数人为设为 t+1（L2715）；③ pre-FEC BER 是标量输入未与 GG 积分（L2707）；④ 单码 (4896,2488) 单调制 M-DPSK（L2743/2745）；⑤ 仅两点 Cn²、固定 SNR=25dB
4. **张岱第6章与前序章节数学可解耦**：实际输入只有标量 pre-FEC BER + m=log2M + LDPC 参数 t/n，无退偏比/相位屏进入公式。**硕士论文只做第6章能独立成章**
5. **王秋悦 L1302 多元 LDPC 展望原话**（完整引用）："本文……都采用的是二元 LDPC 码……多元 LDPC 码相较于二元 LDPC 码具有更优越的编码性能，虽然增加元域会增加译码的复杂度，但是在提升误码率方面则是值得的，以后会研究多元 LDPC 码对星地激光通信系统的误码率的改善情况"
6. **王秋悦 L115 Wen Lei 2010**：国防科大在星地 AWGN 链路用多元 LDPC 级联，1.85dB 达 10⁻⁶——唯一星地多元 LDPC 前序文献，可追溯

**4 子问题结论（按创新强度排序）**：

| 子问题 | 证据强度 | 创新空间 | 风险 |
|---|---|---|---|

### F17. 4b #1 创新核可行性核查 — "GG 信道 LCR/AFD → 最优交织深度"解析推导（2026-06-19）

用户对 4b #1 提三个疑虑（唐承茂复刻风险 / 开环查表算不算算法创新 / 空空→星地迁移新意）。三个疑虑都指向同一核心：创新厚度够不够。判断标准 = "LCR/AFD → 最优交织深度 B/D" 能不能解析推导出来。派子 agent 核查文献现状。

**核查结论：解析推导可行，创新点成立（强）**。

**文献现状三层**：
1. **RF/Markov 侧最近邻**：Moltchanov 2018（arXiv:1801.09923, Computer Communications）——"相关无线信道交织解析建模"，给 packet error probability 闭式 + 最优交织深度**数值识别**。但用相关性参数（非 LCR/AFD），输出是数值（非 D_opt 解析闭式），纯 RF（非 FSO）。
2. **FSO/GG LCR/AFD 侧**：Le 2021（IEEE Photonics J, 50+ 引）推了"卫星-UAV FSO GG+指向误差 LCR/AFD 闭式"；Issaid & Alouini 推 FSO LCR/平均中断时长；Stefanović 2021 推 N 跳 GG LCR/AFD；Uysal 2006（595 引）推 GG 编码 FSO BER bound。**全部止步于统计本身或 BER bound，无人把 LCR/AFD 代入交织深度优化求解析解**。
3. **空白明确**：**"GG 信道 LCR/AFD → 最优交织深度 B/D 解析关系"无人推导**。Moltchanov（RF/Markov/数值）与 Le 2021（FSO/LCR-AFD/无交织）之间存在断层。

**非平凡性**：GG 分布的 LCR/AFD 含 Meijer-G/Bessel 复杂核，嵌入交织深度优化（最小化 codeword 错误概率，或 BER 约束下最小化延迟）求解析/半解析解，有数学难度，非简单套用。

**链条完整性**：Le 2021 的卫星-UAV GG+指向 LCR/AFD 闭式 → 硕士工作推导到交织深度 → 自适应交织（开环）+ FPGA 验证。上游统计已有，下游应用成熟，中间的解析桥是空白。

**化解三疑虑**：
1. **唐承茂复刻风险** → 创新核是 LCR/AFD→B/D 解析推导（唐承茂只静态估 Lburst≈800 反推 B=27，没推解析关系），不是星地版唐承茂
2. **开环查表算不算算法创新** → 算法创新在解析推导（和张岱 post-FEC BER 同级），查表只是实现手段。方法章必须有推导过程，不能只有仿真
3. **空空→星地迁移新意** → 仰角依赖的 GG-LCR/AFD 是星地特有物理（空空 Cn² 常数无此问题），Le 2021 卫星-UAV LCR/AFD 闭式是直接起点。迁移不是场景平移，是物理问题升级（常数 Cn² → 仰角依赖 Cn²）

**风险提示（须写进创新点边界）**：
- (a) 必须显式区分于 Moltchanov 2018——强调统计描述（LCR/AFD vs Markov 相关性）与信道（GG vs RF）双重差异
- (b) 若 GG 核函数过繁导致无法完全闭式，退守"半解析 + 渐近闭式"仍是有效创新
- (c) 文献综述需显式引用 Moltchanov 2018 + Le 2021 作"最近邻"，明确画空白边界，防审稿质疑

**关键文献**：
- Moltchanov 2018（arXiv:1801.09923, Computer Communications）—— RF/Markov 最近邻
- Le 2021（IEEE Photonics J, 10.1109/JPHOT.2021.3097363）—— 卫星-UAV FSO GG+指向 LCR/AFD 闭式，直接上游
- Issaid & Alouini —— FSO LCR/平均中断时长
- Uysal 2006（IEEE TWC, 595 引）—— GG 编码 FSO BER bound
- Chang 2024（IET）—— FSO 深交织实验（非解析，对照用）

**对决策的影响**：4b #1 创新核（LCR/AFD→B/D 解析推导）可行性 PASS，三疑虑化解。**4b #1 从"最强单点候选"升级为"创新核已验证的可执行方向"**。可建 D004 正式定方向，开执行专题做 Groundwork 可行性（MVE）。

- 评审视角："唐承茂做了，你比他好在哪？"——**可回答**（自适应 + 星地 + LCR/AFD）

这样定位后，4b#1 不再是"填补 LCR/AFD→B/D 空白"（无 baseline 危险），而是"唐承茂工作的延伸"（有 baseline 可比）。**解析推导从"创新核"降为"实现手段"**——推不推得出闭式不影响方向成立（推得出加分，推不出退半解析或数值优化，仍有改进点）。

#### 对决策的影响

D005 增量改进视角下，4b#1 仍是最优候选，但**定位重写**：
- 从"填补 LCR/AFD→B/D 空白" → "唐承茂静态交织的增量改进"

#### 综合判断：A3 排除

**三条硬证据**：
