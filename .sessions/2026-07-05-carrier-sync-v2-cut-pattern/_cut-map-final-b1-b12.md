## 0. 这份地图是什么 + 用户核心诉求

用户原话："别人都咋弄的？是怎么排列组合方法水一篇的？我也想水一篇该咋弄"+"发个会议就行"。

这份地图回答 **"切的动作本身"**——别人怎么在引用网络里找到自己的小切口的。**完整定稿覆盖 B1-B12 全 12 点**，按子 agent 建议分两类池呈现（饱和池 vs 稀池结构不同，混合会失真）。

## §B 稀池点（B6-B12）—— 三种稀池模式

> 来源：3 批子 agent 产出。B6-B12 七点按稀池模式分三类：① B6/B7/B10/B11 细分独占赛道 ② B8/B9 自相干"绕开"孤点 ③ B12 频域 pilot 双视角稀池。

### B.1 B6/B7/B10/B11 细分独占赛道（4 特征）

**4 特征**（与饱和池结构性对照）：
1. **细分独占赛道 + 彼此正交**：B6 OPLL 鉴相器（环路硬件侧）/ B7 Gardner TED 复用 FOE（DSP 数字 FOE）/ B10 pilot-RLS CPE/CFOE（DSP 数字 CPE）/ B11 NDA-ML CPE（DSP 频域 NDA-ML CPE）—— **无两点切同一子大点**（vs 饱和池 Spalvieri ~18 篇切同一大点）
2. **低横向对比**：4 点全部"独占或无对比"——B6 cited-by 2 篇均不承接 / B7 cited-by 空（OFC 2026 索引滞后）/ B10 cited-by 1 篇是同作者纵向自接力 / B11 cited-by 1 篇是背景路过引用
3. **dB 偏鲁棒性/范围维度**：4 点里 3 点（B6/B7/B10）dB 形态偏"失效区/范围/鲁棒性"非"赢 baseline 几 dB"，仅 B11 +2dB 达梯队下沿（条件性强，仅 (8,8)-16APSK 成立）
4. **纯仿真门槛 + "既有方法失效"叙事**：4 点里 3 点纯仿真最低门槛档（B6/B10/B11），1 点实验室模拟（B7）；3/4 点用"既有方法失效 → 提新机制"叙事（vs 饱和池此套路 ~25%，稀池 75%）

**dB 数字（带条件 + 口径警示）**：
- B6：无统一 dB gain，0.42~0.66dB 是 atan2 自报 penalty 非增益；真增益 = 5× 延迟容限（鲁棒性维度）
- B7：**0.6dB @ BER 2e-2 + 1.9× 估计范围 + OSNR 10dB 可解调**（vs PSA FOE，receiver sensitivity 量级倾向）
- B10：无统一 dB（CFO 10GHz 可同步 + 线宽 1.45MHz 保 FEC limit，BPS+4OPM 失效区）
- B11：**+2 dB SNR gain @ (8,8)-16APSK @ 7% HD-FEC vs DA ML**（仅一个调制格式成立，其他格式持平）

### B.2 B8/B9 自相干"绕开"孤点（独占孤点特征）

**核心特征**：B8（square-law+LPF 自消除 CFO/PN）+ B9（虚拟载波+DRE 自相干）都在"绕开传统载波同步链"。**自相干"绕开"切法在合并 7 篇池里 0/7 follow**——所有 cited-by 都切相邻维度（物理前提 / 机制并列 / 跨场景 / 综述 / 同团队延伸），与 B1-B5（cited-by 密集 follow 载波同步子环节）本质对照。

**B8 主判定"本篇无核心 Q#"是事实**（自消除使载波同步需求冗余，不强行凑 Q#）。

**dB 口径碎片化（5+ 口径，比饱和池 2 口径更严重）**：
- B8 锚：无 dB（BER 量级）
- B9 锚：~3 dB SNR 增益 @ 3 PNOB DAC + DRE（vs w/o DRE 内部对照，非传统相干 baseline）
- photonics10050493：homodyne 比 heterodyne mixing gain 高 ~3 dB（mixing gain 结构差，非 SNR penalty）
- lcomm.2024.3511129：shaping gain 0.65 dB（average optical power，信息论）
- apn.3.3.036007：~0.5 dB ROP sensitivity 增益（dBm 灵敏度）
- lpt.2026.3655104：无 dB（BER 倍数）

**横切观察**：至少 5 种不同口径的 dB，**横向比"赢 baseline 几 dB"几乎不可直接做**。

### B.3 B12 频域 pilot 双视角稀池

**双视角机制独立性清晰**：
- B12 锚（Gävert TCOMM 2022）：频域 CW pilot 占连续频位（功率/带宽代价），三估计器 BLUE/ML/improved vs CRLB，**无 vs baseline dB 仅结构性**
- MAP（OECC 2025）：时域 pilot-aided 占符号位（开销代价），block-wise 并行 + AOPN，**同族 dB**（vs PA ML 1 dB / vs PA 3.5-7 dB，baseline 是 PA/PA ML 非传统 V-V/BPS）
- 机制正交（频域 vs 时域），均前馈无环路 TF 不撞 D006；MAP 引 B12 锚作"牺牲频谱效率"对照方向标，算法源是 Wang [5] 非频域延伸

**频域 pilot 路线对"水一篇"的启示（中性观察非推荐）**：理论框架已齐（B12 锚）+ 工程实现维度空（无 FPGA/实测）+ vs 传统 baseline dB 缺口——切法空间在场景迁移/硬件实现（Paillier 安全区同构）或补传统 baseline dB 对照（D005 第一梯队切口），但样本密度低（3 篇有效），独占空间大但参考少。

## §C 两类池对照—— 给"我也想水一篇"的尺子（中性参照系，不推荐方向）

> 守 profile 第 7 次"急于推进"防线：本节是分布描述非方向推荐。"水一篇"选哪条路径是 Step 4a 用户侧动作。

### C.1 饱和池 vs 稀池的"水一篇"路径差异

| 维度 | 饱和池（B1-B5）| 稀池（B6-B12）|
|---|---|---|
| **大点性质** | 改进 CFO/CPR/OPLL/TED 算法（载波恢复需求存在）| 三种：① 细分独占赛道（B6/B7/B10/B11）② 绕开载波同步（B8/B9）③ 双视角（B12）|
| **cited-by follow 度** | 高（Spalvieri 85 / Paillier 43 团队自切密集，场景迁移+硬件实现过半）| **零或几乎零**（B6/B7/B10/B11 全独占 / B8/B9 0/7 follow / B12 仅 3 篇有效）|
| **Q# 产出** | 有（B1-Q1 自适应 N / B3-Q2 +2-3dB / B4 双环 / B5 短时谱 / B6 OPLL / B7 Gardner TED / B11 +2dB / B12 频域 pilot）| B8 无核心 Q#（事实）/ 其他稀池点有但 dB 偏鲁棒性 |
| **dB 形态** | 主流两口径（dBm 灵敏度 vs SNR penalty dB）| **碎片化**（B8/B9 5+ 口径 / B6/B7/B10/B11 偏鲁棒性非"赢 baseline 几 dB" / B12 偏结构性同族）|
| **D005 够格难度** | 架构替换/工具借用/联合建模有 dB（jphot +2-3dB / L053 +2-3dB 是样本）| **整体偏弱**——仅 B11 +2dB 达梯队下沿（条件性强）；其他点 dB 偏鲁棒性/范围维度 |
| **动机叙事** | "X 已被研究但 Y 未覆盖"绝对主流（~35%）| "既有方法失效 → 提新机制"高频（B6/B7/B10/B11 75%）/ "绕开而非赢"（B8/B9）/ "补理论/扩维度"（B12）|
| **赛道定位** | 在"载波同步算法改进"赛道内拥挤（Paillier 安全区场景迁移+硬件实现过半）| 三种稀池各占独占赛道，无饱和池的"子大点密度聚集" |
| **实现复杂度** | 梯度完整（纯仿真~10 / FPGA~8 / outdoor~3）| 稀池集中纯仿真档（B6/B10/B11 / B8 / B12 锚+MAP），仅 B9 outdoor 实测 |

### C.2 "水一篇"路径选择（中性参照系，会议级别门槛）

> "发个会议就行"门槛让可行性显著提高——会议不卡 dB，纯仿真档 + 鲁棒性 dB 也够发。

**饱和池路径（挤进已有大点）**：
- 优点：模板多参考多（Spalvieri/Paillier 池 cited-by 密集），intro 套路通用（"X 已被研究但 Y 未覆盖"~35%）
- 缺点：拥挤（Paillier 安全区场景迁移+硬件实现过半），dB 难出（Paillier 安全区 5 篇落盘 0 篇出 dB）
- **样本**：B4/B5 同 BUPT 团队 Arria 10 FPGA demo 是会议级模板（绝对指标够发会议）

**稀池路径 1：细分独占赛道（B6/B7/B10/B11 模式）**：
- 优点：独占空间大（cited-by 池空或仅 1），"既有方法失效 → 提新机制"叙事证据链强，纯仿真门槛低
- 缺点：dB 偏鲁棒性/范围维度（仅 B11 +2dB 达梯队下沿），无横向对比样本（参考少）
- **样本**：B7 Gardner TED 复用 FOE（OFC 2026 poster）/ B11 NDA-ML STO+CPE（IEEE PTL 2025）都是会议/期刊级

**稀池路径 2：绕开载波同步（B8/B9 模式）**：
- 优点：实现复杂度可调档（B8 纯仿真最低 / B9 outdoor 最高），"绕开而非赢"叙事独特
- 缺点：dB 口径碎片化（5+ 口径横向比极难），B8 不产出载波同步改进型 Q#（自消除使需求冗余）
- **风险**：被引用但不被接力切的孤点（0/7 follow），切这条路线 cited-by 池无密集参考

**稀池路径 3：双视角稀池（B12 模式）**：
- 优点：理论框架已齐（B12 锚），双视角机制独立（频域 vs 时域正交），独占组合空间（联合架构 + 星地迁移 cited-by 未出现）
- 缺点：样本密度低（3 篇有效），vs 传统 baseline dB 缺口（无一篇给出 vs V-V/BPS 明确 dB）
- **样本**：B12 锚 TCOMM 2022（理论）/ MAP OECC 2025（双视角对照）都是会议/期刊级

### C.3 给"我也想水一篇"的尺子（中性参照系，不推荐方向）

- **选路径 = 选"D05 够格难度 vs 独占空间"权衡**：饱和池有 dB 样本但拥挤（Paillier 安全区 dB 难出）/ 稀池独占空间大但 dB 偏鲁棒性
- **选大点 = 选"参考密度 vs 切口稀缺"权衡**：饱和大点参考多但切口少 / 未饱和子大点切口多但参考少
- **选叙事 = 选"intro 立得住的证据链强度"**：open problem 自报最强但稀少（~5%）/ "既有方法失效"稀池高频（75%）/ "X 已被研究但 Y 未覆盖"饱和池主流（~35%）
- **选复杂度档 = 选"毕业门槛"**：纯仿真最低（B6/B10/B11 / B8 / B12 锚+MAP / 张思齐/jphot/oe 都是这档）/ FPGA demo 中（B4/B5 同 Arria 10 模板）/ outdoor 实测最高（B9）
- **会议级别门槛放宽**：B4/B5 绝对指标够发会议 / B7 鲁棒性 dB 够发 OFC / B11 +2dB 条件性强够发 PTL / B12 锚理论够发 TCOMM —— **会议级别下稀池点可行性显著提升**

## §D 完整地图一句话总结（中性，不判 Go/Kill）

**别人怎么从大点切小点的**（B1-B12 全 12 点横切）：

1. **切哪个大点**：饱和大点（Spalvieri 85 / Paillier 43）= 拥挤安全区；TS-FOE/Park 线 = 未饱和子大点；B6-B12 七点各占独占赛道（细分独占 / 绕开 / 双视角三类稀池）
2. **切什么角度**：8 类角度，**饱和池拥挤区在场景迁移+硬件实现（dB 难出），稀池集中"既有方法失效 → 提新机制"叙事（75%）**
3. **dB 怎么报**：饱和池 D005 第一梯队有 6 篇 vs 传统 baseline 明确 dB（jphot +2-3dB / L053 +2-3dB / sat.1553 pilot 1dB / Paillier 2.3dB penalty / 张思齐 +0.67-0.76dB）；**稀池 dB 整体偏鲁棒性/范围维度**（仅 B11 +2dB 达梯队下沿），**B8/B9 5+ 口径碎片化**
4. **intro 怎么讲**：饱和池"X 已被研究但 Y 未覆盖"绝对主流（~35%）；稀池"既有方法失效"高频（75%）/"绕开而非赢"（B8/B9）/"补理论"（B12）
5. **实现多复杂**：饱和池梯度完整（纯仿真~10 / FPGA~8 / outdoor~3）；稀池集中纯仿真档（仅 B9 outdoor 实测）

**给"我也想水一篇"的尺子（中性参照系，不推荐方向）**：
- 饱和池路径 = 挤进已有大点（模板多但拥挤 dB 难出，B4/B5 Arria 10 模板是会议级样本）
- 稀池路径 1（B6/B7/B10/B11 模式）= 细分独占赛道（独占空间大 dB 偏鲁棒性，"既有方法失效"叙事，纯仿真门槛，B7 OFC/B11 PTL 是会议级样本）
- 稀池路径 2（B8/B9 模式）= 绕开载波同步（实现可调档但 dB 口径碎片化，孤点风险 0/7 follow）
- 稀池路径 3（B12 模式）= 双视角稀池（理论框架已齐工程实现维度空，独占组合空间但样本少）

**会议级别门槛放宽**：纯仿真档 + 鲁棒性 dB / 绝对指标 / 同族 dB 都够发会议 —— **B4/B5/B7/B11/B12 锚都是会议/期刊级样本**。
