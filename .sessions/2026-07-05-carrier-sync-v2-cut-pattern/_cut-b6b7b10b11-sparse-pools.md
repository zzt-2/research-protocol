## 1. B6 Z-ODPLL 切入点切法（6 维，OPLL 锚 cited-by 仅 2）

> 锚 = Panasiewicz 2023 Photonics（10.3390/photonics10121312），sin 鉴相器幅度衰落鲁棒性；切入点动作 = 站在 OPLL 鉴相器大点上切"幅度衰落鲁棒性"维度

### 1.1 B6 切入点本身（6 维）

| 维度 | 提取 |
|---|---|
| **(1) 站在哪个大点上切的** | **OPLL 鉴相器架构大点**（homodyne/intradyne 相干接收机的"光学 hybrid + PD + ADC + 数字 LF + DAC + 从激光器"环路里"鉴相器"这个子模块）。具体子点 = sin 鉴相器（四次方虚部，KD∝Ps²）的幅度衰落鲁棒性。**不**站在环路 TF / 联合建模大点上（D006 边界外）。 |
| **(2) 切的什么角度** | **架构替换**——把 sin 鉴相器（增益与 Ps 耦合）替换为 atan2 四象限反正切鉴相器（KD=1 与信号电平解耦，改自 Viterbi-Viterbi 逐样而非数据块）。次角度 = **参数调度**（双采样率 10GSa/s vs 625MSa/s 的 BnTs/功率惩罚调度分析）。 |
| **(3) dB 真实性条件性** | **无统一"X dB Q-factor gain"——dB 形态是"失效区定性保锁 + 稳态 penalty 同量级"**。@10GSa/s Bn=2MHz σ=2.6° power penalty 0.42dB；@625MSa/s Bn=0.5MHz σ=4.06° penalty 0.66dB（**这些是 atan2 自身的 penalty 非"vs sin 增益"**）。真增益维度 = **定性保锁**（sin 在延迟>6ns 即失锁→BER≈0.5，atan2 全湍流态保锁容 30ns 延迟，**扩展工作范围 5×**）。D005"赢 baseline 几 dB"标尺下**偏弱（无 dB 量级赢）**，鲁棒性维度下强。**口径警示**：0.42~0.66dB 是 atan2 自报 power penalty，不是"atan2 比 sin 多赢几 dB"。 |
| **(4) 横向多样性** | **池里无同角度对比**——B6 cited-by 池仅 2 篇（Halliwell 2025 被动轨道测定 / Xu 2025 ECL 快速调谐），**均不承接 sin 鉴相器幅度衰落鲁棒性**。backward refs 里 Z-ODPLL（Chen 2021）是建模工具引用、OIPLL（Shoji 2012）/ SS-SC-OPLL（Ferrero 2008）/ 四次方 LUT（Lu 2020）**均假设稳定 Ps 或靠 AGC**，**无第三方在 sin 鉴相器幅度衰落鲁棒性上做扩展或持续工作**。**B6 切法在 cited-by 池里独占，无横向对比样本**。 |
| **(5) 动机叙事** | **"前作有缺陷 → 改进" + "机制独占"**——intro 从"OPLL 用于星地 LEO 下行受大气湍流致 Ps 波动"大问题收窄到"sin 鉴相器 KD∝Ps² 耦合是 OPLL 失锁根因"，再收窄到"atan2 解耦 KD 与 Ps"。叙事锚点 = MWP 2022 会议前作同源（同团队同问题同解，2023 仅增低采样率场景），**作者团队到此为止无后续**（"幅度衰落鲁棒性止于 atan2，无后续工程化/Z 域建模整合跟进"——锚团队留白判定成立）。 |
| **(6) 实现复杂度** | **纯仿真**（VPI + Python 协仿真，CC-BY OA 参数全）——最低门槛档。硬件实现作者自陈"in progress"未交付。无 FPGA / 无 outdoor 实测 / 无湍流信道相位建模（湍流建模为**幅度衰落**Log-Normal/Gamma-Gamma 功率波动，非相位）。 |

| **(4) 横向多样性** | **池里无对比（cited-by 池为空，OFC 2026 索引滞后）**——B7 是 OFC 2026 poster，cited-by 池子天然为空（**不是漏检，是索引滞后事实**）。backward refs 5 篇（Gardner 1986 / Leven 2007 M-th power FE / Shoji 2012 OIPLL / Paillier 2020 AO+DPLL / Vieira 2023 LEO-LEO OISL）是 B7 自引的理论锚与 baseline 源头，**不是横向同角度对比**（Gardner 1986 是定时算法本体非 Doppler 估计；Vieira 2023 是 baseline 非同角度同伴；Shoji/Paillier 是光学方案对照非 DSP FOE）。**B7 的"TED 复用做 FOE"切法在 OFC 2026 cited-by 池里是首发独占**（OFC 2026 cited-by 空意味着该切法尚未被引用网络验证/承接）。 |

## 5. 稀池模式归纳（中性，不判 Go/Kill）

> 四点（B6/B7/B10/B11）均为稀池/天然稀，样本规模 B6 cited-by 2 + B7 cited-by 0 + B10 cited-by 1 + B11 cited-by 1 = **cited-by 池共 4 篇**（B7 池空按 backward refs 5 篇补理论锚）。切法样本密度不足以画完整 6 维分布（vs B1-B5 饱和池 26 篇），下面是**中性观察非统计推断**。

### 5.1 大点分布：稀池点的"被反复切的子大点"集中在哪

- **四点全部站在 DSP 数字法大点赛道，且彼此正交**——B6 OPLL 鉴相器（环路硬件侧）/ B7 Gardner TED 复用 FOE（DSP 数字 FOE）/ B10 pilot-RLS CPE/CFOE（DSP 数字 CPE）/ B11 NDA-ML CPE（DSP 频域 NDA-ML CPE）。**无两点切同一子大点**（vs B1-B5 里 Spalvieri 池 ~18 篇切同一大点 / Paillier 池 11 篇切同一大点）。
- **稀池点的大点本身就是"细分独占赛道"**——B7 的"TED 复用做 FOE"在 OFC 2026 cited-by 空（首发）、B10 的"pilot-RLS 联合 CFO+PN" cited-by 仅同作者续作（团队自切）、B11 的"NDA-ML STO+CPE 闭式" cited-by 仅背景路过（零技术承接）、B6 的"sin 鉴相器幅度衰落鲁棒性" cited-by 2 篇均不承接（机制独占）。
- **结论（中性）**：稀池点的"被反复切的子大点"**不集中**——每点各占一个细分独占赛道，**无饱和池点的"子大点密度聚集"现象**。这是稀池点与饱和池点（B1-B5）的结构性差异。

### 5.2 dB 形态分布：稀池点 dB 多在哪个形态

- **B6**：无统一 dB gain，形态 = "失效区定性保锁 + 稳态 penalty 同量级"（0.42~0.66dB 是 atan2 自报 penalty 非增益；真增益维度是 5× 延迟容限的鲁棒性）。
- **B7**：vs 传统 baseline 真实 dB 但偏小（0.6dB @ BER 2e-2）+ 结构性范围优势（1.9×）+ 鲁棒性极限（OSNR 10dB 可解调）。
- **B10**：无统一 dB gain，形态 = "失效区范围/鲁棒性优势"（CFO 10GHz / 线宽 1.45MHz 可同步，BPS+4OPM 失效区）。
- **B11**：vs 传统 baseline 真实 dB 达梯队下沿但条件性强（+2 dB SNR gain @ (8,8)-16APSK @ 7% HD-FEC，仅一个调制格式成立）。
- **四点 dB 形态横切**：**4 点里 3 点（B6/B7/B10）的 dB 形态偏"失效区/范围/鲁棒性"非"赢 baseline 几 dB"**，仅 B11 有 +2dB 达 D005 梯队下沿（且条件性强）。**vs B1-B5 饱和池 6 篇 vs 传统 baseline 明确 dB**——稀池点的 dB 量级优势整体弱于饱和池。

### 5.3 横向多样性：稀池点是独占还是无对比

### 6.2 是否建议主线汇总时把稀池点单独成段（不与 B1-B5 饱和池点混）

> 守 D018 中性提取 + profile 第 7 次防线：下面是结构性建议非方向推荐。

**建议单独成段**。理由（中性结构观察）：

1. **样本规模不同量级**：B1-B5 饱和池 26 篇画完整 6 维分布；B6/B7/B10/B11 稀池共 cited-by 4 篇 + 切入点 4 篇 = 主样 8 篇，且横向多样性维度"全独占/无对比"——**混在一起会让饱和池的分布被稀池的"独占"稀释，反之亦然**。
2. **dB 形态分布不同结构**：饱和池 6 篇 vs 传统 baseline 明确 dB（第一梯队）；稀池 4 点里 3 点 dB 偏鲁棒性维度，仅 B11 有 +2dB 达梯队下沿。**两类池的 dB 形态不可横向聚合统计**（口径不同 + 条件性不同）。
3. **大点分布不同结构**：饱和池有"子大点密度聚集"（Spalvieri ~18 篇 / Paillier 11 篇切同一大点）；稀池"每点各占一个细分独占赛道，无密度聚集"。**混在一起会掩盖"饱和池拥挤 vs 稀池独占"的结构性差异**。
4. **动机叙事分布不同结构**：饱和池"X 已被研究但 Y 未覆盖"绝对主流（~35%）；稀池"既有方法失效/次优 → 提 Z"高频（3/4 点）。**两类池的叙事套路分布不同**。

**建议的主线汇总结构**（中性建议，主线 agent 决策）：
- §A 饱和池点（B1-B5）：完整 6 维分布 + dB 形态分布 + 横向多样性 + 团队自切模式（沿用定稿 §1-§6 结构）
- §B 稀池点（B6/B7/B10/B11）：稀池模式单独归纳（本文件 §5 结构）——突出"独占赛道 + 鲁棒性 dB + 纯仿真门槛 + 既有方法失效叙事"四特征
- §C 两类池对照：饱和池 vs 稀池的"水一篇"路径差异（中性观察非推荐）

**不建议**把稀池点混入饱和池点的 6 维分布表（会让饱和池分布失真 + 稀池点信息被淹没）。
