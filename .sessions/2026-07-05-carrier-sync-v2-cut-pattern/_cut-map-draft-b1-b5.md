## 0. 怎么读这份地图（用户核心诉求对齐）

用户原话："别人都咋弄的？是怎么排列组合方法水一篇的？我也想水一篇该咋弄"+"看 cited-by 怎么从大点找到小点"。

这份地图回答的是 **"切的动作本身"**，不是"切出来的是什么"。读法：
- **看"被反复切的超级大点"分布** → 哪些大点已经被切得很密（别人切过的安全区）
- **看"切法角度"分布** → 别人常用哪些角度切（参数调度 / 架构替换 / 场景迁移 等）
- **看 dB 形态分布** → 哪些切法容易做出 dB 增益，哪些只给绝对指标
- **看动机叙事套路** → 别人 intro 怎么把"我切这一刀"讲成"值得做"
- **看实现复杂度梯度** → "水一篇"要选哪个复杂度档（纯仿真最易上手）

**这份地图不告诉你"该切哪一刀"**（那是 Step 4a 用户侧动作），只告诉你"别人是怎么切的"。

## 1. "被反复切的超级大点"分布（B1-B5 横切）

> 一个"超级大点"= 被多篇 cited-by 反复引用作为起点的奠基论文/经典算法/综述。切法地图的首要分类轴。

| 大点 | 池规模 | 被切的子点（按密度） | 主流切法角度 | 团队自切集中度 |
|---|---|---|---|---|
| **Spalvieri pilot-aided 相位估计**（B1 锚 sat.1553[57]） | 85 篇 cited-by | ① 信息率界（最密集）② Kalman carrier recovery ③ pilot-aided dual-stage ④ trellis demod | 性能极限 / 架构替换 / 参数调度 / 工具借用 | **极高**（~18+ 篇 Barletta/Magarini/Spalvieri 合著，"自己切自己大点"连续轨迹）|
| **Paillier 星地相干下行 ground receiver**（B4/B5 锚 jlt.2020.3003561） | 43 篇 cited-by | ① 系统级参考架构（被当标准引用）② AO/波前校正模块 ③ 接收机硬件 ④ DPLL/OPLL 同步本体 | 场景迁移 / 硬件实现 / 架构替换 / 工具借用 | 中（L039 Paillier 自引延伸；B4/B5 同 BUPT 团队续作）|

**关键横切发现（B2/B3 子 agent 报，FR-26 已核查 `_cut-b2b3-sat1553-line.md` §3）**：
> **sat.1553 不是这 4 篇共同的"被反复切的超级大点"。** sat.1553 自己是综述（自身即大点），它通过 L558/L582/L790 把"fade 冻结"和"子系统协同"两条切法**事后归并**出来；但池里 4 篇自己的大点锚各不相同——张思齐锚载波恢复经典算法（QPSK 分圈/4th-FFT/Cheng 联合）、LCOMM 锚自前作 PTJ、jphot 锚传统 TS+Park、oe 锚同课题组前作 jphot FSTS。**真正的"被反复切的子大点"是"传统 TS-FOE / Park 帧同步 / QPSK 分圈"这条 FSO 帧导频算法线**（jphot + oe + 张思齐第四章共切），而非 sat.1553。

**对"我也想水一篇"的含义（中性观察非推荐）**：
- 切**饱和大点**（Spalvieri 85 池 / Paillier 43 池）= 进拥挤区，独占切口少，但参考样本多容易找模板
- 切**未饱和子大点**（TS-FOE/Park/QPSK 分圈线，池小 ~4 篇）= 独占切口空间大，但参考样本少需自己定标准
- 切**综述延伸**（sat.1553 自报 open problem）= 套路占比较低（Spalvieri 池 ~10%），但空白声明由综述作者亲口给出（不是 agent 臆造）

## 4. 动机叙事套路分布（B1-B5 横切）

> 别人 intro 怎么把"我切这一刀"讲成"值得做"。**对"水一篇"最直接的借鉴**——同一份切法，叙事套路决定 paper 读起来是否"立得住"。

| 叙事套路 | 占比（粗估）| 典型代表 | 套路结构 |
|---|---|---|---|
| **"X 已被研究但 Y 场景/维度未覆盖"** | ~35% | L005 / L008 / L027 / L013 / L024 / L030 / L009 | "Paillier/Spalvieri 已证 X 在 A 场景可行 → 但 B 场景未覆盖 → 本工作填 B" |
| **"既有方法失效/次优 → 提 Z"** | ~25% | L003 / L009 / L053 / L030 / B1-Q1 / sat.1553 | "blind 在 cycle-slip 失效" / "PS 损坏 BPS" / "PSAM 高阶+强 PN 失效" → 提新方法 |
| **"前作有缺陷 → 改进"** | ~15% | LCOMM（PTJ 偏振衰落→解耦）/ oe（Park 侧峰→PRBS 消侧峰）/ L036（Paillier 经验式→Z 域建模）| "我们前作/经典方法有 X 缺陷 → 改进" |
| **"绕开而非赢"** | ~10% | L005（PCS+符号率绕开非对称滤波）/ L024（self-canceling 绕开相位噪声）| "不动 Paillier 同步本体，换一个维度绕" |
| **"借 ML/NN 工具到 FSO"** | ~10% | L013（attention）/ L024（RL）/ L032（NN）/ L053（CNN）/ L033（semantic）| "ML 在 Y 领域成功 → 借到 FSO 的 X 子环节" |
| **"open problem 自报 → 填空白"** | ~5% | sat.1553 L440/L790 自报 / B1 切入点 | 综述作者亲口说"未量化/未做"→ 直接填 |

**横切观察（中性）**：
- **"X 已被研究但 Y 未覆盖"是绝对主流**（~35%）——这是"水一篇"最通用的叙事（找一个已被切的子大点 + 找一个没切过的 Y 维度）
- **"既有方法失效"套路**（~25%）在 Spalvieri 池最常见（信息率界 + dual-stage 主流）；**"前作改进"套路**（~15%）在 B3 池最常见（同课题组续作）
- **B1 切入点用的"open problem 自报"**套路在池里**占比最低**（~5%）——但空白声明由综述作者亲口给出（不是 agent 臆造），FR-26 证据链最强
- **"绕开而非赢"**（~10%）是 D005 边际路线（不动 baseline 本体，换维度绕，dB 可能不出但工程价值在）

**对"我也想水一篇"的含义（中性观察非推荐）**：
- 选**主流套路**（"X 已被研究但 Y 未覆盖"）= 容易写但需要找未切的 Y 维度
- 选**独占套路**（"open problem 自报"/"绕开而非赢"）= 证据链强但需要找综述自报或换维度绕的工程价值

## 5. 实现复杂度梯度（B1-B5 横切）

> "水一篇"要选哪个复杂度档。**abstract 级缺失率次高维度**（~25%），本节是粗档。

| 复杂度档 | 篇数（粗估）| 典型代表 | "水一篇"门槛 |
|---|---|---|---|
| **纯仿真/理论** | ~10 | sat.1553 / B1-Q1 / L004 / L010 / L019 / L024 / 张思齐 / jphot 相位屏 | **最低**（一台机器 + Python/MATLAB）|
| **仿真 behavioral model（标未来 hardware）** | ~2 | L036 / B1 部分 | 低（仿真为主 + 标"未来 FPGA"展望）|

| **实验室 + outdoor/野外实测** | ~3 | L001（42m 48h）/ L039（Jungfraujoch-Zimmerwald）/ Matsuda FPGA 实时 4Gbps | **高**（需野外链路 / 长期实测）|

**意外发现（B2/B3 子 agent 报，FR-26 已核查 `_cut-b2b3-sat1553-line.md` §3）**：
> **梯度规律：协同角度越宽/越靠近综述 open problem 端（张思齐、sat.1553），硬件实现越弱；协同角度越靠近工程痛点端（LCOMM、Matsuda），硬件实现越强。**

**对"我也想水一篇"的含义（中性观察非推荐）**：
- 想**最低门槛毕业**（D005 务实路线）→ 选**纯仿真**档（~10 篇样本，参考模板多）
- 想做**工程价值论文** → 选**FPGA demo**档（B4/B5 同 BUPT 团队模板）
- 切**综述 open problem**（B1 切入点）大概率只能纯仿真（梯度规律）

## 6. "团队自切"模式（中性观察，用户已纠正"不是同门"）

> 用户原话："其实不是同门，这块理解错了。"——团队维度只标作者名不推断师承。但"团队自切"作为切法模式仍值得标（中性）。

| 模式 | 案例 | 切法特征 |
|---|---|---|
| **同一团队连续切自己大点** | Spalvieri 团队（Barletta/Magarini/Spalvieri 合著 ~18+ 篇）/ B4-B5 BUPT 团队（Na Liu/Cheng Ju/Jiamin Fan）/ jphot-oe 同课题组 | "自己切自己大点"形成连续轨迹，切法偏理论延伸（信息率界 / Kalman / dual-stage）|

## 7. B1-B5 切法地图一句话总结（中性，不判 Go/Kill）

**别人怎么从大点切小点的**（B1-B5 横切 26 篇样本）：
1. **切哪个大点**：Spalvieri 85 池 / Paillier 43 池是饱和安全区（团队自切密集），TS-FOE+Park+QPSK 分圈线是未饱和子大点（独占空间大），sat.1553 是综述自身即大点但不是子大点
2. **切什么角度**：8 类角度（场景迁移/架构替换/参数调度/硬件实现/工具借用/联合建模/性能极限/综述延伸），拥挤区在场景迁移+硬件实现，dB 空间区在架构替换+工具借用+联合建模
3. **dB 怎么报**：vs 传统 baseline（D005 第一梯队）/ vs 内部对照（边际）/ 绝对指标（不够格）/ 无 dB 仅结构性（理论），Paillier 安全区恰恰是 dB 最难出区
4. **intro 怎么讲**：5 套路（"X 已被研究但 Y 未覆盖"主流 / "既有方法失效" / "前作改进" / "绕开而非赢" / "借 ML 工具"），B1 用的"open problem 自报"占比最低但证据链最强
5. **实现多复杂**：纯仿真（最低门槛）→ FPGA demo → outdoor 实测，协同角度越宽硬件越弱

**给"我也想水一篇"的尺子（中性参照系，不推荐方向）**：
- 选**切法角度** = 选"D05 够格难度"（架构替换/工具借用/联合建模有 dB；场景迁移/硬件实现无 dB；性能极限/综述延伸理论维度）
- 选**大点** = 选"独占切口空间"（饱和大点参考多但切口少；未饱和子大点切口多但参考少）
- 选**叙事套路** = 选"intro 立得住的证据链强度"（"open problem 自报"最强但稀少；"X 已被研究但 Y 未覆盖"最通用）
- 选**复杂度档** = 选"毕业门槛"（纯仿真最低；outdoor 实测最高）
