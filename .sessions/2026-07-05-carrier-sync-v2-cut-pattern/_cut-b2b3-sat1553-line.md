## 1. B2 切入点的切法动作（deep fade 冻结）

B2 切入点 = sat.1553 L558/L582（deep fade 时冻结 FO 估计器/均衡器跟踪）。B2 池天然小（sat.1553 + Matsuda[79] 摘要 + Paillier 2020 JLT），不强凑。

### 1.1 sat.1553 综述在 L558/L582 这个切口的切法（综述作者怎么把这个点切出来的）

1. **站在哪个大点上切的**：站在"地面光纤 DSP 算法迁移到 OSL 动态低 SNR 信道"这个大点上切。L558/L582 不是 sat.1553 自己的原创机制，是它在综述梳理时**从被引文献（[79] Matsuda）抽出"fade 期间冻结估计更新"作为一条设计建议**——即综述延伸式切口。
2. **切的什么角度**：综述延伸 + 场景迁移。把通用 DSP 里"信号质量退化时停止估计更新"的工程常识，迁移定位到 OSL 大气闪烁 deep fade 场景，并在 L558（CFO 段）/L582（均衡器段）两处重复引用，把它**结构化为"fade 对策"的一个标准动作**。
3. **dB 真实性条件性**：无 dB（sat.1553 自己未对 [79] 冻结机制做独立仿真复现，仅在 L558/L582 引用为设计建议，属"无 dB 仅结构性"）。
4. **横向多样性**：sat.1553 在 fade 对策上**只切了"被动冻结估计"这一角度**（L558/L582），同段未并列其他角度（如自适应阈值、多估计器切换）——B2 笔记据此指出横向多样性受限于综述本身只列了一条。
5. **动机叙事**：从"地面光纤算法为静态信道优化，OSL 是动态低 SNR"（line 28/167）→ "fade 期间继续更新估计会产生 rapid tracking error"→ "因此应冻结"。常见"光纤算法直接搬会出问题 → 局部加对策"套路。
6. **实现复杂度**：纯仿真（综述级，无硬件）。冻结机制本身复杂度低（功率阈值 gating）。

### 1.2 Matsuda[79] 摘要级切法（信息受限，仅摘要可得）

1. **站在哪个大点上切的**：信息不足（仅摘要，backward refs 不可见）。从摘要贡献看，锚点偏"scintillation-tolerant 相干接收 + FPGA 实时实现"这条工程线，而非某一篇被反复切的"超级大点"。
2. **切的什么角度**：硬件实现 + 场景迁移。把"接收功率下降时关闭 FOE tracking"这个估计器 gating 机制，落到 scintillation fading 场景并做到 FPGA 实时 4 Gbps 验证。
3. **dB 真实性条件性**：vs 内部对照。摘要报告灵敏度 +0.6 dB（offline 评测，FOE freeze 相对无 freeze baseline 的增益）。**注意（B2 笔记陷阱 1）**：0.6 dB 是 [79] 自身相对无冻结 baseline 的增益，不是 B2 候选（自适应阈值/双模）相对 [79] 的增量。
4. **横向多样性**：信息不足（摘要看不出 [79] 切的角度 vs 同池其他篇的差异；池本身只有 sat.1553+Matsuda+Paillier 三篇，样本过小）。
5. **动机叙事**：信息不足（仅摘要，intro 收窄路径不可见）。从摘要可推断"scintillation → rapid tracking error → freeze FOE"，但 intro 怎么从大问题收窄到此点不可得。
6. **实现复杂度**：FPGA 实时实现（4 Gbps 相干接收）+ offline 双评测。是 B2 池里硬件实现最强的一篇。

### 1.3 Paillier 2020 JLT（jlt.2020.3003561）作为 B2 baseline 分支的切法

> 注：Paillier 在 B2 笔记里作为"闭环 DPLL baseline 分支"出现（与 [79] 前馈 FOE 路线对照）。此处提取它作为一篇论文自己的切法。

1. **站在哪个大点上切的**：站在"星地 OSL 相干链路 + 传统 OPLL/OIPLL 不适用"这个大点上切。是这条线的奠基级 baseline（ONERA+CNES 联合 PhD，盲区 A 脉络源头）。
2. **切的什么角度**：架构替换 + 性能极限论证。把闭环 OPLL 替换为 digital intradyne + DPLL（二阶），并端到端数值湍流仿真论证"湍流相位噪声对载波同步可忽略"这一条件性结论——既是架构替换也是性能极限边界刻画。
3. **dB 真实性条件性**：vs 理论上界 + vs 内部对照。湍流 fading 致 2.3 dB BER penalty（vs AWGN 理论）；幅度起伏致最小临界 SNR 从 -9 dB 升到约 -4 dB（5 dB 退化，内部对照）；AO flux penalty -4.5 dB。**条件性极强**（结论依赖 BPSK+10 GBaud+理想 timing+AGC 恒幅+AO 校正后活塞相位慢）。
4. **横向多样性**：Paillier 切的是"闭环 DPLL 管多普勒残频 + AO 管湍流"的分治架构角度，与 [79] 的"前馈 FOE + 功率阈值 freeze"角度**机制上不同**——B2 笔记据此把二者标为 B2 的两条 baseline 分支。
5. **动机叙事**：从"传统 OPLL/OIPLL 不适合星地（频偏大+湍流）"→"改用 digital intradyne + DPLL"→"end-to-end 验证分治够用"。挑战"OPLL 够用"常识的反例驱动。
6. **实现复杂度**：纯数值仿真（Hufnagel-Valley Cn² 剖面 + Zernike AO up to mode 91 + Bufton 风剖面），无硬件实现。参数完整公开，arXiv LaTeX 源公开。

## 2. B3 切入点 + 4 篇已落盘的切法动作

B3 切入点 = sat.1553 L788/L790（Conclusion open problem：各 DSP 子模块协同设计）。B3 池资料最齐：sat.1553 + 张思齐学位论文 + LCOMM.2026 + jphot FSTS + oe.520452。

### 2.1 B3 切入点本身的切法（sat.1553 综述作者怎么把这个点切出来的）

1. **站在哪个大点上切的**：站在自己（sat.1553）梳理出的 OSL 接收机标准 DSP 流水线（Fig.1：静态补偿→定时→均衡→载波恢复[FOE+CPE]→FEC）这个大点上切。L790 是综述 Conclusion 里**事后归并出的 open problem**，不是从外部大点切入。
2. **切的什么角度**：综述延伸。把前文按子系统分模块介绍的几十种算法，在 Conclusion 里**重新组织成"模块间存在共享资源（同一套 pilot）+ 依赖链（CPE 依赖 FOE 残频、均衡依赖定时、FOE 依赖 FS 对齐）"**，并指出"evaluating the complete DSP chain under realistic conditions is critical"。
3. **dB 真实性条件性**：无 dB 仅结构性。L790 是 open problem 陈述，sat.1553 自己未做任何跨模块联合优化，仅给了场景 4 里 pilot 比 Viterbi–Viterbi+差分好 1 dB 的单模块对比作为间接量级参考。
4. **横向多样性**：sat.1553 只切了"声明 open problem"这一个角度（陈述空白），未并列不同协同形态（数据复用 / 共享 TS / 解耦 / 联合矩阵估计 等）——这些具体形态是池里 4 篇分别切的。
5. **动机叙事**：从"4 大子系统几十种算法系统梳理完成"→"但这些算法模块间存在共享 pilot 且相互依赖"→"完整 DSP 链在真实条件下待评估"。典型的"综述收尾抛 open problem"套路。
6. **实现复杂度**：纯综述 + 仿真背书（4 场景 SNR penalty 仿真），无跨模块联合实现。

### 2.2 张思齐学位论文的切法

1. **站在哪个大点上切的**：信息不足（笔记未载张思齐的 backward refs 网络）。从笔记看，其锚点是载波恢复模块内的经典算法（QPSK 分圈 / 4th-FFT / Cheng 联合 FS+FOE），**不直接以 sat.1553 为大点锚**（sat.1553 是 2025 综述，张思齐是硕士学位论文，时间线上未必能引）。B3 笔记把张思齐"汇聚到 sat.1553 L790"是事后视角，非张思齐自己的切法锚点。
2. **切的什么角度**：联合建模 + 模块内协同。两条具体动作：① FOE↔CPE **数据复用**（FOE 阶段四次方处理后的信号复用至 CPE，避免重复四次方，JCR-IFOE/JCR-AFOE）；② FS↔FOE **共享 TS**（一套短符号块训练序列同时做 FS 消除分集支路相对延迟 + 残余 FOE）。协同**停在载波恢复子模块内部**。
3. **dB 真实性条件性**：vs 内部对照 + vs 传统 baseline。第二章 vs QPSK 分圈：接收机灵敏度 B2B/弱湍/强湍 +0.67/+0.76/+0.71 dB；第三章 JCR 复杂度仅 13.8%/47.6%（IFOE）、13.7%/47.3%（AFOE）vs 4th-FFT 和 QPSK Partitioning，NMSE 达 10⁻¹⁰/10⁻⁹；第四章 vs Cheng 联合：残余 FOE 复杂度仅 17%，NMSE 10⁻⁷。
4. **横向多样性**：张思齐切的是"载波恢复模块内协同（FOE↔CPE / FS↔FOE）"，**未跨到均衡/定时恢复**——这是它相对 sat.1553 L790 open problem（CPE+均衡共享 pilot 且依赖 timing）的独占空白。协同动作是"数据复用 + 共享 TS"，与 LCOMM 的"共享 FPT + 解耦"、jphot/oe 的"共享 TS + 分集合并"机制不同。
5. **动机叙事**：信息不足（笔记未载张思齐 intro 收窄路径）。从章节结构可推断"高频谱效率相干光通信 → 载波恢复复杂度高 → 模块内联合降复杂度"，但 intro 原文叙事不可得。
6. **实现复杂度**：纯仿真，无硬件实现验证（张思齐自陈 §5.2）。

### 2.3 LCOMM.2026.3651445 的切法

1. **站在哪个大点上切的**：站在**作者自前作 PTJ**（JLT 2023，2-FPT 联合相位+偏振跟踪）这个大点上切，是典型的"自承接续"切法。次级锚点是偏振复用 DSCM 系统这个场景大点。**不站在 sat.1553 上切**（LCOMM 是光纤 DSCM，非星地，与 sat.1553 综述场景不同域）。
2. **切的什么角度**：架构替换 + 工具借用。把 PTJ 的"联合矩阵估计（CPE 与偏振耦合受衰落）"替换为"**CPE 与偏振解复用解耦**（先 CPE 后算 Jones 矩阵）"，工具是频域导频音（FPT）功率谱平方合并。属"前作有缺陷 → 解耦重构"的架构替换。
3. **dB 真实性条件性**：vs 传统 baseline + vs 内部对照。Q-factor 较 PTJ +0.9 dB；相对常规 4×4 MIMO+BPS 仅 -0.1 dB penalty（PTJ 为 1.0 dB）；RMSE 4.47° vs PTJ 17.99°；实验 40 km SSMF -0.7 dB ROP penalty。落在"赢传统 baseline 几 dB / 持平"区间。
4. **横向多样性**：LCOMM 切的是"**跨子模块协同（FOE+CPE+RSOP 共享一套 FPT）+ CPE/解复用解耦**"——这是池里**唯一跨到偏振解复用子模块**的角度，也是"解耦"这一独占角度（其他篇都是"联合/共享"而非"解耦"）。B3 笔记标其 B3 贴合度"意外高"。
5. **动机叙事**：从"FPT-CPE 受偏振衰落损害（θ→0°/90° 时 F_2X/F_1Y 趋零，ASE 淹没）"→"功率谱平方合并使 ϕ_PN 与 θ 无关"→"CPE 完成后再解 Jones 矩阵"。痛点（前作偏振衰落）驱动的收窄。
6. **实现复杂度**：40 km SSMF 实验（Keysight 8199A/UXR0594AP、BOX Optronics DFB）+ 仿真双轨。硬件实现中等强度。

### 2.4 jphot FSTS（jphot.2023.3265847）的切法

1. **站在哪个大点上切的**：站在**传统 TS-FOE + Park 帧同步**这个 FSO 分集接收大点上切。锚点是经典算法（传统 TS [18]、4th-FFT [11]、QPSK Partitioning [10]/[15]、Cheng 联合 FS+FOE [19]）。**不站在 sat.1553 上切**（jphot 是 FSO 仿真，2023 年发表，与 sat.1553 综述无直接引用关系）。
2. **切的什么角度**：联合建模 + 场景迁移。核心是"**一套 FSTS 同时做 FS（定位起点 + 对齐分集支路）+ 两段式 FOE**"，把原本分治的 FS 和 FOE 联合成共享一套 TS；X/Y 极化交织共轭对称 TS 使跨极化共轭直接消调制相位（无需四次方）。
3. **dB 真实性条件性**：vs 传统 baseline。单支路强湍 +1.03 dB（960 符号 4-QAM）/ +1.17 dB（320 符号）；4 支路 MRC 强湍 +2.09 dB（4-QAM）/ +3.41 dB（16-QAM）；320 符号匹配传统 960；复杂度降约 25%~75%。MSE 1e-7~1e-9 vs 传统 1e-6~1e-7。
4. **横向多样性**：jphot 切的是"FS+FOE+分集合并协同（共享 TS + 共享 LO）"——与张思齐 FS↔FOE 同质，但**多了 MRC 分集合并这一维度**（张思齐无分集）。与 LCOMM 不同（jphot 不跨偏振解复用，LCOMM 跨）。
5. **动机叙事**：从"传统 TS-FOE 需在接收端备份 TS、开销大、复杂度高"→"一套 TS 同时做 FS+FOE"→"X/Y 极化交织共轭消调制相位省四次方"。开销驱动。
6. **实现复杂度**：相位屏数值仿真（Schmidt 相位屏，Cn²=1e-16/1e-14），无硬件实现。

### 2.5 oe.520452 的切法

1. **站在哪个大点上切的**：站在**同课题组前作 jphot FSTS**（被引为 [24]）这个大点上切，是"自承接续/姊妹工作"切法。次级锚点是 Park 类帧同步大点。**不站在 sat.1553 上切**（与 jphot 同课题组同场景，无星地综述引用关系）。
2. **切的什么角度**：工具借用 + 场景迁移。把 jphot 的 FSTS 升级为"**PRBS 前缀（做 FS）+ 循环 QPSK 后缀（做两段 FOE）混合 Joint TS**"，新增点是**差分共轭消缓变湍流相位 + 侧峰抑制**（解决 Park 算法在循环序列下产生侧峰的问题）。协同动作同 jphot（FS+FOE 共享 TS）。
3. **dB 真实性条件性**：vs 传统 baseline。单支路强湍 +2.9 dBm（QPSK）/ +3.2 dBm（16QAM）；4 支路强湍 +1.78/+2.46 dBm；MSE 1e-8~1e-9 vs 传统 1e-6~1e-7（提升 2 个数量级）；比 Park 节省约 100 符号（≈39% 资源）。
4. **横向多样性**：oe 切的角度与 jphot **高度同质**（FS+FOE 共享 TS + 分集合并），B3 笔记把二者"同质合并"标。独占点是"PRBS+循环 QPSK 混合 TS + 差分共轭消侧峰"——是 jphot FSTS 的工具层改进，非新协同维度。
5. **动机叙事**：从"Park 类算法在循环序列下产生侧峰"→"PRBS 差分共轭提升非同步态非相关性使主峰与侧峰差异显著"→"循环 QPSK 后缀做两段 FOE"。前作工具缺陷驱动。
6. **实现复杂度**：相位屏数值仿真 + 室内 B2B 弱湍实验（Cn²=6e-11，发射 13 dBm）。硬件实现弱强度（仅室内弱湍）。

## 3. B2/B3 综述线切法模式小结（中性，不判 Go/Kill）

- **大点分布**：sat.1553 **不是**这 4 篇共同的"被反复切的超级大点"。sat.1553 自己是综述（自身即大点），它通过 L558/L582/L790 把"fade 冻结"和"子系统协同"两条切法**事后归并**出来；但池里 4 篇自己的大点锚各不相同——张思齐锚载波恢复经典算法（QPSK 分圈/4th-FFT/Cheng 联合）、LCOMM 锚自前作 PTJ、jphot 锚传统 TS+Park、oe 锚同课题组前作 jphot FSTS。**真正的"被反复切的子大点"是"传统 TS-FOE / Park 帧同步 / QPSK 分圈"这条 FSO 帧导频算法线**（jphot+oe+张思齐第四章共切），而非 sat.1553。
- **dB 形态分布**：
  - vs 传统 baseline：3 篇（LCOMM vs PTJ/MIMO+BPS、jphot vs 传统 TS、oe vs 传统 TS/FFT）
  - vs 内部对照：2 篇（Matsuda +0.6 dB vs 自身不冻结、张思齐 vs QPSK 分圈 +0.67~0.76 dB）
  - vs 理论上界：1 篇（Paillier vs AWGN/CRB，2.3 dB BER penalty）
  - 无 dB 仅结构性：2 处（sat.1553 的 B2 切口 L558/L582、sat.1553 的 B3 切口 L790）
- **横向多样性**：4 篇切的角度**集中度高但各有独占点**。共同轴是"共享 pilot/TS"（4 篇都切），但：
  - 张思齐独占"模块内数据复用（FOE↔CPE 共享中间量）"
  - LCOMM 独占"跨子模块解耦（CPE 与偏振解复用解耦，非联合）"
  - jphot 独占"FS+FOE+MRC 分集合并三模块协同"
  - oe 与 jphot 同质，独占点仅在工具层（PRBS+循环 QPSK 混合 TS）
  - **未有任何一篇切到 sat.1553 L790 真正指出的"定时恢复 + 自适应均衡 + 载波恢复"跨子系统协同**——这是 4 篇共同未占的最大空白。
- **动机叙事常见套路**：
  1. **"前作有缺陷 → 改进"**（LCOMM 的 PTJ 偏振衰落 → 解耦；oe 的 Park 侧峰 → PRBS 消侧峰）——最常见，2 篇。
  2. **"传统分治开销大 → 共享资源降开销"**（jphot 传统 TS 备份 → 一套 TS 双用；张思齐模块内联合降复杂度）——2 篇。
  3. **"地面/光纤算法直接搬会出问题 → 局部加对策"**（sat.1553 综述级；Matsuda 场景迁移）——B2 线。
  4. **"传统架构不适合 → 架构替换 + 端到端验证"**（Paillier OPLL→DPLL）——B2 baseline 分支。
- **实现复杂度梯度**（从弱到强）：
  - 纯仿真/纯综述：sat.1553（综述）、张思齐（仿真）、jphot（相位屏仿真）
  - 仿真 + 弱硬件：oe（相位屏 + 室内 B2B 弱湍）
  - 仿真 + 中硬件：LCOMM（40 km SSMF 实验）
  - 强硬件：Matsuda（FPGA 实时 4 Gbps）、Paillier（端到端数值湍流仿真，虽无硬件但信道建模最深）
  - **梯度规律**：协同角度越宽/越靠近综述 open problem 端（张思齐、sat.1553），硬件实现越弱；协同角度越靠近工程痛点端（LCOMM、Matsuda），硬件实现越强。

## 4. 自评

- **6 维里哪几维信息缺失率高**：
  - **"动机叙事"维度缺失率最高**：Matsuda 仅摘要（intro 不可得）、张思齐学位论文（笔记未载 intro 收窄路径）、Paillier（笔记有动机但未引 intro 原文）——3/7 篇该维信息不足或半不足。

  - **"横向多样性"维度在 B2 池受限**：B2 池天然小（sat.1553+Matsuda 摘要+Paillier），样本过小致横向对比信息不足；B3 池（4 篇）该维信息充分。
