# [R002] 方向 E 深入评估：湍流信道跟踪与预测

> 2026-05-30 | 关联：2026-05-30-ch3-direction-exploration / D001

## 调研问题

方向 E（Gamma-Gamma 湍流信道的时变跟踪与预测）能否作为 Ch3 替代方案？需回答四个关键问题：
1. 时间尺度不匹配有多严重？
2. 与 Ch2 信道估计的区别是什么？
3. 创新点是否足够强？
4. 仿真可行性如何？

## 发现

### 1. 时间尺度分析：致命缺陷

**核心数据：**

| 指标 | 弱湍流 | 中湍流 | 强湍流 |
|------|--------|--------|--------|
| 相干时间 T_coh | 10 ms | 5 ms | 2 ms |
| T_coh / FFT窗口 (3.28 μs) | 3052 | 1526 | 610 |
| T_coh / VV窗口 (102 ns) | 98039 | 49020 | 19608 |
| T_coh / 符号周期 (0.4 ns) | 2.5×10⁷ | 1.25×10⁷ | 5×10⁶ |

**接收端处理延迟（估计 h → 设置自适应参数）：**
- 导频间距 D_p = 8 符号 = 3.2 ns
- 自适应参数计算（闭合公式）≈ 0.1 ns
- **总延迟 τ_rx ≈ 5 ns**

在此延迟下，信道归一化变化量 MSE/σ² < 10⁻⁶（三种湍流均如此）。**信道在 5 ns 内完全静止。**

**发射端场景（唯一可能需要预测的场景）：**
- LEO 500 km 往返时延 τ_rt ≈ 3.3 ms
- 强湍流下 MSE/σ² = 0.96（信道几乎完全改变，预测有价值）
- 但功率预补偿已在 S013 MVE 中全面 FAIL（估计噪声放大导致崩溃）

**结论：接收端不需要预测，发射端预补偿已失败，方向 E 无应用场景。**

### 2. 与 Ch2 信道估计的区分度

理论区分（PROMPT-007 提出）：
- Ch2 估计 = "当前 h 是多少"（瞬时估计）
- E 跟踪 = "未来 h 会是多少"（预测 + 不确定性量化）

实际区分：**不存在。** 接收端 τ = 5 ns，预测值 ≈ 当前估计值（差异 < 10⁻⁶）。

Ch2 已有的估计方法（LS/MMSE/Kalman）在 NMSE ≥ -10 dB 时，Ch4 载波同步已全部通过（S002 级联实验 6/6 PASS）。"更好的预测"没有工程需求支撑。

### 3. 创新点强度评估

**文献现状：**
- Nguyen 2024：ESN 信道预测 + 自适应功率控制
- Song 2021：GRU FSO 信道预测
- Ying 2024：CNN+LSTM LEO 卫星信道预测

**方向 E 提议的创新**：将预测从"功率控制"迁移到"载波同步参数"。

**问题**：
1. 这只是应用场景迁移，方法论无创新（同样用 RNN/LSTM 做预测，只是下游任务变了）
2. 定量分析证明载波同步场景下预测无工程价值（见 §1），迁移缺乏物理依据
3. Nguyen 2024 已经做了"预测 → 自适应"的完整框架，换下游任务是增量创新

**结论：创新点太弱，仅是场景迁移 + 无工程价值支撑。**

### 4. 仿真可行性

技术上可行（sim_ch3_precomp.py 已有 AR(1) 信道生成和预测代码），但问题在于仿真结果会证明预测对载波同步无增益——因为 τ_rx / T_coh < 10⁻⁶，预测 = 估计。

### 5. 尝试的救援方向

**救援 A：不确定性量化**
用预测误差方差 σ²_pred 构建鲁棒参数设计（worst-case 自适应）。
问题：σ²_pred < 10⁻⁶·σ²（接收端），不确定性可忽略，无设计价值。

**救援 B：长程预测用于链路规划**
预测秒级/分钟级信道状态用于资源分配（AMC 方向）。
问题：这属于方向 B（AMC）的变体，且 S001 已将 B 评为 Maybe（非首选）。

**救援 C：Kalman 滤波统一框架**
将估计和预测统一到 Kalman 框架，作为 Ch3 的方法贡献。
问题：Kalman 估计已在 Ch2 中，独立成章需要更多增量。且 Kalman 预测 ≈ Kalman 估计（τ ≈ 0）。

**所有救援方向均不可行。**

## 结论

**No-Go。** 方向 E 不能作为 Ch3 方向。

**致命原因（任一条即可否决）：**
1. **时间尺度致命**：接收端 τ/T_coh < 10⁻⁶，预测 ≡ 估计，无物理意义
2. **无应用场景**：发射端预补偿已 FAIL，接收端不需要预测
3. **创新太弱**：只是"预测用于功率控制"→"预测用于载波同步"的场景迁移

**与方向 G 的对比：**

| 维度 | 方向 E（信道跟踪预测） | 方向 G（链路性能界） |
|------|----------------------|---------------------|
| 物理依据 | 无（τ≈0使预测无意义） | 强（相位噪声导致BER floor） |
| 工程价值 | 无（已有估计足够） | 强（给出Ch4设计目标） |
| 新颖性 | 弱（场景迁移） | 强（GG+高斯相位误差+QPSK = 零论文） |
| 叙事链 | 断裂（Ch4不需要预测） | 完整（Ch3性能界→Ch4设计目标） |
| 文献空白 | 小（已有大量信道预测论文） | 大（零竞争论文） |
