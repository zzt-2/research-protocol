## 已确认结论

### 对话7 新增结论 (S007)

18. **国内博士论文实验呈现高度统一**：折线图>85%（X轴=负载/规模，多算法曲线对比），收敛曲线为DRL标配，柱状图偶尔使用，无热力图/箱线图。来源：7a+7b
19. **国内论文无统计报告惯例**：5篇论文均不报告mean±std/CI/t-test，结果为单次仿真+定性分析。我们3 seeds+CI+t-test显著超标。来源：7a+7b
20. **相关工作统一在绪论按主题分节**：占6-10页，引用96-133篇，每篇1-2句概括。各章引言补1-2页本章相关工作。来源：7a+7b
21. **局限性讨论普遍以"展望"形式间接处理**：不单独设局限性节，措辞委婉（"未来方向"），不涉及方法论局限。汪宇是例外（明确说"不足"）。来源：7a+7b
22. **"卫星+计算卸载+图神经网络"CNKI零结果**：Ch3 HGAT+DAG方向在中文硕博论文中仍为空白，对新颖性有利。来源：7c
23. **董飞虎(2024博士)明确指出GNN是卫星路由下一步**：其Ch3小结写道"利用GNN提取更精确的网络特征将是未来工作"，直接支撑我们Ch3 HGAT的动机。来源：7e
24. **2025年同方向论文均有显式章间过渡**：刘英海和王宇卓两篇2025硕士论文都有明确的"上章局限→本章解决"过渡语，比旧论文(2018-2023)的多数无过渡有显著改善。来源：7d
25. **博士论文(董飞虎)各章小结内嵌局限性**：比"展望"间接讨论更坦诚，Ch3指出DQN在大规模时收敛下降→引出GNN需求。来源：7e

### S007 扩展精读新增结论（2026-05-26，18篇）

26. **GNN端到端路由在CNKI硕博论文中极罕见**：18篇精读中仅汪昊(2022)使用GNN做路由决策（MPNN+GATE，66颗铱星+预计算路径），唐宏京的GNN仅作特征提取器。无任何论文研究size generalization。来源：S007扩展
27. **18篇论文零统计报告**：所有论文均为单次仿真+定性分析，无mean±std/CI/t-test。宋佳鑫声称"95%置信水平"但未给CI值。我们3 seeds+CI+t-test是独一无二优势。来源：S007扩展
28. **Ch3 HGAT动机获多篇独立支撑**：董飞虎(2024)指出"GNN是卫星路由下一步"，王旭(算力网络)展望中提出"引入GNN对星间资源竞争关系进行编码"。两篇从不同角度论证GNN必要性。来源：S007扩展(王旭+董飞虎)
29. **星座规模普遍偏小（中位数~100颗）**：最大441颗(胡越)，多数66-288颗。我们24×66=1584显著超出，size generalization实验设计在CNKI无对标。来源：S007扩展
30. **王旭DAG任务建模更细致可借鉴**：数据/控制流/资源三类依赖加权融合，比我们当前的DAG建模粒度更细。来源：S007扩展(王旭)
31. **基线选取两极分化**：孔梦燕/唐宏京仅2个弱基线(Q-learning+贪心)，宋佳鑫6个基线最多。我们4-5基线含传统+DRL+消融，处于上端。来源：S007扩展
32. **Size generalization 实用性获三重支撑**：(1)行业现实：Starlink 60→42000(700x)、千帆 18→14000(28x)渐进部署；(2)计算经济：训练成本∝N^1.7，小规模训练5.4min vs Starlink规模82.6天(0.25%耗时+8.3%性能损失)；(3)标准趋势：3GPP Rel-19 multi-orbit roaming + IETF RFC 9717。来源：S007扩展(3个子agent)
33. **Krishnan et al.(2026, arXiv:2604.27478)独立验证GNN inductive generalization**：在Starlink 1442卫星上，小规模训练直接部署大规模无需重训练。与我们方法高度吻合，是重要的佐证论文。来源：S007扩展

### 对话6 新增结论 (S005)

1. **Ch3 排队模型是确定性 FIFO，不是 M/M/1**：代码实现 `completion_time = max(node_available, pred_finish) + transfer_time + compute_time`，是确定性单服务台模型。论文描述必须匹配，不能称 M/M/1。来源：6b
2. **三章核心物理公式数学一致**：Shannon 容量 `B·log2(1+SNR)` 三章相同；Ch2/Ch3 FSPL 等价（一个用波长，一个用频率）。来源：6c
3. **Ch3 antenna_gain=1.0 定义但未使用**：G2S 直连 (Ka-band, 0dBi) 速率接近零。与 K2/M01 (G_P=1) 一致，仿真中可能通过 UAV 中继绕过。来源：6b
4. **Ch3 noise_power=-100dBm 对应 20MHz BW 热噪声**：用于所有链路导致 ISL (1GHz) SNR 高估 ~17dB。来源：6a

### 不变量

1. **Walker-Delta 星座拓扑是 GNN size generalization 的理论最优图族**：恒定度数4 + 2D球面流形 + 规则网格满足四族充分条件（局部结构不变/graphon收敛/谱相似/架构对齐），无已知不可能性定理适用。来源：3a 理论检索综合

### 其他结论

1. **GNN > MLP at scale 在无线领域有中-强支撑**：Shen JSAC 2021 + Eisen TSP 2020 + Huang COLT 2025 量化。交叉点 N~20-50。反例仅来自小规模特征丰富节点分类。来源：3b
2. **3 seeds + mean±std 低于 ML 标准但符合 IEEE 通信 DRL 通行做法**。必须加 bootstrap 95% CI + Welch's t-test（零计算成本）。来源：3c
3. **跨章 GNN 叙事应分层**：规模不变性(Ch1) / 排列等变性(Ch2) / 类型感知(Ch3)，不能用简单的"GNN在大规模才有效"统一。来源：3d
4. **Ch3 零样本泛化失败与理论一致**：HGAT attention 方差在跨规模时过高，简单聚合器(GCN mean)泛化性更好。来源：3d + D020
5. **Ch2 竞品覆盖完整**：6轮补充检索(~210条)，无GNN+DRL+卫星切换先例。新发现6篇低-中威胁论文。来源：S001-1a
6. **二部图+DRL 先例存在**：Xie 2023(WCAP, 二部图+GNN+RL做HAP接入) + Yin 2022(卫星-BS二部图+DDQN)。Ch2 新颖性需引用这两篇并限定范围。来源：S001-1b
7. **Ch2 方法论符合或超越子领域通行标准**：5篇零统计检验，3-seed是下限可接受。主要风险在GNN增量论证策略(侧重size gen而非小规模提升)。来源：S001-1c/1d
8. **Ch1 竞品覆盖完整**：7组关键词检索，新发现5篇低威胁论文，无一覆盖GNN+跨规模泛化+LEO ISL路由交叉点。来源：S002-2a
