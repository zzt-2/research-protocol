对方向侦察 Top 1（#12 卫星 IoT NTN 接入+GNN）和 Top 2（#11 工业无线 TSCH+GNN/Meta-RL）执行 GW Step 4a 可行性评估。

## 记录

### #12 卫星 IoT NTN 接入 + GNN — Kill

**精读论文**：
- Lee 2025 (arXiv:2512.07053v2) "Random Access for LEO Satellite Communication Systems via Deep Learning" — 1D-CNN 碰撞分类器，星形拓扑
- Le 2024 Survey (c=84) "Survey on RA Protocols in Direct-Access LEO Satellite IoT" — 仅摘要（IEEE 付费墙）
- ML RA 2025 — DNNB 碰撞解析器，星形拓扑

**GNN 空白确认搜索**：10 篇结果中 0 篇使用 GNN。

**A0 致命信号**：
1. 跨域成功先例 = 0（GNN × 接入控制无成功案例）
2. 先验覆盖 >90%（ACB + 解析优化 P* 在主指标已覆盖）
3. 星形拓扑（1 卫星 → N 用户），GNN 退化为 MLP
4. 空白原因 = "不需要"（决策是 per-preamble 局部分类）

### #11 工业无线 TSCH + GNN/Meta-RL — Kill

**精读论文**：
- Ben Yaala 2025 "Optimizing TSCH Scheduling for IIoT Using RL" — DQN/DDQN/PER-DQN 信道选择

**搜索发现**：
- GNN × TSCH 调度 = 0 篇
- GNN × IoT 调度 = 1 篇 (c=6，非 TSCH)
- GNN + DRL × job-shop 调度 = c=336（跨域先例，但拓扑不同）

**A0 致命信号**：
1. TSCH 拓扑 = 汇聚树（convergecast tree，RPL DODAG），非 mesh
2. 树形拓扑 GNN 退化为 MLP（与 #12 星形同模式）
3. 状态 ≤24 维，动作 16 离散值，DQN 已足够
4. 规模固定且极小，size generalization 无意义

### 关键洞察

**GNN + 接入/调度是错误的问题空间**。接入/调度问题的拓扑天然简单（星形或树形），信息一跳可见，GNN 无增量。这与 GNN 在路由（网状拓扑）和 NFV（双图结构）上的成功形成对比。

**失败模式一致性**：
- Walker 网格（leo-congestion-routing 风险）→ GNN 退化
- ISL 调度 → 物理约束+网格
- Beam Hopping → 物理约束
- 卫星 IoT 接入 → 星形退化
- 工业无线 TSCH → 树形退化

### #13 NTN-TN 双连接切换 + GNN — Kill

**搜索发现（3 路并行检索）**：
- DRL+卫星切换：30-50 篇，0 综述，方法同质（DQN 变体），GNN+切换仅 2 篇 → 非红海
- GNN×切换/关联跨域先例：≥4 篇成功（Lee'25 卫星、Bermudez'25 O-RAN、TH-GCN'25 车联网、Deng'23 mmWave）

**精读论文**：
- GEMS (Wang, TMC 2026)：GAT 边权重 + 二部图匹配 + 时间扩展，DC 辅助链路配置
- Lee 2025 (ICT Express)：MPNN T=2，卫星切换目标选择，1584 星+50 UE，有 size gen

**A0 评估**：通过（无致命信号）
- 拓扑非平凡（时变二部图，非星形/树形）
- 跨域先例 ≥4，MDP 非平凡，问题结构适配

**A' 竞争维度**：关键发现——原空白声称"GNN×NTN-TN切换=0篇"**不成立**
- GEMS 已用 GAT 做 DC 配置（TMC 顶刊）
- Lee 2025 已用 MPNN 做卫星切换目标选择
- 剩余空白：TN→NTN 主链路切换（可能是伪需求）、异构图+深层GNN+DRL 组合（增量未验证）

**A/B 风险信号**：
1. GEMS 高质量直接竞品，浅层 GAT 已发顶刊
2. 差异化窄：深层 GNN vs 浅层 GAT 的增量未验证，可能收益递减
3. 空白原因非"没人想到"，而是"不同团队从不同角度逼近"，竞争窗口正在关闭
4. 组合创新（异构图+深层GNN+DRL）每个组件已独立验证，但组合后的改进幅度不确定

**Kill 理由**：空白声称失效 + 高质量竞品存在 + 差异化空间不足以支撑独立研究方向

### 关键洞察（更新）

**第三种失败模式**：除了"拓扑退化"（#12/#11）外，#13 暴露了"空白声称失效"模式——初始搜索因关键词不精确或数据库遗漏导致"0篇"误判，深度验证后发现已有直接先例。这类方向的 Kill 不是方法不匹配，而是竞争已覆盖。

**GNN 方向全局审视**：
- 拓扑退化（星形/树形）：#12, #11, DC-TE, IAB 树, Walker 网格
- 物理约束主导：BH, ISL, MIMO, 频谱, RIS
- 红海：V2X, CDN, 切片, 光网络, 边缘计算, 无线链路调度, 网络节能
- 空白声称失效：#13（NTN-TN 切换已有 GEMS+Lee）
- **仍存活的 GNN 方向**：#1 NFV/SFC（最高置信度）、#2 IoT mMTC、#4 组播路由、#5 CFN

## 后续

1. **GNN 方向评估建议暂停**：连续 Kill #12/#11/#13，GNN 路线的命中率极低。剩余 GNN 候选（#1/#2/#4/#5）虽然置信度较高，但需要警惕"空白声称失效"模式
2. **优先评估非 GNN 方向**：#7 离线 RL+流量工程（高空白质量）、#6 离线 RL+资源调度、#10 离线 RL+边缘卸载
3. **#1 NFV/SFC 仍是最强 GNN 候选**：如果继续 GNN 路线，应优先验证 #1，它有 c=99 验证 GNN>MLP 且 NP-hard 保证优化空间

### #7 离线 RL + 流量工程 — Kill（重叠）

**搜索发现（3 路并行检索）**：
- offline RL + TE/routing 精确交叉 = **0 篇**，真空白确认
- offline RL 在通信领域 <20 篇，以 CQL 和 Decision Transformer 为主
- Peri'25 (ICMLCN)：离线 RL 在行为策略质量高时可匹配在线 RL，但数据质量是核心风险
- 跨域先例强：机器人(D4RL)、自动驾驶、医疗、推荐系统

**A0 评估**：全部通过
- 性能间隙 ✅（传统 TE 非最优，在线 RL+TE 有综述说明问题有空间）
- 问题结构适配 ✅（运营商有历史流量矩阵，在线探索代价高）
- 跨域先例 ✅ 强（多领域成功 + Yang'24 通信 RRM 验证）
- MDP 非平凡 ✅，先验覆盖 ✅

**致命问题：与 leo-congestion-routing (Ch3) 重叠**
- leo-congestion-routing 本质是 **TE 问题用路由决策范式解**（优化 MLU，TE 核心指标）
- 离线 RL + TE = **同一问题空间的不同解法**
- 不满足论文"3个互相关联**问题**"结构要求
- Roth'25 ASMS 已做"卫星星座 DRL 自适应 TE"，进一步压缩差异化空间
- 答辩时难以论证为独立贡献（同一问题的两种 RL 变体）

**Kill 理由**：空白极强但与 Ch3 问题重叠致命，不满足论文结构要求

### 关键洞察（再更新）

**第四种失败模式**：问题空间重叠——空白本身成立，方法也有价值，但与已有项目（Ch3）在问题定义层面高度重叠，不满足"独立问题"的论文结构要求。这种失败在初筛阶段难以发现（因为空白本身是真实的），只有对照已有项目后才能识别。

**离线 RL 方向的教训**：方法本身（离线 RL）在通信中有价值，但需要找一个与路由/TE **问题空间不同**的应用场景。#6(资源调度)和 #10(边缘卸载)可能在问题空间上与 Ch3 正交。
