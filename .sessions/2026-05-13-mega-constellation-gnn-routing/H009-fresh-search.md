# 新对话提示词：卫星通信方向大规模文献检索

## 任务

在卫星通信大类下做 Groundwork Step 1（大规模文献检索 + 方向扫描），目标是找到 2-3 个有研究价值的候选切口方向。

## 背景

读 `.sessions/STRATEGY.md` 了解完整上下文。核心要点：

- 用户是研究生，导师给的初始方向是 **"LEO 卫星链路"**，参考方向是 ISL ACM 预测
- 之前在这个方向下做过 4 个项目（见 archive/studies/archive/），但验证不到位，结论不可信
- **不复用旧结论**，在当前框架下从头检索
- 范围：**卫星通信大类**（不限于 LEO，NTN/6G/星地融合/星间链路等均可考虑）
- 用户当前在找实习，时间有限，本轮只要检索产出，不需要仿真器

## 执行步骤

### 1. 读框架文件（必须，按顺序）

1. `stages/groundwork.md` — 整体流程
2. `stages/gw-search.md` — 检索步骤的完整操作规范和质量门槛（[MUST] 严格遵守）
3. `domain-comms.md` — 通信领域定制
4. `tools-guide.md` §1-2 — 工具调用方式和检索参数

### 2. 构造检索词

从以下角度各构造 1-2 组关键词（共 ≥5 组），覆盖卫星通信大类下的不同子方向：

- **角度 A：链路层问题**（信道预测、链路自适应、ACM、波束管理）
- **角度 B：网络层问题**（切换、资源分配、路由、负载均衡）
- **角度 C：接入层问题**（随机接入、多址接入、D2D/NTN 融合）
- **角度 D：新兴场景**（NTN-地面融合、星地协同、低轨巨型星座、ISL 组网）
- **角度 E：AI/ML 方法在卫星通信中的应用**（DRL、GNN、Transformer 等）

每组关键词用 `tools/search` 执行，参数建议：

```bash
cd /mnt/d/code/study/research-protocol && ./tools/search "关键词" --mode academic --preset scenario-method
```

### 3. AI 候选审查（[MUST]）

按 `gw-search.md` 第 4 步执行，对每条候选标注 priority 和 priority_reason。

### 4. 方向切口分析

检索完成后，基于候选列表做方向切口分析：

- 哪些子方向论文密度高但创新空间仍有？（热门但未饱和）
- 哪些子方向论文少但问题真实？（冷门但有价值）
- 哪些子方向与导师"LEO 卫星链路"方向关联度最高？
- 每个候选切口的最小可发表单元是什么？

### 5. 输出

- 搜索结果 JSON：`search-archive/{date}/{slug}.json`（脚本自动存档）
- 候选方向分析：写入 `.sessions/DIRECTION-CANDIDATES.md`，格式：

```markdown
# 候选方向分析

## 方向 1：{名称}

- 核心问题：{一句话}
- 与导师方向关联度：高/中/低
- 论文密度：{高/中/低}，近年趋势
- 创新空间：{描述}
- 最小可发表单元：{描述}
- 代表文献：{top 3-5 篇，含 priority 标注}

## 方向 2：...

## 方向 3：...

## 综合推荐排序

1. ...
```

## 约束

- 严格按 `gw-search.md` 的质量门槛检查（≥20 条候选、覆盖度、正式发表占比等）
- 不达标时按 `gw-search.md` 的"不达标时"指引补充搜索
- 搜索工具必须从项目根目录调用：`cd /mnt/d/code/study/research-protocol && ./tools/search ...`
- 每条文献的 DOI/发表状态必须验证，不接受虚构条目
- 子 agent 最多 3 个并发
