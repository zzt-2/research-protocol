### 地勘执行规范

- **工具**：`tools/search`（脚本，不是 web search——守主对话禁令）
- **检索范围**：**星地激光通信全谱**（不预设方向、不锁模块、不锁湍流）。标题"星地湍流信道激光通信处理技术研究"——背景锁星地激光通信，湍流可去，处理技术是宽义。
- **检索词原则（方法中性 + 不锁模块）**：用大背景词（`satellite optical communication` / `satellite laser communication` / `LEO optical downlink` / `free-space optical satellite` 等），**不带** synchronization/estimation/modulation/coding 这些模块限定词。让"做什么"从结果涌现，不预设。
- **年份**：2019+（thesis-fso master-state 项目级参数）
- **全留原则（关键，区别于之前检索）**：**不要只留几个候选**。所有结果按规范化标题去重后全留，拉表。被"看起来不相关"筛掉的也标注理由（附录），不直接丢——这是领域记忆的基础。
- **产出位置**：`projects/thesis-fso/landscape.md`（与 literature_notes.md 平级，新文件）

### landscape.md 产出格式（强制）

每行最小字段：

| 字段 | 内容 | 为什么留 |
|---|---|---|
| 子地带 | 它属于哪个子方向（同步/估计/调制/编码/pointing/系统级/光学处理/...） | 分类用，从结果涌现不预设 |
| 做的事 | 一句话：用什么方法解决什么 | 知道领域在做什么 |
| 是否跟湍流强相关 | 强/弱/无关 | 标题湍流可去，这条判断空间 |
| baseline 是谁 | 它对标/改进的方法 | 后续找缝要看 baseline |
| 增益怎么验证 | 仿真/MC/实测/解析 | 难度参考 B（工程可验证性） |
| 缝潜力初判 | 🟢有缝/🟡不确定/🔴死地饱和 + 一句话理由 | 分类用，**初判不是结论** |

### 拉完表后分类（主线做，不是子 agent）

按缝潜力三分：
- 🟢 **有缝潜力**：baseline 在某条件下真失效的迹象 + 增益可验证。→ 候选进批评汇总
- 🟡 **不确定**：看着像有空间但 baseline 最优性存疑。→ 标记，🟢 走不通再看
- 🔴 **死地/饱和**：已知饱和（5 次失败的轴 + 批评汇总标的拥挤赛道）+ baseline 已最优。→ **永久标记，不再碰**

**🔴 必填项**（本轮就要标进去，作为领域记忆种子）：
- 载波同步（N1 PCS / A3 CPE / "Are PLLs dead?"）—— 5 次失败核心子环节
- 自适应交织（4b#1）—— D001 Kill
- GG-LLR 译码（(c)）—— D002 Kill
- MCS 排程（③）—— oracle 0.09dB
- 信道估计 LS/LMS/RLS、静态均衡、理想CSI假设 —— S002 批评汇总标的拥挤赛道
