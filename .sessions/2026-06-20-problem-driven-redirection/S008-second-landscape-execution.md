## 关键方法论结论（本轮新增）

### M1：判读死轴成因必须分两步（偏航检查 E 提炼）

**旧做法**（v2 S006）：只看占比 → 载波同步 5.3% / 信道估计 3.0% 判为"结构性冷区"。
**新做法**（v3 动作 B）：占比 + 真缝密度 → 载波同步 5.3% + 23.5% 真缝率 = **"有缝但人少"的候选地**，不是死地。

**规则**：死轴判读 = 人数信号（占比/搜索 raw 数）× 缝信号（abstract 真缝密度）。只看占比会误杀有缝冷区，只看缝密度会忽视饱和热区。**v2 的"死轴冷区"结论需要 v3 动作 B 的真缝密度修正——不是推翻，是细化**：冷区里可能藏着未被充分探索的真缝。

### M2：设备词检索 vs 模块词检索的互补性

- 设备词（动作 A）召回**硬件/载荷层**（transceiver/PIC/DPU/module），死轴方法维度零命中
- 模块词（动作 B）召回**方法层**，直接命中缝信号
- **两者物理隔离的必要性得到验证**：S007 的"拆分方案"不是方法论洁癖，是两种检索词召回不同层面的真实反映。合并会让候选池混入硬件层噪声（动作 A 79 核心里方法层信号稀薄）。

### M3：IEEE 限流的精确机制 + 债务处理原则

- 机制（外部对话 3 词样本）：**高频通用词实时反爬 + 累积风险分**，非纯 IP 全封
- 债务处理原则：**增量价值 < 执行成本时留债务不重跑**。search API 够主信号时 IEEE 是密度补充不是判读必需。不卷用户进体力活（手动下 JSON 格式适配成本 > 等解封）。
