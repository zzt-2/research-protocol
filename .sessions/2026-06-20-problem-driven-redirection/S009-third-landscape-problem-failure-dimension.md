# [S009] 第三轮换维度检索方法论讨论 + 外部评审 + push back + 三动作方案定案

> 2026-06-22 | 阶段：方法论验证（地勘 Step 0，第三轮检索设计）| 状态：T002 定案待执行，本轮讨论已完成

## 目标

1. 处理用户对 landscape.md v3 的不满信号——"多找几个角度切入，看看哪些角度能拿到合适内容"，判断是焦虑驱动还是方法论驱动
2. 验证"换维度检索"的真实价值——是真盲区（A：检索没覆盖）还是物理约束（B：地真没缝）

## 记录

### 步骤 1：用户提"多找几个角度切入"

主线评估 S008 产出（landscape.md v3，509 主表）后，用户提："我们有没有可能，多找几个角度切入，去检索，看看哪些角度能拿到合适的内容？还是说概率很小？感觉我这开题方向是真的难搞啊"

主线**没有立即同意也没有立即反对**——先做 A/B 分离诊断：
- 之前 3 轮（场景词/设备词/模块词）共同盲区：全在搜"**是什么**"（什么场景/设备/模块），没有一个在搜"**出了什么问题**"
- 换到"问题/失效"维度可能召回自陈失效论文（跟判据 A 同构）
- 但换维度能不能找到东西，取决于 A/B 两种"难搞"哪种：
  - A（检索盲区）：地有缝但词没覆盖 → 换维度有用
  - B（物理约束）：地真没缝被中弱湍流 σ²_R<1 压死 → 换多少维度都颗粒无收
- **换维度检索的真正定位 = A/B 分离诊断**

主线明确告诉用户：概率不小但有前提（必须换到没试过的维度）。用户说"做吧"。

### 步骤 2：主线起草问题/失效维度检索词集（v1）

主线草拟 3 组词：
- A 组（物理损伤/退化，7 词）：atmospheric impairment / scintillation effect / turbulence impact / SNR degradation / link budget penalty / beam wander
- B 组（失效/差距，6 词）：performance degradation / performance limitation / BER floor / capacity loss / Doppler impact / mismatch loss
- C 组（可选，更窄）：phase noise impact / pointing loss / fading mitigation

主线给用户 4 个判断点过目（方法中性够不够 / C 组要不要加 / 数量 / 隐藏风险）。

**用户说"说实话我不太确定。你给我一段话我问问别的对话？"** → 主线写外部评审用文本，用户拿去问别的对话。

### 步骤 3：外部对话评审 + 主线 push back

外部对话返回详细评审，**质量高，挑出真问题**：

| # | 外部观点 | 主线评估 |
|---|---|---|
| 1 | A 组重叠严重应砍（scintillation/turbulence 在 v2 主表已是最大子地带 47 条），B 组才是真增量 | **PASS**——硬数据验证，不是推断 |
| 2 | 视角偏差："degradation/loss" 偏"已解决"（工程师词），"limitation/challenge/open" 偏"未解决"（研究者词）| **PASS**——信息检索里真实词频分布 |
| 3 | 检索阶段分不开方法层/物理分析，用 S007/S008 A/B 物理隔离解 | **PASS**——直接复用已定案方法论 |
| 4 | **判据 A 同构的是方法对比不是问题描述**；建议加 C 组（综述/对比/自陈失效声明词）| **部分 push back** |

**对第 4 点的 push back**：

对方说"方法对比论文 = 判据 A 信号"。技术上对——判据 A 需要 baseline vs 新方法对比信号。**但对方漏了一个约束**：

判据 A = baseline 在**常见条件**下真失效。方法对比论文召回的是"**我的新方法 vs 某 baseline**"——能证明新方法更好，但**未必证明 baseline 在常见条件下失效**。可能只是"我的方法比 baseline 好一点"（特定场景），baseline 在常态下其实好。

真正跟判据 A 同构的信号是：有人**独立于任何新方法**地，证明某 baseline 在常见条件下失效——诊断性/分析型论文（标题常含 limitation of / failure of / when X fails）。

**所以对方第 4 点**：
- 对的部分：综述论文是找缝金矿（作者主动盘点 open problem）
- 偏的部分：方法对比论文 ≠ baseline 失效证据。方法对比可能只是"我比你好一点"，不代表你失效

**用户提醒**："你也得小心，不要偏离初衷"——主线据此守住了 A/B 分离诊断的初衷（换维度是为了 A/B 分离，不是为了塞方向）。

### 步骤 4：三动作融合方案定案

主线融合对方评审 + push back，提**三动作方案**（不是对方的两个）：

**动作 A（真·地勘，方法中性）**：问题/失效维度
- 用对方 B 组研究者词（砍 A 组重叠词）：performance limitation / open challenge / fundamental limit / capacity bound / bottleneck / Doppler impact
- 加少量结果型词（跟已有重叠低）：SNR degradation / BER floor
- **产出入主表**

**动作 B（受控诊断，不地勘）**：方法+问题复合词
- 对方建议：satellite optical equalizer Doppler / satellite optical synchronization turbulence
- 按 S007/S008 方法论：标诊断不地勘，产出只入诊断段，物理隔离

**动作 C（综述金矿）**：对方说综述是最强缝信号源
- satellite optical survey / satellite optical review / satellite optical tutorial
- 综述天然做对比、主动盘点 open problem
- **产出入主表**（综述是合法地勘对象，不是诊断）

**AskUserQuestion 问用户**：4 选项（三动作 / 只 C+B / 回初稿 / 暂停想清楚）。**用户选三动作方案**。
