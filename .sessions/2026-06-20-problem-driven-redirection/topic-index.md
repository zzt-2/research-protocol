- **【S003】路由 vs FSO 结构性差异**（为什么一个顺一个难）：路由顺 = baseline 在常态下真失效（故障8%）+ 工程可验证（跑一下就知道）+ 离散组合优化；FSO 难 = 地被物理压死没缝 + 物理可证明（参数敏感，一错整轮废）+ 连续物理信道。
- **【S003】判据分层**：判据 A（缝，硬 Go/No-Go）+ 判据 B（难度，软参考）。之前混成"4 条都满足才顺"是错的——真卡死的是 A 不是 B。
- **【S003】之前检索的结构性缺陷**：每次只留几个候选、被筛掉的大多数消失 → 无领域记忆 → 反复检索反复忘 → 原地打转。地勘全留拉表 + 🔴 死地标记 = 解药。
- **【S003】地勘阶段不用批评汇总的框法乙**：地勘要全景不是批评视角。套框法乙会只看有批评的地方，漏"很多人做但没人批"（可能饱和也可能暗藏问题）。
- **【S007】诊断 vs 地勘的分类原则**：用模块词（synchronization/estimation/equalization）检索**不算地勘**，是诊断。S006 死轴冷区结论如果要验证（是检索词偏差还是结构性事实），必须用模块词搜——但这违背 S003/H02 地勘方法中性。解法不是"允许地勘用模块词"（会侵蚀原则），而是**承认这是诊断动作不是地勘**：产出只入诊断段不入候选池，不污染候选池，不侵蚀原则。**T001 把动作 A（设备词真地勘）和动作 B（模块词诊断）物理隔离**。
- **【S007】处理技术边界（用户 2026-06-22 确认）**：✅ 算处理：调制/复用、检测（相干/自相干）、编码/FEC/交织、信道估计/均衡、同步、信道建模/湍流（信道处理）、AO/自适应光学算法（波前校正算法，跟 DSP 补偿同构）。❌ 不算（老师不同意）：ATP/指向（光学/控制工程非通信处理，用户原话"ATP/指向这玩意算通信吗？感觉不是呢？"）、网络层/路由/RWA、ISL/feeder/系统级、QKD/深空/在轨/硬件。
- **【S007】方法论跨对话评审 + push back 机制有效**：外部对话评审挑出主线 T001 草案违反 H02 方法中性（真问题，H002:24/67 原文为证）；主线用 receiving-code-review 纪律不盲目同意，push back 外部"砍到 3 个死轴词"建议的矛盾（压力测试本身必须用模块词），提拆分方案被用户采纳。比主线草案和外部建议都好。**这本身是"方法论被验证不是被执行"的实例**。
- **【S008】判读死轴成因必须分两步**（偏航检查 E 提炼）：死轴判读 = 人数信号（占比/搜索 raw 数）× 缝信号（abstract 真缝密度）。只看占比会误杀有缝冷区（v2 S006 判载波同步 5.3% 为"死轴冷区"，v3 动作 B 测出真缝密度 23.5% 反高于热区调制 10%——是"有缝但人少"非"没缝"）。**v2 的"死轴冷区"结论需 v3 真缝密度细化，不是推翻是细化**。
- **【S008】设备词检索 vs 模块词检索的互补性**：设备词（动作 A）召回硬件/载荷层（transceiver/PIC/DPU/module），方法维度零命中；模块词（动作 B）召回方法层直接命中缝。两者物理隔离的必要性得到验证——S007 拆分方案不是方法论洁癖，是两种检索词召回不同层面的真实反映。合并会让候选池混入硬件层噪声。
- **【S008】IEEE 限流的精确机制 + 债务处理原则**：机制是"高频通用词实时反爬 + 累积风险分"非纯 IP 全封（外部 3 词样本：receiver/photonic-receiver 拿到 24-25 条，transceiver/frontend 被挡）。债务处理原则：增量价值 < 执行成本时留债务不重跑，search API 够主信号时 IEEE 是密度补充不是判读必需，不卷用户进体力活。
