写作模板工具（thesis-platform `.sessions/2026-05-29-writing-template-workflow/`）已验证通过，绪论模板+句级语感均达标。工具需要三类输入才能生成开题报告：

## 产出目标

### 产物1：章节内容卡片（每节一张）

格式参照 thesis-platform R001 的 structure.md 逐节四列模板：

```markdown
### X.Y 节标题
| 维度 | 内容 |
|------|------|
| 功能 | 本节在论证链中的角色 |
| 核心论点 | 2-3 个关键 claim |
| 支撑文献 | [作者年份] 具体贡献 |
| 可用数据 | MVE 数据/文献数据/公式 |
| 衔接上 | 承接上一节的什么 |
| 衔接下 | 为下一节铺垫什么 |
| 约束 | D005(传统主线)、QPSK、导师框架限制 |
```

### 产物2：分章文献清单

按 S012 v4 目录结构，每章列出核心文献（5-8 篇/章），含：
- 论文元数据（作者/年份/期刊/引用数）
- 与本节的对应关系（哪篇支撑哪个论点）
- 已获取状态（content.md 是否存在）

### 产物3：FSO 领域句级范例

从参考论文中按 T1-T6/R1-R2 模式提取标注句子（通用化，不带具体数据）。
当前 sentence-examples.md 是卫星网络领域的，需要补充 FSO 领域范例。
