### 论文2：大气激光通信数字相干探测关键技术研究（李学良，中科院长春光机所，2018，硕士）

## 综合结论

### 1. 我们的计划在深度上是否达标？

**基本达标，但需要调整。** 锚点论文显示：

- 典型硕士论文：3-4章主体，每章1个核心算法/技术 + 对比实验
- 张岱（国防科大）覆盖"信道建模+信号处理"≈2个方向
- 李学良（中科院）覆盖"载波恢复+I/Q补偿+概率整形+调制识别"≈4个方向，48次被引
- 闫旭（西电博士）覆盖"波前补偿+载波估计+跟踪"≈3个方向

**我们的计划（信道估计+均衡+载波同步，3章）与典型硕士论文的结构一致。** 但需要注意：
- 李学良的硕士论文做了4个方向且被引48次——说明这个领域的硕士论文可以做得相当深入
- 闫旭的博士论文做了3个方向但每个更深（有专利+SCI论文支撑）

### 2. 我们计划的方法对比数量是否足够？

**足够，甚至比多数锚点论文更系统。**

| 论文 | 每章对比方法数 | 我们计划 |
|------|-------------|---------|
| 张岱 | 1-2个 | Ch2: MMSE/LS/DL = 3个 |
| 李学良 | 1-2个（+DL） | Ch3: CMA/DFE/MMSE/DL = 4个 |
| 闫旭 | 1个（二分法CPE） | Ch4: VV/BPS/Pilot = 3个 |
| 赵远帆 | 传统+DL对比 | 每章都有DL对比 |

我们的方法对比数量（3-4个/章）**多于**多数锚点论文。关键是要保证DL方法确实有提升，否则会显得多余。

### 3. 我们计划的工作量（每章2-3天仿真）是否现实？

**偏紧但可行。** 理由：
- 李学良（48被引）覆盖4个方向，属于高产出
- 多数硕士论文覆盖2-3个方向
- 我们有本科毕设的MATLAB仿真基础（Gardner、CMA、PLL、LDPC都有现成代码）
- **风险**：DL方法（如果从零训练）可能需要额外时间，建议用简单网络（MLP/小型CNN）

### 4. 有没有我们漏掉的内容是这些论文都做了的？

**有一个共性值得关注：**

- **I/Q失配补偿**：李学良专门做了ASOP算法，汤昕宇也涉及。相干检测系统需要I/Q正交化校正，我们计划中没有明确提及。建议在Ch3或Ch4中考虑。
- **仿真平台验证**：多数论文都有完整的MATLAB/Python仿真链路，我们已有毕设代码基础，这是优势。
- **Gamma-Gamma模型**：所有论文都用GG模型，我们Ch2也计划用，方向正确。

### 5. 最终建议：我们的计划需要调整什么？

| 调整项 | 优先级 | 说明 |
|--------|--------|------|
| 确认选题独特性 | **高** | 张岱2018年国防科大硕士论文标题与我们几乎完全相同，需要在开题报告中明确区分点（DL方法、方法对比系统化等） |
| I/Q失配补偿 | **中** | 考虑在某章中加入I/Q补偿作为系统完整性的一部分 |
| DL方法定位 | **中** | 赵远帆的导师团队已做了BP/LSTM信道均衡，我们需要确保DL方法有差异化（建议：不同网络结构、不同训练策略、或更系统的对比框架） |
| 工作量预留 | **低** | 每章2-3天仿真基本可行，但DL部分预留额外1-2天 |
| 参考文献覆盖 | **低** | 锚点论文（尤其李学良48被引、闫旭博士论文）的参考文献列表可作为我们文献综述的起点 |
