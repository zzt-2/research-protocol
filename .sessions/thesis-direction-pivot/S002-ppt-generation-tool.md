# [S002] 开题答辩 PPT 自动生成工具

> 2026-05-29 | 执行 | 进行中

## 目标

基于北理学术答辩 PPT 模板，构建 python-pptx 自动化工具，从结构化 JSON 生成答辩 PPT。与开题报告内容定稿同步，快速出 PPT 初稿后手动微调。

## 记录

### 工具调研（3 个子 agent 并行）

派出 3 个子 agent 分别搜索 LinuxDo 论坛、综合工具对比、学术答辩专项方案。结论：

| 类别 | 推荐方案 | 说明 |
|------|---------|------|
| **在线 SaaS** | 豆包(免费)、笔灵AI(答辩稿+问题预测)、Gamma | 无法套用学校模板 |
| **开源工具** | Presenton(Docker)、PPT-master(SVG) | 部署重/排版不可控 |
| **Markdown→PPT** | Marp、Slidev | 不兼容 .pptx 模板 |
| **学术专用** | academic-pptx-skill (GitHub) | 需要 claude.ai 环境 |
| **最终选择** | **python-pptx + 克隆模板幻灯片** | 完全可控，保留模板视觉 |

**关键共识**：内容不是瓶颈，排版才是。有学校模板时，python-pptx 克隆方案是最优解。

### 工具实现

脚本路径：`tools/gen_pptx.py`

**核心思路**：克隆模板示例幻灯片 → 替换文字 → 删除原有幻灯片 → 保存

**模板分析结果**：
- 北京理工大学学术答辩PPT模板：362 张幻灯片，38 种版式
- 选用风格：封面样式1（首页+尾页）、目录样式1、封面样式6（章节分隔）、内页样式1（全部内容页）
- 内容布局：20+ 种（一段文字、观点对比、四个观点、框架图、时间轴、图表等）

**支持的布局类型**（全部注册，JSON 中通过 `"layout"` 字段指定）：

| 布局 | 索引 | 自动填充 |
|------|------|---------|
| 一段文字 | 66 | ✅ 标题+要点 |
| 两段文字 | 69 | ✅ 标题 |
| 观点对比 | 72 | ✅ 标题 |
| 三个观点 | 78 | ✅ 标题 |
| 四个观点 | 79 | ✅ 标题 |
| 五个观点 | 83 | ✅ 标题 |
| 六个观点 | 85 | ✅ 标题 |
| 参考文献 | 86 | ✅ 标题 |
| 框架图 | 93 | ✅ 标题 |
| 一段一图 | 94 | ✅ 标题 |
| 一段二图 | 99 | ✅ 标题 |
| 四段时间轴 | 111 | ✅ 标题 |
| 五段时间轴 | 112 | ✅ 标题 |
| 数据表格 | 114 | ✅ 标题 |
| 折线图/柱状图/饼图 | 117-122 | ✅ 标题 |
| 其他（二段二图、三段三图等） | ... | ✅ 标题 |

"一段文字"布局会自动填充要点列表（`"points"` 字段），其他布局只自动填充标题，详细内容在 PowerPoint 中手动填写。

### JSON 格式

```json
{
  "meta": { "title": "...", "subtitle": "...", "author": "...", "advisor": "...", "date": "..." },
  "toc": ["目录项1", "目录项2", ...],
  "slides": [
    {"type": "section", "title": "章节标题"},
    {"type": "content", "layout": "一段文字", "title": "...", "points": ["...", "..."]},
    {"type": "content", "layout": "四个观点", "title": "..."},
    {"type": "content", "layout": "五段时间轴", "title": "..."}
  ]
}
```

### 用法

```bash
# 用 JSON 内容文件生成
python tools/gen_pptx.py --content slides.json

# 用示例内容测试
python tools/gen_pptx.py --example

# 指定模板和输出路径
python tools/gen_pptx.py --content slides.json -t 模板.pptx -o 输出.pptx
```
