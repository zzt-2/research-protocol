# S018: Ch4 自适应载波同步仿真修复探索

> 2026-05-30 | 执行 | 进行中
> 来源: PROMPT-009

## 目标

修复 sim_direction_a.py，使"三公式自适应"（FOE N∝h⁻⁴, VV M∝h⁻²/⁵, DPLL B_L∝h）在强湍流下展示 ≥2 dB 增益（L2 标准）。

## 记录

### 发现 1: 原始仿真只有 DPLL 自适应

- `carrier_recovery_adaptive` 只调整 DPLL 带宽，FOE (N=1024) 和 VV (M=64) 均固定
- 原始结果（有 MMSE，DPLL-only adaptive）:

| 场景 | 固定 BER | 自适应 BER | 增益 |
|------|---------|-----------|------|
| 弱湍流 | 0.0586 | 0.0020 | 14.7 dB |
| 中湍流 | 0.1328 | 0.0899 | 1.7 dB |
| 强湍流 | 0.2234 | 0.1990 | 0.5 dB |

### 发现 2: 去掉 MMSE 后两方都变差，自适应反而更差

PROMPT-009 建议去掉 MMSE（方案 A），理由是"非标准处理流程"。

测试结果（无 MMSE，三公式全自适应）:

| 湍流 | Fixed BER | Adapt BER | 结果 |
|------|-----------|-----------|------|
| 弱 | 0.132 | 0.205 | 自适应更差 |
| 中 | 0.280 | 0.357 | 自适应更差 |
| 强 | 0.366 | 0.405 | 自适应更差 |

**原因**: 没有 MMSE，信号 r = h·s·exp(jφ) + n 含幅度变化。载波恢复算法（FOE/DPLL/VV）设计用于恒幅信号，幅度变化导致性能退化。两方都退化，自适应方退化更多。

### 发现 3: 恢复 MMSE + 三公式自适应，仍然更差

使用 h_foe (10th percentile) 驱动全部三公式:

| 湍流 | Fixed BER | Adapt BER | 结果 |
|------|-----------|-----------|------|
| 弱 | 0.155 | 0.254 | 更差 |
| 中 | 0.246 | 0.344 | 更差 |
| 强 | 0.333 | 0.365 | 更差 |

**原因分析**: h_foe（强湍流下 ≈0.03）给出 DPLL B_L = 2.55 MHz（远低于 fixed 8.5 MHz），环路太窄无法跟踪载波相位变化。同时 FOE N=8192（信号只有 5000 符号）过大。

### 发现 4: DPLL-only adaptive（原始方案）可复现增益

恢复 MMSE，仅自适应 DPLL 带宽（用 h_med），保留宽 clip [0.5, 100] MHz:

| 湍流 | Fixed BER | Adapt BER | Gain | h_med | B_L |
|------|-----------|-----------|------|-------|-----|
| 弱 | 0.083 | 0.027 | +4.82 dB | 0.84 | 74.8 MHz |
| 中 | 0.216 | 0.178 | +0.83 dB | 0.50 | 44.7 MHz |
| 强 | 0.289 | 0.272 | +0.25 dB | 0.34 | 30.3 MHz |

### 根因分析: 为什么三公式反而更差

**B₀ = √(πΔν_L·γ̄/T_s) ≈ 88 MHz** — 这是 h=1 时的理论最优带宽。固定配置 B_L ≈ 8.5 MHz（保守设计）。

当 h_med ≈ 0.3-0.8:
- DPLL: B_L = B₀·h = 26-70 MHz → 比 fixed 8.5 MHz **宽** → 更好跟踪（原始增益来源）
- FOE: N = 80/(γ̄·h⁴) → 对于 h > 0.17, N < 1024 → 比 fixed **短** → 更少平均 → 更差
- VV: M ∝ (γ̄h²)⁻⁰·² → h=0.5 时 M≈16 → 比 fixed 64 **短** → 更少平滑 → 更差

**核心矛盾**: FOE 和 VV 的自适应公式要求 h 很小时增大窗口（N↑, M↑），但对 h_med ≈ 0.5 的帧，自适应给出比 fixed 更短的窗口。DPLL 的公式恰好方向正确（h 大时带宽大，匹配更好跟踪需求）。

**为什么原始 DPLL-only 有效**: 更高带宽 = 更快跟踪。在 MMSE 补偿后的干净信号上，DPLL 高带宽的代价（更多噪声通过）小于收益（更好跟踪 Doppler 残余）。

## 后续

### 可选方向（按可行性排序）

**方向 A: DPLL-only adaptive 为主，三公式作为理论框架**
- 论文: 推导三个公式（理论贡献），仿真验证 DPLL 自适应增益（实验验证）
- FOE/VV 公式通过参数可视化图展示理论正确性
- 工作量: 最小，现有代码已支持
- 风险: 答辩可能追问"为什么只验证了 DPLL"

**方向 B: 逐块自适应（per-block）**
- 每个块独立计算 h_est，独立调整 FOE/DPLL/VV 参数
- 深衰落块用大 N、大 M、低 B_L；好块用小 N、小 M、高 B_L
- 需要重写载波恢复函数（支持参数逐块变化）
- 预期: 深衰落块增益显著，好块持平 → 整体增益提升
- 工作量: 中等，需要重构仿真代码
- 风险: 不确定增益是否足够大

**方向 C: 无 MMSE + 逐块自适应 + 更低 SNR**
- 去掉 MMSE（让信号更有挑战性）+ 逐块自适应
- 更低的 SNR 范围（10-16 dB）让载波恢复更有挑战
- 工作量: 大
- 风险: 高，不确定是否能出结果

**方向 D: 调整公式参数**
- 增大 FOE 公式系数（如 80→800），让 N 在 h_med 下也大于 fixed
- 降低 B₀（如加修正因子），让 DPLL 带宽在 h_med 下接近 fixed
- 工作量: 小
- 风险: 参数修正缺乏理论支撑，变成"调参凑结果"

### 建议

先选方向 A（最快出结果），同时探索方向 B（如果时间允许）。方向 C/D 风险高不建议。
