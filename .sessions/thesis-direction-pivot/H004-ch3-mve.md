## 核心问题

**反馈延迟 τ 下，功率预补偿还有没有用？** 这是 Ch3 能否成立的决定性问题。

## 不要做什么

- 不要做复杂的预测算法（ML/DL），那是后续优化，不是 MVE
- 不要纠结调制格式细节，QPSK 就行
- 不要写论文，只出数据
- 不要用理想化假设（τ=0 不代表最终结果，那只是上界）
- 不要做参数扫描以外的分析——MVE 只回答 go/no-go

## MVE 设计

### 仿真逻辑

1. 生成 GG 衰落序列 h(t)，参数：弱/中/强湍流（α,β 三组）
2. 功率预补偿：P_tx(t) = P_target / ĥ(t-τ)，其中 ĥ 是延迟 τ 后的信道估计
3. 接收信号：y(t) = h(t) · x(t) · √(P_tx(t)) + n(t)
4. 扫描 τ = 0, 1, 5, 10, 20, 50, 100 ms
5. 每个 τ 算有预补偿 vs 无预补偿的 BER

### 关键参数

| 参数 | 值 | 来源 |
|------|-----|------|
| 符号速率 | 1 Gsps | S007 |
| SNR | 10, 15, 20 dB | 标准范围 |
| 湍流 | 弱(α=4,β=4), 中(α=2,β=2), 强(α=1.5,β=1.5) | GG典型值 |
| 信道相干时间 | 1-10 ms | S009 |
| LEO 往返时延 | 5-20 ms | 500-1200km |
| 发射功率约束 | 有上限（防止深衰落时功率爆炸） | 工程约束 |

### PASS/FAIL 标准

| 判定 | 条件 | 含义 |
|------|------|------|
| 强 PASS | τ≤20ms 时改善 >3dB | Ch3 充足底气 |
| PASS | τ≤10ms 时改善 >1dB | Ch3 可写，但需限制适用场景 |
| 弱 PASS | τ≤5ms 时改善 >1dB | 偏薄，考虑加入简单预测 |
| FAIL | τ≥5ms 无改善 | Ch3 需要换定位或合并到 Ch4 |

### 可能结果与对策

| 结果 | 概率估计 | 对策 |
|------|---------|------|
| τ<10ms 有效 | ~40% | 正常写，强调适用场景 |
| 只有 τ<5ms 有效 | ~35% | 加简单信道预测（AR模型），参照 Nguyen 2024 |
| τ>20ms 仍有效 | ~10% | 意外正面，好写 |
| 全部没用 | ~15% | Ch3 换定位：改为"延迟影响系统研究"或合并到 Ch4 |
