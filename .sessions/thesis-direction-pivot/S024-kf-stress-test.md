#### D2: 增益归因消融 — **核心发现**

| 方案 | weak | moderate | strong |
|------|------|----------|--------|
| FOE only | 10.9% | 10.2% | 13.4% |
| FOE+VV | 27.4% ↓ | 26.6% ↓ | 30.5% ↓ |
| FOE+DPLL | **0.20%** | **0.37%** | **1.93%** |
| KF frame | 0.016% | 0.89% ↑ | 25.8% ↑↑ |
| KF pilot | 0.016% | 0.17% | 3.08% |

**关键结论**:
1. **VV (V&V CPR) 在所有场景下都有害**: BER 从 10-13% 恶化到 27-30%。可能原因: 相位展开错误在湍流信道下被放大
2. **DPLL 是真正的英雄**: FOE+DPLL 单独就达到 0.2-1.9% BER，这是当前 Fixed 的主要贡献者
3. **KF frame 在中/强湍流下有害**: 中等 0.89% > FOE+DPLL 0.37%，强 25.8% >> 1.93%。帧级 h 太粗糙
4. **KF pilot 弱/中等有效，强湍流不如简单 DPLL**: 强湍流 3.08% > FOE+DPLL 1.93%
5. **"Fixed 基线"的真实组成**: FOE + DPLL 是核心，VV 是负担。之前的"Fixed"因为包含 VV 而被人为拉低

### 核心结论

**1. 增益是真实的（A1 通过）**
- 共享信道修复 TL-13 后，KF pilot vs Default Fixed 增益仍然显著: +11/+12/+7 dB
- Wilcoxon p<2e-18, rank-biserial r≥0.998

**2. 但"对手"被不公平地弱化了（D1 逆转）**
- Fixed 基线从未被正确优化: M_vv=64 vs 最优 256, omega_n=8MHz vs 最优 20MHz
- **最优 Fixed vs KF pilot**: 弱 +13dB, 中 +5.3dB, **强 -1.4dB (KF 输)**
- 之前报告的 +17/+14/+9 dB 中约一半来自 Fixed 参数次优

**3. KF 的增益来源不是"湍流感知"（B2+D3 双重验证）**
- B2: 导频 h 估计对 R 矩阵无显著价值 (1.00x~1.13x)
- D3: 标准 PA-KF (固定 R) 在强湍流下反而优于"湍流感知" KF 2.31 dB
- **"湍流感知 R 矩阵"不是真实贡献**

**4. V&V CPR 在湍流信道下有害（D2 消融）**
- FOE+VV 使 BER 从 10-13% 恶化到 27-30%
- FOE+DPLL 单独达到 0.2-1.9%，是真正的核心贡献者
- Fixed 基线因包含 VV 而被人为拉低

**5. KF 的真正适用范围**
- **弱/中等湍流**: KF pilot 有效，增益 +5~13 dB (vs 最优 Fixed)
- **强湍流**: KF pilot 不如简单的 FOE+DPLL (1.93% vs 3.08%)
- **崩溃边界**: SNR<5dB + 强湍流

### 最终判定: **CONDITIONAL PASS**

- 弱/中等湍流下方案有效（PASS）
- 强湍流下方案不如优化的 Fixed（FAIL）
- "湍流感知"贡献被证伪（B2+D3）
- 适用范围需要明确限定：SNR≥10dB, 弱/中等湍流

### 对论文的影响

1. **Ch4 叙事需要调整**: 不能声称"全湍流增益"，只能声称弱/中等湍流
2. **Fixed 基线必须用最优参数**: M_vv=256, omega_n=20MHz
3. **"湍流感知 R 矩阵"不能作为贡献**: B2+D3 证伪
4. **V&V CPR 不适合湍流信道**: 需要说明或移除
5. **强湍流下建议用 FOE+DPLL**: 比 KF pilot 更简单且更好
