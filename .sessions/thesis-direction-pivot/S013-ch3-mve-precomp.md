# [S013] Ch3 功率预补偿 MVE — 反馈延迟下的有效性验证

> 2026-05-30 | MVE验证 | 完成
> 依赖: H004(Ch3 MVE设计), S011(Ch4 MVE参考实现)
> 产出：sim_ch3_precomp.py + MVE结果 + AR预测对比

## 目标

执行 H004 设计的 Ch3 MVE：验证功率预补偿在反馈延迟 τ 下是否有效。
核心问题：**反馈延迟 τ 下，功率预补偿还有没有用？**

## 记录

### 仿真设计

- **信道模型**：AR(1) 相关对数正态衰落（GG近似），α,β 参数决定衰落深度，T_coh 决定时间相关性
- **三档湍流**：weak(α=4,β=4,T_coh=10ms), moderate(α=2,β=2,T_coh=5ms), strong(α=1.5,β=1.5,T_coh=2ms)
- **功率预补偿**：P_tx(t) = P_nom / |ĥ(t-τ)|²，上限 100×（20dB），平均功率归一化
- **延迟扫描**：0, 0.5, 1, 1.5, 2, 3, 5, 10, 20, 50, 100 ms
- **SNR**：10, 15, 20 dB
- **判定标准**：H004 定义（强PASS/PASS/弱PASS/FAIL）

### 实验1：纯预补偿（Naive，无预测）

**结果：τ≥5ms 全面FAIL**

| 延迟 | 弱湍流(15dB) | 中湍流(15dB) | 强湍流(15dB) |
|------|-------------|-------------|-------------|
| τ=0 | +20.4 dB | +14.8 dB | +14.4 dB |
| τ=1ms | +9.9 dB | +3.0 dB | NEG |
| τ=3ms | +2.1 dB | NEG | NEG |
| τ≥5ms | NEG | NEG | NEG |

**精细扫描（0.5-5ms）的过渡点**：
- 弱湍流：>0.5dB 增益持续到 τ=3ms，τ=4ms 处截断
- 中湍流：>0.5dB 增益持续到 τ=1.5ms，τ=2ms 处截断
- 强湍流：>0.5dB 增益仅 τ=0.5ms，τ=1ms 处截断

**物理原因**：功率反转 (1/h²) 放大估计误差。即使 ρ(τ)=0.6（弱湍流 τ=5ms），估计误差经反转后功率分配严重偏移，预补偿反而恶化 BER。

### 实验2：AR(1) 最优线性预测

AR(1) 模型的 MMSE 最优预测器解析已知：ĥ_pred(t) = ρ^k · h(t-τ)。预测器自动将估计向均值收缩（延迟越大越保守），避免过时估计的激进功率反转。

**AR 预测结果**：

| 延迟 | 弱湍流 | 中湍流 | 强湍流 |
|------|--------|--------|--------|
| τ=1ms | +13.2 dB | +4.9 dB | +1.9 dB |
| τ=3ms | +6.5 dB | +1.3 dB | 0.3 dB |
| τ=5ms | +3.7 dB | 0.4 dB | 0 dB |
| τ=10ms | **+1.0 dB** | 0 dB | 0 dB |

**Naive vs AR 对比**（AR 带来的额外增益）：

| 延迟 | 弱湍流 | 中湍流 | 强湍流 |
|------|--------|--------|--------|
| τ=5ms | **+3.7 dB** | +0.4 dB | — |
| τ=10ms | **+1.0 dB** | — | — |

### MVE 判定（修正：排除 τ=0 理想反馈）

**对 LEO 场景（RTT 5-20ms）的判定：**

| 判定维度 | Naive 预补偿 | AR 预测辅助 |
|---------|-------------|-------------|
| 弱湍流+短距LEO(5ms) | FAIL | **PASS (+3.7dB)** |
| 弱湍流+中距LEO(10ms) | FAIL | **WEAK PASS (+1.0dB)** |
| 中湍流+短距LEO(5ms) | FAIL | FAIL (+0.4dB) |
| 强湍流+任意LEO | FAIL | FAIL |

**综合判定：WEAK PASS** — AR 预测使预补偿在弱湍流+短中距 LEO 下有效，但适用场景受限。

### 关键发现

1. **纯预补偿在 LEO RTT 下不可行**：延迟 5ms 以上，过时估计导致功率分配恶化 BER
2. **AR 预测显著扩展有效范围**：弱湍流从 3ms→10ms，中湍流从 1.5ms→3ms
3. **物理极限**：AR 预测无法突破信息论极限——延迟超过相干时间 2-3 倍后，信道本质上不可预测
4. **适用场景明确**：弱中湍流（α≥2）+ 短距离 LEO（RTT≤10ms）→ 可行；强湍流或长距离 LEO → 不可行
