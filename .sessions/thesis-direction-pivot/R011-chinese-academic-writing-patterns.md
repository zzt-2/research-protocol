## 一、开篇模式（首段前3句）

### 1.1 漏斗收束式（最常见）

从宏观领域判断开始，逐步收窄到具体技术。

**曹阳示例：**
> S1："自1979年第一代模拟通信系统得到商用以来，移动通信系统每十年都会迎来一次巨大技术变革，以便更好地支撑和促进人类信息社会发展[1]。"
> S2："自2019年始，5G系统商用化已稳步推进。"
> S3："而对6G系统的研究工作也逐渐成为未来十年全球产学研的焦点。"

**逻辑链：** 过去规律(S1) → 当前节点(S2) → 未来方向(S3)

**特征分析：**
- S1用一个"近似概括"（"每十年"并非严格事实）换取叙述力度——AI不会做这种权衡
- S2极短（9字），与S1的长句形成节奏反差
- S3用"而"做轻转折，不显式说"本文研究6G"

**刘晔祺示例：**
> S1："科学技术的进步和发展，推动空间通信技术向着不断深入的方向探索。"
> S2："在数据量爆发式增长和用户服务多样化的刺激下，人们对空间技术领域中大功率轨道运载水平和大容量卫星通信能力的要求不断攀升，人工智能等新技术也开始融入卫星产业的各个方面。"
> S3："相较通信带宽已达瓶颈的传统射频通信，空间激光通信具有高速实时性，高容量和保密稳定性等特点，将成为未来军事和商业空间网络的重要构成系统。"

**逻辑链：** 宏观趋势(S1) → 需求驱动力(S2) → 对比引出主角(S3)

**特征分析：**
- S3用"相较...已达瓶颈的传统射频通信"做对比，同时贬旧扬新——一个从句完成两个功能
- "高速实时性，高容量和保密稳定性"三个短并列，节奏紧凑

### 1.2 本质定义式

用一句话定义研究对象的本质属性，暗示后续展开维度。

**金骥丰示例：**
> S1："低轨卫星网络的发展历史是一段交织着技术进步、战略举措和商业计划的历程。"
> S2："低轨卫星星座的想法出现于20世纪80年代中期，作为战略防御计划（SDI）的一部分，旨在开发一种导弹防御系统。"
> S3："同时，低轨卫星低延迟通信的潜力也得到了认可，这为以后的发展奠定了基础。"

**逻辑链：** 本质定义(S1, 设定"三维交织"框架) → 第一个维度(S2) → 第二个维度(S3)

**特征分析：**
- "交织着"——口语化但书面可用，AI不太会选这个词
- S1定义了"三维"，S2和S3分别展开第一、二维度——前后呼应
- "这为以后的发展奠定了基础"——向后指涉的锚点，引出后续内容

### 1.3 开篇模式的反模式（避免）

| 反模式 | 表现 | 为什么不好 |
|--------|------|-----------|
| "随着X的发展" | "随着卫星通信技术的快速发展..." | 千篇一律，审稿人看腻了 |
| 数据轰炸开头 | "截至2024年，全球已发射超过10,000颗低轨卫星..." | 没有叙事铺垫，数据缺乏语境 |
| 问题直陈 | "当前星地激光通信面临大气湍流的严重挑战..." | 太突兀，缺乏背景 |
| 定义教科书式 | "自由空间光通信（Free Space Optical Communication, FSO）是指..." | 绪论不是教科书，读者知道什么是FSO |

## 二、段落内部展开模式

### 2.1 演绎式（先总后分）

最常用模式。首句给论断，后续句子展开/支撑。

**曹阳第2段（长段范例）：**

结构拆解：
```
愿景句："为实现这一愿景，6G系统需要具备..."
    ↓ [因果：愿景→指标]
指标句："峰值速率大于100吉比特、端到端时延低于0.1毫秒、可靠性达到99.99999%..."
    ↓ [补充递进："此外"]
扩展句："此外，随着...场景的不断涌现..."
    ↓ [因果收束："因此"]
需求句："因此，急速增长的性能需求...迫使6G系统需要..."
    ↓ [手段承接："基于这一目标"]
路径句："基于这一目标，6G系统将利用..."
    ↓ [时间锚定]
标准句："在2019年11月，3GPP已..."
    ↓ [定义+评价]
定义句："NTN作为一种...多维异构网络，其网络规模...均远超传统地面网络"
    ↓ [因果收束："这使得"]
问题句："这使得NTN中无线资源管理模块面临...问题，亟须要打破..."
```

**关键节奏：** 论断→数据支撑→收束到问题。段落的终点不是总结，而是**为下一段制造悬念**。

**通用节奏公式：**
> 论断句(1句) → 展开句(2-3句，含数据/引用) → 收束句(1句，归结到问题/需求)

### 2.2 对比转折式（先扬后抑）

先建立正面趋势/成果，再用让步转折引出不足。这是**论证研究空白的黄金模式**。

**曹阳第3段：**
> 正面论断："近年来，机器学习和人工智能技术...蓬勃发展..."
> ↓ [权威引用支撑]
> 引用支撑："在中国移动所提出的'三体四层五面'的6G总体架构[7]中..."+"北美Next G联盟..."
> ↓ [让步转折："虽然...但..."]
> 转折："虽然这些架构为...提供了指导思想，但智能化方案在实际部署过程中仍面临..."
> ↓ [因果收束]
> 问题收束："因此，...是亟待解决的问题。"

**冷涛（残存片段）的变体：**
> 先肯定："在现有切换策略的研究中，基于服务时长、空闲通道资源等因素...做了大量研究，在...方面取得了很多成果"
> ↓ [转折："但"]
> 后否定："但上述研究多考虑了通信资源对切换性能的影响，而对卫星本身资源如计算资源、缓存资源的考虑较少。"

**节奏公式：**
> 正面成果(1-2句) → 让步转折(1句："虽然/尽管...但...") → 不足/空白(1句) → 收束到研究需求(1句)

**为什么AI写不好这个模式：** AI倾向于平铺直叙——"A做了X，B做了Y，C做了Z，但仍有不足"，缺乏"先扬后抑"的论证策略感。人类的"先扬后抑"是一种修辞选择，暗示作者对领域有整体判断，而非逐篇罗列后的机械总结。

### 2.3 归纳式（先分后总）

先给多个具体实例，最后归纳出共性结论。

**刘晔祺段2（应用场景展开）：**
> 总提句："卫星激光通信技术可作为一种应急通信方案"
> ↓ [举例："比如"]
> 分述1："比如：在地震、洪水..."
> ↓ [并列："另外"]
> 分述2："另外，卫星激光通信技术..."
> ↓ [并列："此外"]
> 分述3："此外，卫星激光通信技术..."

**节奏公式：**
> 总提句(1句) → 分述1+分述2+分述3(各1-2句，用并列词连接) → [可选收束]

### 2.4 叙事弧线式（故事感）

按时间线展开，有起伏、有转折，像在讲故事。

**金骥丰OneWeb段（完整叙事弧线）：**
> 起步：FCC批准 → 规模缩减 → 破产
> 转折：被收购 → COVID期间重启
> 高潮：俄乌冲突换发射伙伴 → 达到全球覆盖门槛

**为什么有"故事感"：** 不是平铺"2002年做了X，2005年做了Y"，而是有失败有复兴，用"尽管面临挑战""由于俄乌冲突"这类转折词制造起伏。

**AI为什么做不到：** AI倾向于按时间线平铺直叙，每段时间权重相同。人类作者会有意选择哪些事件值得展开、哪些一笔带过，形成叙事重心。

## 三、句间衔接模式

### 3.1 高频衔接词及其功能

| 衔接词 | 功能 | 使用位置 | 原文举例 |
|--------|------|---------|---------|
| 而 | 并列递进，轻转折 | 段内句间 | 曹阳："5G已稳步推进，**而**对6G的研究也逐渐..." |
| 因此 | 因果收束到问题/需求 | 段末 | 曹阳："**因此**，急速增长的性能需求迫使..." |
| 这使得 | 因果收束，前后句紧耦合 | 段末倒数第2句 | 曹阳："**这使得**NTN中无线资源管理模块面临..." |
| 虽然...但... | 让步转折 | 段内中后部 | 曹阳："**虽然**这些架构为...提供了指导思想，**但**..." |
| 此外 | 补充递进 | 段内展开中 | 曹阳："**此外**，随着...场景的不断涌现" |
| 为实现这一愿景 | 目的/因果 | 段首第2句 | 曹阳："**为实现这一愿景**，6G系统需要具备..." |
| 相较 | 对比 | 段内转折处 | 刘晔祺："**相较**通信带宽已达瓶颈的传统射频通信..." |
| 不仅...还... | 递进并列 | 技术特征罗列 | 刘晔祺："**不仅**传输速率高...**还能够**抵抗电磁干扰" |
| 同时 | 并列维度切换 | 段内并列 | 金骥丰："**同时**，低轨卫星低延迟通信的潜力也..." |
| 事实上 | 认知纠偏 | 转折段首 | 冷涛："**事实上**，除了与通信指标相关的因素外..." |
| 综上所述 | 显性总结 | 收束段首 | 刘晔祺："**综上所述**" |

### 3.2 无衔接词的"语义承接"

中文论文中最常见的衔接**不是**连接词，而是语义上的承接。

**模式1：时间锚点承接**
> "20世纪90年代..." → 前文讲的是80年代，读者自动理解时间线推进

**模式2：专有名词当路标**
> "Starlink由美国航天公司SpaceX运营..." → 前文讲完Iridium/Globalstar，读者自动理解这是下一个星座

**模式3：数据密度推进**
> "5,504颗""5,442颗""300万""42,000颗" → 不需要衔接词，数据本身就是叙事推进力

**关键发现：** 高质量中文论文的衔接词密度**远低于AI生成文本**。人类靠语义承接，AI靠连接词堆砌。

### 3.3 段首句的6种接法

| 接法 | 功能 | 示例 |
|------|------|------|
| 时间锚点 | 承接前段时间线 | "在过去的20年中"（金骥丰） |
| 视角切换 | 从一个维度跳到另一个 | "从各国和地区下一代数据中继卫星系统的方案看"（刘晔祺） |
| 因果回指 | 回应前段末尾的问题 | "为实现这一愿景"（曹阳） |
| 让步转折 | 先承认前段结论再转折 | "虽然激光通信技术能够大大提高...但是由于..."（刘晔祺） |
| 概念承接 | 展开前段末尾提到的概念 | "卫星激光通信技术可作为一种应急通信方案"（刘晔祺，承接段1末尾的"有效支持"） |
| 专有名词直入 | 用具体对象名开启新段 | "Starlink由美国航天公司SpaceX运营"（金骥丰） |

## 四、引用嵌入模式

### 4.1 三种引用位置

| 位置 | 功能 | 示例 | 适用场景 |
|------|------|------|---------|
| 论断句末 | 给论断做背书 | "移动通信系统每十年都会迎来一次巨大技术变革[1]" | 最常见，占70%+ |
| 专有名词后 | 标注来源 | "在中国移动所提出的'三体四层五面'的6G总体架构[7]中" | 引用报告/标准/框架名时 |
| 多项并列末 | 统一标注 | "Globalstar[1], Iridium[2], Odyssey[3], Teledesic[4]等" | 列举时 |

### 4.2 核心原则

**引用是论断的"签证"，不是论述的起点。**

- 正确：先用自己的话说清楚 → 引用附后面做背书
- 错误："文献[X]指出...[大段复述]" → 这是AI最常见的引用方式

### 4.3 文献综述的引用节奏

**曹阳模式（最佳实践）：**
> 归纳句（用自己的话概括共性）→ 展开最相关的1-2篇（引用嵌在句末）→ 一句带过其余

**AI反模式：**
> "文献[1]做了X...文献[2]做了Y...文献[3]做了Z...文献[4]做了W..." → 逐篇复述

## 五、动词与措辞选择

### 5.1 有力度的动词（人类常用，AI少用）

| 人类用词 | AI倾向用词 | 差异 |
|---------|-----------|------|
| 迫使 | 需要 | "迫使"暗示不可抗拒的必然性 |
| 交织着 | 包含/涉及 | 口语化但书面可用，暗示作者有整体理解 |
| 亟须 | 需要 | "亟"字带紧迫感 |
| 坦然承认失败 | 粉饰/绕过 | "高昂的成本导致大多数公司缩减或取消" |
| 涌现 | 出现 | "涌现"暗示数量多且出乎意料 |
| 重塑 | 改变 | "重新塑造着我们的互联世界"有修辞力度 |
| 蔚然成风 | 广泛使用 | 带文学色彩，AI不会选 |

### 5.2 需要避免的AI高频词

| 避免 | 替代 | 原因 |
|------|------|------|
| 显著提升 | 具体数字（"降低55%"） | 模糊化用词，无法验证 |
| 具有重要意义 | 直接说意义是什么 | 空话 |
| 被视为 | 谁视为？ | 翻译腔（"is regarded as"） |
| 提供了...的能力 | 能... | 翻译腔（"provides the capability"） |
| 使...成为 | 直接说结果 | 翻译腔（"makes it possible"） |
| 一定程度上 | 删除或具体化 | 模糊化，不提供信息 |
| 填补了空白 | 描述具体贡献 | 自我声称，开题阶段尤甚 |

### 5.3 自造对比词组（简洁有力）

曹阳："从传统的**地表式**覆盖向**三维立体式**覆盖演进"
刘晔祺："**不仅**传输速率高、传输容量大、安全性高，**还能够**抵抗电磁干扰"
金骥丰："从20世纪80年代的**概念化**到今天**蓬勃发展**的星座"

特征：用两个对立词组构造一个动态过程，一句话讲清"从哪到哪"。

## 六、数据嵌入模式

### 6.1 集中轰炸（强调需求紧迫性时用）

多个量化指标集中在一句里密集出现：

> 曹阳："峰值速率大于100吉比特、端到端时延低于0.1毫秒、可靠性达到99.99999%、连接密度达到每平方公里1000万设备，相比5G系统提升10倍以上。"

**效果：** 读者对6G性能需求产生直观感受。
**AI倾向：** 分散在不同句子里慢慢铺陈，或用"大幅提升"等模糊表述。

### 6.2 数据叙事（按项目/时间线展开时用）

用数据充当叙事推进力，不需要衔接词：

> 金骥丰Starlink段："5,504颗"→"5,442颗"→"300万"→"12,000颗"→"42,000颗"→"200-300亿美元"

**特征：** 一段话6个量级不同的数字，节奏紧凑，像笔记整理。

### 6.3 数据使用原则

- **首次完整出现，后续概括引用**（防"数据三重出现"）
- **数值精度与上下文匹配**——引用文献数据时保持原始精度，自己的仿真数据保持合理精度
- **括号不超过1处/段**（缩写定义除外）——参数融入句子，不括号堆砌

## 七、AI写作5大系统性缺陷（及修复方向）

### 7.1 翻译腔

**表现：** "使...成为""被激活""提供了...的能力""转化为实际性能增益"

**根因：** LLM训练数据以英文为主，生成时逐词翻译英文从句结构。

**修复方向：** 写完后全文搜索"使""被""的""了"，高频出现处逐个检查是否可以换中文表达。

### 7.2 清单体（逐篇罗列）

**表现：** "A做了X在Y条件下取得Z结果。B做了X'在Y'条件下取得Z'结果。"

**根因：** LLM自回归生成时逐篇处理文献，"先归纳后展开"需要先形成整体概括再倒推展开策略。

**修复方向：** 动笔前先画分组表（行=技术路线，列=核心思路/主要结果/共性局限），按行展开。

### 7.3 段落衔接断裂

**表现：** 每段独立存在，段间零过渡。

**根因：** LLM逐段生成，"前段末尾→后段开头"的衔接需要跨越两段的连贯意图。

**修复方向：** 写完一段后检查"前段末句→后段首句"是否有语义承接（见3.3段首句6种接法）。

### 7.4 数据堆砌/检索报告体

**表现：** "对25篇文献的检索表明..."、"经系统调研发现..."

**根因：** LLM倾向展示调研完整性来建立可信度。

**修复方向：** 删除所有关于检索过程本身的描述，只保留技术结论。

### 7.5 元叙述

**表现：** "本节阐述...""如前所述""下面将介绍..."

**根因：** 模仿英文"This section presents..."的预告式写法。

**修复方向：** 直接进入论述，不预告"我要说什么"。

## 八、段落自检协议（每段写完后执行）

### 8.1 结构自检（30秒）

| 检查项 | 通过标准 | 不通过时怎么办 |
|--------|---------|--------------|
| 首句是否即主旨 | 遮住首句，第二句能否直接当首句？不能则通过 | 删掉铺垫句 |
| 段内是否只有一个论点 | 能否用一句话概括全段？能则通过 | 拆分为两段 |
| 收束句是否归结到具体问题 | 最后一句是否含"因此/亟须/面临...问题"？ | 补充收束句 |
| 有无元叙述 | 搜索"本节/本段/下面/如前" | 删除，直接论述 |

### 8.2 语言自检（30秒）

| 检查项 | 通过标准 | 不通过时怎么办 |
|--------|---------|--------------|
| 翻译腔残余 | 全段搜索"使""被""的""了"，每项≤3次 | 换中文表达 |
| 括号过多 | 段内括号≤1处（缩写定义除外） | 改为独立句 |
| 单句过长 | 无超过60字的句子 | 拆分为两句 |
| 推销性用词 | 无"强大的""显著提升""完美""首次" | 换具体数据 |

### 8.3 衔接自检（30秒）

| 检查项 | 通过标准 | 不通过时怎么办 |
|--------|---------|--------------|
| 段首承接前段 | 前段末句→本段首句有语义关联？ | 加衔接手段（见3.3） |
| 衔接词有实际逻辑 | "然而"后面确实有转折？"因此"确实可从前提推出？ | 删除无效连接词 |
| 引用紧跟论断 | 引用是否在完整论断的末尾而非紧跟人名？ | 调整引用位置 |

## 九、结构化模仿方法论

### 9.1 核心思想

**不是"多读多练"，而是"先标注再仿写"。**

每写一段之前：
1. 找到参考论文的对应位置
2. 逐句标注每句在做什么（铺垫/定义/评述/转折/引出空白）
3. 按同样的节奏写自己的段落

### 9.2 句子功能标注体系

| 标注 | 含义 | 识别方法 |
|------|------|---------|
| DEF | 定义/概念介绍 | "X是指/是..." |
| FACT | 事实陈述 | 有具体数据、年份、项目名 |
| CLAIM | 论断/判断 | "X具有...优势""X将成为..." |
| EVAL | 评价/定性 | "取得了瞩目成果""蔚然成风" |
| TRANS | 过渡/衔接 | "然而""因此""此外""相较" |
| GAP | 指出空白/不足 | "但仍面临...""考虑较少" |
| NEED | 引出需求/动机 | "亟须""迫使""需要" |
| CITE | 引用嵌入 | [数字]出现的位置 |

### 9.3 标注示例（曹阳第2段）

```
S1  [CLAIM] 为实现这一愿景，6G系统需要具备远超5G的性能指标
S2  [FACT]  峰值速率大于100吉比特...相比5G系统提升10倍以上[3,4]
S3  [TRANS] 此外，随着...场景的不断涌现
S4  [CLAIM] 6G系统需要从传统的地表式覆盖向三维立体式覆盖演进
S5  [NEED]  因此，急速增长的性能需求迫使6G系统需要...
S6  [TRANS] 基于这一目标，6G系统将利用NTN等技术
S7  [FACT]  在2019年11月，3GPP已开始NTN标准化研究[6]
S8  [DEF+CLAIM] NTN作为一种...网络，其规模远超传统地面网络
S9  [GAP]   这使得NTN中无线资源管理模块面临...问题，亟须要打破...
```

**然后用同样的功能序列写自己的段落。**

### 9.4 不同段落位置的功能序列模板

**背景段（P1-P2）：**
> CLAIM → FACT → CLAIM → [TRANS"相较/然而"] → CLAIM → [TRANS"因此"] → NEED

**文献综述段（P3-P7）：**
> DEF(方法分类) → CLAIM(第一类共性) → FACT(代表论文1-2篇) → [TRANS"然而/但"] → GAP(共性局限)
> → CLAIM(第二类共性) → FACT(代表论文1-2篇) → [TRANS"此外"] → GAP

**空白引出段（P8-P9）：**
> [先扬] CLAIM(现有成果总结) → [后抑 TRANS"尽管如此/然而"] → GAP(结构性不足)
> → [TRANS"因此"] → NEED(本文动机)

**收束段（P10）：**
> CLAIM(本章研究内容) → METHOD(方法概述) → EXPECT(预期贡献)

## 十、跨论文共性总结

基于曹阳、刘晔祺、金骥丰、夏兆宇四篇论文的交叉验证：

### 10.1 确认可复用的模式（4篇均具备）

1. **漏斗式开篇**：宏观→具体，不用"随着...的发展"
2. **首句即主旨**：每段第一句话直接说这段要讲什么
3. **段末因果收束**：几乎每段都以"因此/这使得/亟须"归结到具体问题
4. **先扬后抑**：论证空白时先肯定已有成果再转折
5. **引用后缀**：先说清楚再附引用，不用"文献[X]指出..."
6. **并列排比**：技术特征用短句并列罗列，节奏紧凑
7. **数据集中轰炸**：需要强调时密集排列量化指标

### 10.2 论文间的差异（需根据体裁选择）

| 特征 | 刘晔祺/金骥丰 | 曹阳 | 夏兆宇 |
|------|--------------|------|--------|
| 叙事弧线 | 强（国别/星座故事） | 弱（以论证为主） | 中（技术挑战递进） |
| 衔接词密度 | 低（靠语义承接） | 中（有明确连接词） | 中高（显性逻辑链） |
| 数据密度 | 高（大量项目参数） | 中（集中在指标段） | 低（以定性论述为主） |
| 时间线使用 | 强（历史发展叙事） | 弱（以趋势论证为主） | 弱（以问题论证为主） |

### 10.3 对开题报告写作的建议

开题报告绪论（1.1研究背景+1.2研究现状）的推荐模式组合：

- **1.1 P1（领域背景）**：漏斗收束式 + 并列排比
- **1.1 P2（技术引出）**：对比转折式 + 数据集中轰炸
- **1.2.x P1-P3（方法综述）**：先扬后抑 + 引用后缀 + 低连接词密度
- **1.2.x P8-P9（空白引出）**：先扬后抑 + 因果收束到具体问题
- **1.3 P1（本文内容）**：直接陈述，不用元叙述

## 结论

1. **"像人写的"核心特征**：让步转折论证、段末因果收束、并列排比、数据集中轰炸、低衔接词密度+高信息密度
2. **AI最顽固的缺陷**：翻译腔、清单体、段间断裂，根因是自回归生成机制与中文表达习惯的结构性冲突
3. **模板方法的局限**：控制"写什么位置"但不控制"怎么思考"，缺判断力、叙事节奏、跨节差异化
4. **最有效的提升方法**：结构化模仿——先标注参考论文的句子功能序列，再按同样的节奏写自己的段落

## 对决策的影响

- 这些发现应整合进S004模板，或替换为新的"句式模式库"指导方式
- 后续可开发"句子功能标注→仿写"的工作流，自动化部分标注过程
- 开题报告写作时应先标注参考论文对应段落的句子功能序列，再动笔
