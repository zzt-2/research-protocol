## 需要推导/分析的内容

### 分析1：自适应窗口的定点化精度分析（5.3.2-5.3.4 节）

**目的**：确定关键运算的定点位宽，保证与浮点仿真的精度差异在可接受范围内。

**需要分析**：
1. $N_\text{opt} = 80/(\bar\gamma \cdot h^4)$ 的实时计算：$h^{-4}$ 在定点下的量化误差
   - $h$ 范围：弱湍流 ~0.8-1.2，强湍流 ~0.01-5.0
   - $h^{-4}$ 范围：弱 ~0.5-2.4，强 ~0.0016-10^8（极端动态范围！）
   - 需要分析：用什么定点格式能覆盖这个动态范围？还是需要浮点/对数表示？
2. $M_\text{opt}$ 和 $B_\text{L,opt}$ 的定点化分析（相对简单，动态范围小）
3. VV 四次方运算的定点溢出分析
4. 给出推荐的位宽选择和量化方案

### 分析2：资源利用率预估（5.4 节）

**目的**：基于参考论文数据和算法复杂度，预估我们设计的 FPGA 资源消耗。

**需要分析**：
1. FFT 模块资源：可变点数 FFT（$N$ 从 4096 到 65536）的 LUT/DSP/BRAM 消耗
   - 参考：闫佳欣论文中 FFT IP 核资源数据
2. VV/CPR 模块：滑动平均 + 相位除法的资源
3. DPLL 模块：二阶环路的乘法器/累加器资源
4. 自适应参数计算模块：$h^{-4}$ 运算的 CORDIC/查找表方案选择
5. 汇总：总资源预估 + 与目标 FPGA（参考闫佳欣的 XC7K325T）的利用率对比

**参考数据来源**：
- 闫佳欣 FPGA 论文：`projects/thesis-fso/cnki-downloads/面向空间激光通信的实时信号处理算法研究与实现_闫佳欣.md`
- `毕设/写作材料/formulas-ch5-fpga.md` 中已提取的资源表

### 分析3：时序约束分析（5.4 节）

**目的**：确认目标时钟频率下流水线设计可行。

**需要分析**：
1. 关键路径：VV 四次方 → 滑动平均 → 相位估计 的延迟
2. 目标时钟频率下的吞吐率（与 Gsps 符号率的匹配）
3. 流水线级数设计

## 验证要求

由于没有实际 FPGA 代码：
1. **参考论文对比**：资源预估与闫佳欣/Liu 2023 的实际数据对比，差异应 < 30%
2. **合理性检查**：资源利用率应在 50-85% 范围内（太低说明 FPGA 太大，太高说明不可行）
3. **功能验证方案设计**：设计 VPI/MATLAB → ModelSim → 板上的验证流程（不需要实现，但方案要完整）
