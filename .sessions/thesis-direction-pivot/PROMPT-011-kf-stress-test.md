## 1. 项目背景

### 信号模型

相干检测 QPSK 星地激光通信系统：
- 接收信号：`r[k] = √h[k] · s[k] · exp(jφ[k]) + n[k]`
- 瞬时 SNR：`γ = γ̄ · h`（h 是归一化辐照度，GG 分布）
- MMSE 均衡后：`rx_eq[k] ≈ s[k] · exp(jφ[k]) + n'[k]`，残余幅度调制很小

### 系统参数

```
R_SYM = 2.5e9       # 符号率 2.5 Gsps
T_S = 400 ps         # 符号周期
LASER_LW = 10 kHz    # 激光线宽
F_RESIDUAL = 1 MHz   # 残余频偏（预补偿后）
F_DOT = 150 MHz/s    # 多普勒变化率
BLOCK = 100           # 信道块大小（块内恒定）
GAMMA_BAR = 100       # 20 dB 平均 SNR
```

### 湍流参数（Gamma-Gamma）

| 等级 | α | β | 物理场景 |
|------|---|---|---------|
| 弱 | 4.0 | 3.0 | 夜间/高仰角 |
| 中 | 2.5 | 1.8 | 白天/中仰角 |
| 强 | 1.5 | 0.8 | 低仰角/恶劣天气 |

### KF 方案概述

2 状态 KF（φ, Δf）统一跟踪载波相位和残余频偏：
- 状态转移：F = [[1, T_s], [0, 1]]
- 观测模型：QPSK 判决导引，H = [1, 0]
- R 矩阵：R = 1/(2·γ̄·h_est)，用导频估计的逐块 h
- Q 矩阵：分湍流强度参数化，σ²_φ = 激光 + 湍流贡献
- 导频：每 100 符号插入 5 个已知 QPSK 符号（5% 开销）
- 帧级 FFT-FOE 粗补偿（N=4096）→ 块级 KF 精跟踪

### 已报告结果（S022 阶段十，公平验证后）

| 湍流 | Fixed BER | KF pilot BER | 增益 |
|------|----------|-------------|------|
| 弱 | 1.23% | 0.02% | +17.2 dB |
| 中 | 5.04% | 0.21% | +13.7 dB |
| 强 | 26.9% | 3.66% | +8.7 dB |

**导师反馈："不要全信，里面有不少错误"**

## 2. 已知问题清单

以下问题已在之前的代码审查中发现但**未修复**（原始代码在 `sim_ch4_kf_pilot_h.py`）：

### 问题 1：不同信道实现对比（TL-13 违规）

**严重度：高**

Fixed 基线和 KF pilot 分别用不同的函数生成信号：
- Fixed 用 `generate_signal_no_pilots()`（或类似函数）
- KF pilot 用 `generate_frame_with_pilots()`

虽然用同一个种子，但 RNG 调用顺序不同（导频符号的生成会消耗 RNG 状态），导致：
- 信道 h 的实现不同
- 噪声 n 的实现不同
- 相位轨迹 φ 的实现不同

**修复方向**：所有方案必须在**同一组** channel/noise/phase realization 上运行。生成一份原始信号，各方案各自处理。

### 问题 2：Q_fine 频率跟踪冻结

**严重度：中**

```python
Q_fine = Q.copy()
Q_fine[1, 1] = (50e3 * T_S)**2  # Δf 的过程噪声方差
```

Q[1,1] 被硬编码为 (50kHz)²，这是网格搜索的结果。问题：
- 50kHz 是在测试数据上调出来的，可能有 overfitting
- 不同 SNR/湍流下最优值可能不同
- 频率跟踪能力被人为限制

**需测试**：Q[1,1] 对 10kHz~500kHz 的灵敏度

### 问题 3：MMSE 残余幅度调制

**严重度：低-中**

MMSE 均衡 `rx * √h / (h + 1/γ̄)` 消除了大部分幅度影响，但：
- 残余 `1/γ̄` 项导致不完全消除
- 深衰落块（h→0）时残余更大
- KF 的观测模型假设纯相位调制，忽略了残余幅度

S022 阶段十一验证了 20dB 下影响可忽略，但**未在其他 SNR 下验证**。

## 4. 压力测试计划（20 个维度）

### A 组：实验设计基础（5 项）

**A1. TL-13 共享信道验证**（最高优先级）
- 重写信号生成：所有方案共用**完全相同**的 h/noise/phase realization
- 导频处理：在原始信号上标记导频位置，不重新生成
- 对比：共享信道 vs 各自生成信道的 BER 差异
- **PASS 标准**：共享信道后 KF 增益 >5 dB（所有湍流等级）

**A2. 多种子鲁棒性**
- 100 个独立种子，每个 10000 符号
- 报告：均值、中位数、标准差、5/95 分位数、最大/最小
- 检查：是否存在异常种子（增益为负或 >30dB）
- **PASS 标准**：≥90% 种子增益 >3 dB（中/强湍流）

**A3. 统计显著性检验**
- 对 100 个种子的 BER 配对做 Wilcoxon 符号秩检验
- 报告 p-value 和效应量
- **PASS 标准**：p < 0.01，效应量 >0.5

**A4. SNR 全扫描**
- SNR = 0, 5, 10, 15, 20, 25, 30 dB（每点 50 种子）
- 画 BER vs SNR 曲线，检查是否有 BER floor
- 检查增益是否随 SNR 变化
- **PASS 标准**：20dB 以上 KF BER 持续下降（无 floor）

**A5. 序列长度影响**
- Ns = 1000, 2000, 5000, 10000, 20000, 50000
- 检查短序列（1000）是否可靠（收敛问题）
- 检查长序列（50000）是否有累积漂移
- **PASS 标准**：BER 在 Ns≥5000 后稳定

### B 组：KF 算法参数（5 项）

**B1. Q 矩阵灵敏度**
- 固定 Q[0,0]，扫描 Q[1,1]：10kHz, 30kHz, 50kHz, 100kHz, 200kHz, 500kHz
- 固定 Q[1,1]，扫描 Q[0,0]：0.1×, 0.5×, 1×, 2×, 10× 当前值
- 画热力图（BER vs Q[0,0] × Q[1,1]）
- **检查**：当前参数是否在"平台区"（不敏感）还是"悬崖边"（微调即崩）

**B2. R 矩阵替代方案**
- R1: `1/(2·γ̄·h_est)` — 当前方案（导频估计 h）
- R2: `1/(2·γ̄·h_med)` — 帧级 h（不用导频）
- R3: `1/(2·γ̄)` — 忽略 h（纯 AWGN 假设）
- R4: `1/(2·γ̄·max(h_est, 0.1))` — 防止深衰落 R→∞
- **PASS 标准**：R1 显著优于 R2/R3（证明导频 h 估计有价值）

**B3. P 矩阵初始化**
- P_init[0,0]：0.01, 0.1, (π/4)², π², 10π²
- P_init[1,1]：(10kHz)², (100kHz)², (1MHz)²
- **检查**：收敛速度和稳态性能是否受 P_init 影响

**B4. 导频密度扫描**
- 开销：1%, 2%, 5%, 10%, 15%, 20%, 30%
- 画 BER vs pilot overhead 曲线
- 画 net BER（扣除导频开销后的有效 BER）vs pilot overhead
- **PASS 标准**：5% 在 net BER 意义上接近最优

**B5. 导频放置策略**
- 前置式：每块开头放 P 个导频（当前方案）
- 均匀式：每块均匀分布 P 个导频
- 中心式：每块中间放 P 个导频
- **检查**：放置策略是否影响 BER

### C 组：物理场景扩展（5 项）

**C1. 不同多普勒率**
- f_dot = 0, 10, 30, 50, 100, 150, 300 MHz/s
- 检查 KF 频率跟踪能力上限
- **检查**：增益是否随 f_dot 增加（因为 Fixed 更差）还是减少（因为 KF 也跟不上）

**C2. 不同激光线宽**
- Δν = 0.1, 1, 10, 100, 1000 kHz
- 检查 KF 在大线宽下是否仍有效
- **PASS 标准**：Δν≤100kHz 时增益 >5 dB

**C3. 不同残余频偏**
- f_res = 0, 100kHz, 500kHz, 1MHz, 5MHz, 10MHz
- 检查 FOE+KF 级联对残余频偏的容忍度
- **PASS 标准**：f_res≤5MHz 时增益稳定

**C4. 块大小影响**
- BLOCK = 20, 50, 100, 200, 500, 1000
- 块太短→导频占比太大；块太长→h 不再恒定
- **检查**：当前 BLOCK=100 是否在最优范围

**C5. 深衰落分析**
- 统计 h < 0.01, 0.05, 0.1, 0.2 的块数和比例
- 对深衰落块单独计算 BER（KF vs Fixed）
- 检查：KF 是否在深衰落下真正改善，还是只在正常块有优势
- **PASS 标准**：深衰落块（h<0.1）BER 改善 >3 dB

### D 组：基线公平性与增益归因（5 项）

**D1. Fixed 基线参数优化**
- FOE 窗口：256, 512, 1024, 2048, 4096
- VV 窗口：16, 32, 64, 128, 256
- DPLL 带宽：1, 2, 5, 8, 10, 15, 20 MHz
- 对 Fixed 做网格搜索找最优参数
- **关键问题**：如果 Fixed 给了最优参数，KF 还有多少增益？

**D2. 增益归因消融实验**
- 方案 1：FOE only（无 KF，无 VV）
- 方案 2：FOE + VV（无 KF）
- 方案 3：FOE + DPLL（无 KF）
- 方案 4：FOE + KF + frame_h（无导频）
- 方案 5：FOE + KF + pilot_h（完整方案）
- **目标**：量化每一步的增量贡献

**D3. 与光纤 KF 方案对比**
- 实现文献中的标准 PA-KF（恒定 h 假设）
- 对比：标准 PA-KF vs 我们的湍流感知 KF
- **检查**：我们方案的"湍流感知"是否真有价值

**D4. EKF / UKF 对比**
- 用 EKF 替代线性 KF（更好的非线性处理）
- 用 UKF 替代（无迹变换）
- **检查**：线性 KF 是否足够，高阶方法是否更好

**D5. 极端条件压力测试**
- 超强湍流：α=1.0, β=0.5
- 极低 SNR：0-5 dB
- 极大频偏：f_res=20MHz, f_dot=500MHz/s
- 极大线宽：Δν=10MHz
- **目标**：找到方案的崩溃边界
