## 本轮目标

产出一张「内容映射表」和一份「缺口清单」，为加厚决策提供对标集驱动的依据。

### 产出 1：对标集 5 篇每节实际词数（量化标尺）

用词数统计（不是行数，行数含公式/图注/引用，不准）量对标集每篇每节。这是核实"我们到底差多少"的硬数据。

格式：
```
| 论文 | 总词数 | Intro | System Model | Method | Results | Conclusion | 备注 |
|---|---|---|---|---|---|---|---|
| Le Bidan | ? | ? | ? | ? | ? | ? | ICSOS 4-6页，体例最像 |
| Johst | ? | ? | ? | ? | ? | ? | 卖点最贴 |
| ... |
```

同时量我们自己的（已知总数 ~1649，分节量出来）：
```
| 我方当前 | 1649 | ? | ? | ? | ? | ? | |
```

### 产出 2：对标集 5 篇每节内容构成（核心产出）

这是 R010 漏掉的关键。不是记"力度"（1-2句/段落/推导），而是记**"每节每段具体写什么内容"**。

每篇每节按这个粒度提取：
- 这节分几段，每段的**论点**是什么（一句话）
- 每段用了什么**素材**支撑（具体：引了什么文献/给了什么公式/描述了什么参数/讨论了什么现象/跟什么 baseline 对比）
- 每段的**功能**（背景铺垫/动机建立/方法描述/参数交代/数据呈现/现象解释/对比讨论/局限说明）

重点对照 3 篇（这 3 篇覆盖三种"填充模式"）：
- **Le Bidan**（872 行，最完整）：Method 那 340 行到底在讲什么？怎么填满的？
- **Johst**（268 行，卖点最贴）：DA vs blind 对比那段怎么展开的？外场实验怎么描述的？
- **Panasiewicz**（148 行，最精简）：作为"精简下限"参照——它这么短靠砍了什么？

### 产出 3：逐节缺口清单（对标集驱动，不是拍脑袋）

对照产出 2（别人每节有什么内容）和我们 W001/W002/W003（我们每节有什么内容），**逐节列出缺口**：

格式（每节一张表）：
```
### §I Introduction 缺口
| 内容项 | Le Bidan 有？ | Johst 有？ | Panasiewicz 有？ | 我方有？ | 缺口判定 |
|---|---|---|---|---|---|
| FSO 容量需求/LEO 趋势背景 | ✓ §I Lxx | ✗ | ✗ | ✗ | 2/3有我没→可考虑加 |
| 具体任务/链路场景描述 | ✓ | ✓ | ✗ | ✗ | 2/3有我没→可考虑加 |
| ...（逐项列）| | | | | |
```

**缺口判定规则**（不拍脑袋）：
- 3/3 或 2/3 对标集都有、我们没有 → **明确缺口**（加厚依据强）
- 1/3 有 → **可选缺口**（看是否服务于我们的逻辑链）
- 0/3 有 → 不是缺口（我们独有，视情况保留或删）

**重要**：缺口清单只列"别人有我们没的内容项"，**不直接给加厚方案**（加不加、怎么加是后续决策，本轮只提供依据）。

## 纪律
1. **不拍脑袋**——缺口判定严格基于"对标集有没有"，不基于"我觉得该写"。这是本轮存在的全部意义
2. **不直接给加厚方案**——本轮只产出依据（缺口清单），不产出方案（加什么）。方案是后续决策
3. **词数统计诚实**——用 wc -w，不估。公式行单独标注
4. **内容地图记内容不记力度**——R010 已经记了力度，本轮不重复。本轮记"每段写什么内容"
5. **守 FR-22**——只读已有 content.md，不下载新论文
