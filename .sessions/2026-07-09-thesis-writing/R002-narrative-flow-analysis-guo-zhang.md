# [R002] 同门位论文叙事流程分析（郭欣宇 + 张思齐）——量级/侧重/结构/措辞四维横向对比

> 2026-07-09 | 关联：专题 slug 2026-07-09-thesis-writing / S001（论点审查发现"不知该侧重什么"触发）

## 调研问题

R001 只浅摸张思齐一篇结构。用户提出"得看别人的叙事流程——量级、侧重、小节段落分布，不然不知道我们该侧重什么"。深挖 2 篇同门位论文全文，四维提取，横向对比，产出"我们该侧重什么"。

## 样本

| 论文 | 场景 | 全文行数 | 与我的相关性 |
|------|------|---------|------------|
| 郭欣宇《面向大气激光信道的动态可变接收技术》| FSO 大气激光 + 动态/自适应接收（FPGA 实时）| 1253 行 | **最贴**——FSO + 自适应/动态主题 |
| 张思齐《高阶调制相干空间光通信系统载波恢复算法研究》| 空间光 + 高阶调制 + 载波恢复（仿真）| 1244 行 | 同领域同层级，R001 浅摸过 |

## 发现

### 维度 1：量级对标

| | 郭欣宇 | 张思齐 | **我们（A4）** |
|---|---|---|---|
| 主增益 | 2.7dB（BPSK 半带滤波灵敏度）| 0.67~0.76dB（创新点1）/ 9~10dB（创新点2 特殊配置）| **fair_gain +1.34~3.10dB** |
| 次增益 | 2.2dB（vs 另一基线）| 复杂度节省 27.2%/13.8%/17% | **切换增益 +0.27~0.48dB** |
| FEC 门限 | 1e-3 | 3.8e-3（7% HD-FEC）| 3.8e-3（与张一致）|
| 仿真规模 | **无蒙特卡洛**（FPGA 实测）| **零 seed/符号数报告** | **30seed + 95% CI**（优势）|

**量级判定**：fair_gain（+1.34~3.10dB）跟郭 2.7dB、张创新点1（0.67~0.76dB）同级甚至更优。切换增益 +0.27~0.48dB 略低于张创新点1 低端但同数量级（亚 dB），**够投会议/学位论文**。

**关键差异化**：两篇都不报 seed/蒙特卡洛，我们有 30seed+CI——明确方法学优势。

### 维度 2：侧重/篇幅分布

| | 郭欣宇 | 张思齐 | 共同点 |
|---|---|---|---|
| 原理推导 | **40%**（最大）| 创新章原理 >> 仿真 | **两篇都重原理** |
| 实验验证 | 46% | 仿真次之 | 重验证 |
| 复杂度 | 嵌入实验章（资源量）| **极薄**（8 行乘法器表）| 都有但都薄 |
| 纯算法创新 | Ch4 独立章 20% | 三独立算法章 | 创新独立成章 |

**侧重判定**：两篇**叙事重心都在"算法原理机制设计"，不在"性能数字"**。张尤其明显——原理推导篇幅 >> 仿真验证。

**对我们的含义**：简报目前以数据表驱动（§2-§4 都是表），**叙事重心跟同门惯例相反**。转正式论文需加重算法原理机制（per-block 有效 SNR 估计器构造 / DA/NDA 切换判据推导 / crossover 物理解释），把 dB 数字降为佐证。

### 维度 3：小节段落结构（两篇高度一致）

**算法章内部铁律模板**：
```
引言（复述问题）→ 原理（含子节拆解 + 公式推导）→ 复杂度分析 → 仿真验证（系统设置 + 结果分析）→ 本章小结
```

**创新点章节安排**：绪论"主要创新点"段点题 + 每个创新点独立成章。

**单个创新点引言套路**（张最清晰）：①复述问题背景 → ②列现有方法 N 个具体缺陷 → ③"针对上述问题，本章提出了…"声明 → ④点仿真平台与结论。

### 维度 4：创新点包装措辞（最有用的发现）

**统一句式三连**：
> **"针对 [问题]，提出 [方法]，[仿真] 表明 [指标]"**

动词集中在"**提出 / 创新性设计 / 设计**"。**几乎不用"发现/首次/改进"**作自我声明。

**小增量包装三板斧**（两篇一致）：
1. **方法学新意当主卖点，dB 当副卖点**——强调"时序标记""菱形分圈""半带滤波"等**命名化机制**，而非数字
2. **叠加"低复杂度"双卖点**——每个创新点必报复杂度节省百分比，单维增益升维为"精度+复杂度"二维贡献
3. **"针对…问题"句式锚定痛点**——让任何增量都显得是"解决了一个明确缺口"

**郭欣宇特殊话术**（FPGA 工程型）：④"对比研究了…算法"（把对比基线也写成贡献）；⑤"可以在…前提下，消除…，提高…"（资源约束式卖点）。

## 结论：我们该侧重什么

基于两篇实证，对照简报现状，5 条结论：

### 1. 量级够格，无需焦虑（但要正确归因）
fair_gain（+1.34~3.10dB）跟同门同级甚至更优，切换增益（+0.27~0.48dB）同数量级（亚 dB）。**够投会议/学位论文**。焦虑点不在量级，在叙事重心。

### 2. 叙事重心从"数字"转向"机制"（最大调整）
简报现状（数据表驱动）跟同门惯例（原理机制驱动）相反。转正式论文需：
- **加重原理推导**：per-block 有效 SNR 估计器 γ_eff = γ_bar + 10log10(ĥ) 怎么构造、DA/NDA 切换判据（CV 门控 + γ_eff 门控）怎么设计、crossover 的物理因果（低有效 SNR 导频可靠 / 高有效 SNR 积分鲁棒+省开销）
- **dB 数字降为佐证**：fair_gain 表和切换增益表从"主角"变"验证手段"

### 3. 包装措辞套"针对…问题，提出…方法"句式
不要写"我们提升了 0.27dB"，而写：
> "针对星地 FSO 湍流下 per-block 有效 SNR 动态变化导致固定 DA/NDA 在跨界区性能折损的问题，提出了基于 per-block 有效 SNR 的 DA/NDA 自适应切换载波相位恢复算法。"

动词用"提出/设计"，避免"发现/首次"（除非确实是 crossover 发现，可破例用"揭示"）。

### 4. 机制命名化 + 双卖点
给方法起名（如"per-block 有效 SNR 驱动的 DA/NDA 自适应切换"——已有），补**复杂度小节**（即便只有乘法器/加法器计数表，张思齐 8 行就够撑卖点）。把单维 dB 增益升维为"精度 + 复杂度/鲁棒性"多维贡献。

### 5. 严谨性是差异化武器（两篇都没有）
两篇都**零蒙特卡洛/seed 报告**。我们有 30seed + 95% CI + 诚实标注 weak/moderate 统计不可分。**明确报告"蒙特卡洛 N 次独立仿真，每 seed M 符号，95% CI ±x"**，作为相对同门的方法学优势。

### 额外：crossover 发现的特殊定位
crossover（per-block 有效 SNR 驱动的赢家切换汇聚 12~14dB）是两篇都没有的"**发现类**"贡献。用"**揭示了…的 crossover 规律及其物理意义**"包装，配一张解释图当原理贡献——这是我们的差异化卖点，补足同门只有"提出类"的空白。

## 对决策的影响

- **不新建 D###**：叙事分析是写作指导，不改方向/架构决策。但产出的"该侧重什么"直接影响简报/论文写作重排
- **简报调整方向已明确**（待用户决定执行）：①叙事重心转机制 ②套"针对…提出…"句式 ③补复杂度 ④突出 30seed 严谨性 ⑤crossover 作发现类卖点
- **后续 R### 可能**：如转正式论文，可补第 3 篇（董凡 2345 行作量级完整参照）或英文 Trans（Wang 2025 OE 已 R001 读过）的叙事对比

## §B 追加（2026-07-09 续）：载体差异修正——学位论文 vs 期刊论文叙事

### 触发

用户质疑："这是别人毕业论文里的？还是会议这么写的？如果是会议这么写那可以？" 核查发现**张思齐/郭欣宇的学位论文工作均无对应会议/期刊发表**（参考文献零自引，无"已发表"声明）。因此 R002 主体基于学位论文的结论**不能直接指导会议/期刊投稿**。本节用 3 篇英文 Trans 全文（Wang 2025 OE / Paillier 2020 JLT / Wang OE 2024）做修正。

### 期刊论文叙事真相（3 篇实证）

| 维度 | 学位论文（R002 主体）| **期刊论文（3 篇 Trans）** |
|------|---------------------|---------------------------|
| 原理推导 | 40%+ 独立成章，机制自成宇宙 | **30-45% 压进 Method，紧贴数字闭环** |
| Complexity | 独立章（8 行乘法器表）| **降为 Results 子节，不单列** |
| 层级 | 章+小节多层 | **扁平，3-5 个一级章** |
| Related work | 独立段/章 | **并入 Intro** |
| 贡献包装 | "针对…提出…" 句式 + 创新点列表 | **用数字立贡献**（95%/7.72%/省100符号/2.3dB），**不写 contributions 列表** |
| Conclusion | 本章小结 + 总结展望 | **1-2 行，极短** |

### R002 主体的关键修正

**R002 原结论"叙事重心转机制"对会议/期刊投稿是错的。** 期刊论文真相：**机制和数字并重且必须闭环**——机制必须讲清（Method 30-45% 不可省），但每个机制点都要配 dB/%/MSE 量级证据，机制→数字在同一节内闭环。纯机制无数字的写法只适合学位论文。

**这对我们是好消息**：简报本是数据驱动（fair_gain 表+crossover+切换增益），期刊路子是对的。需补的不是"少写数字多写机制"，而是"每个机制点配数字 + Complexity 收成子节"。

### 期刊贡献包装方式（与学位论文根本不同）

学位论文：靠"针对…提出…"句式 + 创新点列表。
期刊论文：靠**硬数字**，不堆句式，不写 contributions 列表，卖点塞 abstract+intro 末段：
- Wang 2025 OE："reduces by over **95%**… **7.72%**" + "0.7 dB"
- Wang OE 2024："省 **100 符号** / MSE **两个量级** / **480 符号够用**"
- Paillier 2020 JLT："flux penalty **−23→−4.5 dB** / BER 代价 **2.3 dB**"

### 量级对标（期刊标准，更新 R002 维度1）

| 期刊卖点 | 我们能对标 |
|---------|-----------|
| Wang 2025: 0.7dB + 复杂度 95% | fair_gain +1.34~3.10dB（更强）+ 切换 0.27~0.48dB |
| Paillier 2020: BER 代价 2.3dB | 切换增益 0.27~0.48dB（偏小，靠 fair_gain 撑）|
| Wang 2024: MSE 两量级 | 无 MSE 量级，但有 30seed CI（严谨性差异化）|

### 修正后"我们该怎么写"（取代 R002 原结论 5 条）

1. **数据驱动是对的**（期刊要机制+数字闭环，纯机制是学位论文体例）
2. **Method 占 30-45%**：讲清 per-block 有效 SNR 估计器 / 切换判据 / crossover 物理因果，但每点配 dB/CI 数字
3. **Complexity 收成 Results 子节**（不单列章）—— 补一张乘法器/加法器计数表即可（期刊都这么做）
4. **贡献用数字不用句式**：abstract+intro 亮 "fair_gain +1.34~3.10dB / 切换 +0.27~0.48dB CI 全正 / 30seed 严谨性"，不写 contributions 列表
5. **层级扁平**：Intro(含 related work) → Method → Setup → Results(含 Complexity 子节) → Conclusion(短)
6. **30seed 严谨性差异化**：3 篇期刊里 Paillier/Wang2024 有蒙特卡洛(3200/800 次)但都不报 CI，我们报 95% CI 是加分

## §C 追加（2026-07-09 续）：自适应/切换型 CPR 期刊样本 + 统计严谨性惯例实证

### 触发

用户判断"3 篇太少要多找" + 用户重要提醒："不要有'别人没做我们做了，我们严谨'这种想法，很可能有的是惯例不需要的"。补下载 3 篇 OA 自适应/切换型 CPR（A/E 成功全文，C 因 Optica 反爬失败降级 abstract），6 篇样本验证统计严谨性惯例。

### 新增 3 篇样本（A/E/C）

| 论文 | venue | 切换机制 | 量级锚点 |
|------|-------|---------|---------|
| A 两阶段 CPE | Frontiers of Physics 2024 | enhanced QPSK-part(粗)+ML(细) | 复杂度 1/10 BPS，性能≈BPS |

### ★ 统计严谨性惯例实证（6 篇全不报 CI）

**6 篇期刊论文（A/E/C + Wang2025/Paillier/Wang2024）无一报 CI，无一画误差棒：**
- A/E/C **连蒙特卡洛都不做**，单次 PRBS(2¹⁷⁻¹/2¹⁵) 跑完报点值
- E 甚至把 lax 延伸到 ML 训练（只报单次训练时间）
- C 以"标准差"为理论核心都不报实验 CI

**机理（用户提醒的实证验证）**：相干光 CPE/ACM 仿真在固定 OSNR 下 BER 由大数定律确定（10⁵-10⁶ 符号单次即稳），领域认为"曲线确定性高、误差棒没信息量"。**不报 CI 是领域惯例（没必要），不是真省略。**

### 对我们 30seed+CI 的定位修正（重要）

**不能当"我们更严谨"的卖点**（会显得 over-engineered，审稿人可能问"为什么 30seed？单次不够？"）。

**正确 framing（用场景随机性正当化）**：
> "湍流随机性下，单次仿真不足以表征 per-block 有效 SNR 的分布特性，故用 30seed 报 95% CI 以量化切换增益的统计显著性。"

即用"场景随机性"正当化严谨性，非泛泛宣称"更严谨"。weak/moderate 不可分的诚实标注仍是加分（无论文这么做）。

### 切换型 CPR 特有叙事维度（非切换型没有）

**"跨工况可移植性"卖点**——E 写 "transplanted to different turbulence intensities"，A 写 "flexible scheme… adaptive elastic optical networks"。对应我们的 DA/NDA 切换 = **"跨湍流强度/per-block 有效 SNR 区间可移植"**，是该抓住的 framing。

### contributions 列表的体例差异

R002§B 说"期刊不写 contributions 列表"，但 A（Frontiers of Physics）写了三条列表——这是 Frontiers 体例要求。**"写不写 contributions 列表"取决于目标期刊体例，非通用规律。**

### 量级对标更新

E 切换偏差 0.35dB ≈ 我们切换增益 0.27-0.48dB（同级）；A"逼近 BPS"≈ 我们"逼近 NDA-ML"。投会议/期刊量级无忧。

### §C 总结：我们该怎么写（6 篇样本 + 学位论文对比后的定稿）

1. **机制+数字闭环**（Method 30-45%，每机制点配 dB/% 量级）
2. **切换型抓"跨工况可移植"framing**（跨湍流强度/per-block 有效 SNR 区间）
3. **30seed+CI 用场景随机性正当化，不当主卖点**（"湍流随机性需多 seed 表征分布"）
4. **Complexity 收 Results 子节**，补一张乘法器/加法器表
5. **contributions 列表看目标期刊体例**（Frontiers 要，IEEE/OE 不要）
6. **诚实标注 weak/moderate 不可分**（加分项，无论文这么做）
