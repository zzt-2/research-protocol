## 目标

为 Fig.1 单独设计一套“先找到类型正确的样图，再做深度分析”的多 agent 调研流程；本轮只产出新对话交接，不搜图、不画图、不决定渲染工具。

## 记录

### 1. 先定义要找的图型

候选图不要求与自适应 CPR 完全同题，但至少应能迁移以下一种结构：

1. **端到端系统总览**：发射端—信道—接收端的上下文组织。
2. **接收机/DSP 管线**：顺序处理链、并行 DA/NDA 分支及合流方式。
3. **自适应选择与控制流**：测量量、阈值比较、selector/switch、控制线与数据线的区分。
4. **多尺度表达**：总览 + receiver zoom-in、主图 + inset、Fig.1(a)/(b) 拆图关系。

只“好看”但不能迁移信息层级、数据流或控制流的图不进入深度样本。

### 2. 四批、十二个 agent

#### 批次 A：样图猎手 ×3（预筛门）

- A1：相干光通信 / FSO / coherent receiver / carrier recovery。
- A2：通信 DSP / synchronization / estimation / parallel processing pipeline。
- A3：adaptive selection / feedback control / multimode receiver，以及相邻 IEEE 信号处理系统图。

每个 agent 找 12--15 张候选图，只做轻量卡片：来源、图号、缩略图/页码、所属图型、可迁移点、明显不适用点。三人结果先去重，不做深度审美长评。

#### Gate A：主线程类型审核

去重后至少保留 18--24 张深度样本，并满足：

- 系统总览类不少于 5 张；
- 接收机/DSP 管线类不少于 5 张；
- 自适应选择/控制类不少于 4 张；
- 多尺度/拆图类不少于 4 张；
- 每张至少满足“语义可迁移、结构可迁移、视觉层级可迁移、来源可核验”中的两项，且前两项至少满足一项。

若任一类型缺样本，禁止直接启动深度分析；追加定向猎图 agent 补齐后再过门。

#### 批次 B/C：深度分析 ×6

分两批，每批 3 个 agent；每人分析 3--4 张已通过 Gate A 的图。使用统一矩阵：信息层级、数据流、控制流、模块粒度、拆图方式、线/箭头语法、颜色与灰度、字体/字号、caption 分工、最终单双栏适配、可借鉴点、不可照搬点。

#### 批次 D：综合与 critic ×3

- D1：归纳信息架构与拆图模式。
- D2：归纳视觉语法、专业规范和反模式。
- D3：基于前两者提出并批判 2--3 个 Fig.1 信息架构候选。

总 agent 数目标为 12，但任何时刻最多并行 3 个；后一批必须使用前一批筛选后的材料，不允许十二人同时盲搜。

### 3. 预期产出

- `R019-fig1-reference-corpus.md`：候选与入选样图语料表，含证据指针。
- `R020-fig1-visual-grammar.md`：视觉语法、结构模式和反模式。
- `R021-fig1-architecture-options.md`：2--3 个候选结构，仅规格/线框，不画最终图。
- 用户拍板结构后，再讨论 draw.io、代码 SVG/TikZ 等渲染工具；生成式 image 仅可辅助风格探索，不默认作为最终工程图。

### 4. 停止点

新对话先只完成批次 A + Gate A，并向用户展示“找到的图型是否对路”。未确认样本类型前，不启动后 9 个 agent，不画 Fig.1。
