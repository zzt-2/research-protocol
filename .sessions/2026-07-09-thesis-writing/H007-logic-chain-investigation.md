### 逻辑链（修正版，待逐点验证）

```
背景：星地激光通信，接收端做载波相位恢复（CPR）
  ↓
两种主流方法：
  导频辅助估计（DA）：低SNR也能估，但①花25%带宽②强湍流fade期间pilot符号遭殃估不准
  盲估计（NDA-ML）：不花带宽+块级积分抗fade，但低SNR区M次方去调制放大噪声→崩溃
  ↓
两法各有死穴：
  导频死穴 = 强湍流高SNR区（fade打掉pilot段）
  盲估死穴 = 低SNR区（升幂放大噪声）
  ↓
交叉点现象：两条BER曲线有交叉，低SNR区导频赢，高SNR区盲估赢
  且交叉点随湍流左移（湍流越强→导频越早失效→盲估优势区越宽）
  ↓
切换机制：系统用块有效SNR感知当前信道条件，自动选更优的估计器
  → 高SNR用盲估避开导频的湍流失效
  → 低SNR用导频避开盲估的升幂崩溃
  → 切换是闭环必要环节，不是可选附件
  ↓
数字：盲估vs导频+1.2~1.9dB / 切换vs固定盲估+1.3~2.3dB / 29点选对26个
```

### ❗ 与预期不符的发现（必须查清楚）

验证"盲估低 SNR 崩溃"时发现：**这个现象不是无条件的**。

脚本 `/tmp/check_nda_low_snr.py` 结果：

| 场景 | 低 SNR 区（≤15dB）盲估 vs 导频 | "崩溃"成立？ |
|---|---|---|
| AWGN（无湍流）| 盲估反而全程赢（DA/NDA > 1.0）| ❌ 不崩 |
| weak（弱湍流）| 盲估比导频差（DA/NDA < 0.9，差 10~30%）| ✅ 崩 |
| moderate（中湍流）| 盲估比导频差（DA/NDA ≈ 0.8）| ✅ 崩 |
| strong（强湍流）低 SNR | 两法几乎持平（DA/NDA ≈ 0.98）| ❌ 不崩 |

**问题**：盲估"低 SNR 崩溃"主要在**弱-中湍流**低 SNR 成立，在 AWGN 和强湍流低 SNR 不成立。

**如果这是真的**（物理确实如此），那逻辑链的"两法各有死穴"需要修正——盲估的死穴不是"无条件低 SNR 崩"，是"特定湍流条件下低 SNR 崩"。链条变复杂了。

**如果这是数据问题**（仿真有 bug 或边界效应），那得查数据。

### 逐点核查清单

**断点 A：导频在强湍流高 SNR 区失效**
- 数据：DA BER 在 strong 高 SNR 区高于 NDA（data 口径）→ 已确认（S007）
- 待查：物理因果"fade 打掉 pilot 段"是不是标准解释？还是有别的解释？
- 待查：这个失效是"高 SNR 区专属"吗？低 SNR 区导频不失效？

**断点 B：盲估在低 SNR 崩溃 ← 最关键，与预期不符**
- 数据：弱-中湍流低 SNR 盲估确实差，但 AWGN 和强湍流低 SNR 不崩 → 已确认（/tmp/check_nda_low_snr.py）
- 待查（最重要）：**为什么 AWGN 低 SNR 盲估不崩？** 物理推导——M 次方放大噪声的效应在无 fade 时是否被"多符号平均"抵消了？
- 待查：**为什么强湍流低 SNR 盲估也不崩？** 是不是因为深 fade 时导频也一起烂，两法持平？
- 待查："升幂崩溃/M次方放大噪声"是不是领域标准说法？标准术语是什么？
- 待查：如果"崩溃"是条件性的，逻辑链该怎么修正？

**断点 C：交叉点随湍流左移**
- 数据：已确认（S007：AWGN 无交叉 / weak-mod ~15-20dB / strong ~10-15dB）
- 待查：物理因果链对不对？有没有别的解释？
