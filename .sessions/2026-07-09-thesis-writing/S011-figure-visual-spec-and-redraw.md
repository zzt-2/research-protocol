## 记录

用户否定旧 Fig.1 的视觉与信息架构，并要求检查全部图的标题、坐标、字体和架构图惯例。主线程派 3 个子 agent 分别核查数据图规范、架构图惯例和 Fig.3 信息密度。

对标事实：Johst、Le Bidan、Panasiewicz、OECC、Paillier 的数据图共同采用 caption 承担图意、短量名加括号单位、颜色/线型/小 marker 区分方法、曲线承载全扫描；现有 Fig.2/3/4 的图内 headline、卖点箭头、过载 legend 和程序输出式数字不符合该模式。Fig.3 的三场景不是三个点，而是 3×7=21 个 SNR 工作点，适合单面板三曲线。

实施边界：

- Fig.2：保留六场景，删全部卖点箭头，统一标题/坐标/字体/共享标签并输出矢量 PDF。
- Fig.3：改为三场景 BER reduction 全扫描；纵轴定义为同 SNR 下 BER 比值的 dB 化，不称 SNR gain。
- Fig.4：保留 crossover 专项，删图内总标题、HD-FEC、大叉箭头和 6 组合 legend。
- Fig.1：现图不可沿用；另开新对话讨论拆图和渲染路线。当前倾向 draw.io，待读取用户既有开题经验后再定。

迭代计数器：第 1 轮，PASS。假设：去除汇报式标注并按最终论文尺寸统一视觉规范，可显著提高专业度且不损失论点。否决条件：最终尺寸下文字不可读、图例仍遮挡数据、Fig.3 指标仍可能被误读为 SNR gain，或任一图的数据点与源 JSON 不一致。

实施结果：

- Fig.2 保留六个场景子图，删除全部卖点数字与箭头；统一短子图标题、完整坐标名、字体层级和 HD-FEC 参考线格式。
- Fig.3 改为 weak/moderate/strong 三条 BER-reduction 全扫描曲线，共 21 个工作点；纵轴明确为同 SNR 下相对固定 NDA 的 BER 降低量，不再使用 SNR gain 或 fair/naive 口径。
- Fig.4 保留三场景 DA/NDA 曲线和小型 crossover 标记；曲线、交叉点计算与标记位置统一使用原始采样点间的 log-BER 线性插值，可复现标注为 18.0/16.9/10.7 dB。
- 三图均输出矢量 PDF 和不低于 300 dpi 的 PNG；Fig.1 源文件未修改。

独立 verifier 首轮指出 Fig.4 坐标名不完整、旧硬编码交叉值与显示曲线插值不一致两项 Important。修正后复核 PASS：Fig.2/3 最终尺寸可读，Fig.3 的 21 点与源 JSON 逐点一致，Fig.4 曲线/交叉点/标记共用同一插值口径，三个目标脚本的定向 `git diff --check` 通过。详见 V001。
