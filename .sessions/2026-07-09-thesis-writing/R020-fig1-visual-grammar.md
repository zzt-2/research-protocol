# [R020] Fig.1 信息架构与视觉语法深度分析

> 2026-07-13 | 关联：2026-07-09-thesis-writing / D010 / S012 / R019
> 状态：批次 C 深度分析完成；批次 D critic 已回传，候选规格见 R021

## 调研问题

在用户确认第三轮样本“感觉都不错”后，哪些信息架构和视觉语法在多张参考图中重复出现，足以作为目标 Fig.1 的高置信约束？哪些只是单张特例或容易造成技术误导的表面类比？

## 发现

### 1. 输入样本与分析分组

批次 B 共由 3 个独立 agent 深度分析 12 张图，每人 4 张，并统一检查信息层级、数据流、控制流、模块粒度、拆图方式、箭头语法、颜色/灰度、字体、caption 分工和单双栏适配。

- **系统总览与多尺度**：B1-01、B1-02、A5-01、A1-03。
- **自适应判据与 selector**：B2-02、B2-04、A1-08、A3-01。
- **DSP 管线、旁路与公共后级**：B3-01、B3-03、A2-10、A4-15。

分析只提炼规则，不决定最终一图/双面板结构，不选择 renderer，不绘图。

### 2. 按证据强度分级的规则

#### R1［跨组高置信］：主数据流必须单向、连续、可追踪

三组样本都反复出现单一左→右主阅读方向。系统层、DSP 层即使有辅助输入或反馈，也不应破坏主业务样本的连续身份。辅助量宜从上方或下方接入，而不是与业务样本混在同一条折返线中。

**对目标 Fig.1 的约束**：接收样本从 receiver 前级进入 CPR、补偿和公共后级的路径必须一眼可追踪；禁止把测量支路画成主链的一部分。

#### R2［组内重复］：系统层与算法层必须通过父子关系分开

B1-01、B1-02、A5-01 都采用“宏观系统 + 关键局部放大”，而不是把全部器件和算法压在一条同粒度链上。设计感主要来自尺度控制、图元一致和留白，不来自颜色数量。三张均来自系统总览/多尺度组，因此这是该图型内的稳定模式，尚不是跨组共识。

**对目标 Fig.1 的约束**：外层只保留 Tx—FSO/channel—coherent Rx—DSP 的粗粒度上下文；只有贡献相关的 receiver/CPR 区域进入细粒度。若使用局部面板，必须有明确父级锚点和跨尺度身份标记。

#### R3［跨组高置信］：数据、测量、估计和控制至少要形成可区分的视觉语义

B1-02、B2-02、B2-04、B3-01、A2-10 等图都通过颜色、线型、形状或空间层级区分不同角色。仅靠颜色不足以支撑黑白打印。

**对目标 Fig.1 的约束**：至少区分四类关系：业务样本流、有效 SNR/测量量、阈值/选择控制、相位估计量。采用颜色与线型/形状/位置/标签中的至少两种独立通道，颜色只作辅助，详见批次 C 的 C2。

#### R4［组内重复］：判据模块、selector 和候选算法不能合并成一个黑箱

B2-02、B2-04、A1-08 共同表明，质量量、判据和路由输出是不同职责。异形判据节点或独立控制层能帮助读者理解“谁计算指标、谁作比较、谁路由结果”。三张均来自自适应判据组，因此这是 selector 图型内的稳定模式，尚不是跨组共识。

**对目标 Fig.1 的约束**：effective SNR、fixed threshold comparison、DA/NDA 路径和 selector/mux 必须保持职责可辨；不能用一个“adaptive CPR”大框吞掉全部机制。

#### R5［条件确认］：完整/高密度图默认按双栏通宽设计，局部图可单栏

批次 C 的 4 组密度样本给出的是条件规则，而非“所有图都必须双栏”：A5-01 多面板和 B3-03 硬件双模式图在单栏缩小后明显临界；B1-03 的双泳道图双栏更稳但经过简化可单栏；B3-02 作为 receiver-local 局部图可单栏裁剪。布局 agent 的另一组 4 图也只得到 2/4 明确双栏、1/4 边界、1/4 单栏可行。故 R5 不升级为跨图硬事实。

**对目标 Fig.1 的约束**：完整总览或高密度组合先按双栏通宽的真实目标尺寸验收；局部放大可以单栏，但必须通过目标尺寸下的字号、箭头和图例可读性检查。不得用“看起来能放下”替代缩小检查。

### 3. 重要但尚不能升为“跨图共识”的特例

#### T1：共享输入→并行候选→选择→公共后级

A1-08 是本批唯一把这四步同时画清楚的样本。它对目标语义高度有用，但候选是同构测试相位，不是 DA/NDA 异构估计器，因此只能作为强特例，不能声称为多图重复模式。

#### T2：原始业务数据旁路 + 相位估计量回灌补偿

A4-15 最直接显示原数据不被估计器吞掉、估计量从侧面注入后级。A2-10 只证明监测旁路不截断主 DSP 链，并没有 selector 或补偿回灌。两者不能合并成“已有多图完整同构”的结论。

#### T3：三级几何放大

B1-02 的系统→核心→单元三级 callout 是高质量特例；A5-01 的跨面板频谱身份连续也是特例。是否需要三级而非两级，仍应由目标信息量决定。

### 4. 明确不应迁移的视觉/逻辑语法

- **early-exit 串级**：B2-02/B2-04 的 exit/continue 逻辑若照搬，会误导成“先跑一个估计器，失败后再跑另一个”。目标不是串级补救。
- **训练态占据主图**：A3-01 的 Training/Inference 分面会把论文贡献误导成学习式 selector；目标 Fig.1 不应画训练过程。
- **硬件资源密线**：B3-03 的共享存储、CORDIC 和交叉控制线具有结构证据价值，但造型和密度不可迁移。
- **六面板过载**：A5-01 的频谱、星座、帧结构只适合其论文论点；目标 Fig.1 若照搬会淹没 adaptive CPR 主线。
- **器件 clipart 与折返主路**：A1-03 可核对系统边界，但老式器件图标和折返走线不应成为目标风格。
- **专利长句框**：A4-15 的旁路语义可借，框内大段全大写描述不可借。

### 5. 证据修正：A2-10 来源映射

批次 B 发现 A2-10 本地预览显示 UCL thesis Chapter 5 Fig.5.1，而原卡片标为 *Optics Express* 2015 Fig.1。定向核验结论为：论文图注与 thesis 图的模块、抽取位置和上下排描述高度对应，但因未取得期刊原图本体，无法证明二者图像级相同。

R019 已将本地预览直接来源修正为 Maria V. Ionescu 2015 UCL PhD thesis Fig.5.1、p.83，并把期刊 Fig.1 保留为关联来源。该图继续只支持“监测旁路不截断主 DSP 链”，不支持 selector 或估计回灌。

### 6. 尚未冻结的问题

- 一图双面板、三级放大或单一 receiver-local 图尚未决定。
- DA/NDA 是视觉上并列展示，还是先由控制量路由再执行，必须继续对照真实算法执行语义，不能从参考图反推。
- 是否使用频谱、星座或相位轨迹作为语义小图尚未决定；不得仅为装饰加入。
- 颜色、线型、字体和 caption 的最终数值规范仍未冻结；批次 C 已给出可执行的语义和缩小检查门槛。
- draw.io、SVG、TikZ、HTML/image 等 renderer 均保持 TBD。

### 7. 批次 C 视觉规范复核（12 张）

批次 C 由 3 个独立 agent 分别复核布局层级（B1-01、B1-02、B2-03、B3-01）、流向编码（B2-02、B2-04、A1-08、B3-04）和密度/字号（A5-01、B1-03、B3-02、B3-03）。全部基于 R019 的本地 PNG；密度组另做了约 1050 px（约 3.5 in@300 dpi）的缩小检查。没有调用网页、没有改 SVG、没有选择 renderer。

#### C1：R1 得到独立批次确认，R2 仍只在组内成立

- **R1 再确认（布局组 4/4）**：系统/旁路/流水线样本都保留一条连续、单向的业务主链；测量、估计和控制从上方或下方正交接入，不应成为主链折返的一部分。
- **R2 不升级**：B1-01/B1-02 直接使用父级—局部放大，B2-03 采用训练/部署泳道，B3-01 没有宏观—局部关系。它说明多尺度组内部的父子锚点可靠，但不是跨图型共识。
- **新增暂定 R6：多尺度图必须保持父级锚点与身份连续**。局部层级不宜超过两级；每个局部图应复用父级模块名、编号或视觉身份，避免把多个等权面板拼成“看似多尺度”的拼贴。R6 先作为结构候选的验收条件，不作为最终架构决定。

#### C2：R3 细化为“至少两种独立通道，颜色只作辅助”

流向组在 R020 原有 5 张明确证据上新增 A1-08 与 B3-04，当前共有 7 张跨总览/selector/DSP 语义的直接证据。B2-02/B2-04 的蓝绿箭头、菱形/梯形节点和 TRUE/FALSE 标签，以及 A1-08/B3-04 的线型、位置和反馈方向表明：数据、测量、估计、控制不能只靠颜色区分；至少需要颜色之外的形状、线型、空间位置或文字标签中的一种独立通道，且黑白打印仍可读。

**对目标 Fig.1 的硬约束**：业务样本、测量量、相位估计量和 selector 控制分别定义线型/形状/位置/标签；颜色仅做第二通道。selector 的判据、候选路径和路由结果仍须分开画。

#### C3：R4 保持 selector 组内规则，early-exit 反模式进一步坐实

B2-02、B2-04、A1-08 都把“候选—判据—路由”拆成不同职责；B3-04 则展示了 selector 隐含在黑箱 detector 中的反例。因此 R4 继续标记为 selector 图型内的重复规则，不能升级为所有系统图的跨组共识。两张 early-exit 样本都采用串级 exit/continue，若迁移到 Fig.1 会制造“先运行一个估计器、失败后再跑另一个”的错误语义；目标应保持同一输入的并行 DA/NDA 候选和一次性 selector 路由。

#### C4：密度与 caption 的可执行门槛

- A5-01 的多面板把硬件、公式、频谱、星座和 CPR 诊断混在一张图中；B1-03 的双泳道则用公共前后级和中段差异控制密度；B3-02 适合作为单级局部放大；B3-03 的跨层黑色密线在单栏下不可追踪。
- **多面板门**：超过 3 个面板时，必须由一个单一论点统领、保持单向阅读，并在约 3.5 in 单栏与约 7.16 in 双栏目标尺寸下分别检查；否则应删面板或移出 Fig.1 主图。六面板不是绝对禁令，但 A5-01 是直接负例。
- **跨层线门**：硬件/算法/共享资源跨层连线必须用颜色与线型（并配图例）冗余编码；若仍不可追踪，就抽象模块或拆成局部图。B3-03 是直接负例，B3-02 是“保留局部但不承担总图”的对照。
- caption 应解释泳道、颜色/线型和判据职责；不能依赖 caption 挽救图内读不出的箭头或微小文字。

## 结论

批次 B/C 形成了分级证据：R1（单向连续主数据流）和 R3（至少两种独立通道区分数据/测量/估计/控制）为跨组高置信；R2（父子尺度）和 R4（判据/selector/候选职责分离）仍是组内重复；R5 被批次 C 收窄为“完整/高密度图默认双栏、局部图可单栏但须过目标尺寸门”；R6 是关于多尺度身份连续性的暂定结构条件。共享输入并行候选、原数据旁路回灌和公共后级是目标语义上重要的强特例，但现有参考仍不足以称为多图同构共识。

这一结果说明，后续不应寻找单张模板照抄，而应组合多类证据：用顶刊图控制层级和留白，用 selector 图控制判据语法，用 CPR/旁路图约束真实数据与估计流。
