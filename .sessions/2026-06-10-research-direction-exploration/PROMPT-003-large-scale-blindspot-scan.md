## 扫描双轴设计

### A 轴：按主导损伤重组（核心创新，之前没用过）

Paillier 2020 证明主导损伤是**残余幅度闪烁 + 激光相位噪声**，湍流相位 negligible。之前所有扫描按"信号处理模块"（同步/编码/调制...）切，但**一个损伤的处理空间跨多个模块**——按模块切会漏掉"跨模块组合处理一个损伤"的方向。本轮按损伤切：

| 损伤 | 处理空间（跨模块）|
|---|---|
| **残余幅度闪烁**（主导）| AGC / 导频功率自适应 / 编码交织抗 fade / 分集合并 / ML 检测 / 信道估计加权 |
| **激光相位噪声**（主导）| 线宽容忍载波恢复 / 导频相位估计 / 差分编码 / OPLL 设计 / 多级 CPE |
| **多普勒残频**（次要，已验证可跟踪）| DPLL / 前馈 CFO / 预补偿 —— **已饱和，不扫** |
| **湍流相位**（negligible）| —— **D003 已证伪，不扫** |

### B 轴：补 5 个系统盲区维度

| 盲区 | 为什么是盲区 | 扫什么 |
|---|---|---|
| **β1 DSP 流水线模块** | R002 只扫载波恢复，定时/均衡/IQ补偿/静态补偿几乎没扫 | Gardner/Godard 定时在湍流下 / CMA+DD-LMS 均衡在 deep fade / IQ 不平衡补偿 / 色散补偿（若适用）|
| **β2 系统架构** | R002 多孔径被 S001 排除，但分集有多种非多孔径形式 | 波长分集 / 偏振分集 / 时间分集 / 角度分集 / 中继（相干 DF/AF）/ 多用户（星地多用户调度）|
| **β3 方法论/信息论** | R002 偏算法，信息论界/容量分析弱 | 相干 FSO 容量界 / outage 容量（相干 h·γ̄）/ 对话容量 / 强可译性界 |
| **β4 跨领域迁移** | R002/R005 都是 FSO 内部，没看 RF 卫星/水下/VLC | RF 卫星相干处理迁移 / 水下声波湍流类比 / VLC 相干检测 |
| **β5 局部动态重评** | TL-03/04 砍全局动态，但参数区间内局部动态未评 | deep fade 瞬态检测 / 衰落边沿跟踪 / 突发检测窗口优化 / 跟踪-失锁-重捕机制 |
