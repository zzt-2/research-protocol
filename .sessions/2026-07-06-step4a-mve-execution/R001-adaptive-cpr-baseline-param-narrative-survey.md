# [R001] 自适应/混合载波恢复论文的 baseline 组织 + 参数处理 + 叙述展开调研

## 调研问题

A4 条件适配 PASS（per-block 有效 SNR 驱动 DA/NDA 切换）后，发简报给老师前需搞清楚同领域论文的写作惯例，回答用户 4 个问题：

1. **baseline 怎么组织**：切换/自适应策略的 baseline 结构（固定策略 vs 别的方法），尤其自适应 CPR 或自适应传输论文的惯例
2. **叙述怎么展开**：给出什么参数、什么数据、图怎么画、故事线怎么组织
3. **【最关心】参数照搬参考文献 vs 自调同算法**：baseline 是照搬别人论文参数复现，还是自己重新调参？
4. **【最关心】先按原文复现再迁移**：有没有"先按原文献参数复现验证实现正确，再迁移到自己场景"的流程叙述？

**动机**：简报 §6 的 baseline 结构（固定 DA/NDA 主 baseline + DPLL 异族 + VV/BPS fellow + oracle 上界）是主线自拟的，需验证是否符合领域惯例，否则被老师质疑 baseline 选取时没底。

### Q1：baseline 怎么组织 —— 切换型 CPR 的 baseline = "不做切换的固定版本" + 同族经典参照 + 上界

**三份证据结构高度一致**：

| 论文 | 主 baseline（对照"有没有切换"）| 附加参照 | 上界 |
|------|-------------------------------|---------|------|
| 张思齐 | 文献溯源经典算法（VV/BPS/QPSK 分圈）正文同台对比 | —（固定算法并列）| 无显式 oracle |
| Wang 2025 OE | SSD-only（不做切换，下界）+ hybrid[29]（先验切换方案）| MRS-MLSD[29]、FFT-FOE+BPS | FS-MLSD（全复杂度）|
| Barbosa 2020 JLT | 固定 two-stage CPR（不切换，始终开 BPS）| pilot-only、4 次幂盲 CFR | — |

**核心模式**：切换/自适应论文的 baseline 是**"不做切换的固定版本"**，对照维度是"策略"（有没有切换），不是"方法谁强"。这点三篇一致。

**对简报 §6 的判定**：简报结构（固定 DA/NDA 主 baseline + DPLL 异族 + VV/BPS fellow + oracle 上界）**完全符合惯例，甚至比 Barbosa/Wang 更严谨**（多了异族参照 DPLL + oracle 上界两层）。"切换策略的 baseline 是固定策略，不需找别人论文"这个判断有领域实证支撑。

### Q2：叙述怎么展开 —— "消融选参 → 模块验证 → 主对比 → 条件扫描 → 复杂度表" 五段式

**张思齐（BUPT 学位论文强规范）+ Wang 2025 OE 高度同构**：

1. **先消融/扫描选自身参数**：张思齐块长 N=1024/320/64 消融选；Wang 门限 ∆₁ 扫描（Fig 7 BER vs ∆，选 0.6）
2. **模块化验证**：Wang §4.1 先验 CR（星座图 → BER）→ §4.2 MSDM 扫描；张思齐每章"原理 → 复杂度 → 仿真"
3. **主结果对比**：NMSE/BER vs 接收功率（张思齐）或 BER vs OSNR/ROP（Wang），对 baseline
4. **条件扫描收尾**：张思齐湍流弱/强 + 线宽 50/100/150/200kHz + 频偏范围；Wang 三速率 80/90/100 Gbaud + 线宽 100kHz/1MHz
5. **复杂度表量化**：张思齐乘法器数百分比（27.2%/13.8%/47.6%/17%）；Wang Table 1-3

**图类型**：BER/NMSE vs 接收功率或 OSNR 为主体 + 星座图 + 复杂度表。**无收敛曲线、无柱状图**。门槛统一引 7% FEC 硬判决门限 3.8e-3（张思齐 L454）。

**对简报的判定**：简报 §2-§4 的叙述（主结果表 → crossover 发现 → 方法+切换结果表）符合"先主结果再机制再方法"的展开，但缺 Wang 式的"门限扫描消融图"（简报直接给 γ_eff 阈值=13dB，未展开敏感性扫描的可视化——不过 H008 债务①已记敏感性扫描 11/13/15 鲁棒，写论文时可补图）。

### Q3【最关心】：参数照搬 vs 自调 —— 自调 + 标文献溯源，不照搬别人数值

**三份证据全部"自调 + 标溯源"**：

| 论文 | 参数处理 |
|------|---------|
| 张思齐 | 参数标文献来源（线宽 50kHz[16]、Cn²[57]、耦合效率[16]）但**自己定值**；块长自消融选（N=1024/320/64）；第三章"除非另有说明，频率偏移 300MHz、线宽 50kHz、块长 320"集中声明默认值 |
| Wang 2025 OE | N=64 引 OIF 800G 场景[22]；M=16 自定（按 FOE 范围 ±3.2GHz 推）；门限 ∆₂=1 理论推，∆₁≈0.6 扫描选 |
| Barbosa 2020 JLT | pilot overhead 3.1% 沿袭前作（标 "existing"）；PS factor 以 "AWGN-optimized value"（文献基准）为起点做 detune |

**领域惯例 = "参数标溯源但不照搬别人数值"**。即：方法/参数的**合法性**靠引文献（证明有人用过、有理论依据），**具体数值**按自己场景定 + 消融/扫描选最优。没有任何一篇"照搬别人论文的完整参数表"。

**对简报的判定**：params.py 的 source_type/audit_flag（TL-26 溯源）+ 自定值的做法**完全对齐领域惯例**。简报可放心说"自实现 + 文献溯源"，不需跟任何文献用一样的参数。这正面回答了用户 Q3——**自调同算法，不是照搬原文参数**。

---

### Q4【最关心】：先按原文复现再迁移 —— 三份证据全部"未发现"独立复现验证段

**这是最明确的结论。三篇都不做"先复现 baseline 验证正确再迁移"的流程**：

| 论文 | 复现叙述 | baseline 可信度靠什么 |
|------|---------|---------------------|
| 张思齐 | **未发现**独立复现验证段。绪论（L188-194）逐条指出 baseline 算法局限（如 QPSK 分圈"忽视信号时间间隔致精度下降"），正文直接同台对比 | ① 文献溯源标方法来源 ② 同台对比（同信道同参数同评估）|
| Wang 2025 OE | **未发现**复现-验证-对齐叙述。明言 "all evaluations utilized FS-MLSD for ... fairness"（§4.1）| ① 引文献（hybrid "as described in [29]"、FFT-FOE/BPS "detailed in [32]" 给具体参数）② 同实验台对比（Fig 4 同一装置）|
| Barbosa 2020 JLT | **未发现**。标 "existing/typical" 引文献 | ① 引文献标来源 ② 同组 pilots + 同实验数据离线处理覆盖全场景 |

**领域惯例 = baseline 可信度靠"引文献（合法性）+ 同台对比（公平性）"两机制，不靠"复现对齐"**。没有任何一篇做"先按参考文献数值复现 → 对齐 → 再迁移"的流程。

**对简报的判定**：这正面回答了用户 Q4——**领域不做"先复现再迁移"流程，简报不需要写这段**。写了反而不自然。简报 §6 现状（直接说自实现 + 标角色 + 公平对照）已是正确做法。这印证 H007 认知修正（"通信 baseline 是自实现的，引文献只证方法合法"），三篇实证。

### 附加发现：MSDM vs per-block 有效 SNR 机制不同（防撞车误判）

Wang 2025 OE 的 MSDM 切换是 **per-symbol 瞬时残差型**（metric = |Rₖ − RDₖ₋₁ − HD[Rₖ−RDₖ₋₁]|，前端正信号减上一已解码 PAM-4 符号的残差），粒度是符号级，basis 是局部误差指示。

简报的 per-block 有效 SNR 判据是**块级聚合质量估计**（γ_eff = γ_bar + 10log10(ĥ_blind)），粒度是块级，basis 是块内有效信噪比。

**机制不同**：共同点仅"用低成本运行点 metric 决定是否启用昂贵模式"这一思想。这对简报 §5（有人做过吗）是个补强——即便有人做 per-symbol 切换（Wang），也没人做 per-block 有效 SNR 驱动的 DA/NDA 切换，新颖性锚更稳。

## 结论

**用户 4 问的回答**：

1. **baseline 组织**：切换型 CPR 论文的 baseline = "不做切换的固定版本"（主）+ 同族经典参照（fellow）+ 全复杂度上界。简报 §6 结构符合惯例，甚至更严谨（多了异族 DPLL）。
2. **叙述展开**：五段式（消融选参 → 模块验证 → 主对比 → 条件扫描 → 复杂度表）。简报 §2-§4 符合"先主结果再机制再方法"，可选补门限敏感性扫描图。
3. **参数照搬 vs 自调**：**自调 + 标文献溯源**，不照搬别人数值。简报做法（params.py source_type/audit_flag + 自定值）对齐惯例。
4. **先复现再迁移**：**领域不做此流程**。baseline 可信度靠"引文献（合法性）+ 同台对比（公平性）"两机制。简报不需写复现段，§6 现状已正确。

**一句话**：简报 §6 的 baseline 组织是领域标准做法，调研结论是**验证而非推翻**。微调可加一句"经调研 3 篇同类论文（含 1 篇 BUPT 同门学位论文），切换型 CPR 的 baseline 惯例即固定策略 + 异族参照 + 同族 fellow + 上界"作为惯例背书（本轮按用户意见不动简报，记此建议供后续）。

## 对决策的影响

- **不新建 D###**：本调研是写作准备，不改变 A4 PASS 的 Go 判定，不改变 baseline 结构决策（D-010 五条标准仍是 baseline 选取唯一依据）。调研结论是"简报做法符合惯例"，属验证性发现。

### NDA 缺口的真实性质 + 空白转化叙事

**关键发现**：三轮检索（59 JSON / ~544 篇）独立证实——**"NDA 载波相位恢复"专题在 2020+ 严格 IEEE Trans 是空白**。NDA 大类（定时/频率/信道/均衡估计）在严格 Trans 活跃（4 篇），但 NDA 载波相位恢复专题最新严格档级仍是 Du PTL 2025（Letters）。

**这是物理事实，不是检索不全**（三轮不同查询词独立收敛到同一结论）。

**空白转化叙事**（简报/论文可用）：
- NDA 估计方法论近年严格 Trans 活跃（引 TVT 2023/2025 + JLT 2025 + TWC 2022）→ 证明 NDA 是合法且活跃的研究方向
- 但 NDA **载波相位恢复**专题近年严格 Trans 偏薄（最新仍是 Du PTL 2025 Letters）→ **这本身说明该子领域有空白，我们的工作填补其中**
- NDA-ML 合法性背书 = 经典源头（VV 1983/Leven 2007）+ 理论 CRB（TVT 2023）+ 方法源头（Du PTL 2025）+ NDA 大类活跃（4 篇严格 Trans）四层支撑

从"只有 1 篇 Letters"升级到"四层背书"，且最薄的那层（载波相位专题）转化为"我们填补空白"的卖点。
