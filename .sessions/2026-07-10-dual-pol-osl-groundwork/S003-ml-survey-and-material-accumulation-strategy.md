## 记录

### 本轮做的事

1. **执行 PROMPT-002（R001）**——ML/LSTM 自适应调制切换在光通信现状。两轮检索（英 search 6 查询 + 中 CNKI 7 查询，3 子 agent 消化）。
   - 结论：广义 ML for 光通信成熟（S2 命中 2472），精确调制切换小众；LSTM 切换极少；用户"见过 LSTM 调制切换学位论文"印象未获佐证；双偏振星地 FSO+ML 调制切换=空白
2. **讨论调制格式识别/资源分配/调制切换**——三个都不合适（识别是不同问题/分配是不同层/切换被 ③ oracle 封死）
3. **讨论双偏振**——Q-DP2/DP3 是纯 DSP 不带 ML（与 ML 调研无关，是 Step 4a 主线）
4. **用户追问 ML 全谱 → 执行 R002**——ML 在星地激光湍流全谱。两轮检索（英 search 11 查询 + 中 CNKI 5 查询，3 子 agent 消化）。
   - 结论：9 类应用点全不窄；物理层 DSP 对口的 3 点（衰落预测/ML载波恢复/ML均衡）在湍流场景全空白
   - **修正主线口头判断**：之前说"ML 大概率也窄"是错的——③ oracle 只封调制切换，不封 DSP 模块 ML（急于收敛 profile 第 N 次）
5. **用户确立攒材料策略**——不急进任何一个，全部推到 MVE 前，大量精读攒材料

### 关键发现

- **R001**：调制切换方向物理天花板已封（③ 0.09dB + N1 PS gain≈0），不重开
- **R002**：ML 在星地激光湍流有 9 类应用点，用户直觉"不应该少"正确。跟物理层 DSP 对口的 3 个空白点：
  - A. 衰落预测（LSTM/ESN）→ 目前只喂 AMC，**喂相干 DSP 参数无人做**
  - B. ML 载波恢复 → **湍流场景基本无人做**
  - C. ML 均衡（湍流下）→ Qin/Nasr 3 篇全 0 引，**无与 CMA 正面对比**
- **中文缺口**：没有一篇中文学位论文同时含"星地激光+湍流+ML"
- **与 Q-DP3 结合点**：LSTM 衰落预测→fade 前瞻→跨帧恢复触发，无人接起来
