### B. oracle 上界关键发现（决定战场大小的核心事实）

prompt025（C 类，新参数 4.2/1.4）L0 vs oracle 实测：

| 指标 | L0（ML 固定权重） | oracle（完美 CSI） | 头顶空间 |
|---|---|---|---|
| PI-BER（排列不变） | 7.936e-5 | 3.528e-5 | 仅 ~2× |
| **fixed-label BER** | **0.4996** | **0.0000353** | **~14000×** |

**两大推论：**

1. **夜间全类 MVE 用错了记分牌**：A-E 的 Go 判据全是"mean PI-BER < L0"。但 PI-BER 近底（oracle 仅比 L0 好 2 倍），**任何方法包括开挂 oracle 都"看起来像 Kill"**。PI-BER 对 swap 问题结构性失明（自动选最优排列抹掉 swap 影响）。swap 的全部破坏力在 fixed-label BER（0.4996=完全锁死错标签）。

2. **破坏可恢复但有条件**：oracle 证明 fixed-label 0.4996→3.5e-5（4 个数量级），**前提是有 CSI**。盲均衡器（A/C/D 都是盲的）信息论注定碰不到 fixed-label BER（排列模糊：swap 后两流输出统计完全对称，无参考帧分不清 X/Y）。只有 CSI-aided（pilot）或打破对称性的方法能解。

**信息论边界（决定哪些方向注定 KILL，不用再试）**：
- 盲 swap 统计检测、同分布双流 ICA 单独、更好的盲 loss/训练（A/C/D）→ 注定 KILL（无参考帧）
- 差分偏振编码解 swap → 机制错配（差分解 π/2 相位旋转，解不了标签交换）

### C. 8 机制全景（~40 思路，按"怎么打破排列对称性/怎么攻 swap"分类）

**机制 A：注入 CSI（外部参考）** — 夜间 E 类所在，撞车风险高（coherent 标配）
- A1 preamble 前导序列锁初始标签 / A2 pilot 周期导频 / A3 data-aided / A4 两段式 / A5 叠加导频（零开销）/ A6 半盲 / A7 上下行互易性
- 用法子方向：①估 SOP 角→前馈旋转补偿 ②估 Jones→均衡 ③只校验标签→翻转 ④辅助在线微调（复活 C1）⑤辅助检测器（复活 D）

**机制 B：让信号自身不对称（内生参考）** — 🔥主战场，创新潜力极高，撞车低
- B1 非对称调制阶数（X=16QAM Y=QPSK）/ 🔥B2 非对称功率分配（可能让 swap 不发生，治本）/ B5 非对称脉冲成型 / B6 发射偏振角偏置 / B7 流间已知相关性（Y=f(X)）/ B8 非对称符号率 / B9 扩频码标识
- 核心洞察：若两流不对称，CMA 恒模代价对"正确盆地"和"交换盆地"不再等价 → swap 多解可能消失。绕开"盲方法注定 KILL"约束（前提是双流对称）

**机制 C：时间维利用（突发特征）** — 编码/交织层
- 🔥C1 交织+FEC（swap 是突发错极端形式，成熟武器治新病）/ C2 分段检测翻转 / C3 突发边界分段均衡 / 🔥C4 CMA 在线重启（检测 divergence→reset 重收敛）/ C5 滑窗 CMA / C6 加权遗忘因子

**机制 D：换均衡范式** — 夜间 B 类部分覆盖，多为经典撞车高
- D1 DD（decision-directed）/ D2 ICA 盲分离（条件存活：需 B 机制让流不对称）/ 🔥D3 MMA 多模算法（CMA 直系变种）/ D4 DFE / D5 卡尔曼 SOP 跟踪（撞车高）/ D6 粒子滤波

**机制 E：ML 范式创新** — 🔥夜间 B 类的真正出路（夜间 defer 是没找对 ML 工具）
- 🔥🔥E1 群等变神经网络（group equivariant CNN，架构上解决 D031 泛化痛点）/ E2 排列等变网络（deep sets/transformer）/ E3 元学习（test 时快速适配）/ E4 neural-CMA（端到端可微盲均衡）
- E1 核心：D031 痛点="训练段 SOP 角度泛化不到 test late 段 57°"，等变网络架构上就解决（输入转 θ→输出转 θ，无需"见过"该角度）
