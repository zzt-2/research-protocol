# [R006] Q-DP3 前置问题厘清：预测性检测物理可行性 + 与 D003 关系判定

> 2026-07-14 | 关联：专题 2026-07-10-dual-pol-osl-groundwork / D003 / R005 / S016
> 性质：B 边前置厘清（文献+机制分析），不立 Q#、不判 Go/Kill（FR-22）

## 调研问题

R005 给 Q-DP3 方向留两个前置问题，答清楚才能进 GW Step 4a 维度 A 正式竞争分解：
1. 预测性检测 vs 响应性重置——预测性检测在信道模型下物理可行吗？界线在哪？
2. R005 的"方向2 发散检测+响应"和 D003 的"Q-DP3 跨帧恢复"是同一方向吗？子集？独立？

## TL;DR

- **前置 1**：预测性检测**物理上有条件可行但存在关键认知反转**——(a) 对 **GG fade** 预测性可行（AR(1) 强相关 ρ≈0.99997，h 下降趋势在 fade 前数百-数千 block 可观测，预测窗口 0.16-5ms ≫ 响应延迟）；(b) 对 **CMA 发散**预测性**证据不足且可能无前兆**（R4 修正版"前窗口零深衰落"从 57% 降到 32%，J_CM(t) 与 h(t) 前兆轨迹从未测过）。Q-DP3 必须明确检测对象是 fade 还是 divergence——若检测 fade 触发预防性恢复，物理可行；若检测 divergence 本身，前兆存疑。
- **前置 2**：**子集关系**——R005 方向2 ⊂ D003 Q-DP3。D003 原始定义已含"fade 检测 + 跨帧状态管理 + 快速重锁定"完整链（feasibility L624-625），R005 的"预测性检测+响应"是其中"检测"环节的具体化并加了"预测性"约束。两者 A 相同（hang-up recovery open）。合并后的精确定义见 P2.4。
- **对主控建议**：Q-DP3 可进 step 4a 维度 A 正式竞争分解，但致命风险从 D003 原记的"L-DP5 预期性论述"升级为"预测性检测对象的物理可行性"——必须先厘清检测 fade 还是 divergence。D003 Conditional Go 条件仍满足但需补一个 Conditional：检测对象须为 fade（物理可行）非 divergence（前兆存疑）。

## 前置 1：预测性检测 vs 响应性重置

### P1.1 可观测前兆信号

**信道模型下的可观测信号**（双偏振星地 GG 湍流 + 连续 SOP，参数来源 S004/_gg_time.py）：

| 信号 | 物理来源 | 实时可获取？ | 前兆性质 |
|---|---|---|---|
| **接收包络/功率 h(t)** | GG 强度闪烁，AR(1) 块间相关 ρ=exp(-block·t_s/τ_c) | ✅ 接收端直接测 | **对 fade 有前兆**：ρ≈0.99997（f_G=100Hz）→ h 下降趋势在 fade 谷底前数百-数千 block 已存在于数据中 |
| **CMA 代价 J_CM(t)** | J_CM=E[(R²-‖z‖²)²]，权重漂移时变化 | ✅ 接收端算 | **对 divergence 前兆存疑**：S005/S007 **从未提取 J_CM 时间序列**（results/ 50+ JSON grep `j_cm\|cost` 零命中）。R4 只统计了 min_h/事件计数/位置分位三类标量汇总，无轨迹形状分析 |
| **SOP 漂移速率** | 机械振动/热漂移驱动（sat.1553 L563，非湍流） | ✅ 但需估计 | **非 fade 前兆**：SOP 与 GG 衰落是独立过程（sat.1553 §6 + L-DP5/L-DP6 均独立建模，三篇精读确认未讨论耦合）。SOP 快变预示的是极化串扰（D014），不是 fade |
| **权重范数 ‖w(t)‖** | CMA 在线更新累积漂移 | ✅ 接收端算 | R5 保存了 w_norm_traj，但发散判据本身就是 ‖w‖>10×init——**检测 ‖w‖ 超阈是响应性**（已发散才检测到），非预测性 |

**关键约束验证**：以上信号均接收端可实时获取，不依赖发送端先验。✅

**认知反转（PROMPT-017 陷阱 3 的实证）**：fade 和 divergence 是两个不同事件。R4 证明发散由高 μ 数值不稳定驱动（r=0.70-0.75），深衰落是加剧因素非必要触发。因此：
- 检测 **fade** 的前兆（h 下降趋势）→ 物理可行，但 fade ≠ divergence，检测到 fade 不等于检测到即将发散
- 检测 **divergence** 的前兆 → J_CM/w_norm 的轨迹前兆**从未被测量**，现有数据不能下"有/无前兆"结论

### P1.2 预测窗口（物理约束）

**fade 的时间尺度**（S004 验证 + Conan 1995）：
- τ_c = 1/(2π·f_G)：f_G=30Hz→τ_c≈5.3ms；f_G=100Hz→1.59ms；f_G=1000Hz→0.16ms
- block·t_s = 100 符号 × 0.4ns = 40ns
- ρ=exp(-40ns/τ_c)：f_G=100Hz 时 ρ=0.99997（块间强相关）

**预测窗口估算**：一个 GG 深衰落事件从正常 h 下降到 h<0.3（深衰落阈值），由于 AR(1) 强相关，下降过程持续约 0.5-1 个 τ_c。以 f_G=100Hz（τ_c=1.59ms）为例：
- 从 h 开始下降到 h 触底：~0.8-1.6ms
- 可提前检测到下降趋势的窗口：h 下降初期（前 10-30% τ_c）≈ 0.16-0.5ms ≈ 400K-1.25M 符号 ≈ 4000-12500 block
- **响应延迟**：压 μ（即时）/模式切换（帧级；注：feasibility_report 记 L-DP5 帧时长 ~74µs 有误，精读笔记确认 4160 sym@56GBaud=74ns，L-DP6 32768 sym@32GBd=1.024ms，见 topic-index 债务条目）/重训练 ML（数百 ms，**太慢**）

**结论**：对 fade，预测窗口（0.16-0.5ms）≫ 响应延迟（µs 级压 μ/切换），**物理可行**。但重训练 ML 太慢（数百 ms），只能做压 μ/冻结/切换等轻量响应，不能做重训练。

**对 divergence 的窗口问题**：divergence 是高 μ 数值不稳定的累积效应（R5 √n 律），不是单一事件。它的"发生时刻"是 ‖w‖ 累积漂移超阈的时刻，没有明确的"前兆窗口"概念。30% 发散在序列前 10%（R4 两版一致 ~0.30）说明发散可以极早发生——若早期就发散，根本没有足够历史数据做预测。

### P1.3 预测性 vs 响应性的可操作判据

基于文献调研（web 子 agent）+ 信道物理，给出判据：

**预测性检测**（proactive）= 信号 X 在 fade/divergence **发生前** T_predict 时间出现可辨识变化，且 T_predict > T_response（响应延迟），且 X 的变化方向在统计上预示 fade/divergence。

**响应性重置**（reactive）= 信号 X 在 fade/divergence **发生时或之后**才出现变化，或 T_predict < T_response（来不及响应），或 X 变化与 fade/divergence 无因果预示关系。

**文献现状对照**（web 子 agent 检索，2026-07-14）：

| 工作 | 预测/响应 | 时间尺度 | 检测信号 |
|---|---|---|---|
| sat.1553 L582 被动冻结 | **响应**（功率低→停更新） | 实时 | 接收功率 |
| L-DP6 outage 丢弃 | **响应**（BER>0.44 事后统计） | 帧级事后 | BER |
| Vgenis 2010 Nonsingular CMA | **算法层规避**（非检测） | — | 修改代价函数防 singularity |
| Faruk 2014 Modified CMA | **算法层规避** | — | 同上 |
| Lauinger 2022 变分盲均衡 | **算法层规避** | — | 变分推断提升收敛可靠性 |
| Li2023/Islam2025 fade 预测 | **预测**但统计级 | 分钟级 | 强度统计 → 喂链路层 AMC |
| Gao 2025 scintillation 分离 | **预测**最接近符号级 | ms 级 | 高频 scintillation 分离（但目标信道建模非 DSP 触发） |
| RF 长程预测（Adeogun 2025/Heidari 2006） | **预测**成熟范式 | 1-10ms | LMS/Kalman 信道预测 |

**关键文献空白**：**未找到任何"符号级/帧级 fade 预测 → 触发物理层 DSP 响应（重置 CMA/调步长）"的工作**。光通信 hang-up recovery 全是响应性或算法层规避；光 fade 预测全是统计级喂链路层。RF 有成熟预测范式但落在信道级非环路级。

**JR-CMA 界线**（PROMPT-017 陷阱 1）：JR-CMA（L-DP8）的"误差阈值重置"是**响应性**——error 超阈值（已发散征兆）才重置。Q-DP3 要成为算法创新，检测必须在 fade 发生前（h 下降趋势期）触发，不是 error 超阈后。这条界线清晰可操作：**用 h(t) 趋势预测 = 预测性；用 error/J_CM 超阈 = 响应性（退化成 JR-CMA）**。

### P1.4 ML 的角色（预测器/分类器）

若纯物理信号（h 趋势）做预测性检测：
- **可行路径**：h(t) 的滑动窗口斜率/短期预测（AR/Kalman）→ 预测 h 将低于阈值 → 提前压 μ/冻结/切换。这是经典信号处理，不需 ML。
- **ML 的增量空间**：ML 可学习"h 下降模式 → fade 深度/持续时间"的非线性映射（AR(1) 是一阶近似，真实 GG 有高阶统计）。但这是**增强非必需**。

若用 ML 预测 divergence 本身：
- **前提不成立**：divergence 前兆未证实存在（J_CM(t) 未测）。ML 不能学习不存在的前兆模式。
- **除非**：先做 J_CM(t) 轨迹提取实验，证明确实有可辨识的前兆模式，ML 才有预测对象。

**ML 的有物理意义的位置**：fade 预测器（输入 h(t) 历史 → 输出 fade 概率/深度），不是均衡器、不是 divergence 预测器。这与 R002 发现的"ML 衰落预测喂 DSP 参数无人接"空白对齐。但注意 R002/L-ML7 确认现有 fade 预测全是统计级（ms-分钟），符号级 CSI 预测喂相干 DSP 仍空白——Q-DP3 若做符号级 fade 预测，是全新问题不是迁移。

### 前置 1 小结

**预测性检测物理可行性判定**：

| 检测对象 | 预测性可行？ | 理由 |
|---|---|---|
| **GG fade**（h 下降） | ✅ **可行** | AR(1) ρ≈0.99997 强相关，h 趋势在 fade 前 0.16-0.5ms 可观测，窗口≫响应延迟。信号=h(t) 滑窗斜率 |
| **CMA divergence**（‖w‖ 爆炸） | ⚠️ **证据不足** | J_CM(t)/w(t) 前兆轨迹从未测过；30% 发散极早（前 10%）无足够历史；R4 修正版"前窗口零深衰落"从 57% 降到 32% |

**对 Q-DP3 的约束**：Q-DP3 的检测机制**必须以 fade 为检测对象**（物理可行），以"fade 即将发生→提前触发预防性恢复"为机制。**不能以 divergence 为检测对象**（前兆存疑，且 divergence 由 μ 主导用调 μ 就能防，不需要预测）。这与 D003 原始定义"fade 检测触发的恢复协议"一致，但比 D003 更精确地排除了"检测 divergence"路径。

## 前置 2：与 D003 Q-DP3 的关系

### P2.1 D003 原始定义（decisions.md L92-133，逐字核对）

- **M** = 跨帧恢复机制。feasibility_report L624-625 细化为三种形态："帧间状态保持 / 快速重锁定 / **fade 检测触发的恢复协议**"
- **C** = 双偏振星地（帧间湍流衰落）
- **A** = L-DP5 L766-771 点名"深衰落跨帧挂起恢复 open" + L-DP6 DSP outage（BER>0.44 锁定失败）
- **结构优势**（L625）：被动冻结（sat.1553 L582）→ 主动恢复（**fade 检测** + 跨帧状态管理 + 快速重锁定）
- **Conditional Go 理由**：A0 通过且物理基础最扎实（跨帧+挂起+恢复 open 三点文献支撑）

**关键发现**：D003 原始定义**已经包含"fade 检测"环节**——它在结构优势里明确写了"fade 检测 + 跨帧状态管理 + 快速重锁定"三步完整链。D003 不是只讲恢复动作，它本来就含检测。

### P2.2 R005 方向2 定义（R005-RESULT L20-27）

- **M** = 发散检测 + 响应（预测性检测 → 触发恢复/重训练/切换）
- **C** = 同（双偏振星地 GG）
- **A** = hang-up recovery 算法层无先例（Le Bidan 2023 开放问题）+ ML 预测衰落→触发 ACM 有邻近范式（Galijasevic 2025）

### P2.3 对比（等价/子集/独立）

| 维度 | D003 Q-DP3 | R005 方向2 | 关系 |
|---|---|---|---|
| **M 侧重** | 恢复动作（状态管理+重锁定）**+ fade 检测**（已含） | 检测触发（预测性检测→触发） | R005 是 D003"fade 检测"环节的**具体化**+加了"预测性"约束 |
| **C** | 双偏振星地帧间湍流衰落 | 双偏振星地 GG | **相同** |
| **A** | L-DP5 hang-up open + L-DP6 outage | Le Bidan 2023 hang-up open + Galijasevic 2025 ML 预测邻近 | **同一空白的不同证据**（L-DP5 L766-771 = Le Bidan 2023 同源——L-DP5 的作者 Le Bidan 就是 ICSOS 2023 那篇；Galijasevic 是 ML 预测的邻近范式非 hang-up 本身） |
| **检测对象** | fade（L625"fade 检测"） | "发散检测"（措辞含混，可读作 fade 或 divergence） | R005 措辞需修正为 fade 检测（见前置1 结论） |
| **预测性要求** | 未明确（D003 说"fade 检测触发"但没说必须预测性） | **明确要求预测性**（否则退化 JR-CMA） | R005 是 D003 的**加强约束** |

**判定：子集关系——R005 方向2 ⊂ D003 Q-DP3**。

理由：
1. D003 原始定义已含完整方法链"fade 检测 → 跨帧状态管理 → 快速重锁定"（feasibility L624-625）
2. R005 的"预测性检测 + 触发响应"对应 D003 方法链的**第一环（检测）**，并把"检测"具体化为"预测性检测"
3. R005 没有超出 D003 范围——它没有新增恢复动作设计，只是强调检测必须是预测性
4. A 相同（hang-up recovery open，L-DP5=Le Bidan 2023 同源）
5. R005 的增量贡献是给 D003 的"fade 检测"环节加了"必须预测性"的约束条件

**不是等价**：D003 比 R005 多了"恢复动作设计"（状态管理+重锁定）。**不是独立**：R005 没有独立于 D003 的新场景/新空白。

### P2.4 合并后的精确定义

**Q-DP3（合并 D003 + R005 方向2）**：

- **M** = 预测性 fade 检测驱动的跨帧 DSP 恢复机制。完整方法链：**前兆检测（h(t) 趋势预测 fade）→ 触发 → 恢复动作（压 μ/冻结/快速重锁定/模式切换）→ 性能指标（outage 概率/恢复时间）**
- **C** = 双偏振星地相干 FSO（intradyne 单孔径单链路 GG 湍流 LEO，帧间衰落）
- **A** = L-DP5（Le Bidan 2023）点名"深衰落跨帧挂起恢复 open，requires further work" + L-DP6 DSP outage（BER>0.44）实证 + sat.1553 仅有响应性被动冻结无主动恢复

**关键约束（合并后新增，来自前置1）**：
1. 检测对象 = **fade**（h 下降趋势），**不是 divergence**（前兆存疑）
2. 检测性质 = **预测性**（h 趋势在 fade 谷底前可观测），**不是响应性**（否则退化 JR-CMA 阈值重置）
3. 响应动作 = 轻量（压 μ/冻结/切换），**不含重训练 ML**（太慢，数百 ms ≫ 预测窗口）
4. ML 角色 = fade 预测器（可选增强），**不是均衡器、不是 divergence 预测器**

### 前置 2 小结

- **关系判定**：R005 方向2 是 D003 Q-DP3 的子集（检测环节的具体化+预测性约束）
- **合并 M-C-A**：见 P2.4，关键是"预测性 fade 检测驱动"取代 D003 原文的"fade 检测触发"
- **D003 Conditional Go 是否仍满足**：仍满足，但 Conditional 条件需补一条——"检测对象须为 fade 非 divergence"（前置1 物理可行性约束）。D003 原三条 Conditional（L-DP5 预期性论述/衰落持续时间未量化/dB 量级需 MVE）不变

## 对主控决策的建议

### Q-DP3 要不要进 step 4a 维度 A 正式竞争分解？

**建议：可以进**，但主控需带着以下已厘清的边界进正式评估：

1. **检测对象锁定 fade 非 divergence**——这是前置1 最重要的产出。D003 原文"fade 检测"措辞正确但 R005"发散检测"措辞含混，合并后统一为"fade 检测"。进维度 A 竞争分解时，对手分析要区分"fade 检测"（Q-DP3 做）vs"divergence 检测"（JR-CMA 做，响应性 error 阈值）——两者不同维度。

2. **预测性是硬约束非可选**——进维度 A 时，Q-DP3 的卖点必须建立在"预测性 fade 检测"上。若正式评估发现预测性做不到（如 fade 前兆在实际信道下不可辨识），Q-DP3 退化成响应性 = 退化成 JR-CMA = Kill。

3. **致命风险升级**：D003 原记致命风险是"L-DP5 预期性论述"（湍流未仿真）。前置1 发现**新的致命风险**：预测性 fade 检测的**实证基础薄弱**——现有 R4 数据测的是 divergence 与 fade 的相关性，**从未测过 fade 发生前 h(t) 的可预测性**（前兆轨迹未提取）。进 MVE 前需补一个最小验证：提取真实 GG 序列 fade 事件前的 h(t) 趋势，确认下降趋势可辨识。

### 若进，致命风险是什么

按严重度排序：
1. **fade 前兆可辨识性未实证**（最高）——AR(1) 理论说有趋势，但真实 GG（高阶统计+lognormal/GAR 混合）下 h 下降是否足够平滑可预测，未经数据验证。若 fade 是突变型（h 在 1-2 block 内骤降），预测窗口消失。
2. **预测性 vs JR-CMA 的界线**——reviewer 可能判"h 下降趋势检测"仍是响应性（h 已在下降=fade 已开始）。需论证"趋势预测"vs"阈值检测"的本质区别。
3. **恢复动作的 dB 量级**（D003 原风险③）——预测性检测能比被动冻结多救几个 dB？若 fade 期间压 μ 就够（如 R7 显示冻结无效但压 μ 未测），预测性的增量价值有限。
4. **L-DP5 预期性论述**（D003 原风险①，降级）——前置2 厘清 L-DP5=Le Bidan 2023 同源，open problem 表述可靠，但湍流未显式仿真的事实仍在。
