### R001 调研核心发现（两子 agent 交叉验证）

**子 agent A（方法论）**：
- 场景迁移合法性 = "B 场景下 A 方法哪个假设不成立 + 非平凡适配"
- 饱和领域找增量标准动作 = "换未解决子问题/换边界条件"非"换大方向"
- 成功案例：OFDM 无线→光纤（Shieh 2006，处理色散/PMD）/ MIMO 无线→FSO（Ren 2015，湍流模式串扰重建模）

**子 agent B（FSO 领域）**：
- 成功论文套路："不发明新算法，迁移成熟 DSP + 刻画性能边界"（100Gbps FSO Nat Sci Rep 2022 118引 / LEO-LEO IEEE 2023 44引）
- 近年活跃子方向（除载波/均衡）：model-free AO×DSP 联合 / 数字波束合成 / 低功耗相干接收机 / FEC+自适应调制
- 共同结论：**增量在"算法 × 湍流 × 工程约束"交叉，不在纯算法层**

### S001 方法论诊断核心发现（9 次殊途同归的维度归因）

- **9 次 Kill 的维度归因**：全部在"维度①搜索空间锁死（单偏振单孔径）+ 维度②搜索层穷尽"前提下，只在"维度④搜索方法"反复换切法（标题联想→单假设→逐个 Kill→判地→顶刊溯源）。**在最窄空间里换切法，殊途同归是必然**。杠杆在维度1，不在维度4。
- **单偏振约束溯源（FR-26）**：非独立方向约束，是 Ch3/Ch4 BER 闭合解推导的模型沿袭（`thesis-writing-prep/R002` L571 + `S002-d001` C2 归档"复用低"）。**可放**——代价是 Ch3/Ch4 要不要动，留用户决定。
- **sat.1553 §6 是全书篇幅最大 + open problem 最多的层**（step size μ 无理论最优 / fade 期 CMA 发散 local optimum 未分析 / 理想相位补偿假设偏强）。放双偏振 → §6 偏振解复用层整个回到桌面。
- **standalone"性能边界刻画"已被 sat.1553 占地**（DLR 综述判定"大部分能直接用"，做的就是 R001 套路）。我们做增量不是开新地——但边界刻画作合法迁移适配的论证工具仍有效。
