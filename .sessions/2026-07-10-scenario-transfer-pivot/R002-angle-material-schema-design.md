# [R002] 角度素材精读 Schema 设计（"帮想角度"导向）

> 2026-07-10 | 关联：专题 2026-07-10-scenario-transfer-pivot / D002
> 状态：**设计定稿，待第一轮 GW 验证后进 gw-read.md**（守"先测不改协议"）
> 通用范围：通信大类（信号处理/无线/光/网络），不限 FSO

## 设计目标

现有精读 schema（gw-read 7 子表 + Q# 研究问题清单）是**评判视角**（判每个 Q# 过不过四判据进 Contract）。本 schema 补一层**生成视角**：让精读积累的素材能跨篇聚合，支持"上百篇读完看出什么模式 → 帮想角度 → 样本够多自己提"。

**不取代现有 7 子表**（判 Go/Kill 仍需要 M-C-A + 四判据）。是在每篇笔记**追加一个"角度素材"段**，综合分析阶段**追加跨篇视图**。最小改动，旧笔记可回填。

## 设计原则

1. **半结构化**：定死可控词汇表作 join 键（跨篇聚合用），证据/解释自由写（存论文没明说的推理）。纯自由发挥=现有 44 篇各写各的没法聚合；纯填表=复杂推理塞不进选项。
2. **词表自增**：初版词表覆盖已知模式，精读中遇到新模式就加进词表（像编程枚举类型自增），不强行塞旧框。
3. **通信大类通用**：词表不带 FSO/载波同步专有术语，信号处理/无线/光/网络通用。

## 6 类"帮想角度"来源 + 字段

### ① 失效点（"哪里有缝"）

| 字段 | 类型 | 内容 |
|---|---|---|
| 失效对象 | 词表 | 算法 / 模型 / 参数选择 / 架构 / 假设 / 指标 |
| 失效性质 | **词表（核心join键）** | 假设不成立 / 超出适用范围 / 性能不够 / 维度缺失 / 未被研究 |
| 场景条件 | 自由+数值 | SNR范围/信道条件/动态特性，带具体数值 |
| 失效程度 | 自由 | dB penalty / 定性描述 |
| 论文定位 | 必须 | §/行号/图号 |

**提取自**：simulation/analysis 节 baseline 性能退化段 + conclusion 失效表述。
**怎么帮想角度**：跨篇聚合成"对象×性质"矩阵，**某格多篇命中=强失效信号**。

### ② 方法族占点（"防撞车+找空白"）

| 字段 | 类型 | 内容 |
|---|---|---|
| 方法族 | 词表 | 信道估计 / 均衡 / 载波同步 / 定时同步 / 调制 / 检测 / 编码FEC / 资源调度（通信大类通用层） |
| 改进点 | 自由一句话 | 这篇占了哪个具体改进点 |
| 占点状态 | 词表 | 首创 / 改进前人 / 综述总结 |
| 被继承 | 词表 | cited-by 有follow / 无follow / 未知 |

**提取自**：contribution 声明 + related work 定位 + introduction "we propose X to improve Y"。
**怎么帮想角度**：聚合成地图，**密集区=撞车风险，空白区=机会**。

### ③ open problem（"作者自承的缝"）

| 字段 | 类型 | 内容 |
|---|---|---|
| 原文摘录 | **必须原文** | 英文原话 + 翻译 |
| 归类 | 词表 | 自适应参数 / 复杂度 / 跨层 / 建模 / 其他 |
| 论文定位 | 必须 | §/行号 |
| 是否已解决 | 词表 | 未解决 / 已被X解决（标哪篇） |

**提取自**：conclusion / future work / discussion 的 "remains open" / "further research needed" / "not analyzed here"。
**怎么帮想角度**：**多篇独立 future work 指向同一问题=领域共识缝=最安全角度来源**（单篇可能客套，多篇独立就不是）。

### ④ 失效根因定位（"同类失效开一类方向"）

| 字段 | 类型 | 内容 |
|---|---|---|
| 根因层级 | **词表（join键）** | 信道建模 / 信号建模 / 算法设计 / 实现架构 / 系统级 |
| 根因性质 | **词表（join键）** | 假设错 / 能力不足 |
| 根因解释 | 自由（标来源） | 一句话机制，标"论文直说/我推的" |

**提取自**：analysis 节解释"为什么失效"的段落；论文不直说则推理（标"我推的"）。
**怎么帮想角度**：**同一层级+性质解释多个失效现象=根方向**。如"算法设计层+假设错"覆盖多个现象→从假设入手是根方向。从"逐个现象找方法"升级到"按根因聚类找方法"。

### ⑤ 别人怎么做增量（切法地图原型扩展到全链）

**5a 切法类型**

| 字段 | 类型 | 内容 |
|---|---|---|
| 切法角度 | 词表（复用切法地图6类） | 场景迁移 / 架构替换 / 参数调度 / 工具借用 / 联合建模 / 性能界 |
| 对手 | 词表 | 传统baseline / 内部对照 / 绝对指标 / 理论界 |
| 增量形态 | 词表 | dB / BER量级 / 鲁棒性 / 范围 / 结构性 |

**5b idea 生成路径**（切法地图没做的深一层——"按什么想法提出的"）

| 字段 | 类型 | 内容 |
|---|---|---|
| idea 来源 | **词表（核心join键）** | 实证驱动 / 理论驱动 / 迁移驱动 / 需求驱动 / 组合驱动 |
| 触发线索 | 自由一句话 | 作者怎么从 idea 来源走到具体改法的因果链 |

**提取自**：5a 从 contribution+experiment；5b 从 introduction motivation 叙事（"we observed... therefore we..."）的因果链。
**怎么帮想角度**：**5a 告诉哪些切法在哪些池有效（经验模板），5b 告诉有效 idea 怎么冒出来（可复制生成路径）**。归纳出高成功率路径→主动复制它找角度。

### ⑥ 自己提角度（归纳机制——非字段，是综合分析动作）

不是每篇提取，是①-⑤积累后的聚合操作：
- ①矩阵找"多命中格"=强失效根
- ②地图找"空白区"=未占点
- ③聚合找"反复出现 open problem"=共识缝
- ④分类找"一根因覆盖多现象"=根方向
- ⑤路径找"高成功率生成路径"=复制它
- **交叉组合**：①失效点 × ⑤生成路径 = "用路径X修失效点Y"=新角度

## 产出形态

**每篇笔记追加**："## 角度素材"段，含①-⑤五类字段（⑥ 是综合分析动作不是每篇字段）。

**综合分析追加**（literature_notes.md 综合分析节，现有"研究问题清单"之后）：
- 失效点×性质矩阵（①聚合）
- 方法族占点地图（②聚合）
- open problem 聚合表（③聚合）
- 根因层级×性质定位图（④聚合）
- 切法×idea路径分布（⑤聚合）
- **角度生成记录**（⑥产出：用①-⑤交叉组合生成的候选角度，标生成路径）

## 初版词表（通信大类通用）

**失效性质**：假设不成立 / 超出适用范围 / 性能不够 / 维度缺失 / 未被研究

**失效对象**：算法 / 模型 / 参数选择 / 架构 / 假设 / 指标

**方法族**：信道估计 / 均衡 / 载波同步 / 定时同步 / 调制 / 检测 / 编码FEC / 资源调度

**根因层级×性质**：信道建模/信号建模/算法设计/实现架构/系统级 × 假设错/能力不足

**切法角度**：场景迁移 / 架构替换 / 参数调度 / 工具借用 / 联合建模 / 性能界

**idea 来源**：实证驱动 / 理论驱动 / 迁移驱动 / 需求驱动 / 组合驱动

**对手**：传统baseline / 内部对照 / 绝对指标 / 理论界

**增量形态**：dB / BER量级 / 鲁棒性 / 范围 / 结构性

**open problem 归类**：自适应参数 / 复杂度 / 跨层 / 建模 / 其他

> 所有词表自增：精读中遇到新模式加进对应词表，记录新增日期+来源论文。不强行塞旧框。

## 与现有 schema 的关系

| | 现有 gw-read 7子表+Q#清单 | 本 schema 角度素材 |
|---|---|---|
| 视角 | 评判（判Q#过不过四判据）| 生成（积累可重组素材帮想角度）|
| 用途 | 进 Contract 的假设来源 | 找方向/想角度的素材库 |
| 关系 | 不动，保留 | 追加到同一篇笔记，综合分析追加跨篇视图 |

## 验证计划（守"先测不改协议"）

1. 本设计先在本专题定稿（D002）

3. 验证有效后写进 gw-read.md（模板+词表+综合分析节格式）
4. 旧 44 篇笔记按需回填（不强制全回填，用到哪篇补哪篇）
