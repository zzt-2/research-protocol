## 记录

### A. 文献新鲜度 & 新颖性

**判定：SAFE**

- 6 组检索共 ~150 条结果，去重筛选 ~80 条有效
- **"故障弹性路由 + 跨规模零样本泛化"组合仍为空白**（6 组检索零覆盖）
- TELGEN (Zhou'25 ToN) 无后续工作或应用扩展
- DTAR (Zhou'26, arXiv) 是最接近竞品（GNN+DRL+LEO+故障路由），但缺跨规模泛化
- 2026 年 GNN+LEO 路由新论文均未涉及 Walker delta 族内泛化或零样本部署

### B. 竞品-差异化矩阵

| 竞品 | 故障弹性 | 跨规模泛化 | 组合 | 威胁等级 | 差异化强度 |
|------|---------|-----------|------|---------|-----------|
| TELGEN (ToN'25) | 无 | 有(20x) | 无 | 中 | 泛化倍数弱（10.9x vs 20x） |
| GMR (TVT'24) | 无 | 有(1.375x) | 无 | 低 | 泛化倍数远超我们 |
| DTAR (arXiv'26) | 部分 | 无 | 无 | 低 | 问题空间不同（域间vs全网） |
| GNN-ASSSP | 无 | 无 | 无 | 低 | 无故障+无泛化 |
| DeepLaDu | 部分 | 部分 | 无 | 低 | 无系统故障验证 |
| PathGNN | 部分 | 无 | 无 | 低 | 无系统泛化验证 |

**最强差异化维度**：故障弹性（所有竞品均未系统验证 0-15% 故障率）
**最弱差异化维度**：跨规模泛化（TELGEN 20x 远超 10.9x，gap <3% vs ≤10%）

**TELGEN 对比策略**：不声称"比 TELGEN 更好"，定位为"解决 TELGEN 未覆盖的在线故障弹性场景"。TELGEN 自述三条局限（无无线干扰、无时序信息、集中式设计），LEO 故障场景全部命中。

**DTAR 降级合理性**：问题空间不同（域间 vs 全网逐流），架构完全重叠（GAT 2L/4H/d=64 + PPO），对比结果反映问题设置差异而非方法差异。Related Work 详细讨论 + 对比维度表，学位论文层面足够。

**GMR 降级合理性**：per-path 连续分割 vs per-flow 离散选择粒度本质不同，无代码+超参缺失导致复现风险高，泛化仅 1.375x 无参考价值。Related Work 简要讨论即可。

### C. 实验完备性

**领域标准（6 篇 Top 论文中位数）**：
- Baseline 数量 ≥4 个（范围 4-7）
- ECMP 不够普遍（仅 2/6 使用，Dijkstra/SPF 3/6）
- 统计严谨性极低：0/6 报 CI，0/6 做显著性检验
- 故障实验：0/3 报恢复时间（领域空白）
- 泛化范围：2x（GMR）到 20x（TELGEN）

**Ch3 覆盖度评分：8.0 / 10**

| 维度 | 覆盖 | 说明 |
|------|------|------|
| Baseline 数量 | 3 个 | SP+ECMP+MLP，低于中位数 4，但学位论文可辩护 |
| 统计严谨性 | **显著高于领域** | 3 seed + bootstrap p<0.0001 + Cohen's d（领域 0/6 做了） |
| 消融覆盖 | 4 组 | 故障率/流量/层数/头数，E10/E11 已补 3 seed |
| 故障模式 | 3×4=12 条件 | random/regional/cascading × 4 故障率 |

| 可视化 | 12 张 | 建议论文保留 6-8 张 |

**ECMP 作为唯一路由 baseline**：可辩护。DTAR/GMR 粒度不同不直接对比，MLP 是消融对照非 baseline 替代。学位论文不强求复现竞品。

### F. Ch1 差异化论证

**六维差异经得起追问：是**

| 维度 | Ch1 | Ch3 | 差异 |
|------|-----|-----|------|
| 问题域 | 基础路由（时延优化） | 拥塞/故障弹性路由 | 目标函数不同 |
| 图结构 | 同构图（卫星节点） | 同构图（卫星+链路） | 边特征核心程度不同 |
| 学习范式 | 监督学习 | DRL (PPO) | 根本不同 |
| 泛化维度 | 卫星节点数 | 卫星节点数 | 表面相同 |
| 泛化内容 | 路由策略（方向偏好） | 负载均衡能力 | 本质不同 |
| 故障感知 | 无 | 核心贡献 | 关键差异 |
| PE | Orbital PE（核心） | 无显式 PE | 机制不同 |

**论证句式**（建议 Ch3 开头）："第X章已证明 GNN+PE 可实现跨规模路由策略迁移，但假设无故障的理想网络。本章进一步挑战在线故障弹性场景下的规模泛化问题。"

**风险点**：读者仍可能觉得"都是 GNN+路由+节点数泛化"。建议在论文绪论增加"GNN 泛化机制谱"概念图，展示 PE/等变性/message passing 三种机制的互补关系。
