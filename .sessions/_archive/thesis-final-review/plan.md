# 学位论文终审总规划

> 创建: 2026-05-25 | 更新: 2026-05-25
> 目标: 最后一轮全面审查，确保三章论文无遗漏、无隐患、叙事合规
> 预估: 10 个对话，~42 个子 agent

---

## 全局目标

1. **外部合规**: 每章实验设计、指标、统计方法符合子领域通行标准
2. **竞品无遗漏**: 三章 + 跨领域 size gen 无未引关键竞品
3. **技术正确**: 参数合理、公式无误、指标计算正确、无外行错误
4. **内部一致**: 数据溯源完整，旧数据清除，跨章符号/叙事统一
5. **叙事可防御**: 贡献定位准确，无过强声称，GNN 增量叙事有文献支撑

### 对话 5: Ch1 + Ch2 参数/公式/指标审查

**目标**: 验证 Ch1 和 Ch2 的仿真参数、公式推导、指标计算在领域内是否合理

**子 agent 分工**:

| # | 任务 | 数据来源 | 产出 |
|---|------|---------|------|
| 5a | **Ch2 仿真参数审查**: 星座(396星)、频段(Ku 12GHz)、带宽(250MHz)、sat_capacity(10/15/25)、决策间隔(10s)、仿真时长(7200s)、UE分布 | 读代码 c_gnn_ddqn.py + simulator/environment.py + 对比 literature_notes 中 L018/L029/L004/Lee&Lim 参数 | 参数合理性报告（每项标注：我们的值 vs 文献范围 vs 判定） |
| 5b | **Ch2 公式/指标审查**: reward 函数、blocking rate 定义、Jain 公式、throughput 计算、size gen retention 计算 | 读代码 + paper_materials/06_formulas_symbols.md + 对比 literature_notes | 公式正确性报告 |
| 5c | **Ch1 仿真参数审查**: 星座拓扑、路由指标(stretch/E2E delay)、训练配置、评估协议 | 读 Ch1 代码 + 对比 GRLR/TELGEN literature notes | 参数合理性报告 |
| 5d | **Ch1 公式/指标审查**: stretch 定义、PE 编码、size gen retention 计算 | 读代码 + paper_materials | 公式正确性报告 |
| 5e | **Ch2 训练充分性**: 50 episodes + eps_decay=20 是否够？buffer 200K 是否够？eval 3 seeds 是否够？ | 读训练日志 + 对比 literature 训练配置 | 训练充分性评估 |

**重点检查项**:
- sat_capacity=10 对于 20UE 是否合理？文献中同规模用什么值？
- 10s 决策间隔在 LEO 切换中是否标准？
- reward 权重 (w_r, w_l, w_b, w_h) 是否有文献依据？
- eps_decay=20 在 50 episodes 中是否足够探索？
- blocking rate 是按 UE×step 平均还是按 episode 平均？
- Ch1 stretch 是 hop count 比还是 delay 比？

**输出**: Ch1+Ch2 技术审查报告（每项通过/问题/需修）
