## B. 方法论 Checklist 汇总

### Ch1 方法论合规（基于 GRLR/TELGEN/GDRL-SFCR/MCSR 4 篇分析）

| 检查项 | 领域通行标准 | Ch1 当前 | 合规 | 差距 |
|--------|------------|---------|------|------|
| Seed 数量 | 3-5 (GRLR=5, TELGEN=3) | 3 | 部分合规 | 3 是下限可接受 |
| 统计报告 | 多数仅 mean 或 box plot | mean±std | 超标 | 无 |
| 统计检验 | **4/4 论文零统计检验** | 无 | 合规 | 领域不要求，但 S003 建议加 bootstrap CI |
| 指标体系 | 延迟相关为主指标 | stretch + delay | 合规 | P95 和分位数超标准 |
| Baseline 公平 | TELGEN 显式声明"同超参+同 epoch" | 同架构不同编码器 | 部分合规 | **缺显式公平性声明** |
| 消融实验 | 1-2 组件 (GRLR=1, TELGEN=0) | 4 组 | 超标 | 无 |
| 源-目的多样性 | GRLR=3 对，GDRL-SFCR 随机抽样 | 待确认 | 待验证 | 需确认多对评估 |
| 训练详情 | 全部报告 episode/收敛/硬件 | 待确认 | 待验证 | 需报告总量/收敛判据/时间 |

**Ch1 Top 3 修复**：
1. [中] 加基线公平性显式声明（零成本）
2. [高] 确认源-目的对多样性（至少 10-20 对跨短/中/长路径）
3. [低] 补训练详情（总 episode、收敛判据、挂钟时间）

### Ch3 方法论合规（基于 K2/M01/K1/K3 4 篇分析）

| 检查项 | 领域通行标准 | Ch3 当前 | 合规 | 差距 |
|--------|------------|---------|------|------|
| Seed 数量 | **0 篇报告 seeds，全部单次训练** | 3 seeds | 超标 | 无 |
| 统计报告 | 无 mean±std | mean±std | 超标 | 无 |
| 统计检验 | **0 篇做统计检验** | 无 | 合规 | 无 |
| 主指标 | 能耗+延迟双指标 (K2/K1) | reward (单一) | **部分合规** | **需补延迟和能耗分拆** |
| Baseline 公平 | K2 声明 grid search | 统一 PPO backbone | 合规 | encoder-swap 策略比 K1 更严格 |
| Baseline 数量 | 5-8 个 (K1=8, K2=7) | 6 个 | 合规 | 可加 1 个传统优化 (HEFT/LPGO) |
| 消融实验 | 2-3 组件 | 4 GNN variants | 合规 | 可加 HGAT 组件级消融 |
| DAG 拓扑验证 | K1 做 6 种拓扑条件扫描 | 未明确 | **不合规** | **需补不同 DAG 结构测试** |
| 真实数据集 | K2 用 Alibaba trace | 无 | 差距 | 非必须但加分 |
| 泛化测试 | K1 零样本 5+5→20+10 | 有但 D020 失败 | 需重做 | 需重新设计或改范围 |
| 环境条件扫描 | K2 做 3 种 shadowing | 无 | 差距 | 需补不同信道/负载条件 |

**Ch3 Top 3 修复**：
1. [高] 补多指标报告（延迟+能耗+DAG 完成率，从 reward 分拆，无需重跑）
2. [高] 补 DAG 拓扑变体测试（3-4 种：高并行/串行化/高依赖/混合）
3. [中] 补环境条件扫描（IoTD 数量扫描 / 信道条件 / 任务负载）
