# ISL 调度 DRL（阶段 2）

> 状态：closed | 创建：2026-05-16 | 最后更新：2026-05-16
> Route-aware labeling 实现，N_LCT=4 决策，7 种方法未超越先验 → 归档

## 进展线索

### H016-route-aware-labels.md
ILP 标签验证失败后的修正阶段。Phase A 用 ILP 监督训练达到 F1=0.9998，但 ILP 解本身是代理目标（最大化加权容量），不等于路由吞吐量优化，导致 M1=0.079 远低于 B1 Grid 的 0.174，且切换率 M3=0.044 严重。决策 D029 确认 ILP 失败，D030 决定转向路由感知贪心标签 + N_LCT 从 3 改为 4。提出了贪心局部搜索方案：从 grid 拓扑出发，逐步替换单条 ISL 并用路由吞吐量验证改善。

### H017-phase-a-grid-complete.md
Phase A Grid 标签训练完成。N_LCT=4 配置下，路由感知贪心搜索因 grid 完美 4-正则图导致 N_LCT 阻塞所有单边替换（D031），转而直接用 grid 拓扑作为标签。GNN 训练 F1=1.0，完美复现 grid 拓扑，与 B1(N_LCT=4) 完全匹配（ratio=1.000）。修正了 B1 基线数据：未剪枝 M1=0.174（6 edges/sat）→ 正确 B1(N_LCT=4) M1=0.115（4 edges/sat）。决策 D033 确认 grid 在 24x20 规模已是最优。提出三个待选方向：Phase B 离散 RL 微调、全规模 24x66 验证、归档。

### H018-dynamic-scenario-stuck.md
动态场景（边失效）实验，Phase B 离散 RL 微调失败。实现了边失效机制（p=0.03-0.05）和 edge_dim 7→8 的扩展。Phase B 训练结果与 Phase A 完全相同（M1=0.109, M3=0.164），RL 未学到有意义的策略。根因：AS-IS 偏置太强（98.7% 边选 AS-IS）、失效信号太稀疏（仅 2% 边失效）、credit assignment 困难（全局 reward vs 逐边动作空间）。决策 D037 确认 Phase B 无效，专题在此暂停待方向决策，最终归档。

## 已确认结论

1. **ILP 标签是代理目标，不可用**：ILP 最大化加权容量 ≠ 最大化路由吞吐量，且无时序一致性导致频繁切换
2. **Grid 拓扑在 24x20 规模已是最优**：4-正则图 + N_LCT=4 阻塞所有单边替换，无优化空间
3. **GNN 能完美学习专家拓扑**：F1=1.0，验证了架构和管线正确性
4. **离散 RL（Phase B）在当前设定下无效**：credit assignment 困难 + 信号稀疏 + AS-IS 偏置过强，与先验策略失败模式相同
5. **动态场景下 LCT 自动替补抵消了 RL 的恢复能力**：替代边质量不足（跨轨候选仅 3 个/星），切换惩罚抵消吞吐量恢复
6. **7 种方法均未超越先验/grid 基线**：包括先验策略（active_bias=3）、ILP 监督、grid 标签监督、Phase B RL 等

## 未决项

1. 全规模 24x66 下 grid 是否仍是最优（跨轨候选 3→8 个/星，可能有优化空间）
2. 更激进失效场景（p=0.10-0.20）下启发式替代策略是否可行
3. 换叙事为"鲁棒性分析"是否具备足够论文贡献
