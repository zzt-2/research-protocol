## D001: 导师文字版采用两阶段有限成稿，并纳入方法强度判断

> status: superseded
> date: 2026-08-30
> 取代：无（承接 `2026-07-09-thesis-writing` D074 的无图文字版讨论）
> 被取代：D004
> 依据：用户原话见本专题 `voice.md` 2026-08-30；结构基线见原专题 D074

### 决策

1. 单独建立“学位论文导师文字版结构与方法强度请示”专题，不在原方法生产/论文材料专题中直接生成文字稿。
2. 交付目标从“给老师看目录”扩充为让导师同时判断：整体结构、Ch3/Ch4 方法强度、两章顺序、Ch5 FPGA 深度与章名条件。
3. 新对话采用两阶段门控：
   - Phase A：只读取已有材料，给出事实盘点、两种有限样稿方案、推荐方案、精确二级目录与内容合同，然后强制停机；
   - Phase B：仅在用户明确批准后，生成有限文字稿；不得自动续写完整论文。
4. “每章暂写第一节、其余只列二级标题”作为候选 A；同时必须审查更符合判断目的的候选 B，即第一章写研究内容与章节安排、第二至第五章写各章引言、第六章只列目录。未经用户选择，不进入正文。
5. 非展开节只保留二级标题及统一占位语，不写半成品段落；不放图，不把计划写成结果。

### 理由

- 结构尚未获得导师认可时全篇生成，后续改章序、方法定位或 FPGA 深度会造成大量无效返工。
- 只列目录不足以让导师判断方法是否“够”；第三、第四章至少需要一段可核对的方法身份、对手、证据与主张边界。
- 逐章机械写第一个二级节形式整齐，但第一章背景和第六章总结不是当前最有判断价值的样本，故必须在成稿前比较。

### 排除的替代方案

- 不由当前对话直接生成导师稿。
- 不在没有内容合同的情况下生成六章第一节。
- 不把所有二级节都写出“简版正文”；这会把占位稿伪装成结构已定的半成品。
- 不只向导师展示优点而隐去状态：Ch5 未完成、Ch3/Ch4 未联合验证必须保持事实准确；同时不主动扩展为自我否定式审稿清单。

### 影响范围

- 新增本专题 `topic-index.md`、S001、D001、`voice.md` 与 T001。
- 原专题 D074 继续拥有一级章名和方法事实；本专题只拥有导师稿的读者、结构与生成门控。

## D002: 采用开题旧流程的轻量版本并授权自主执行

> status: superseded
> date: 2026-08-31
> 取代：无（细化 D001 的 Phase B 执行方式）
> 被取代：D003
> 依据：开题时期写作流程考古；用户原话见本专题 `voice.md` 2026-08-31

### 决策

1. 不原样复刻开题时期约 55–65 个 agent、逐节八路审查的重流程，只保留其有效骨架：七字段内容卡、分节写作、生成与审查分离、内容与格式分离。
2. 六个展开单元先形成内容卡并冻结，再由多个子 agent 分区起草；主线程只负责合同控制、集成和最终判断。
3. 初稿接受三路独立审查：事实与数字、导师可读性与外部表达、跨章一致性与内容合同。只修复有证据支持的问题。
4. 用户授权规划完成后自主推进 Phase B，无需在每个中间步骤等待确认。
5. 过程日志只保留四个检查点：授权与方案、内容卡冻结、初稿生成、终审完成；最终另登记一条验证记录。

### 理由

- 历史流程证明“一次生成全文”会放大事实、结构和表达问题，内容卡与独立审查仍有必要。
- 当前交付物只有 4–6 页，完整复刻重流程的成本远高于收益；轻量版本足以覆盖主要风险。
- 用户将暂时离开并明确要求自主推进，同时要求通过精简日志抵抗上下文压缩。

### 排除的替代方案

- 不复刻完整开题重流程；其规模面向完整开题报告，当前不相称。
- 不直接由主线程一次生成并自审；这会重现旧流程已经暴露的失败模式。
- 不把每个 agent 的过程输出写入 session note；压缩后重读成本过高。

### 影响范围

- 新增 S002，并进入导师讨论稿 Phase B。
- 最终只生成 D001 约定的有限讨论稿和一条验证记录，不扩展为正式论文正文。

## D003: 轻量旧流程未完成范文提取，导师稿写法验收失败

> status: active
> date: 2026-08-31
> 取代：D002
> 被取代：无
> 依据：验证: V002 + 用户原话: voice.md 2026-08-31 + 对照: 夏兆宇学位论文目录与技术章引言

### 决策

D002 的“内容卡—分区起草—三路审查”不足以控制章节体例和文字风格，现稿停止作为可交导师版本，退回 `DIAGNOSE`；在完成夏兆宇及同门论文的逐节写法提取并获得新写法合同批准前，不修改对外稿。

### 核心失败机制

旧流程被压缩时只保留了事实内容卡和通用审查，没有保留“范文原文提取—节级功能模板—标题体例对照”这一前置层。结果是正文事实与边界可以通过检查，但二级标题和章首段落仍由主线程自行归纳，形式正确不等于写法合适。

### 否决了什么

- 否决未经范文抽样便自行命名二级标题，尤其将技术章首节统一写成“本章引言”。
- 否决只凭事实矩阵生成章首段落，再用通用可读性审查替代目标范文对照。
- 否决把 V001 的格式、事实与内部一致性 PASS 等同于用户可接受、可交导师。

### 可复用部分

- Ch3/Ch4 的事实矩阵、数字口径和适用边界继续有效。
- “有限样稿 + 其余标题占位”的低返工交付形态仍可讨论。
- 独立事实审查与外部表达审查仍保留，但必须增加目标范文一致性审查。

### 具体数据

- 当前稿 2.1、3.1、4.1、5.1 均命名为“本章引言”。
- 夏兆宇论文技术章 2.1、3.1、4.1 均命名为“引言”。
- 用户验收原话见 `voice.md` 2026-08-31；V002 结论为 FAIL。

### 影响范围

- `论文整体思路与章节内容说明.md` 保留为失败样稿，暂不继续补写。
- 下一阶段先输出范文证据、标题诊断和 2–3 套重写合同，等待用户批准后再改稿。

### 来源

- S002 / V002
- 用户纠正 2026-08-31

## D004: 扩大为证据支持范围内的全质量章节稿

> status: active
> date: 2026-08-31
> 取代：D001 的有限样稿与大量占位合同
> 被取代：无
> 依据：用户原话: voice.md 2026-08-31 + 调研: S003/CP007 + 失败验证: V002

### 决策

凡现有材料能够支撑的二级节均按正式学位论文正文质量完整撰写，不再以一段内容说明或统一占位作为主要交付；逐章分文件生产并审查后，再组装为导师稿。

### 理由

- 用户明确要求“能写的先都写了，质量按完整版来”。
- 逐节范文调研表明，正式方法章依赖完整的理论—方法—实验—结果闭环，仅写章首引言不足以让导师判断章节是否成立。
- 分章生产可在扩大内容范围的同时保持事实门、范文门和独立审查，不重现一次生成全文的历史失败。

### 排除的替代方案

- 不再采用“只写 1.3 与各章引言，其余全部占位”的有限稿。
- 不采用“每个二级节只写 150～300 字说明”的折中稿；用户要求按完整版质量。
- 不把证据不足的 Ch5 结果、联合链性能或引用缺口凭常识补齐；“能写”以现有证据链为边界。

### 影响范围

- 当前专题允许生成完整章节正文，取代原“不得生成整章或整篇正文”边界。
- 新增逐节写作合同和六个章节稿；最终仍交付同一路径的导师文字稿。
- 不恢复仿真、网络检索、新方法或硬件实现；这些仍需另行授权和对应流程。

- 用户纠正与授权 2026-08-31

## D005: 采用图表—公式双层合同与非均匀章节节奏

> status: active
> date: 2026-08-31
> 取代：无（细化 D004 的完整章节生产方式）
> 被取代：无
> 依据：调研: S004 + 对照: 夏兆宇/董凡/夏煜学位论文 + 用户原话: voice.md 2026-08-31

### 决策

第一、第二和第五章采用“正文轻占位＋独立图表公式合同”；篇幅、公式和图表按论证职责非均匀分配。开题资产经当前主线复核后分级复用。第五章在形成真实级联前采用工作标题“接收端关键算法的 FPGA 设计与实现”。

### 理由

- 后补图容易造成正文与图脱节，语义合同必须先于绘制。
- 中间日志包含旧模型，不能替代公式来源、符号、量纲和跨章一致性审查。
- 同类学位论文各节承担的论证重量不同，平均篇幅会削弱承重部分。
- 当前没有真实级联，使用“信号处理链”作为完成态章名会过度声称。

### 排除的替代方案

- 不只在正文写“图待补”；该做法缺少图的职责和完成门。
- 不立即把开题图原样搬入论文；旧图的算法对象已变化。
- 不为第一章增加公式，不在第五章用大量重复算法公式制造完整感。
- 不在没有级联证据时使用更强的“接收端信号处理链”工作标题。

### 影响范围

- 新增图表与公式合同。
- 更新 Ch1、Ch2、Ch5 的写作、图表占位、公式和审查方式。
- 正式一级章名仍需在导师判断或真实实现状态确定后最终冻结。

- 用户确认 2026-08-31
