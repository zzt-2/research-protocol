## 发现一：三个局部问题的六问比较

### 问题 A：译码失败码字的门控局部救援（failure-gated bounded rescue）

对应入口"失败后的补救"。特定状态 = 20 次迭代 NOMS 后校验子非零的失败码字；局部处理 = 用译码器内部信号判定失败结构，对失败码字做一次有界第二次译码尝试。

| 六问 | 回答 |
|---|---|
| 1. 传统 baseline | B0 = Sionna `LDPC5GDecoder` NOMS(0.75,0) 20 迭代 fresh（现行标准链，T077 实测 FER=132/512≈0.2578）；直接常规替代 = 同预算纯延长迭代（20→40）；文献邻居 = Baldi 2016 IA 失败门控 MRB（短码、10ms 约束下 >1dB vs SPA）、He 2021 syndrome≤10 门控 TS 翻转（error floor 降 1/2–1/10）、Zhao 2023 reliability-guided rescue |
| 2. 可信条件与不足 | M=NOMS 失败终止；C=T077 冻结格（中湍流 α=4.0/β=1.9、15dB、DP-16APSK、exact-APP、无 CRC）；A=失败终止把"接近正确码字的停滞失败"与"混乱失败"一并丢弃，不利用译码内部已算出的迭代轨迹/校验状态做第二次尝试。**A 的成立性是诊断问题**（失败中停滞/小 syndrome 子类占比、延长迭代可救比例、oracle headroom 均未测），诚实标注：当前为 [论证]+待实证 |
| 3. 改变哪一步、为何可能有用 | 在"译码输出"与"宣告失败"之间插入门控救援级：仅失败码字触发（触发率=FER≈25.8%，平均成本可控，Baldi 结构先例）；救援动作 = 定向 LLR 扰动/配置切换后继续译码。机制：迭代译码失败几何异质（Baldi 互补失败几何、He TS 稳定性）；确定性 flooding 轨迹停滞在同一吸引盆时，延长无效而扰动初始条件可能跳出 |
| 4. 接收端可见性 | 全部合法：迭代消息、每迭代校验子权重、最终 LLR、码字估计。触发=syndrome≠0（无真值）；接受=syndrome=0。风险：无 CRC 时救援接受可能落到另一有效码字（undetected error）→ 必须分账 rescued-to-correct vs rescued-to-wrong |
| 5. 历史是否试过 | C5-2 六篇精读（L03–L06）= 本问题族 Step 3 已完成、Step 3.5 闭包（literature_notes_apsk_soft_receiver.md:100–114），verdict"条件未过：当前 adapter 无接口"——接口缺口本轮可低成本补（见发现三）。负结果边界：C1（coded-decoder-feedback D027）否定的是离散滑周 defect→损伤→oracle 纠正链（S2 damage=0.069<0.10、recoverability=0.040 CI 跨零），动作轴不同；C5-0 否定全局标量 LLR 缩放（动作不同）；C5-1 否定协方差软解调度量（对象不同）；P08 NOMS 配置为正结果（同章可共存）。无历史结果否定"失败码字的停滞门控救援" |
| 6. 最大未知与最小实验 | 最大未知 = 本合同失败码字结构。最小实验 = 512 评估帧 B0 轨迹记录 + 延长迭代对照 + oracle 置零 headroom 诊断，半天有界完成；视结果加 1–2 个救援臂（发现三合同） |

## 发现三：最小实验合同（预注册，执行前冻结）

完整合同：`projects/simulation/explore/decode-failure-rescue/contract.yaml`；模块 README 同目录。要点：

- **底座复用**：`ch5-apsk-llr-calibration/single_cell.py` 冻结链重生成物理帧（种子确定性），exact-APP LLR 逐帧缓存；所有臂共享同一 LLR 字节（TL-13 最强形式）。T077 raw 不入库（已核实 repo 内无逐帧 raw），重生成后以 T077 日志的 B0 BER/FER（0.0492935/132/512）为一致性锚点。
- **仪器化译码器**：优先探测 Sionna 2.0.1 `LDPC5GDecoder` 的 return_state/单迭代步进能力；不支持则自实现 flooding NOMS 镜像（复用 Sionna `cn_update_offset_minsum` 与 encoder 交织表，逐样本与 Sionna num_iter=20 输出比对）。正确性门：B0 终判 ≥64 码字 bit 级一致 + 热续跑 ≡ fresh 40 迭代等价抽样验证。
- **臂**（第二阶段仅对 B0 失败帧触发，+20 迭代）：R1 纯延长（必设常规对照）；R2 定向擦除（未满足校验相连变量中 |LLR| 最小 k 个置 0，k∈{8,16,32} 仅开发集选）；R3 配置切换 (0.875,0.1)（P08 开发冻结配方）；O1 真值置零（仅 headroom 诊断，非部署、非上界）。门控变体（如"仅停滞类触发"）由逐帧 raw 事后切窗得出，不重跑。
- **指标**：主 = 配对 FER 差（臂 vs R1，eval 512 帧，帧级 bootstrap 95% CI，PCG64 定种子）；次 = BER、vs B0、分类救援率、rescued-to-correct/wrong、触发率、平均/P95 额外迭代。诊断输出：失败分类（收敛错码字/停滞/振荡/下降中）、最终 syndrome 权重分布、失败码字硬判错误数分布。
- **开发/确认分离**：dev = seeds 5000–5063（64 帧，全新种子防污染）选 k 与门控；eval = seeds 4000–4511（512 帧，同 T077 评估集保可比）一次性冻结臂集运行。
- **预算与停机**：帧生成 ≤584 帧；单轮设计—运行—诊断 + 至多一轮有界修复；门控/臂不追加第三轮。正确性修不动 → 如实记录停。
- **解释边界**：R1≈R2≈R3 → "该格延长吸收可救性"，收窄记录非全族 Kill；R2/R3>R1 CI 下界>0 → 局部正信号，升级用户/导师；O1 也救不动 → 该格失败偏混乱，救援族在此格 unlikely，记录。全部结论限本格本合同。

## 结论
