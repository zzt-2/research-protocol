# S003: Ch3→Ch4 衔接实验

> 2026-05-31 | 实验 | 完成

## 目标

量化信道估计误差（NMSE）对载波同步 BER 的影响，确定"安全阈值"，论证 Ch4 使用 oracle h 假设的合理性。

## 记录

### 实验设计

- 使用 `common.py` 的共享信道框架
- 注入 noisy h 到 MMSE 均衡：`rx * √h_hat / (h_hat + 1/γ̄)`
- h 噪声模型：`h_hat = h_true + √(NMSE) · randn`，截断至 ≥0.01
- 测试 3 方法 × 3 湍流 × 5 NMSE（oracle/-5/-10/-15/-20 dB）× 10 种子
- 统一用 resolve_qpsk 评估

### 实验结果

| 湍流 | 方法 | oracle BER | NMSE=-5 退化 | NMSE=-10 退化 | NMSE=-15 退化 | NMSE=-20 退化 |
|------|------|-----------|-------------|--------------|--------------|--------------|
| weak | FOE+VV | 3.20e-4 | +0.3 dB | +0.4 dB | +0.4 dB | +0.5 dB |
| weak | FOE+DPLL | 2.17e-3 | -0.2 dB | -0.3 dB | -0.5 dB | -0.2 dB |
| weak | Fixed | 3.20e-4 | +0.3 dB | +0.3 dB | +0.4 dB | +0.5 dB |
| mod | FOE+VV | 1.16e-3 | +0.2 dB | +0.1 dB | +0.1 dB | +0.1 dB |
| mod | FOE+DPLL | 3.21e-3 | +0.0 dB | +0.1 dB | +0.1 dB | -0.0 dB |
| mod | Fixed | 1.18e-3 | +0.1 dB | +0.1 dB | +0.1 dB | -0.0 dB |
| strong | FOE+VV | 9.22e-2 | +0.7 dB | +1.2 dB | -1.6 dB | -0.6 dB |
| strong | FOE+DPLL | 1.88e-2 | -0.0 dB | -0.0 dB | +0.0 dB | +0.0 dB |
| strong | Fixed | 8.72e-2 | +1.7 dB | +1.8 dB | -0.8 dB | -2.6 dB |

### 关键发现

1. **弱/中湍流：完全鲁棒**。所有 NMSE 水平退化 < 0.5 dB，几乎无影响
2. **强湍流 DPLL：完美鲁棒**。所有 NMSE 水平退化 = 0.0 dB
3. **强湍流 VV/Fixed**：高方差（BER~10%，仅 10 种子），退化值在 ±2 dB 波动，属于统计噪声而非系统性退化
4. **安全阈值**：所有方法在 NMSE ≥ -5 dB 均安全（< 1 dB 退化）

### 附带发现

- **DPLL 在强湍流远优于 VV**：FOE+DPLL (1.88%) vs FOE+VV (9.22%)，5 倍差距
- **VV 在强湍流反而有害**：Fixed (FOE+DPLL+VV, 8.72%) 远差于 FOE+DPLL 单独 (1.88%)
- 这与 S002 的 VV 公式修正结论一致：修正后 VV 在弱/中湍流有效，强湍流中退化

### 对 Ch3→Ch4 叙事衔接的影响

**结论：Ch4 使用 oracle h 假设完全合理**。即使估计器性能很差（NMSE=-5 dB，32% 相对误差），载波同步 BER 几乎不受影响。这论证了：
- Ch3（信道估计）和 Ch4（载波同步）可以独立研究
- Ch4 的 oracle h 假设有实验支撑
- 级联系统的瓶颈不在信道估计精度

## 后续

- NMSE=-5 dB 已是最差测试点，但实际工程中估计器通常 > -10 dB。如需更极端测试可加 NMSE=0 dB
