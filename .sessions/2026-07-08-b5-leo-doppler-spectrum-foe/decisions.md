### 决策

**开 B5-Q1 专题，阶段 0 六项规约设计完成，首验证范围优势够格路径。**

1. **阶段 0.1 = 够格路径验证**（最高优先）：B5-Q1 不是 dB 增量是范围优势（±4.5GHz vs 传统 ±312.5MHz，15× 范围扩展），D005 "赢 baseline 几 dB" 标尺下不够格（本体无"vs baseline 改善 X dB"对比只给绝对残频/范围指标，`_cut-b4b5-verify.md:64-66`）。阶段 0.1 验证范围优势在 D005 会议门槛下能不能当 Go 判据——对标 BUPT Arria 10 FPGA demo 会议模板（绝对指标够发会议）+ 饱和池警示
2. **阶段 0.2 = dB/范围溯源核查**：±4.5GHz 出处（B5 锚 optcom.2024.130981，abstract/intro/experiment/conclusion 四处一致）+ 残频指标全读原文数值（σ<140MHz / <5MHz / ±312.5MHz 精估范围 / BER 1e-3 接收灵敏度 −48 dBm）
3. **不直接当 Go 判据**：范围优势必须阶段 0.1 验证后才能定够格路径，不能因为"15× 范围扩展听起来很厉害"直接当 Go
4. **阶段 0 不写代码**：守 profile 第 9 次"急于推进"防线 + INVARIANT 6，六项规约全做完才进 sandbox

### 理由

1. **B5-Q1 比 B2-Q2 更"干净"**（主控对话核查结论）：无 step4a 实测反证 + 锚论文已发期刊（Optics Communications）+ B5 本身就是星地场景（A1 归属不在"搬星地"）+ 不撞 D006 + LEO Doppler 跟星地天然对口。但有自己风险（范围优势够格路径 + 饱和池大池 + 代码新增需求）
2. **首验证够格路径是防线不是拖延**：B5-Q1 不是 dB 增量是事实（`_cut-b4b5-verify.md:64-66` 明确"本体无 vs baseline 改善 X dB 对比"），D005 "赢 baseline 几 dB" 标尺下不够格。会议门槛放宽允许范围维度够格，但必须验证够格路径具体怎么走（BUPT Arria 10 FPGA demo 会议模板 / 补 dB 对比 / 鲁棒性维度），不能默认够格
3. **代码基建新增需求是成本但可控**：short_time_spectrum_foe 需新写（common/ 没有 B5 的"正负功率谱面积比"机制），但 fft_foe_m0_omega 可作起点骨架（分块 FFT 部分复用），信道侧完全复用（TL-13），参数族参考 B7Params 扩 B5Params。新增成本低于"全栈从零"
4. **LEO Doppler 主题有跨候选价值**：B5（频域功率比）/ B7（定时域 TED）/ B4（双环）是 LEO Doppler 大动态的三种正交解法，B5 结果（无论成败）对 B7 方向决策有交叉验证价值，且可作大论文跨章节统一叙事

### 排除的替代方案

- **不开 B5-Q1，换 B3-Q2/D006 边界模式**：否决。用户选 B5-Q1，遵守用户决策权。B3-Q2 4 支路迁移风险 + A1 归属未解，D006 边界模式涉及环路 TF 联合建模撞 D006，都不比 B5-Q1 风险低
- **不开新候选，推现有**：否决。用户明确"再开另一个方向"（第二次），且现有 3 候选各有阻塞（NDA-ML 卡 D-008~D-009 方法方向待用户拍板 / B7 阶段 0.2-0.6 H002 已交接 / B2 阶段 0.1-0.6 H001 已交接），并行第四个候选不阻塞
- **直接当 Go 跑 MVE**：否决。范围优势够格路径未验证（不是 dB 增量）+ 饱和池警示双红旗，直接跑 = 跳阶段 0 重蹈 NDA-ML 覆辙
- **补 dB 对比强够格**：pending 阶段 0.1 验证结果。如果范围优势能走 BUPT Arria 10 FPGA demo 会议模板够格（绝对指标路径），就不需要补 dB；如果不行再考虑补 dB 对比（但 B5 本体无 dB 对比，强补可能不真实）

### 影响范围

- **阶段 0.1 够格路径验证**：核心动作=验证范围优势在 D005 会议门槛下的够格路径。输出 `explore/b5-leo-doppler-spectrum-foe/_qualification_path_validation.md`
- **阶段 0.2 dB/范围溯源核查**：±4.5GHz + 残频指标全读原文数值
- **跟 B7/B4 专题的交叉**：B5 LEO Doppler 跟 B7 Gardner TED（LEO Doppler rate 适配）/ B4 双反馈环（±920MHz）机制正交。B5 够格路径验证结果对 B7 方向决策有交叉价值
- **债务**：short_time_spectrum_foe 需新写（阶段 0.6 文件组织时定接口，sandbox/MVE 时实现）

### 教训

1. **S031 排序的"无 A0/D 详评"是相对的**：Explore agent 发现 B5-Q1 早在 S003 全文核验阶段就做过详评（`_B5-short-time-spectrum-cfo-increment.md:100-167` 全文增量核验段），S031 第二档 #6 是引用该详评的浓缩。**但 S003 只判了 D006/D005/范围三维，没判 A1 归属和代码复用**——这次详查的增量价值在 A1 + 复用两块。**教训：开新候选前要先查 gw-read 阶段的结构化笔记，可能已有详评**
2. **"不是 dB 增量"不等于"不够格"**：B5-Q1 靠范围维度够格（会议门槛放宽允许），BUPT Arria 10 FPGA demo 是会议级模板（绝对指标够发会议）。**会议够格路径不只 dB 一条**，范围/绝对指标/同族 dB 都算够格（D005 会议门槛放宽）
3. **饱和池警示在 B5 验证方式不同**：B5 饱和池 §A 跟 B4 共锚 Paillier 43 篇大池，但 B5 走范围维度（不是 dB），可能绕开"饱和池是 dB 最难出区"的警示。**饱和池警示要看走什么维度够格**，不是一刀切
