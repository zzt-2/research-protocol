### 决策

**开 B5-Q1 专题，阶段 0 六项规约设计完成，首验证范围优势够格路径。**

1. **阶段 0.1 = 够格路径验证**（最高优先）：B5-Q1 不是 dB 增量是范围优势（±4.5GHz vs 传统 ±312.5MHz，15× 范围扩展），D005 "赢 baseline 几 dB" 标尺下不够格（本体无"vs baseline 改善 X dB"对比只给绝对残频/范围指标，`_cut-b4b5-verify.md:64-66`）。阶段 0.1 验证范围优势在 D005 会议门槛下能不能当 Go 判据——对标 BUPT Arria 10 FPGA demo 会议模板（绝对指标够发会议）+ 饱和池警示

3. **不直接当 Go 判据**：范围优势必须阶段 0.1 验证后才能定够格路径，不能因为"15× 范围扩展听起来很厉害"直接当 Go
4. **阶段 0 不写代码**：守 profile 第 9 次"急于推进"防线 + INVARIANT 6，六项规约全做完才进 sandbox

### 理由

1. **B5-Q1 比 B2-Q2 更"干净"**（主控对话核查结论）：无 step4a 实测反证 + 锚论文已发期刊（Optics Communications）+ B5 本身就是星地场景（A1 归属不在"搬星地"）+ 不撞 D006 + LEO Doppler 跟星地天然对口。但有自己风险（范围优势够格路径 + 饱和池大池 + 代码新增需求）
2. **首验证够格路径是防线不是拖延**：B5-Q1 不是 dB 增量是事实（`_cut-b4b5-verify.md:64-66` 明确"本体无 vs baseline 改善 X dB 对比"），D005 "赢 baseline 几 dB" 标尺下不够格。会议门槛放宽允许范围维度够格，但必须验证够格路径具体怎么走（BUPT Arria 10 FPGA demo 会议模板 / 补 dB 对比 / 鲁棒性维度），不能默认够格
3. **代码基建新增需求是成本但可控**：short_time_spectrum_foe 需新写（common/ 没有 B5 的"正负功率谱面积比"机制），但 fft_foe_m0_omega 可作起点骨架（分块 FFT 部分复用），信道侧完全复用（TL-13），参数族参考 B7Params 扩 B5Params。新增成本低于"全栈从零"
4. **LEO Doppler 主题有跨候选价值**：B5（频域功率比）/ B7（定时域 TED）/ B4（双环）是 LEO Doppler 大动态的三种正交解法，B5 结果（无论成败）对 B7 方向决策有交叉验证价值，且可作大论文跨章节统一叙事

### 决策

**1. B5 原定位"范围优势够格"崩塌（实验 B Kill 级证据）**

修正版审计 3 决定性问题实测结果：
- **实验 A（BER 根因）**：非评估 bug。AWGN 13dB BER=0（评估链路正确）。根因是 B5 估计噪声 σ=6.8MHz 显著大于 fft_foe 的 0.05MHz，B5 粗估残频在 BER 路径致退化（f_true=0 weak 湍流下 fft_foe BER=0.0083 vs B5 BER=0.2622）
- **实验 B（公平范围对照，Kill 级）**：fft_foe 配星历预补后 **19/19 收敛 = B5 19/19 持平**，残留范围优势 **1.00×（归零）**。且 fft_foe 配星历后残频 976kHz **比 B5 的 10.27MHz 好 10 倍**。B5 的"14.4× 范围优势"本质是**星历预补的功劳**，给任何 FOE 配星历都能覆盖 ±4.5GHz
- **实验 C（同族 PSA 对照）**：B5 vs Vieira 2023 PSA 同族确认（α 同量级 6.0e8 vs 6.1e8），但 B5 σ=9.7MHz vs Vieira σ=28.7MHz，**rel_diff=66%（V3 同族警报未触发，有真增量）**。消融：同 n_fft=1024 下 B5 σ=14.1MHz < Vieira σ=28.7MHz，增量来自**线性归一化比 vs 对数比在小残频处更鲁棒**

**2. "星历预补+FOE"架构不能水（用户直觉确认）**

- Paillier JLT 2020 content.md L17/L105 已明确发表"ephemeris coarse FE 预补 + residual tracking"框架
- sat.1553 综述 L464-466 已列"precompensated at Tx + blind methods"
- 实验自证伪：fft_foe+星历残频 976kHz 比 B5+星历 10.27MHz 还好 10× → B5 在这个架构里不必要

**3. 选路 2：B5 同族精度改进重定位（不 Kill）**

B5 原定位（范围优势）已死，但**不 Kill**，转路 2 重定位。理由：
- 唯一活路：实验 C 证明 B5 线性 Rp-n 比同族 Vieira 对数比残频 σ 好 66%
- **关键约束（改变决策权重）**：用户原话"别的也一般般？有方向就可以试试，方向没那么多"——候选池整体偏弱（NDA-ML 卡 D-008/D-009 / B7 待 MVE / B2 阶段 1.5 重设计），方向稀缺。B5 即使是增量改进也值得试，**不能拿"增量不够新"当 Kill 理由**
- 路 2 需重走 Step 4a：新 M-C-A（M=同族 PSA 精度瓶颈 / C=对数比数值噪声 / A=线性归一化比）

### 理由

1. **范围优势崩塌是硬证据不可推翻**：实验 B 三方对照（fft_foe blind 1/19 → fft_foe+星历 19/19 = B5 19/19）+ fft_foe 精度反超 10×。这不是"测试条件偏差"是"架构本质"——星历预补把任何 FOE 的捕获范围扩展到全量程
2. **同族精度增量是唯一真贡献**：实验 C 证明 B5 vs Vieira rel_diff=66%，非持平（不像 NDA-ML vs VV）。但增量归因需拆清（线性 vs 对数算子贡献多少，1024×16 块结构降噪贡献多少）
3. **不 Kill 因候选池约束**：用户明确"方向没那么多"。在这个约束下，Kill 一个有 66% 同族增量的候选不明智——应重定位试，而非砍掉
