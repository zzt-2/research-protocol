# [R002] 3500 词内容架构与公式方案

> 2026-07-14 | 关联：2026-07-14-ccisp-content-expansion / D001

## 调研问题

在正文至少 3,500 词、不运行新仿真、不修改数据/JSON/算法的约束下，现稿能否通过真实内容和必要公式补足？应采用什么章节预算、公式集合与停止条件？

## 发现

### 1. 目标差额和毛增量

- 当前正文：2,219 词。
- 用户硬下限：3,500 词。
- 最低净增量：1,281 词。
- 现稿含需删除或替换的错误/重复文字；按推荐方案估算，需删除或替换约 985 词，再新增约 2,336 词，才能得到约 3,570 词正文。
- 3,500 词高于三篇短会 benchmark 的 2,247、2,650、3,025 词，因此它是用户指定的篇幅约束，不是 benchmark 自然推出的目标。必须由多个真实审稿职责共同支撑，不能靠单一 switching 方法的重复解释。

### 2. 公式静态审计结论

公式可以增加，但职责应限定为“把现有代码中的系统、信息流、公平比较和结果指标显式化”。

#### 必须替换的公式（修错，不计净新增）

1. 接收模型：代码中 Gamma–Gamma 变量是强度增益，信号乘 `sqrt(h)`；现稿写成 `h*s`，需修正，并显式区分 100-symbol channel block 与 256-sample DSP/switching window。
2. DA estimator：实现是多导频相位—时间最小二乘回归，同时估计 CPE/CFO；现稿单导频相位式不成立。

#### 公式职责候选（按合同总账合并）

1. 盲强度代理量 `h_hat_dsp`：说明 switching 实际可见的信息；并入现有 switching 公式的替换组，不计净新增。
2. CV 统计量及 SNR-dependent 经验门限：形式化第一层门控；净新增 1 组。
3. effective-SNR 与两层分段选择规则：忠实呈现 `CV gate + blind-h + fixed 13 dB`；并入现有 switching 公式的替换组，不计净新增。
4. pilot 开销与 DA/NDA total-energy SNR 坐标：解释 1.249 dB 的公平比较映射；净新增 1 组。
5. Fig.3 BER ratio/reduction 指标：明确它是同 SNR 下 `10log10(Pb,NDA/Pb,sw)`，不是 SNR gain；净新增 1 组。

上述职责预计支撑约 250–360 英文词，公式数量以“公式数量总账”为唯一口径：净新增固定为 3 组；Gamma–Gamma 乘积分布结构仅可作为第 9 组。完整相位过程已属于现有相位公式的合并替换，观测 crossover 根不加入本合同。

#### 明确禁止的公式

- 完整 Gamma–Gamma PDF 及 `alpha/beta -> Rytov variance` 闭式映射：当前参数来源和代码路径不闭合。
- switching SNR gain/equal-BER 公式：现有 switching 数据只有同 SNR BER ratio；约 1.9 dB 是 NDA-vs-DA。
- 理论最优 13 dB 阈值推导：13 dB 只是固定经验实现值。
- 复杂度大 O、CRLB、MSE 下界、新 ML 推导、26/29 计数公式：无现有证据职责，属于 filler。
- 把 100-symbol channel block 和 256-sample DSP window 合并为一个 block 公式。

### 3. 三种内容架构

#### 方案 A：平衡式六节闭环（推荐）

| 节 | 当前词数 | 删除/替换 | 新增 | 目标词数 | 主要职责 |
|---|---:|---:|---:|---:|---|
| Abstract | 133 | 133 | 170 | 170 | 重写为问题—真实机制—受限结果，分离 switching 与 DA/NDA 贡献 |
| Introduction | 420 | 95 | 315 | 640 | 固定选择的具体不足、窄 related-work 定位、三条真实贡献 |
| System Model | 341 | 85 | 424 | 680 | 信道/DSP 块、信号损伤、pilot/data 与 SNR/BER 契约 |
| Method | 715 | 330 | 700 | 1,085 | DA/NDA 修正式、CV 门控、blind-h、13 dB、信息访问与诚实代价 |
| Results | 513 | 245 | 582 | 850 | 实验/baseline/metric 契约、代表锚点和受证据约束的解释 |
| Conclusion | 97 | 97 | 145 | 145 | 从后果归纳，不第三次复读 headline |
| **合计** | **2,219** | **985** | **2,336** | **3,570** | 净增 1,351 |

建议小节：

- System Model：`Signal and impairment model`；`Block and receiver timing contract`。
- Method：`DA/NDA estimators`；`Switching information flow`；`Decision variables and access assumptions`。
- Results：`Simulation and metric contract`；`DA/NDA behavior`；`Switching evaluation`。

最终控制为 8–9 个 displayed equation groups；System Model + Method + Results 占正文约 73%。

#### 方案 B：方法与可复现性中心（备选）

- 目标 3,520 词：Abstract 160、Introduction 580、System Model 700、Method 1,170、Results 770、Conclusion 140。
- 优点：对 26/29 等结果阻塞依赖较弱，主要依赖代码和 JSON meta。
- 风险：Method 占 33.2%，可能把本质简单的选择器解释过度；最终公式上限仍为 9 个。
- 触发条件：P0 完成后结果证据仍有较多 BLOCKED，但方法信息流证据完整。方案 B 不自动执行，必须另交完整预算并重新取得用户批准。

#### 方案 C：结果证据中心（否决）

- 可做到约 3,650 词，但需 Results 达 1,110 词。
- 当前 26/29、Oracle、BER 分母和 switching gain 均未闭合，容易退化为逐点数字堆砌或为错误 headline 补故事。
- 在不新增实验的限制下证据风险最高，不进入合同。

#### 修改批次

1. **Batch A：事实链与公式前置门**
   - 校正 `sqrt(h)` 接收模型、多导频 DA-LS、100/256 block 边界、实际两层 switching、Fig.3 指标、1.9 dB 归属、crossover/13 dB 区分。
   - 统一 BER 分母、Oracle、26/29 的证据状态；不能闭合的声称标记 `EXCLUDED/REMOVED` 并从写作计划和 Gate 分母移除，不围绕其扩写。
   - 为每个计划保留或新增的实质论点建立 `source/data/code pointer -> verifiable fact -> allowed claim -> target paragraph` 映射。
   - Introduction/System Model 所需文献必须在本批完成内容级原文核验；Batch C 只处理 BibTeX、格式和确定性引用检查。
   - Gate：所有计划写入的论点 100% PASS 后才进入 Batch B；PASS 分母不包含已标记 `EXCLUDED/REMOVED` 的声称。

2. **Batch B：按方案 A 扩写到 3,500–3,700 词**
   - Introduction：只补可核的具体局限和贡献边界，不设独立 Related Work。
   - System Model：补信号/损伤、块时序、参数性质、pilot/data 与 SNR/BER 合同。
   - Method：补真实 estimator、门控、盲估计、信息访问、固定量/在线量和诚实计算职责。
   - Results：补实验/baseline/metric 合同、代表锚点和不越界解释。
   - Abstract/Conclusion 最后重写，避免复读与贡献错接。

3. **Batch C：引用、术语、图表和版面收口**
   - 将 Batch A 已完成内容核验的来源写入 BibTeX/正文引用，关闭 11 个显式 unresolved citation；删除 DRAFT/TBD/内部代号，使用已接受的真实图。
   - 删除 TBD Table I；除非证明有非冗余职责，否则不以新表替代。
   - 正常调整浮动体，消除 figure-only page 和完全空白栏，但不把排版回收计为正文增量。

#### 明确不动

- 不运行新仿真，不改算法、实验参数、结果 JSON、原始数据和曲线数值。
- 不新设计未批准的图，不新增独立 Related Work、伪代码、完整推导链、链路几何、参数堆表和逐点数字段落。
- 不把约 1.9 dB 归给 switching；不把 BER ratio dB 称为 SNR gain。
- 26/29 若无持久证据复核，全文出现次数为 0。

#### 外部呈现门（D002）

- 内部完整保留 `BLOCKED/GAP/EXCLUDED`、证据债务、停止条件和失败原因；这些只用于写作门控，不进入论文正文。
- 对外正文只写有利且可证实的机制、比较和结果。无法闭合的声称直接删除或收窄，不写“我们原先写错”“证据不足”“未能验证”等自曝式说明。
- 不新增 limitations、future work、失败路线、弱场景讨论或内部审计段落；完整 sweep 保留在既有图中，正文选择最能支撑贡献的代表锚点。
- 事实修正采用积极表达：Fig.3 正面定义为 `BER reduction in dB`，而不是在正文强调“它不是 SNR gain”；约 1.9 dB 作为 NDA-vs-DA 的独立正向观察，不讨论曾被错接到 switching。
- CV curve、1.10 margin、blind-h proxy 和 13 dB 在内部按经验固定量审计；对外写为 `pre-calibrated/fixed decision parameters`，解释其算法职责和固定方式，不主动加入“heuristic/non-optimal/unbiasedness not guaranteed”等降调措辞，也不声称理论最优或跨场景普适。
- `B11`、`P0`、`BLOCKED`、`EXCLUDED/REMOVED`、证据路径和内部文件名在论文中出现次数为 0。

#### 量化验收

1. `texcount` 六节正文总计 3,500–3,700 词；相对 2,219 净增至少 1,281 词。
2. 单独报告删除/替换和毛新增；不得只报净值。方案 A 基准约为删除/替换 985、毛新增 2,336。
3. System Model + Method + Results 不少于正文 70%；Abstract + Introduction + Conclusion 不超过 30%。
4. 最终 8–9 个 displayed equation groups；按公式总账逐项核对保留/替换/合并/新增状态，每个都有变量、假设、信息访问和论证职责，无职责公式为 0，总数不得超过 9。
5. 核心事实矩阵 100% PASS；公式、代码、数字、metric、baseline、图表冲突为 0。
6. `1.9 dB` 不归于 switching；Fig.3 明确定义为 BER ratio/reduction dB。
7. 26/29 无持久证据则全文出现 0 次；100-symbol channel block 与 256-sample DSP window 明确分离。
8. 实际 `CV gate + blind-h effective SNR + fixed 13 dB` 信息流完整；13 dB 明示为经验实现阈值。
9. 内部证据表将 CV 曲线、1.10 margin、blind-h proxy 和 13 dB threshold 记录为离线固定的经验量；外部论文统一写为 `pre-calibrated/fixed decision parameters`，不使用主动降调措辞，也不声称理论最优、无偏估计或跨场景普适性。
10. 独立 Related Work、伪代码、完整推导链、链路几何、逐点数字段落均为 0。
11. 无 figure-only page、完全空白栏、DRAFT/TBD/UNRESOLVED CITATION/未定义内部代号。
12. fresh full rebuild、逐页 PNG 目检、确定性 grep 和独立 verifier 全部 PASS；否则只能报 PARTIAL/BLOCKED。
13. 外部呈现审查 PASS：正文无内部风险标签、失败路线、证据债务、limitations/future work 或自我否定措辞；所有保留声称仍有内部证据指针。

#### 停止条件

- P0 后 BER 分母、Oracle 或核心指标仍无法统一，且继续扩写会依赖这些冲突。
- 忠实呈现两层判据后，论文冻结定位与真实算法不兼容。
- 达到 3,500 词需要加入任一被禁止内容或无证据公式。
- 需要新仿真、新数据或算法修改；立即退出写作流程，单独报告。

## 结论

在当前证据边界内，达到至少 3,500 词是可规划的，但公式不能单独承担篇幅缺口。推荐方案 A：通过约 2,336 词毛新增和约 985 词删除/替换，把正文净增到约 3,570 词；其中公式仅承担系统模型、真实 switching 信息流、公平比较和结果指标的形式化职责。最终公式总量止于 8–9 个 displayed equation groups，理论堆砌路线明确排除。
