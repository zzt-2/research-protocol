## 3. 冻结实验设计

### 3.1 网格

- scenes：`weak`, `moderate`, `strong`
- parameter sets：`old`, `new_family1`
- SNR：`[5, 13, 17, 19, 25]` dB
- seeds：`[0, 1, 2]`
- 每 case-seed：400 windows × 256 symbols；common-768 mask 不变

### 3.2 Runner 分工

1. **A-style offline evaluator**：old/new 各跑三档，产出 fixed DA、fixed NDA、selected common-768、oracle、branch counts；同一 scene/SNR/seed/window 内两分支共享 realization。
2. **B branch-routed receiver**：只跑 new_family1 三档；先 `decide()`，只执行被选分支，物化 `selected_rx`，输出 selected common-768 errors 与 branch counts。
3. **Independent verifier**：从原始 probe JSON 重算 old-vs-new 汇总，并逐 case-seed 比较 A/B selected errors、`n_select_da`、`n_select_nda`、window seed/identity。

应检查 `3 scenes × 5 SNR × 3 seeds = 45` 个 new case-seed；A/B 目标 45/45 严格整数相等。

### 3.3 允许新增

- `projects/simulation/explore/nda-awgn-tracking-sandbox/_family1_downlink_probe.py`
- `_family1_downlink_probe.json`

## 4. 预注册判断

### 4.1 必须报告

逐 scene × SNR 同时给 old/new：

- fixed DA / fixed NDA / selected / oracle common-768 BER 或 error counts；
- selected-vs-fixed-NDA pooled gain（只作方向诊断）；
- DA/NDA fixed winner；
- `n_select_da/n_select_nda` 与比例；
- new-old 差异，不得只报有利点。

### 4.2 硬正确性门

任一失败即 `BLOCKED`：

1. A/B 不是 45/45 bit-exact；
2. shared realization identity、common-768 denominator 或 window count 不一致；
3. 原 A/B runner 或冻结逻辑被修改；
4. 出现 NaN、负参数、seed 重复/缺失或结果无法由 verifier 重算。

### 4.3 “三档还行”筛选门

全部满足才判 `DOWNLINK_ONLY_PROMISING`：

1. 45/45 bit-exact；
2. new_family1 完整网格中 DA、NDA 两个分支都实际被选择；
3. 15 个 scene-SNR cell 中 fixed DA/NDA winner 至少发生一次变化，而非一个固定分支全胜；
4. selected-vs-fixed-NDA pooled gain 在至少 8/15 个 cell 为正；
5. 不存在每个 cell 都由同一分支以 ≥99% 比例垄断的整体退化；
6. new strong 下不存在相对 old/new 其余档明显反常的严重度排序或数值方向错误。

其中 8/15 是预注册粗筛，不是论文显著性标准。若只有个别门未过，判 `REVISIT_BEFORE_FULL_RUN` 并展示原始表，不自行调参；不得因不理想自动加回 uplink。
