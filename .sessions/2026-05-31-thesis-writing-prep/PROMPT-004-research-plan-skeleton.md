## 背景

开题报告的"研究方案"是**主体部分**（导师原话："从第二章开始就是研究方案"，"比如他最后写了160页，现在这个有60页"）。这不是简单的"写个实验方案"，而是**毕业论文第2-5章的缩水版**——需要包含模型描述、公式推导、算法原理、实验设计。

本对话的目标**不是写完研究方案**，而是：
1. 研究别人怎么写研究方案
2. 确定我们的研究方案应该怎么写
3. 搭好骨架和写作模板
4. 尽量多写（能写多少写多少）
5. 产出手接材料（handoff），供后续对话继续

**本对话产出**:
1. `毕设/写作材料/开题报告/03-研究方案.md` — 研究方案草稿（写到哪算哪）

## 子 Agent 策略（自适应，分阶段）

**核心原则: 先探索再规划，不要一开始定死所有 agent。**

### Phase 1: 研究别人怎么写（3-4 个 agent）

**方法论参考**: `/home/zzt/code/thesis-platform/.sessions/2026-05-29-writing-template-workflow/S006-cnki-985-thesis-analysis.md` 展示了一套论文结构分析方法论——先检索同领域论文，下载后做量化结构分析（字数/段落数/引用数/技术数据点/逻辑模式/空洞占比），再适配自己的论文。本 Phase 应遵循类似方法。

**Agent R1**: 精读旧开题报告的研究方案部分（`projects/thesis-figures/开题报告.md` §二+§三），量化分析：
- 结构怎么组织（按章节？按实验？按方法？）
- 每个小节写多深（公式到什么程度？算法描述到什么程度？）
- 实验设计怎么呈现（表格？参数列表？还是叙述？）
- 可行性分析怎么写
- 总字数、段落数、公式数、引用数
- 总结: 一份"研究方案写作模式量化分析"

**Agent R2**: 精读**毕业论文**（非开题报告），重点是：
- 夏兆宇（北理工硕士）的论文结构——导师指定参考
  - 搜索位置: `/mnt/d/code/study/research-protocol/papers/downloads/2026-05-31-cnki-985/` 或 CNKI
  - 如果找不到夏兆宇论文，搜索同目录下已有的董凡、夏煜、曾嘉、闫佳欣论文
- 分析其第2-5章各章写法（因为研究方案 = 毕业论文缩水版）：
  - 每章的公式密度（公式数/千字）
  - 算法描述深度（伪代码 vs 文字描述 vs 流程图）
  - 实验设计格式（参数表 vs 叙述）
  - 图表数量和类型
  - 章节之间的衔接写法
- 总结: 一份"毕业论文各章结构量化分析"

**Agent R3**: 搜索 2-3 篇同领域开题报告（FSO/激光通信/载波同步/信道估计方向），分析其研究方案写法。重点关注：
- 硕士论文开题 vs 博士论文开题的深度差异
- 信号处理类论文的实验方案描述范式
- 开题报告的研究方案 vs 最终毕业论文的对应关系（缩了多少？哪些砍了？）
- 总结: 一份"同领域研究方案参考"

**Agent R4**: 读取所有 Ch2-Ch5 参考材料，评估：
- 每章现有材料的充足程度（哪些可以直接展开，哪些缺材料）
- 每章预估需要多少字（基于 R1/R2 的量化分析推断）
- 材料缺口清单
- 总结: 一份"材料现状评估"

### Phase 2: 制定写作计划（主对话）

基于 Phase 1 的三个分析报告，主对话决定：
- 研究方案的整体写作模式
- 每章的深度目标
- 本对话能完成多少（哪些章先写，哪些留给后续对话）
- 具体的 agent 派遣计划

### Phase 3+: 分章节写作（根据 Phase 2 计划派 agent）

可能的工作量分布：
- Ch2（模型）: 中等，有现成公式

**单个对话的合理目标**: 写完 1-2 章 + 手接材料。

## 写作风格要求

1. **术语**: 严格遵循 TERMS.md
   - h = "归一化辐照度"（非"信道增益"）
   - ω_n 单位写 rad/s（非 MHz）
   - "理想信道状态信息"（非"oracle CSI"）
   - "级联"（非"联合"）
   - "前馈方法"（非"开环方法"）
2. **措辞**: 防御性写作（R003）
   - 不写"首次"、"填补空白"
   - 写"研究...性能表现"而非"提出一种...方法"
3. **公式**: LaTeX 格式，暂用 `[TBD: 见formulas-master §X.X]`
4. **语气**: 正式学术中文，避免口语和机器感
5. **禁止**: 不要出现旧开题报告中的"探索性分化"框架、GNN、路由等内容

- 不运行仿真代码
- 不画图
