# PROMPT-018: 信号处理方向综述检索与宽壳方向设计

> 创建: 2026-06-03 | 优先级: 高
> 依赖: 无（独立调研），但结果影响 PROMPT-013/016/017

## 目标

通过检索综述论文，找到"湍流下相干接收端信号处理方法研究"（Ch4 标题）的合理研究方向切分。目标是确定 3 个足够宽的"研究主题"作为 §4.4 探索方向，使得后续论文中几乎所有信号处理相关工作都能装进去。

## 背景

当前 §4.4 三个探索方向（环路参数解析设计/多源相位噪声联合补偿/编码辅助载波恢复）太窄，全部聚焦在载波同步子领域。但 Ch4 标题是"**信号处理方法**研究"，信号处理链远不止载波同步。

核心问题：别人是怎么切分"FSO 相干接收端信号处理"这个领域的研究方向的？有哪些比"载波同步"更大的研究主题？

## 检索方向

### 第一轮：英文综述

用 `tools/search` 搜索以下关键词组合（每次只搜一组）：

1. `survey "coherent receiver" "signal processing" "free space optical"` — FSO 相干接收机信号处理综述
2. `survey "digital signal processing" "optical wireless" turbulence` — 湍流光无线 DSP 综述
3. `review "satellite-to-ground" optical communication DSP` — 星地光通信 DSP 综述
4. `survey "carrier synchronization" "channel coding" "joint" optical` — 编码与同步联合方向
5. `survey "receiver architecture" "atmospheric turbulence" coherent FSO` — 湍流 FSO 接收机架构

### 第二轮：中文综述/学位论文

用 `tools/search --source cnki` 搜索：

1. `星地激光通信 信号处理 综述` — 中文综述视角
2. `大气湍流 相干接收 综述` — 湍流相干接收中文综述
3. `自由空间光通信 数字信号处理 进展` — FSO DSP 进展
4. `激光通信 接收机 综述` — 激光通信接收机综述

### 第三轮：定向补充

根据前两轮结果，可能需要：
- 查高被引综述的引用链（找更细分的方向综述）
- 查近 2 年的综述（2024-2026，确保覆盖最新方向）

## 分析要求

对每篇找到的综述，提取：

1. **作者如何切分信号处理链的研究方向**（按模块？按功能？按信道挑战？）
2. **哪些方向是"大方向"**（覆盖面广，能装多种具体方法）
3. **哪些方向在 FSO 湍流场景有空白**（gap = 我们的空间）
4. **与载波同步的关系**（载波同步是大方向下的子集，还是独立方向？）

## 输出

1. **综述论文列表**：每篇的标题、年份、关键贡献、研究方向切分方式
2. **研究方向汇总表**：从综述中提取的所有研究方向，标注哪些是"大方向"
3. **推荐方案**：3 个推荐的研究主题，每个需满足：
   - 覆盖面够宽（至少能装 3 种以上具体方法）
   - 不只是"载波同步"的子集
   - 在 FSO 湍流场景有文献支撑的 gap
   - 不使用禁词（自适应/优化/增强/首次/填补空白）
   - PPT 上能用短标签（5-8 字）表达
   - 与 §1.2 文献综述能自然衔接
4. **与现有三个方向的对比**：新方案 vs 旧方案，哪些工作在新方案能装但旧方案装不下

## 约束

- 检索用 `tools/search`（英文）和 `tools/search --source cnki`（中文），不在主对话直接 WebSearch
- 综述论文精读在子 agent 中执行，返回 ≤500 词/篇的摘要
- 找到的论文如果本地库没有，记录 bib 信息待后续添加
- 不在本文档中做最终决策——输出推荐方案，由用户确认
- 不引入与已否决方向冲突的切分（如"自适应载波同步"作为独立方向）
