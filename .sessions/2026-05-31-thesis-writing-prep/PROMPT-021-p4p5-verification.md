# PROMPT-021: P4 矩阵验证 + P5 空白数据研究

> 创建: 2026-06-05 | 优先级: 高
> 本文档供新对话使用，包含全部设计上下文

## 任务目标

P4（方法场景覆盖矩阵）和 P5（研究空白）的每条声明都需要文献支撑。本对话的任务：

1. **验证 P4 矩阵中每格的声明**（方法×场景覆盖度）
2. **为 P5 两个空白的每条具体表现找到文献证据**（支撑论文或确认空白）
3. **输出可直接用于 PPT 的精炼文字**（每条声明 ≤10 字，附文献来源）

## P5 空白需验证的声明

### 空白①：估计精度与下游需求脱节

| 具体声明 | 需要什么证据 |
|---------|-------------|
| CE 以 NMSE 为核心指标，精度与下游同步需求缺乏定量关联 | 找到 CE 论文用 NMSE 作为主指标的证据 + 确认无人做"NMSE→下游BER/同步性能"映射 |
| 不同调制格式对估计误差灵敏度差异大 | 找到 QPSK vs QAM 对 CE 误差灵敏度的对比文献 |
| E[1/h] 发散导致前馈方法前提不成立（口述，不在 slide） | 找到 GG 湍流下 E[1/h] 发散条件的文献或数学证明 |
| "设计者无法确定精度做到多少才够用" | 确认无"面向同步的 CE 精度需求"文献 |

### 空白②：载波同步缺乏湍流场景系统性研究

| 具体声明 | 需要什么证据 |
|---------|-------------|
| 分析框架未将 CE 误差纳入，多以白噪声为前提 | 找到 CPR 分析假设白噪声的论文 + 确认无考虑 CE 误差的 CPR 分析 |
| 经典公式多以白噪声为前提，湍流下设计准则不完善 | 找到 VV/BPS/DPLL 设计公式基于 AWGN 的证据 + 确认湍流下无等价设计准则 |
| 编码辅助在 FSO 湍流下研究有限 | RFC 载波恢复 + FEC 在光纤/RFFSO 的文献 vs FSO 湍流的文献对比 |
| "缺乏分湍流条件的方法选择和参数配置指导" | 确认无"按湍流强度选 CPR 方法/参数"的系统性工作 |

## 验证方法

1. 用 `tools/search` 检索相关文献（英文为主，CNKI 补充）
2. 对每条声明，找到 ≥1 篇支撑论文或确认空白
3. 已有文献库(references.bib)中的论文优先使用
4. 对不确定的声明标注置信度（HIGH/MEDIUM/LOW）

## 输出要求

1. **P4 验证报告**：每格声明 → 支撑文献/空白确认 → 置信度
2. **P5 验证报告**：每条声明 → 支撑文献/空白确认 → 置信度
3. **需要修改的声明**：如果验证发现某声明不准确，给出修正建议
4. **新增文献**：需要加入 references.bib 的新文献列表
