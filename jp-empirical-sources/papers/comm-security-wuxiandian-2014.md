# 利用无线传播信道的安全空时网络编码

## 摘要
提出了一种利用无线传播信道特性的安全空时网络编码方案。通过将物理层安全技术与空时网络编码相结合,在不牺牲频谱效率的前提下实现了信息安全传输。理论分析了该方案在慢衰落和快衰落信道下的安全容量下界。仿真结果表明,所提方案在中高信噪比条件下具有显著的安全性能优势。
