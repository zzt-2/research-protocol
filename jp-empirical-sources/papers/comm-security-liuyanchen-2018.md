# 窃听协作网络下联合中继和目的节点选择方案

## 摘要
针对存在窃听者的协作通信网络,提出了一种联合中继和目的节点选择方案。通过优化中继节点和目的节点的选择策略,最大化系统的保密速率。仿真结果表明,所提方案在不同窃听者数量和信道条件下,均能有效提升系统的物理层安全性能,保密中断概率显著降低。
