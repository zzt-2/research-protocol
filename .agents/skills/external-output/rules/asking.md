# 问问题纪律（汇报类产物专用）

> 本文件管"对外输出里想问的问题"。适用于导师简报、进展报告、答辩 Q&A 预判等"带问句"的产物。论文/摘要不能有问句，不走本文件。

## 核心原则

**每个问出去的问题，自己先查过。** 没查的问题 = 没做功课 = 不能问。

为什么：导师/评委的时间宝贵，且"不调研就问"显得没主动性。更糟的是——没调研就问，可能问的是已经能查到的，或问的是导师刚说过的，显得没在听。

## 问题分级

| 级别 | 定义 | 能不能直接问 |
|---|---|---|
| **L0 常识/可查** | 领域常识、文献能查、数据能算 | ❌ 不能问，自己查 |
| **L1 需判断** | 查了但需要导师经验判断（"这个方向值不值得做"）| ✅ 带"我查过 X，结论 Y，请判断"问 |
| **L2 需决策** | 只有导师能拍板（"主卖哪个""投哪""删不删"）| ✅ 带选项 + 我们的倾向问 |
| **L3 需信息** | 只有导师有的信息（"您说的某文献是哪篇"）| ✅ 直接问，但要具体 |

**L0 绝对不能问。** L1/L2 必须带"我做过的功课"。L3 可以直接问但要问得具体（别泛问）。

## 问之前的"做功课"清单

每个想问的问题，写进简报前过这个清单：

- [ ] 这个问题我自己查过吗？（文献/数据/领域惯例）
- [ ] 查了，结论是什么？（一两句话能说清）
- [ ] 查完还卡在哪？（为什么需要导师）
- [ ] 我有倾向吗？（L2 决策类，带着倾向问比空问好）

**四条答不全 = 这个问题还没准备好，别问，先查。**

## 正反例

### 反例（今天的错）

导师说"图要框图+几个仿真图"。简报里问：
> "图怎么画？画几张？每张什么？"

**为什么错**：导师刚给方向（框图+仿真图），我没按方向调研/画初版就反弹问"怎么画"。属于 L0/L1 混着没做功课。

### 正例

导师说"图要框图+几个仿真图"。先做功课：
- 按方向画初版框图 + 3 个仿真图
- 对标领域惯例（查 3-5 篇同类论文的图组织）
- 带成果问：
> "按您的方向，我画了初版（框图 + BER + 切换机制 + 线宽 4 个图）。对标领域 5 篇，他们一般也是 4-5 图。请看初版行不行，或哪里要调。"

差别：先做 + 带成果 + 问"行不行"（L2 决策），不是空问"怎么画"（L0/L1 没做功课）。

## 特例：导师反馈后多久能再问

导师刚给反馈/方向后，**先消化 + 调研 + 执行，不要立刻反弹问**。

| 时间窗 | 该做什么 |
|---|---|
| 导师刚说完 | 记录 + 消化 + 调研 + 按方向做 |
| 做了一轮有成果 | 带成果汇报 + 问"方向对不对" |
| 做了卡住 | 带卡点 + 已试方案 + 问"怎么破" |

**绝对不要**：导师说完 X，下一份简报立刻问 X 怎么办——等于没消化。profile 里的"急于推进"防线专门防这个。

## 与 claims.md 的关系

问数字类问题（"这个增益够不够""BER 到不了怎么办"），数字本身要先过 claims.md（溯源+边界）。带着没查过的数字问导师 = 把验证责任甩给导师。
