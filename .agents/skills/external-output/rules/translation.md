# 翻译规则：内部语言 → 外部语言

> 本文件是 SKILL.md §2 步骤 2-3 的详细规则。任何对外输出，先列内部语言清单（步骤 2），再按本文件翻译（步骤 3）。

## 内部语言的 6 类（动笔前先扫一遍要写的内容，标出哪些是这 6 类）

### 类型 1：内部流程代号（必须删）

研究流程里给候选/方向/实验编的号。对外人无意义。

| 例子 | 翻译方法 |
|---|---|
| A4（第四个候选）/ B11-Q1（第十一个 B 档第一个 Q）| 删，用方法的功能名替代 |
| step4a / GW Step 3（框架阶段名）| 删或换成"前期可行性验证阶段" |
| D005 / D-010（决策编号）| 删，直接说决策内容 |
| "路径 A / 路径 B"（内部讨论的分叉）| 换成具体内容"重标定方案 / 不重标定方案" |

**判定**：这个词脱离我们项目的 .sessions/ 文件还有意义吗？没有 = 内部代号，删。

### 类型 2：自造术语（必须定义或换标准词）

我们为了内部讨论方便造的词，领域里没有，或不是标准用法。

| 例子 | 翻译方法 |
|---|---|
| fair_gain（自造变量名）| 换领域标准词"net gain"，首次给全称定义 |
| "有效 SNR"（我们这么叫）| 换"块内信噪比"或首次定义 |
| "工作区 grand mean"（内部数据处理说法）| 换"高信噪比区的平均增益" |
| crossover（半自造，通信里非标准用法）| 换"切换点"或"两法性能交叉区"，给定义 |

**判定方法**：这个词在领域文献（IEEE Trans 等）里能搜到标准用法吗？搜不到 = 自造，要么换标准词要么首次严格定义。**不要想当然**——查一下（可用子 agent 查 Semantic Scholar）。

**今天的教训**：fair_gain 被导师问"是什么"，调研发现领域标准是 "SNR gain net of pilot power penalty"，fair_gain 是自造合成词。查证后才敢换。

### 类型 3：缩写（首次必须展开全称）

领域标准缩写可以保留，但**首次出现必须写全称 + 中文**，之后才能单用缩写。

| 缩写 | 首次出现写法 |
|---|---|
| DA-ML | 导频辅助最大似然估计（Data-Aided Maximum Likelihood, DA-ML）|
| NDA-ML | 盲最大似然估计（Non-Data-Aided ML, NDA-ML）|
| CPR | 载波相位恢复（Carrier Phase Recovery, CPR）|
| FSO | 自由空间光通信（Free-Space Optical, FSO）|
| HD-FEC | 硬判决前向纠错（Hard-Decision Forward Error Correction, HD-FEC）|

**规则**：每个缩写在全文第一次出现处 = 全称（中文 + 英文 + 缩写）。之后单用缩写。**不要假设读者懂某个缩写**——哪怕是 SNR，导师可能懂但审稿人未必跟你同领域。

**简报可以例外**：极常见的（SNR/BER）导师档可不展开。审稿人档以上全部展开。

### 类型 4：内部讨论措辞（必须换成规范表达）

讨论时用的口语化、文学化、比喻性说法。对外显得不专业。

| 内部说法 | 规范说法 |
|---|---|
| "击穿短导频" | "使导频估计性能急剧退化" / "导致导频估计失效" |
| "兑现优势" | "利用该优势" |
| "同族/近亲" | "数学等价算法" / "同族算法" |
| "搞定/拿下" | "实现/完成" |
| "这坨屎"（自嘲内部）| 删，不进对外文档 |
| "大空白""死地"（内部判地用语）| 换具体描述"该子领域近年无严格 Trans 工作" |

**判定**：这个词进正式论文/导师邮件合适吗？犹豫 = 换。

### 类型 5：未验证数字（见 claims.md，单独管）

数字问题严重到单列。见 `claims.md`。

### 类型 6：内部简称文献（必须换规范引用）

讨论时用"作者+期刊+年"简称，对外必须 IEEE/GB7714 规范格式。

| 内部简称 | 规范引用 |
|---|---|
| "Du PTL 2025" | X. Du et al., "Title," IEEE Photon. Technol. Lett., vol. XX, 2025. |
| "Wang 2024 JPhoton" | L. Wang et al., "Title," IEEE J. Sel. Top. Quantum Electron., 2024. |
| "Paillier JLT 2020" | [作者全], "Title," IEEE J. Lightwave Technol., vol. XX, 2020. |

**规则**：对外文档的参考文献一律规范格式（作者. "标题," 期刊, 卷, 年.），不用内部简称。导师档可用"（作者，期刊 年）"行内注，审稿人/论文档用规范 [N] 引用。详见各 scenario。

## 翻译优先级

遇到一个内部语言项，按这个顺序选处理方式：

1. **删**（内部代号，对外无意义）——首选
2. **换标准词**（自造术语，领域有标准词）——次选
3. **首次定义**（自造但无标准词可换，或确实是新概念）——给全称定义后才能用
4. **展开**（缩写，首次全称）——领域标准缩写走这条

**不要**：保留内部语言 + 加个括号解释。那是打补丁，不是翻译。要么删要么换要么定义。

## 正反例（今天的简报）

**反例（v2，黑话版）**：
> "A4 per-block 有效 SNR 驱动的 DA/NDA 切换，在 crossover 区稳定改善 +0.27-0.48 dB fair_gain。"

**正例（v3，翻译版）**：
> "我们提出一种方法：接收端按每个数据块的信号质量（块内信噪比），自动选择用盲估计（NDA-ML）还是导频辅助估计（DA-ML）。在两种估计器各有优势的过渡区，该方法相对始终使用固定一种，稳定改善。"

差别：删了 A4，"有效 SNR"→"块内信噪比"，crossover→"过渡区"，fair_gain 删（净增益另段定义），缩写首次展开。
