# 场景：导师简报

> 本文件是导师简报这一产物的特有约束。核心翻译+审查统一走 SKILL.md §2+§3，本文件只讲简报特有的。

## 导师简报的本质

导师简报 = **汇报进展 + 请示决策**。不是论文（不展示完整贡献），不是回复（不逐条对应反馈），是让导师在有限时间内看懂"你做到哪了 + 卡在哪 + 需要他拍什么"。

导师是**半内行**——懂大领域，但不懂你这两个月的具体术语和内部代号。简报的首要读者假设 = "导师第一次接触你这些具体概念"。

## 导师简报必备结构

```
1. 一句话（30 秒抓住导师：做了什么 + 主要结果 + 要干嘛）
2. 工作介绍（核心概念自包含讲清，见 translation.md）
3. 关键结果（数字过 claims.md 审查）
4. baseline/对比（规范文献格式，见 translation.md 类型6）
5. 想请老师定的（带问题，问题先做功课，见 asking.md）
6. 附：数据/图位置（可追溯）
```

**不是每节都要**——按汇报内容裁。但"一句话"和"想请老师定的"几乎必有。

## 简报特有的 5 条纪律

### B1 问问题前先做功课（最重要）

导师说了一个方向/要求/反馈后，**不能不调研就反弹回去问**。

| 情况 | 错误做法 | 正确做法 |
|---|---|---|
| 导师说"BER 要到 10⁻⁵" | 直接问"强湍流到不了怎么办" | 先查数据/查领域惯例，带着调研结果问"强湍流衰减慢到不了，领域里别人怎么处理，我们这样行不行" |
| 导师说"图要框图+几个仿真图" | 直接问"画几张怎么画" | 先按方向画初版 + 对标领域惯例，带着成果问"这样行不行" |
| 导师说"发对比方法文献" | 直接问"发哪篇" | 先筛候选+核实，带着清单问"这几篇哪个合适，或我们漏了什么" |

**判定**：这个"想问"的问题，我自己有没有先查过？没查 = 不能问，先查。查完还卡 = 带着调研问。

**今天的教训**：导师刚说完图结构方向，我没调研就把"图怎么画"塞进简报问——被用户纠正"老师刚说完，没调研就问不好"。profile 防线"急于推进"再次触发。

### B2 标清"初步/未定/待验证"

简报里任何没定稿的东西（图/数字/方案），必须诚实标注状态：

| 状态 | 标注 |
|---|---|
| 初步图（画法没定）| "本图是初步的，根据已有数据直接画的，画法没定稿" |
| 探索性数据（5 seed 非 30 seed）| "5 seed 探索性，非正式统计" |
| 未验证数字（代码没核查）| "增益待验证"——**不可写没查过的具体数字** |
| 待老师拍的方向 | "我们的倾向是 X，请老师定" |

**绝对禁止**：把未验证/初步的东西，用确定的语气呈现。导师会当真的。

### B3 概念自包含（导师第一次接触）

简报里每个核心概念，假设导师第一次见。讲法：

- 先讲"是什么"（一句话，用类比或对比）
- 再讲"怎么来的/为什么"（背景）
- 最后讲"结果/数字"

**反例**：直接写"切换增益 +0.27dB"——导师不知道切换是什么、增益怎么算的。
**正例**：先讲"我们提出一个方法，接收端按块信号质量自动选盲还是导频估计"，再讲结果。

### B4 诚实标注不确定/争议

简报是请示决策的，**把不确定和争议摊开给导师看**，别藏：

- 数据有限制（CI 重叠/场景到不了/seed 不够）→ 标清
- 叙事有争议（主卖哪个/怎么定位）→ 摊开选项 + 我们的倾向，请老师定
- 有 bug/债务 → 如实说"这部分待验证"

藏起来导师拍错板，后面更麻烦。

### B5 数字过 claims.md

简报的数字最容易翻车（导师会拿去判断/对外说）。每个数字必过 `rules/claims.md` 两关（溯源 + 声称边界）。**没过的数字写"待验证"，不写具体数。**

## 简报 vs 论文的区别

| 维度 | 简报 | 论文 |
|---|---|---|
| 目的 | 汇报+请示 | 说服+呈现 |
| 读者 | 导师（半内行）| 审稿人（更外行）|
| 问题 | 带"想问老师"段 | 不能有问句 |
| 数字 | 可标"初步/待验证" | 必须定稿可信 |
| 长度 | 灵活（几页到十几页）| 严格（会议 4-6 页）|

简报可以先于论文，作为论文的"草稿+请示"。但简报过了不代表能直接当论文——论文要走 `scenarios/paper.md`。
