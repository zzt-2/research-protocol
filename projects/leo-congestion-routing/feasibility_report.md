# 方向可行性报告: leo-congestion-routing

> GNN 拥塞感知 per-link 负载均衡 for LEO 卫星星座 + size generalization

## A0. 问题-方法适配性预检

1. **性能间隙**: ECMP 在 66 节点+8%链路故障下 MLU=1.244，GNN MLU=1.096，差距 **12% [实证]**（MVE-2 直接对比数据）。24 节点无故障时 GNN≈ECMP，但链路故障打破等价路径后 ECMP 退化显著。→ **有空间，≥10%**

2. **问题结构适配**（满足多项）:
   - ✅ 状态空间大：66+ 节点星座，每节点 4 邻居，链路负载+拓扑状态连续空间
   - ✅ 环境动态复杂：LEO 时变拓扑（ISL 连接变化）+ 非均匀流量（热点区突发）
   - ✅ 需跨场景泛化：不同星座规模（48/66/720/1584 星），不同流量模式
   - ✅ 延迟奖励/长期依赖：当前 per-link 决策影响下游拥塞

3. **跨域成功先例**: ≥2 篇 — GMR (L02, MPNN+DDPG per-path splitting)、GRLR (L01, GAT+AC 逐跳路由)、PathGNN (L04, attention+SL TE) 均验证 GNN 在路由/TE 场景有效

4. **MDP 非平凡性**:
   - S: 全图链路负载分布 + 拓扑结构 + 流量需求矩阵，连续高维
   - A: per-link 分流比（连续，softmax 约束）
   - R: 负 MLU 或类似拥塞指标
   - 最优策略非平凡：局部贪心选最轻负载链路→可能将拥塞转移到下游；需全局协调
   - 状态空间 >> 1000 → ML 合理

5. **负面证据**: leo-resilient-routing 项目 MVE 两次证明 GNN≈MLP for routing。但本研究核心差异：(a) 拥塞/负载信息需全局聚合（非纯拓扑路由）；(b) MVE-2 已验证 GNN/MLP=0.80，GNN 结构优势成立

6. **先验覆盖检查 [FR-01]**:
   - 主指标 MLU: ECMP 在无故障场景接近最优（MVE-1 GNN≈ECMP），但链路故障下退化 12% → **故障场景未覆盖**
   - 次指标 size generalization: 无任何论文在拥塞路由场景验证 → **完全未覆盖**
   - 创新声称建立在"故障/非均匀场景 ML 改善 ≥10% + size gen 完全空白"上 → **合理**

**A0 结论**: 6 项均无致命信号。✅ 通过

## A'. 竞争维度分解 [FR-05]

| 维度 | 先验覆盖度 | ML 改善空间 | 方法增量 | 本研究竞争点 |
|------|-----------|------------|---------|------------|
| 基本连通路由 | 高（Dijkstra/ECMP ≥95%） | <5% | 低 | 非竞争维度 |
| 拥塞/负载均衡 | 中（ECMP 在故障下退化 12%） | ≥10% [实证] | 高（全局负载聚合） | **核心竞争维度** |
| 链路故障适应性 | 中（ECMP 退化，Dijkstra 失效） | ≥10% [实证] | 高（GNN 拓扑异常适应） | **核心竞争维度** |
| 跨规模泛化 | 低（无先例） | 未知（MVE 待验证） | 高（GNN size gen） | **差异化竞争维度** |
| LEO 时变适应 | 低（TELGEN 静态快照） | ≥5% [论证] | 中（DRL 在线 vs SL 离线） | 补充竞争维度 |

创新声称建立在"拥塞+故障适应（先验覆盖低+ML 改善 ≥10%）+ size gen（完全空白）"上。✅ 合理

## A. 结构优势论证

**核心结构性优势**: GNN message passing 实现全局负载信息聚合，在链路故障打破 ECMP 等价路径后仍能有效路由。

具体条件与信息损失分析：
- ECMP 依赖等价路径集合（等代价路径间均匀分配）。当链路故障移除部分路径后，等价路径数减少，ECMP 盲目在剩余等价路径上均匀分配→无法感知各路径实际负载
- GNN 通过多跳消息传递聚合全局链路负载状态，在故障后仍能做出负载感知的分流决策
- MLP 仅能处理固定维度输入（局部特征拼接），无法适应拓扑变化（节点/链路增减），且缺乏邻居间的信息交换

文献证据：
- MVE-2: GNN/ECMP=0.88（12% 优势），GNN/MLP=0.80（20% 优势）
- L01 GRLR: GAT vs FC 消融验证 GNN > FC，收敛更快
- L07 Fan 2026: GNN+DQN 消融显示 GNN-only +5%, DQN-only +4.2%, GNN+DQN +8.6%
- L04 PathGNN: path-link 消息传递 vs MARL-GNN 提升 ≥24.4%

**增强基线对比 [FR-03]**: ECMP+负载感知权重（类似 ELB）是合理的增强基线。MVE 中 ECMP 无负载感知，后续仿真应加入 ELB 类增强版 ECMP 作为对比。

**范式对齐 [FR-08]**: 领域 top-3 成功范式 — GMR(MPNN+DDPG), GRLR(GAT+AC), PathGNN(attention+SL)。本研究采用 GAT/GIN+PPO（RL 范式），与 GMR 和 GRLR 对齐（GNN+RL）。偏离 PathGNN 的 SL 范式，因为 LEO 时变场景无法预先获取最优解标签。

**A 结论**: 结构优势清晰，MVE 实证支撑，范式与主流 RL 方法对齐。✅ 通过

## B. 新颖性-可行性解耦

- **新颖性论据**: "GNN per-link 负载均衡 + LEO 时变拓扑 + size generalization" 三角交叉为真空（literature_notes Step 3.5 确认）。最接近竞品 TELGEN 做了 GNN+TE+size gen 但仅限静态快照；GMR 做了 GNN+跨星座泛化但是 per-path；GNN-ASSSP 做了 congestion-aware 但是 per-edge weight
- **可行性论据**: MVE-2 已验证核心假设（GNN 在故障场景下优于 ECMP 12%）。GNN message passing 对负载信息的全局聚合能力是结构性的，不是偶然的
- **空白原因分析**: 
  - 技术限制刚解除：Walker delta 星座 GNN 建模近年才成熟（GMR 2024, GRLR 2025）
  - 问题拆分惯性：现有工作沿"路由→TE→负载均衡"逐步细化，per-link 粒度是自然的下一阶段
  - 组合新颖性：各子技术（GNN、per-link 决策、size gen）单独已验证，但组合到 LEO 拥塞路由尚未尝试

**B 结论**: 新颖性有文献支撑，可行性有 MVE 实证，空白原因合理。✅ 通过

## C. 仿真条件可行性

1. **优势体现条件**: MVE-2 已验证非均匀流量 + 链路故障是 GNN 优势的激活条件。正式仿真器需包含：
   - ✅ Walker delta 拓扑（24/66/720 节点）
   - ✅ 非均匀流量（热点区 + 突发模式）
   - ✅ 链路故障（≥5% 概率，模拟 ISL 不可用）
   - ✅ 时变拓扑（LEO 轨道运动 → ISL 连接变化）
   - ✅ Per-link 分流比决策空间

2. **差异信号充分性**: MVE-2 GNN vs ECMP MLU 差距 12%（0.88 比值），信号充分。加入更大规模（720+ 节点）预计差距会放大（拓扑复杂性增加）

3. **反模式检查（domain-comms.md "过于平滑"）**:
   - ⚠️ MVE-1 教训：24 节点无故障 → GNN≈ECMP（条件过于平滑）
   - ✅ MVE-2 修复：加入 8% 链路故障后差异显现
   - 正式仿真器必须包含：非均匀流量 + 链路故障 + 时变拓扑，三者缺一不可
   - 流量模型必须包含突发成分（非纯均匀/泊松），否则 ECMP 足够好

4. **仿真复杂度评估**: 基于 MVE 代码扩展，主要增加：轨道力学（时变拓扑）、动态流量模型、per-link 决策输出层。复杂度中等，MVE 已验证核心训练循环可行

**C 结论**: 仿真条件可支撑核心方法优势。需确保非均匀流量+链路故障+时变拓扑三要素。✅ 通过

## D. 最小可行实验（MVE）

- **假设**: GNN message passing 能有效聚合全局负载信息，在链路故障场景下做出优于 ECMP 的 per-link 分流决策
- **最小实例**: Walker delta 24 节点（MVE-1）+ 66 节点 6×11（MVE-2）
- **pass/fail 标准**: GNN MLU 显著低于 ECMP（比值 < 0.95）且 GNN 优于 MLP（比值 < 0.90）
- **MVE-1 结果** (24 节点, 无故障):
  - GNN/MLP = 0.83 ✅ | GNN/ECMP = 1.01 ❌
  - 结论：GNN > MLP 验证通过，但 GNN ≈ ECMP → 小拓扑条件不足
- **MVE-2 结果** (66 节点, 8% 链路故障):
  - GNN/ECMP = 0.88 ✅ | GNN/MLP = 0.80 ✅
  - 结论：故障条件下 GNN 显著优于 ECMP（12%）和 MLP（20%），核心假设验证通过
- **实例保真度 [FR-04]**: Walker delta 拓扑保留轨道面结构 + 非均匀流量保留热点模式 + 链路故障模拟 ISL 不可用 → 与 LEO 真实场景结构一致
- **决策**: Go（MVE 部分通过但有解释和改善路径：小拓扑无差异→大拓扑+故障后差异显现）
