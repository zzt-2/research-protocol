## 三、到底在做什么(不堆术语)

### 3.1 场景

星地激光下行链路。发端用 (8,8)-16APSK 调制(DVB-S2X 同源,4 bit/符号)。信号经过的大气信道有三层损伤:
- **大气湍流**:幅度随机衰落,分弱/中/强三档
- **激光相位噪声**:相位随机漂移(激光线宽 500kHz)
- **Doppler 残余频偏**

接收端必须先估出载波相位(CPE),才能解调。**这就是要解决的问题。**

### 3.2 两种主流做法

载波相位估计有两种范式:
- **DA(pilot-aided,数据辅助)**:发端定期插入已知的 pilot 符号,收端用 pilot 估相位。优点:简单可靠。缺点:**pilot 占用了 25% 的发射功率**(等价浪费 1.25 dB),且在湍流 deep fade 块里 pilot 容易跟着衰落崩掉。
- **NDA(blind,非数据辅助)**:不发 pilot,直接从数据符号盲估相位。优点:**省掉 25% pilot 功率,全频谱效率**;理论上对 deep fade 更鲁棒(用全帧符号积分,不依赖个别 pilot 点)。缺点:盲估要"去掉调制相位",实现更难,高 SNR 下精度有损失。

这俩是载波同步领域的天然对照(文献里 NDA 论文基本都拿 DA 当 baseline)。

### 3.3 我的方法

在 NDA 这条路上,核心是把一篇 2025 年的论文(B11,IEEE PTL)的思想从 OFDM 频域搬到单载波时域。具体三步:

1. **升 8 次幂去调制**:(8,8)-16APSK 星座点升 8 次幂后,调制相位归一到 8 个固定方向,只剩载波相位。
2. **闭式 ML 公式估相位**:对升幂后的序列用最大似然闭式解算出相位,不需要 pilot。
3. **逐块估计 + 块内分段跟踪**:把 256 个符号一块,先按块估一个常相位;但在 AWGN(无湍流)场景下,块内的相位漂移不能忽略,所以再把每块切 8 段,每段独立估、段间插值,得到逐符号的相位轨迹。

为什么第 3 步要分场景——这在下面 §五 会讲,是消融逼出来的改进。

### 3.4 公平比较怎么做

这是关键,不做好公平性会被 reviewer 直接打回来:
- **DA baseline**:pilot 间距 4(每 4 符号 1 个 pilot),25% overhead,pilot 符号从已知 bits 生成(不是用解出来的符号反馈,避免错误传播)。BER 只在 data 位置算。
- **公平坐标**:两条 BER 曲线都画成"总发射功率 SNR"。也就是说,DA 的功率里要包含它浪费在 pilot 上的 1.25 dB,这是 DA 的代价。NDA 没有这个代价。这样比出来的差距才是真实的频谱效率差距。

我已经逐行审计过 DA baseline 没有任何信息泄露:pilot 只用已知 bits、信道估计只用 pilot 位置、BER 只算 data 位置、pilot overhead 在总功率里付过钱。**审计结论:0 dB 渗透。**

### 4.2 主结果:我的方法 vs 传统 pilot-aided(DA ML)

5 个种子,HD-FEC 阈值处的功率增益(正值 = 我的方法省功率):

| 信道场景 | 功率增益 (dB) | 标准差 | 95% 置信区间 | 有效种子 |

| AWGN(无湍流) | **+1.483** | 0.024 | [+1.453, +1.512] | 5/5 |
| 弱湍流(α4/β3) | **+1.529** | 0.321 | [+1.131, +1.928] | 5/5 |
| 中湍流(α2.5/β1.8) | **+1.712** | 0.250 | [+1.314, +2.110] | 4/5* |
| 强湍流(α1.5/β0.8) | **+2.515**(工作区均值) | 0.555 | [+2.239, +2.791] | 5/5 |

**结论:所有场景都比传统 pilot-aided 省功率,置信区间不跨零,统计显著。**

## 五、消融逼出来的一个关键改进(这是重点,讲清楚怎么避免翻车)

刚开始跑出来的结果不是这样的。一开始我的 NDA-ML 在 AWGN 场景**输给 BPS 0.53 dB、输给 VV 0.69 dB**(统计显著)。如果就这样写论文,reviewer 复现一下就打脸了。

**查根因**:不是 bug。是方法的一个真实短板——我原本把每 256 符号块当成"块内相位恒定"来估,但 500kHz 线宽下块内相位实际漂移约 0.17 弧度。BPS 和 VV 都是滑窗跟踪,跟得上这个漂移,我的原版跟不上。

**改进**:在 AWGN 场景,把每块切 8 段,每段独立估、段间插值,得到逐符号跟踪。这个改进来自一段独立的 sandbox 实验(先在隔离环境验证可行,再回写到主代码)。

**代价**:这个块内跟踪在强湍流里反而有害(湍流衰落主导,块内相位跟踪会放大升幂噪声)。所以方法是**场景自适应**:AWGN 用块内跟踪,湍流保持原版。sandbox 已经在强湍流验证过退化是真实的(不是单种子噪声),所以这个分场景处理是物理上必须的,不是凑数。

**验证纪律**(防"半场开香槟"):
- 改进版在 AWGN 的结果跟 sandbox 逐位一致(bit-exact,同一套数学两份独立实现)
- oracle 上界一致性检查:**全场景 0 违例**(我的方法 BER 始终高于 oracle,说明没偷看发送端、没单位错误)
- 所有数字都用独立 Python 脚本复核过原始 JSON,不信任中间报告
- 核心算法实现做了三项独立核查(BPS 适配数学、DA pilot 信息渗透、改进代码)全部 PASS

**这段是我觉得最值得跟老师讲的**:不是一开始就赢,是先发现输、查根因、改方法、再验证。

## 七、后续可能方向(按优先级,逐个尝试)

以下方向不一定全做,是"如果当前方向继续推进,接下来按什么顺序探索"的备选清单。优先级排序的依据是:跟当前方向的衔接度 → 可行性 → 新颖性。**请老师帮忙看看排序合不合理、有没有漏掉的、有没有不该做的。**

### 优先级 1:把当前方向做扎实(深化,不换方向)

这是最稳的路线,不碰新方向,把 NDA-ML 这条线做到能投会议的程度:

- **1a. 加种子到 10+ 个,补真实损耗**:现在 5 个种子,补到 10+ 让统计更稳;加量化 bit 限制、残余同步误差、非理想信道估计等真实系统损耗,看增益还剩多少。**目的**:让增益数字从"方法潜力"变成"工程预期"
- **1b. 改进版 + DD-KF 消融**:当前主方法是 per-block 估计。更强的 per-symbol 卡尔曼跟踪(DD-KF)在弱/中湍流会让 DA 发散(不适用),但在 AWGN 能进一步扩大 NDA 优势。要验证改进版 + DD-KF 是否在所有场景都不反转
- **1c. 更强的对比 baseline**:现在有 DA + BPS + VV 三个。如果 reviewer 觉得不够,可补 PCA-based CPR(现代 NDA 方法簇)或 Kalman 类。但当前 3 个已是该子领域共识度最高的

### 优先级 2:并行第二方向(B7 — Gardner TED 频偏估计)

**方向**:Gardner TED(Time Error Detector)+ FOE(Frequency Offset Estimation),针对星地 LEO Doppler 频偏场景。

- **跟当前方向的关系**:当前 NDA-ML 聚焦**载波相位**(CPE),B7 聚焦**载波频偏**(CFO/FOE),是载波同步的两个子问题。两者可互补——CPE 和 CFO 联合估计是完整载波恢复方案
- **依据**:OFC 2026 论文(B7),上游文献精读排序第二候选,跟 B11 同属载波同步簇
- **风险**:B7 主面是 inter-satellite(星间),搬到星地需验证 Doppler 模型适配;Gardner TED 对 M-APSK 的适用性需验证(经典 Gardner 是 QPSK/16-QAM 设计的)
- **判断点**:是先把 B11 做深,还是 B7 并行开?如果只够一篇会议,B7 可以作为 B11 的"频偏估计子模块"整合进去,不单独成文

### 优先级 3:更架构级的方向(B3 — 子系统协同联合估计)

**方向**:载波同步 + 其他接收端子系统(如信道估计、均衡)的联合估计,而不是各模块独立优化。

- **跟当前方向的关系**:当前 NDA-ML 是"载波相位估计"单模块。B3 是"多个估计模块联合优化",架构上更大,潜在增益更大但复杂度也高
- **依据**:上游文献精读里 B3-Q2 跟当前 B11-Q1 增益量级相当(第一梯队),S031 排序第三候选
- **前置依赖**:**必须先决架构假设**——多孔径阵列 vs 单链路,这决定了联合估计的状态空间维度。这是个大决策,不能跳过
- **风险**:架构级方向,工作量大,可能超出会议论文范围,更适合学位论文的主章节
- **判断点**:这个方向是留作学位论文深化,还是现在就开?如果现在开,要先碰多孔径 vs 单链路的架构决策

### 优先级 4:已被标准校准"救回"的候选(S001 校准扩围)

精读阶段曾用偏严的标准(期刊级 oracle 上界 <0.5dB 砍 + 主题锁窄)砍掉一批方向,后来校准为会议级标准重评,以下方向重新进入评估范围,但**还没跑 MVE**:

- **B9-Q1**:载波同步相关的另一个角度(曾被主题锁窄排除,校准后重评)
- **D006 边界 7 次**:湍流相位进同步环路的一类(注意:D006 红线——前馈不撞 DPLL 环路则可做,环路联合建模则撞已 Kill 的旧方向,这个边界要先确认)

这些是"如果 1/2/3 都不顺利,或老师觉得当前方向不够,还有这些备选"。**不是现在要做的事**,是兜底清单。

### 优先级 5:理论延伸(B12 锚 + MAP 双视角)
