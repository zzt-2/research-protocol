# 阶段 0.3 架构定性：前馈开环（INVARIANT 13 + D006 边界）

> 来源: B3-Q2 阶段 0.3 | 日期: 2026-07-08（S003）
> 门控对象: INVARIANT 13（D006 边界——前馈开环不撞 / 环路 TF 联合建模撞转 B3-Q3）
> 决策: **走前馈开环**（一套 TS 块估 FS+FOE+CPE+Doppler，不进环路 TF）

---

## TL;DR

| 候选架构 | 是否撞 D006 | 增量空间 | 判定 |
|---|---|---|---|
| **前馈开环**（一套 TS 块估 FS+FOE+CPE+Doppler，逐块估计不反馈） | **否** | 合法（jphot FS+FOE 前馈扩展 +CPE/Doppler 维度）| ✅ **采用** |
| **环路 TF**（Doppler/湍流相位进 PLL 环路 TF 联合建模） | **是**（撞 D006，B1/Q12 双重证伪）| 转 B3-Q3 | ❌ 排除 |

**一句话**：B3-Q2 联合估计走**前馈开环**——一套 TS 块同时估 FS+FOE+CPE+Doppler 四参数，逐块估计不进反馈环路。这跟 jphot 本身的 FSTS 前馈块估计同构（jphot-L101/L175 都是逐块前馈），只是多加 CPE 联合维度 + Doppler 维度，**不撞 D006**。

---

## 1. D006 边界判据（已核实，逐条引证）

### D006 禁区（decisions.md L341 原文）

> "把**湍流相位纳入载波同步算法设计**（无论 KF/环路传递函数/其他数学工具）——已被旧 B1 + Q12 双重证伪，除非找到 Q12/KF 之外的**全新机制**（不是单纯换数学工具）"

**D006 禁的是**：湍流相位 φ_T **进环路传递函数 H(z)**（或 KF 状态向量）做联合建模——因为 Paillier JLT 证明"湍流相位噪声对载波同步可忽略"（D006 L337），旧 B1 + Q12 两次证明"主动建模湍流相位带不来同步增益"。

### B3-Q2 前馈开环不进禁区（三重证据）

1. **jphot 本身就是前馈块估计**：jphot-L101 "TS is firstly used for FS ... TS is used again to complete FOE"——一套 TS 顺序做 FS→FOE，逐块前馈，无反馈环路。jphot-L175 两段式 FOE 也是前馈（粗估→补偿→细估，块内顺序，不跨块反馈）。
2. **B3 详评 Q2 判定**（`_B3-...md` L77）："撞 D006？否——协同在 FS/FOE/分集合并子模块间，不涉 PLL 环路 TF"。
3. **B3 详评 Q3 边界**（`_B3-...md` L85）："B3 跨子系统协同是 DSP 子模块间资源共享/依赖管理，不等于'湍流相位进 PLL 环路 TF'。**注意边界**：若候选被具体化为'把湍流相位与多普勒在环路 TF 内联合建模'则撞 D006（只标不砍）；若具体化为'定时/均衡/载波恢复共享 pilot + 残差级联容限设计'则不撞。"

→ **B3-Q2 走"一套 TS 块估四参数 + 前馈"= 后者形态，不撞 D006。**

### 撞 D006 的形态（明确排除，转 B3-Q3）

若 B3-Q2 被具体化为"把 Doppler 频偏斜率 + 湍流相位纳入 PLL 环路 TF 联合建模（H(z) 含 φ_T 项 / KF 状态向量扩 [ω, φ, φ_T]）"——**撞 D006**，应走 B3-Q3 边界（D006 边界点，只标不砍，不在本专题实现）。

## 2. 前馈开环架构详述（B3-Q2 采用形态）

### 2.1 估计流程（逐块前馈，单 TS 块内顺序）

```
接收多支路信号 (每支路 k: r_k^branch)
   │
   ├─ [1] FS（帧同步）：FSTS 相关峰搜索，定位各支路 TS 起点并对齐支路时延
   │      └─ 复用 jphot FS（跨极化共轭相关），前馈一次性
   │
   ├─ [2] FOE（两段式，前馈）：粗 FOE（全范围 ±Rs/2）→ 补偿 → 细 FOE（残频，BL² 降噪）
   │      └─ 复用 jphot 两段式 FOE（jphot-L175/L208），前馈块内顺序
   │
   ├─ [3] Doppler 维度（前馈扩展，B3-Q2 增量点）：
   │      └─ 对 FOE 残余频偏序列做线性回归 / 多项式拟合抽 Doppler 斜率（f_dot）
   │         不进 PLL 环路，逐块前馈估计后前向补偿
   │
   ├─ [4] CPE（载波相位估计，前馈）：复用 FOE 中间共轭积作相位先验 → VV/BPS 块估计 Wiener 相位
   │      └─ jphot 原 CPE 独立，B3-Q2 联合（复用 FOE 中间量），前馈块估计
   │
   └─ [5] MRC 合并（多支路）：各支路相位预校正后按最大比合并
          └─ 复用 jphot MRC（共享 LO，合并后联合补偿，jphot-L101）
```

**关键**：步骤 [1]-[5] 全部**逐块前馈**——每个 TS 块内顺序执行，块与块之间不反馈进环路。这跟 jphot 的 FSTS 前馈块估计同构，只是多了 Doppler 斜率拟合（[3]）+ CPE 联合复用（[4]）。

### 2.2 Doppler 维度的前馈形态（B3-Q2 增量核心，不撞 D006）

**问题**：jphot-L208 自承"frequency offset drifts slowly"（缓变假设），LEO Doppler 时变会破坏。

**B3-Q2 前馈解**（不进环路）：
- jphot 两段式 FOE 估的是**块内常数频偏** Δf（一个 TS 块 BL 符号内假设恒定）
- B3-Q2 加一层**块间 Doppler 斜率估计**：对连续多个 TS 块估出的 Δf̂_k 序列做线性回归 → f_dot = d(Δf)/dt
- 用 f_dot 前向补偿（逐块外推 Δf̂_k = Δf̂_0 + f_dot·k·T_block），**不进 PLL 环路 TF**

**为什么这不撞 D006**：
- D006 禁的是"湍流相位 φ_T 进环路 TF 联合建模"
- B3-Q2 的 Doppler 斜率拟合是**纯频偏序列的块间回归**，处理的是 FOE 估计输出（频偏），不是湍流相位
- Doppler 斜率 f_dot 是确定性轨道运动（可预测），不是随机湍流相位（D006 禁区）——两者物理本质不同
- 形态上是"前馈估计 + 前向补偿"，没有反馈环路（PLL 的 VCO/integrator 反馈）

**边界声明**：若 Doppler 维度被具体化为"f_dot + φ_T 联合进 KF 状态向量 [ω, f_dot, φ_T] 做环路联合建模"→ 撞 D006（湍流相位进环路），转 B3-Q3。**B3-Q2 只做 f_dot 前馈回归，不含 φ_T 进环路。**

### 2.3 CPE 联合维度的前馈形态（B3-Q2 增量点 2）

**jphot 原 CPE**：独立（FOE 后另起 CPE，jphot-L101/L243）。jphot CPE = 相位噪声估计 + DD-LMS 兜底。

**B3-Q2 联合 CPE**（前馈）：
- FOE 两段式产生的**跨极化共轭积**（jphot-L208 的 R1/R2 中间量）含相位信息
- 复用这个中间量作为 CPE 的相位先验（避免 CPE 重复四次方/共轭运算）
- CPE 仍用 VV/BPS 块估计，但输入带 FOE 中间量的相位先验——**前馈数据复用，非环路**

**为什么这不撞 D006**：
- 协同发生在 FOE↔CPE 子模块间（共享中间量），是 DSP 子模块数据复用
- 不涉及把湍流相位纳入环路 TF
- 跟张思齐 JCR-IFOE/JCR-AFOE（FOE 四次方信号复用至 CPE，`_B3-...md` L14）同形态——张思齐已验证这是合法协同

**注**：0.1b CRB 推导显示"等导频长度下 CPE joint-vs-separate CRB 增益 ≈ 0 dB"（`_stage0_1b` L88）——CPE 联合的增益预期偏薄，sandbox 必须验证它是否产生真增益（可能靠"开销节省"而非"精度提升"，见 0.4 公平对照）。

## 3. 架构决策结论

### 决策：B3-Q2 走前馈开环（一套 TS 块估 FS+FOE+CPE+Doppler，逐块前馈不进环路）

**理由**：
1. **不撞 D006**（三重证据：jphot 本身前馈 / B3 详评 Q2 判否 / B3-Q2 形态是"共享 TS + 残差级联"非"湍流相位进环路"）
2. **跟 jphot 同构可复用**（jphot FSTS 就是前馈块估计，B3-Q2 只加 Doppler 斜率拟合 + CPE 中间量复用，保持前馈）
3. **增量切口对齐 A1 归属**（D002）：jphot 已 claim FS+FOE+MRC 前馈，B3-Q2 增量 = +Doppler 维度（前馈回归）+ CPE 联合（前馈数据复用）+ 星地场景
4. **规避 B1/Q12 换皮陷阱**（D006 教训）：不碰湍流相位进环路，只做频偏序列的块间回归（确定性 Doppler，非随机湍流）

### 排除的形态（撞 D006，转 B3-Q3 边界）

- ❌ Doppler + 湍流相位联合进 PLL 环路 TF（H(z) 含 φ_T）
- ❌ KF 状态向量扩 [ω, f_dot, φ_T] 做联合建模（旧 B1 换皮）
- ❌ 把湍流相位作为 CPE 先验进环路（D006 禁区）

→ 这些形态若要做，走 **B3-Q3**（D006 边界点，只标不砍，本专题不实现）。

### 对后续阶段的约束

- **阶段 0.4 公平对照**：baseline 的 jphot FSTS 也是前馈（同架构形态），公平对照 = 前馈 vs 前馈，只差 CPE/Doppler 维度
- **阶段 0.5 参数**：Doppler 维度需明确 f_dot 量级（LEO 轨道，常见 ±数十 GHz/s 斜率范围，需标 source）
- **阶段 0.6 接口**：联合估计管线必须是前馈管线（无环路反馈），MRC 合并器接收各支路前馈预校正后信号

## 4. 方法局限（诚实标注）

1. **Doppler 斜率前馈回归的精度未验证**：jphot 缓变假设下块间 Δf 近似常数，LEO Doppler 时变下块间 Δf 有真实斜率——前馈线性回归能否捕捉需 sandbox 验证（可能需多项式而非线性）
2. **CPE 联合增益预期偏薄**（0.1b CRB ≈0dB）：CPE 联合的增益可能靠"开销节省"（一套 TS 复用，省 CPE 独立导频）而非"精度提升"，sandbox 需设计开销对照（见 0.4）
3. **前馈形态下 Doppler 大动态范围可能不够**：LEO 可见弧段 Doppler 全量程 ±几 GHz（B5 主题），前馈块估计的 FOE 范围是 ±Rs/2（jphot-L183，10GBaud 下 ±5GHz），块内够但块间斜率累积需外推——外推误差是风险点
