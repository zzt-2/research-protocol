## CRB 推导

### 1. FOE CRB（单链路，联合 FSTS 两段式 vs 分立传统 TS）

**基础 mCRB（Mengali/Rife-Boorstijn，TS-based FOE）**：块长 N、每符号 SNR=γ 的 AWGN + 缓变相位噪声信道下，归一化角频偏 ν ≜ 2πf·Ts 的估计方差下界

```
var(ν̂) ≥ 6 / [ N·(N²−1)·γ ]                         …(M1)
```

代入 N=320, γ=8 dB（单支路强湍 FEC 工作点附近，γ≈6.3 线性）：

```
N·(N²−1) = 320 × 102399 = 3.2768e7
var(ν̂)_single-stage ≥ 6 / (3.2768e7 × 6.3) = 2.91e-8   [rad²]
归一化 (f·Ts)² = var(ν̂)/(2π)² = 7.36e-10                [无量纲]
```

**分立管线（传统 TS，单段）**：直接用 (M1)。实测 MSE 落在 1e-6~1e-7（jphot-L289），与 (M1) 同阶——即传统 TS 已接近但**未达** mCRB（实现损失），且恰在 2.5e-7 陡崖上方 → BER 受残余频偏拖累。

**联合管线（FSTS 两段式）**：关键结构增益来自二阶 FOE——一阶补偿后，对间隔 BL·Ts 的跨极化共轭积取角，再将估计值除以 BL（jphot-L208）。频偏灵敏度（dφ/df）放大 BL 倍 → 估计方差降 BL² 倍：

```
var(ν̂)_FSTS-2nd-stage ≥ 6 / [ N·(N²−1)·γ·BL² ]       …(M2)
BL = 20 (4-QAM, 320 sym, jphot-L299)
→ var(ν̂)_FSTS ≥ 2.91e-8 / 400 = 7.27e-11   [rad²]
→ 归一化 (f·Ts)² ≥ 1.84e-12                  [远低于 2.5e-7 陡崖]
```

**FOE CRB 方差比（联合 / 分立）**：

```
var_sep / var_joint ≈ BL² = 400   →   10·log10(400) = +26.0 dB（方差域）
```

即联合 FOE 在方差域有 **26 dB 的 CRB 余量**，实测 MSE 1e-7~1e-9（jphot-L289）与 (M2) 同阶，自洽。这个 26 dB 是 *估计精度* 上界，**不是**可直接兑现的 BER 灵敏度 dB——灵敏度被 MSE 陡崖（2.5e-7）封顶（见下）。

---

### 2. CPE CRB（单链路，联合复用 FOE 中间量 vs 分立 VV/BPS）

CPE 处理的是激光线宽（Δν=50 kHz）引起的 Wiener 相位噪声，与 FOE 残余是**不同物理量**。单链路下：

- **分立 CPE**（独立 VV/BPS 或独立导频块）：CPE 方差下界 ~ 1/(2γ·M_eff)，M_eff 为等效导频/块长。
- **联合 CPE**（复用 FOE 中间共轭积作为相位先验）：FOE 已把残余频偏压到 (f·Ts)²≈1.8e-12（远低于 4-QAM 陡崖 2.5e-7），CPE 不再受频偏残余污染。但 CPE 自身的 Wiener 相位噪声方差下界由 Δν·Ts 与 γ 决定，**不因共享 TS 而改变**（CRB 只依赖 N、γ、Δν，不依赖"是否共享"）。

```
CPE joint-vs-separate CRB 增益 ≈ 0 dB（单链路，等导频长度下 CRB 恒等）
```

唯一非零项：若总开销固定、分立管线把预算切成 FS+FOE+CPE 三份而联合复用全 N，则 CPE 等效导频可放大约 √3 倍 → 方差降 ~3 倍 → **≤ +2.4 dB（开销受限模型上界）**。但这是开销分配论据，不是估计理论增益，且 jphot 的 FSTS 本身就只做 FS+FOE（CPE 另用相位噪声估计 + DD-LMS 兜底，jphot-L101/L243），故 CPE 联合增益实际 **≈ 0 dB**。

---

### 3. FS 项（单链路）

单链路无多支路时延差需对齐 → FS 的"支路对齐"增益 **归零**（任务设定）。FS 仅余起点定位精度，对 FOE/CPE 的 CRB 不构成额外增益。

```
FS joint-vs-separate CRB 增益 = 0 dB（单链路，无支路对齐）
```

---

### 4. 合成单链路联合 vs 分立管线 dB 增益

**CRB（方差域）上界**：FOE 项主导，+26 dB（BL²）；CPE ≈ 0；FS = 0。方差域合计 ≈ +26 dB。

**可兑现 BER 灵敏度上界（陡崖封顶）**：FOE-MSE 一旦低于 2.5e-7（jphot-L279），残余频偏被后续 CPE 完全补偿，BER 不再受益。故联合相对分立的**可兑现灵敏度增益 ≤ 分立因高 MSE 付出的陡崖惩罚**。分立 MSE ≈ 1e-6~1e-7 恰跨陡崖 → 付出全部惩罚；联合 MSE ≈ 1e-8 远低于陡崖 → 零惩罚。该惩罚的实测值即 jphot 单支路 +1.03/+1.17 dB。

```
单链路联合 vs 分立 可兑现灵敏度 CRB 上界
  = FOE 陡崖惩罚（分立侧） ≈ +1.03 dB（960 sym）/ +1.17 dB（320 sym）
  CRB 方差余量 26 dB ≫ 陡崖，故上界不被 CRB 卡住，被陡崖封顶。
```

取**保守单值（960 sym，更短 TS 更不利联合）**：

```
单链路联合 vs 分立 CRB 上界 ≈ +1.0 dB（保守，960 sym）
                          ≈ +1.2 dB（320 sym，jphot 优化点）
```

## 结论（给主线判定用，不含 Kill 判定）

- **单链路联合 vs 分立 CRB 上界增益 ≈ +1.0 dB（960 sym，保守）/ +1.2 dB（320 sym）**；方差域余量 +26 dB（FOE 两段式 BL² 结构）。
- **vs FR-21 阈值 0.5 dB**：1.0 ≥ 0.5 ✓ 且 1.2 ≥ 0.5 ✓ → **单链路场景够格（不触发 Kill 前置门控）**。余量 +0.5 ~ +0.7 dB。
- **一句话**：B3-Q2 单链路场景 **够格**（CRB 上界 ≈1.0~1.2 dB > 0.5 dB 门限，且自洽性 PASS）。

## 关键反直觉发现（供主线参考，非判定）

**"单链路 dB 砍半"假设不成立**：jphot Fig.18 数据（jphot-L375, note-L36）显示 4-QAM 强湍 320 sym 下，**单支路增益(+1.17) ≥ 4 支路(+0.7)**。机理：4 支路 MRC 把等效 SNR 抬得太高，两套算法都跌到 MSE 陡崖(2.5e-7)以下 → 增益被压缩；单支路低 SNR 恰卡在陡崖上 → FSTS 结构增益充分兑现。**即单链路反而是 FSTS 联合估计增益最显著的场景**，与"分集砍半"直觉相反。主线若以"单链路 dB 不够"为由 Kill，与 jphot 数据冲突。

**增益归因警示（方法诚实性）**：本算 +1.0~1.2 dB 的来源是 **FSTS 两段式 FOE 的 BL² 结构降噪**，而非"FS+FOE+CPE 共享一套 TS"的纯粹共享增益。若分立管线也采用同等两段式 FOE 结构，则纯粹"共享"带来的 CRB 增益在单链路下趋近 0 dB（FOE/CPE 的 CRB(N,γ) 在等长 TS 下恒等，FS 支路对齐项归零）。换言之：**B3-Q2 在单链路的 dB 优势主要靠 FOE 算法结构，不是子系统协同**。这对"子系统协同联合估计"的核心卖点是削弱——主线判定时应区分"算法结构红利"与"协同红利"。

## 方法局限（诚实标注）

1. **CRB 模型假设 AWGN + 缓变相位噪声**：用经典 mCRB (M1)，未显式建模强湍 deep fade / 相位跳变 / 耦合效率起伏的时变统计。jphot 自身也是相位屏数值仿真（非 Gamma-Gamma 解析），无 deep fade 中断率建模（note-L51）。真实星地强湍下 deep fade 期间 FOE 中断会吃掉部分增益 → 本上界偏乐观。
2. **BL² 方差缩减是 FSTS 论文自述机理（jphot-L208）的 CRB 化**，假设二阶 FOE 残余噪声仍高斯、BL 间隔内相位噪声完全相干（缓变假设）。星地 LEO 多普勒时变 + 强湍相位跳变会破坏"缓变"假设（note-L53/L54）→ BL² 实际兑现打折。
3. **CRB→BER 灵敏度 dB 的映射非闭式**：本算用 jphot 自测的 MSE 陡崖(2.5e-7)做封顶，属于"实测锚定的半经验上界"，非纯理论推导。严格映射需 BER-vs-MSE 曲线（jphot Fig.8）的解析拟合，本阶段未做。
4. **CPE 项简化为 ≈0 dB**：基于"等导频长度下 CRB 恒等"论断，未对"FOE 中间量作 CPE 先验"做联合 CRB（多参数 CRB 矩阵）严格推导。若主线需要更紧的上界，应做 [ν, φ] 联合 Fisher 信息矩阵的数值 CRB。
5. **960 sym 点上界(1.0)与实测(1.03)近乎相等**，自洽性虽 PASS 但余量为零；若主线对 960 点敏感，建议补做该点的多参数联合 CRB 以抬高上界余量。320 sym 点余量健康(+0.67 dB)。
