# PROMPT-012 审计报告：双口径重审 S005-S011

## TL;DR

四项结论中：S005“μ 主导”保留但“μ≤1e-3 安全”需修正；D014 的固定标签“断开”需改写为以可恢复交换为主；D015 的 ML 长序列“真失效”被 PI 口径否证；S009/D012 的 N=2M“ML 优于 CMA”在 PI 口径仍成立，但不可外推到任意序列长度。PI-BER 需要 pilot/帧头完成流标识消歧，不是免费性能。

## 对主控决策的建议

1. 可保留论文结论：发散由 μ 主导、f_G 次级；N=2M 且本参数域内 ML 在 PI 口径仍优于 CMA。
2. 必须重写：`μ≤1e-3 安全`改为“低风险而非零风险”；D014“断开”改为“偏振交换，可经 pilot/帧头恢复但有开销”。
3. D015“ML 长序列真失效”不能进论文；应改为“固定标签下发生输出排列交换，PI 后接近 oracle”。
4. ML 卖点只在 N=2M 切片成立；不得据此声称任意长序列免疫 SOP。监督训练、公平性、流标识开销和 GG 跨 seed 方差仍是限制。
