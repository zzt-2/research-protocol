## 0. 决策问题

B2-Q2 双模切换的信号流架构有两种设计：
- **前馈化**：fade 检测门控 + 模式切换不纳入闭环 TF（每块独立估计，无跨块反馈）
- **环路**：把切换动态（fade 检测→切 pilot→恢复→切回 blind）纳入闭环环路 TF

**判定标准**：前馈化合法不撞 D006；环路若等价于"用 TF 纳入湍流相位"则撞 D006。

## 1. D006 红线边界（原文核查）

### 1.1 D006 Kill 的是什么（`decisions.md:313-355`）

> "Kill Q12：分治架构（AO 管湍流 + DPLL 管多普勒）→ **联合建模进 DPLL 环路（把湍流相位 φ_T 纳入环路传递函数 H(z)）**"

D006 Kill 的核心动作 = **"把湍流相位 φ_T 主动纳入同步算法设计"**（无论 KF / 环路 TF / 其他数学工具）。

### 1.2 D006 被排除方向（`decisions.md:340-341`）

> "把湍流相位纳入载波同步算法设计（无论 KF/环路传递函数/其他数学工具）——已被旧 B1 + Q12 双重证伪，除非找到 Q12/KF 之外的**全新机制**（不是单纯换数学工具）"

> L61（B2-Q1）："撞 D006：**不撞**——FOE freeze 是**估计器更新 gating**（控制何时更新），不是'把湍流相位 φ_T 纳入 FOE 算法设计'"
> L68（B2-Q2）："撞 D006：**不撞**——双模切换是估计器选择，不纳入湍流相位"

**关键区分**：
- D006/B1/Q12 = **算法内部建模** φ_T（把 φ_T 当算法状态/参数估计）
- B2-Q2 = **算法外部选择**估计器（按 fade 状态选 blind 或 pilot，估计器内部不碰 φ_T）

## 2. B2-Q2 信号流架构分析

### 2.1 双模切换的信号流（前馈化设计）

```
接收 rx[n]
   │
   ├─→ 功率检测器 P = mean(|rx[n]|²)  ← 开环观测（无反馈）
   │      │
   │      └─→ 门控判决 g(P) = 1[P < γ_th]  ← 开环阈值（无反馈）
   │
   ├─[g=0, 非 fade]→ fft_foe / nda_ml_recovery  ← 前馈闭式估计
   │
   └─[g=1, fade]→ da_ml_recovery / psa_foe_recovery  ← 前馈闭式估计
                                                   │
                                                   └─→ rx_comp（一次性补偿，无跨块反馈）
```

**前馈化特征**：
1. **功率检测是开环观测**：P = mean(|rx[n]|²) 是当前块的统计量，不依赖历史估计
2. **门控判决是开环阈值**：g(P) = 1[P < γ_th]，阈值 γ_th 是预设参数（不是闭环误差驱动）
3. **估计器选择是 switch 不是 feedback**：根据 g 选估计器，选完就跑，跑完输出 rx_comp
4. **补偿是一次性的**：rx_comp = rx · exp(−jφ̂)，无跨块迭代

### 2.2 复用基建 4 估计器全部前馈（`_recovery.py` 核查）

| 估计器 | 行号 | 算法 | 前馈性 |
|---|---|---|---|
| `fft_foe` | L37 | FFT 4 次幂峰值检测 | ✅ 开环一次性（无历史依赖）|
| `nda_ml_recovery` | L171 | 升幂 mean-angle / 块常数 | ✅ 开环块内一次性 |
| `da_ml_recovery` | L136 | pilot 线性回归闭式 (φ, Δf) | ✅ 开环一次性（L154-166 线性回归）|
| `psa_foe_recovery` | L435 | pilot 差分相位最小二乘 | ✅ 开环一次性（L458-466 最小二乘）|

**核查结论**：4 个估计器全部前馈闭式，**无任何环路反馈**。B2-Q2 双模切换基于这些前馈估计器，整体架构天然前馈。

## 3. 前馈化 vs 环路的 D006 判定

### 3.1 前馈化设计（推荐）—— 不撞 D006

**判定**：前馈化 B2-Q2 **不撞 D006**。

**论证**：
1. **算法内部不碰 φ_T**：4 个估计器内部都没把湍流相位 φ_T 当状态/参数（da_ml 估的是 φ + Δf 的总相位，不区分激光相位 vs 湍流相位；fft_foe 估 Δf；nda_ml 估块常数 CPE）
2. **门控是外部选择不是内部建模**：功率阈值 γ_th 只决定"用哪个估计器"，不进入估计器的数学模型。等价于"按 SNR 选调制"——不是"把 SNR 建模进解调器"
3. **无闭环 TF**：信号流是 rx → P → g → 估计器 → rx_comp 的单向链，无 rx_comp → rx 的反馈回路
4. **机制上 ≠ B1/Q12**：B1 是"Kalman 状态扩维含 φ_T"，Q12 是"H(z) 纳入 φ_T"；B2-Q2 是"按 P 选估计器"。三者物理假设不同

**与 sat.1553 L558 的对齐**：
> sat.1553 L558："avoid updating the estimate when signal quality degrades below a certain threshold"

sat.1553 推荐的就是前馈门控（信号质量阈值 → gate 估计器更新），B2-Q2 前馈化与 sat.1553 推荐机制一致。

### 3.2 环路设计（不推荐）—— 撞 D006 风险

**判定**：环路设计**有撞 D006 风险**，需避免。

**风险机制**：
- 如果把"fade 检测→切 pilot→恢复"的切换动态建模成闭环 TF H_switch(z)
- 且 H_switch(z) 的输入是接收信号（含湍流引起 fade），输出驱动估计器切换
- 则 H_switch(z) 实际上在用湍流 fade 动态驱动同步算法 → 等价于"把湍流影响纳入同步算法设计" → 撞 D006

**论证**：D006 的"被排除方向"明确"环路传递函数纳入"在列。环路 H_switch(z) 把 fade（湍流引起）纳入切换动态 = 把湍流影响纳入同步算法设计 = D006 排除方向。

**避免方式**：切换逻辑用开环阈值（g(P) = 1[P < γ_th]），不用闭环误差驱动（如 e = φ̂_blind − φ̂_pilot → 切换）。

## 4. 前馈化后"双模切换"创新是否还成立

**潜在疑虑**：前馈化后 B2-Q2 的"双模切换"是否退化成"两个前馈估计器的简单 switch"，失去创新性？

**论证：创新仍成立**：

1. **创新点在"切换策略"不在"估计器数学"**：
   - 4 个估计器都是已有前馈闭式（非本工作创新）
   - B2-Q2 的创新 = **何时切换 + 切到哪个 + 如何公平对照**（fade 检测门控策略 + 双模架构 + 公平对照框架）
   - 前馈化不影响"切换策略"创新——门控阈值 γ_th 怎么选、fade 占空比怎么算、pilot overhead 怎么摊薄，都是 B2-Q2 的设计决策

2. **与 [79] Matsuda 的差异**：
   - [79] 是"freeze（关断跟踪）"——fade 期什么都不做
   - B2-Q2 是"fallback（切到 pilot）"——fade 期用 pilot-aided 继续跟踪
   - 前馈化后这个差异依然存在（fade 期 [79] hold 上一估计，B2-Q2 切 da_ml/psa_foe）

3. **与 sat.1553 [58] open direction 的对齐**：
   - sat.1553 L440："pilot-based PE could be combined with a second blind phase estimator"
   - B2-Q2 前馈化双模切换正是这个 open direction 的具体实现（前馈 pilot + 前馈 blind + 开环门控组合）
   - 创新性由综述自报 open direction 背书

**结论**：前馈化不削弱 B2-Q2 创新性。创新在切换策略（何时/切哪个/怎么公平对照），不在估计器数学。

## 5. 架构决策

### 5.1 决策：前馈化（INVARIANT 级）

**B2-Q2 采用前馈化架构**：
- 4 估计器全部前馈闭式（基建已具备，`_recovery.py` 核查）
- fade 检测用开环功率阈值 γ_th（不闭环）
- 模式切换是 switch 不是 feedback
- 补偿一次性（无跨块迭代）

**强度标签**：`INVARIANT`（架构约束级，不可推翻）—— 任何后续设计改动若引入闭环反馈（如用 φ̂_blind − φ̂_pilot 误差驱动切换），需重新讨论并可能撞 D006。

### 5.2 sandbox 阶段 1 的架构约束（留给后续）

1. **fade 检测器实现**：功率阈值 g(P) = 1[mean(|rx|²) < γ_th]，γ_th 是预设参数（扫敏感性，不用误差驱动）
2. **切换是无缝的**：非 fade 块用 blind 估计，fade 块用 pilot 估计，块间不传递相位状态（每块独立前馈估计）
3. **"恢复时间"测度的定义**：fade 结束后 N_recover 个符号内 BER 收敛回稳态。这个 N_recover 是观测指标（不是算法参数），前馈架构下恢复时间由估计器块大小决定（N_DFT=256）

### 5.3 风险（留给 sandbox 验证）

- **前馈化可能限制 B2-Q2 的 fade 恢复优势**：如果 [79] Matsuda 的 freeze 机制（hold 上一估计）在恢复期比 B2-Q2 的"切回 blind 重估"更快，则 B2-Q2 前馈化可能在动态恢复维度不优于纯 blind freeze → 阶段 0.1 维度 B 的核心假设需 sandbox 验证
- **门控阈值敏感性**：γ_th 太低漏触发（真 fade 没切），太高误触发（正常波动当 fade）→ sandbox 扫 γ_th ∈ [γ̄−3σ, γ̄−1σ]

## 6. 阶段 0.3 结论

**架构定性完成**：B2-Q2 采用前馈化架构，合法不撞 D006。

**决策记录**：建议在 decisions.md 新建 D002（架构定性 = 前馈化 INVARIANT 级，不撞 D006）。**但本工作对话只定规约不记决策**（决策是主控对话的事，S002 记录后由主控对话核查确认是否升 D002）。

**进阶段 0.4**：公平对照框架设计（baseline / 双测度 / pilot overhead 摊薄 / 叙事定位 / 范围维度）。
