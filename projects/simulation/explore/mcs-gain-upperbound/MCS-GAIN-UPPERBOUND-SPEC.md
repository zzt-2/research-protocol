# ③ MCS 排程增益上界 — 前置门控 SPEC

> 2026-06-17 | 坑6 MVE 前置门控 | 第三腿 ③ 可行性
> 目标：在投入 Groundwork 前，用理论估算确认"仰角感知 MCS 排程 vs 全程最优固定 MCS"的增益上界，避免重演 N1（参数空间不足 FAIL）。

## 假设（P1 假设先行）

**核心假设**：在 LEO 一次过境中，按仰角分段选不同 MCS（调制阶数/编码率），相比全程用同一最优固定 MCS，在过境平均可达速率上有增益。

**上界条件**（oracle，现实会打折扣）：
- 完美知道每段的统计（CSI oracle）
- MCS 切换零开销、零延迟
- 仰角→σ²_R 映射精确（确定性先验）

**上界判据**（若上界都不达标 → 现实更差 → 砍）：
- **>1.0 dB 或平均速率提升 >15% → ③ 进 GW**
- **0.5-1.0 dB / 5-15% → 边缘，需细 MVE**
- **<0.5 dB / <5% → ③ 砍掉**（重演 N1 教训）

## TL-20 物理预期（动手前先写）

1. **仰角变化 → σ²_R 变化**：sec(zeta)^(11/6)，天顶→5° 变化 ~1-88 倍（坑3 已验）
2. **σ²_R 变化 → GG 参数 (a,b) 变化**：强湍流 a,b 小，弱湍流 a,b 大
3. **GG 容量**：弱湍流容量高且稳定，强湍流容量低且波动大
4. **预期增益方向**：全程固定 MCS 受低仰角段拖累（保守）；仰角感知在高仰角段释放容量
5. **预期增益幅度**：不确定 —— 这是本 SPEC 要回答的
6. **物理上界**：若全程用最强 MCS（无 FEC 保护），低仰角段 outage → 吞吐 0；若全程用最保守，高仰角段浪费。增益来自"不浪费" + "不 outage"的权衡空间

## 方案对比设计

### 方案 A：全程最优固定 MCS（baseline，真对手）
- 对每个候选 MCS m，算过境全程 outage 概率 p_out(m)
- 选 m* = argmax_m { 可达速率(m) × (1 - p_out(m)) }
- 这是"聪明的全程固定"，不是随便固定

### 方案 B：仰角感知分段 MCS（oracle 上界）
- 过境按仰角分 N_seg 段（如 N_seg=10）
- 每段独立选最优 MCS
- 总可达速率 = Σ_seg { 速率(m_seg) × (1 - p_out_seg) × 时长权重 }

### 增益
- 增益_dB = 10*log10(速率_B / 速率_A)
- 增益_相对 = (速率_B - 速率_A) / 速率_A

## 扫描参数

- 天顶 σ²_R 基线：0.1, 0.5, 1.0（弱/中/强天顶湍流）
- 最低仰角：10°（典型 LEO 可见弧段下限）
- γ̄ (平均 SNR)：5, 10, 15, 20 dB
- 段数 N_seg：10（一次过境分 10 段）

## 决策树

- 上界增益 ≥1.0 dB 或 ≥15% → ③ **进 GW**（坑6 后续 MVE 验证现实增益）
- 上界增益 0.5-1.0 dB / 5-15% → ③ **边缘**，需更细 MVE 或降级到 ⑦/⑧
- 上界增益 <0.5 dB / <5% → ③ **砍掉**，重演 N1，转 ⑦/⑧
