# B7 阶段 0.3：架构定性（前馈 vs 环路 TF）

> 阶段 0.3 | 专题 `2026-07-08-b7-gardner-ted-foe` | 日期 2026-07-08
> 依据：INVARIANT 12（架构定性前置）+ D006 红线（Kill Q12 联合建模进 DPLL 环路）+ sim-preflight v1.3.0
> 结论：**B7-Q1 走前馈扫频架构（合法不撞 D006）。禁环路实现（环路 TF 含湍流相位则撞 D006）。poster 原算法的"反馈环"部分（Gardner TR）保留作定时恢复子环，但 FOE 主估计算前馈化。**

## 0. 核查触发

INVARIANT 12 要求：B7 锚方法是反馈环（Gardner TED → loop filter → NCO），如果我们的实现也走反馈环，环路 TF 联合建模可能撞 D006。必须在阶段 0.3 定死前馈 vs 环路，禁边跑边定架构（NDA-ML D-002 B11 OFDM→单载波重定位教训）。

## 1. D006 红线精确边界（来自上游决策）

**D006（problem-driven-redirection）Kill 的精确范围**：
- Kill 对象：**把湍流相位 φ_T 纳入载波同步环路传递函数 H(z) 的联合建模**（Q12 "分治架构 AO 管湍流 + DPLL 管多普勒 → 联合建模进 DPLL 环路"）
- Kill 理由：① B1 换皮（跟旧 B1 湍流感知 Kalman CPR 本质假设相同）② Paillier 2020 JLT 证明湍流相位可忽略 ③ S024 KF 压力测试实证湍流感知增益消失
- **Kill 边界**：禁的是"主动建模湍流相位进同步环路"，**不是"所有反馈环"**

**D006 不禁的情况**：
- 反馈环里**不含湍流相位建模**（如纯 Doppler PLL、纯定时恢复环）
- 前馈估计器（无环路 TF）
- 定时恢复环（Gardner TR）—— 环路跟踪的是符号时钟 τ，不是湍流相位 φ_T

## 2. B7 锚方法的架构拆解

B7 DSP 链（poster 行 47）：`proposed FOE → Gardner TR → MIMO EQ → MP FOC → CPR`

| 组件 | 架构 | 环路 TF 含什么 | 撞 D006？ |
|---|---|---|---|
| **proposed FOE**（B7 创新）| poster 是"扫频+双候选+TED2 判决"，**结构上偏前馈**（扫频是开环搜索，不是反馈跟踪）| 无环路 TF（前馈扫频）| 否 |
| Gardner TR [6]（定时恢复）| 反馈环（Gardner TED → loop filter → NCO，见用户代码 Tx2Rx.m L176-214）| 环路跟踪符号时钟 τ | **否**（τ 不是湍流相位 φ_T）|
| MIMO EQ | 前馈（自适应均衡）| 无 | 否 |
| MP FOC [7]（M-th power 频偏细补偿）| 前馈（Leven 2007）| 无 | 否 |
| CPR | poster 未指明（通用占位）| 取决于实现 | 待定 |

**关键观察**：B7 poster 的"反馈环"其实是 **Gardner TR（定时恢复环）**，**不是载波同步环**。Gardner TR 跟踪的是符号时钟 τ，跟 D006 禁的"湍流相位 φ_T 进载波同步环路"是两个不同的环。

## 3. 用户本地代码架构核查（`毕设/旧本科代码/Tx2Rx.m`）

| 代码段 | 架构 | 环路 TF 含什么 | 撞 D006？ |
|---|---|---|---|
| L176-214 定时同步（Gardner TED + NCO + PI 环路滤波器）| 反馈环 | 符号时钟 τ | **否** |
| L228-272 CMA 均衡 | 前馈自适应（LMS 类）| 无 | 否 |
| L275-321 载波同步（PLL 鉴相器 + 环路滤波器）| 反馈环 | **载波相位 θ**（CFO 残余 + 相位噪声）| **边界**（若 θ 含湍流相位则撞；纯激光相位噪声不撞）|

**用户代码的载波同步环（L275-321）**：跟踪的是 `atan2(imag, real)` 即载波相位 θ。在用户代码的 QPSK/16APSK + AWGN 场景下，θ = CFO 残余 + 激光相位噪声，**不含湍流相位**（用户代码无湍流建模）。所以用户代码本身不撞 D006。

**但 B7 迁移到星地场景后**：如果载波同步环的 θ 包含湍流相位 φ_T（星地 FSO 有大气湍流相位扰动），且我们主动建模 φ_T 进环路 TF → 撞 D006。

## 4. B7-Q1 架构决策

### 4.1 决策：FOE 前馈化 + Gardner TR 保留反馈环 + 载波同步禁建模湍流相位

**B7-Q1 实现架构定死**：

| 组件 | 实现 | 理由 |
|---|---|---|
| **proposed FOE（B7 创新）** | **前馈扫频**（CV mult1 扫频→S-curve 峰检测→双候选→TED2 std 判决→输出 f̂_D→前馈补偿 `rx·exp(−j2πf̂_D t)`）| poster 原算法结构本就是扫频搜索（开环），前馈化合法。且前馈避免环路 TF 纠缠 D006 |
| Gardner TR（定时恢复）| **保留反馈环**（用户代码 Tx2Rx.m L176-214 直接复用）| 跟踪符号时钟 τ，不是湍流相位，不撞 D006。反馈环是 Gardner TR 的标准实现，前馈化会破坏定时跟踪能力 |
| 载波同步（CPR）| **前馈 VV/BPS 或反馈 PLL，但禁建模湍流相位**| 若用反馈 PLL，环路只跟 CFO 残余 + 激光相位噪声，**不主动建模 φ_T**（Paillier 经验性忽略，D006 兼容）|

### 4.2 前馈化后 B7 创新点是否还成立？

**成立**。B7 的创新是"复用 Gardner TED 增益做 FOE"（0.2 已验证机制真实 + 弱同族）。这个创新在 FOE 阶段（前馈扫频），跟后级 Gardner TR 的反馈环是**两个独立的处理阶段**：
- FOE 阶段（前馈）：扫频找 f̂_D → 补偿频偏
- Gardner TR 阶段（反馈）：恢复符号定时

前馈化 FOE 不影响 B7 的"TED 增益↔Doppler 映射"创新（0.2a 数值重建就是前馈扫频验证的，周期相关照样成立）。

### 4.3 跟 D006 的边界声明

**B7-Q1 不撞 D006**，因为：
1. B7 锚方法本身**不涉湍流建模**（poster 实验室纯 Doppler 模拟，无幅度/相位衰落）—— `_B7-gardner-ted-increment.md` 关键发现 5 已确认
2. 我们的实现**FOE 前馈化**，无环路 TF
3. Gardner TR 反馈环跟踪 τ（符号时钟），不是 φ_T（湍流相位）
4. 载波同步环（若用反馈 PLL）**不主动建模湍流相位**（Paillier 经验性忽略）

**唯一撞 D006 的情形**（禁）：若实现时把星地湍流相位 φ_T 主动纳入载波同步环路 TF 联合建模 → 撞 D006。这不在 B7-Q1 范围内（B7-Q1 是 Doppler FOE，不是湍流）。

## 5. 阶段 0.3 判定

| 维度 | 判定 | 依据 |
|---|---|---|
| B7-Q1 FOE 架构 | **前馈扫频**（合法）| poster 原算法是开环扫频；前馈避免环路 TF 纠缠 |
| Gardner TR 架构 | **保留反馈环**（合法）| 跟踪 τ 不是 φ_T，不撞 D006 |
| 载波同步环架构 | 前馈 VV/BPS 或反馈 PLL（禁建模 φ_T）| D006 边界 |
| 撞 D006？ | **否** | B7 不涉湍流 + FOE 前馈 + TR 跟踪 τ |
| B7 创新点在前馈化后是否成立 | **成立** | 0.2a 数值重建就是前馈扫频验证的 |

**门控结论**：0.3 通过，架构定性完成。进 0.4 公平对照框架。
