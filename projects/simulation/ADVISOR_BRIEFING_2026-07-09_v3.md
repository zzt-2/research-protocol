## 一句话

星地自由空间光通信（FSO）的强湍流场景下，我们发现**盲载波相位估计（不用导频）比导频辅助估计有约 +1.2 dB 的净增益**（强湍流，已扣除导频占用的功率开销），并在此基础上提出**按每个数据块的信号质量自动切换两种估计器的方法**，在两法各有优势的工作区稳定改善 +0.27~0.48 dB。**计划投 CCISP 2026 会议（合肥 11 月，IEEE + EI + Scopus 检索）。**

## 1. 我们的工作（两个部分）

我们的工作有两个部分，性质不同。**想请老师定主卖哪个**（见 §5 第 1 问）。

### 第一部分：净增益（net gain）——强湍流下盲估计比导频估计好多少

载波相位恢复（CPR，Carrier Phase Recovery）是相干光通信接收端的关键步骤。它有两种基本思路：

| | 导频辅助估计（DA-ML，Data-Aided Maximum Likelihood）| 盲估计（NDA-ML，Non-Data-Aided Maximum Likelihood）|
|---|---|---|
| 怎么估相位 | 发送端**插入已知的导频符号**，接收端用导频直接估 | **不发导频**，用整个数据块的信号自己估 |
| 代价 | 导频**占用信号资源**（我们仿真里占 1.25 dB 的功率开销）| 不占用资源，但低信号质量时可能估不准 |
| 传统认知 | 光纤/弱湍流里**导频稳赢** | 恒参信道里没必要 |

**我们发现**：到了星地 FSO **强湍流**，信号会深度衰落（deep fade，深度衰落）。这时如果导频那段恰好落进衰落区，**导频本身就废了**，导频估计会崩溃；而盲估计用整个数据块积分，衰落只影响块的一部分，**盲估计反而更稳**。

**净增益（net gain）**衡量的是：强湍流下，盲估计相对导频的优势，**扣掉导频先天吃掉的功率开销（1.25 dB）后，净剩多少**。

> 公式：net gain =（达到相同误码率，导频法所需 SNR）−（盲法所需 SNR）− 1.25 dB（导频开销）

**结果（30 seed 蒙特卡洛）**：

| 场景 | 净增益（dB）| 含义 |
|---|---|---|
| 无湍流（AWGN）| +0.09 | 盲 ≈ 导频，无显著差异 |
| 弱湍流（下行）| +0.18 | 不显著 |
| 中湍流（下行）| +0.19 | 不显著 |
| **强湍流（下行）** | **+1.26** | **盲明显赢** |
| **强湍流（上行）** | **+1.85** | **更明显** |

**诚实说明**：弱湍流/无湍流净增益仅 ~0.1 dB，统计上不显著，我们承认这俩场景没有真实优势。趋势是"弱湍流平 → 强湍流跳"，不是严格单调。强湍流的 +1.2 dB 有明确的物理机制（deep fade 击穿导频），调参救不了（我们做过线宽敏感性分析，见 §4）。

**这一部分的对比方法（baseline）= 导频辅助估计 DA-ML**（导频插入间隔 = 4，近最优配置）。

### 第二部分：切换方法——按块信号质量自动选估计器

回到第一部分的背景：强湍流下，盲估计和导频估计**各有赢的区间**：

| 信号条件 | 谁赢 | 为什么 |
|---|---|---|
| 块信号质量差（deep fade 或低 SNR）| **导频赢** | 信号太差盲估计凑不准；导频是"硬锚"，再差有已知参考兜底 |
| 块信号质量好 | **盲赢** | 信号好了盲估计够准，还省 1.25 dB 导频开销 |

**关键现象**：存在一个切换点——按每个数据块的信号质量（块内有效信噪比）判断，低于约 12-14 dB 时导频赢，高于时盲赢。这个切换点在不同湍流场景下**几乎汇聚到同一处**，意味着用一个固定阈值就能切换。

**我们提出的方法**：接收端每收到一个数据块，先测它的块内有效信噪比（这个量接收端自己能测，不需要知道真实信道），然后：
- 有效信噪比 < 阈值 → 用导频估计
- 有效信噪比 ≥ 阈值 → 用盲估计

这样每个块都用了"当前更优的那个估计器"。

**结果（30 seed）**：

| 场景 | 切换方法 vs "始终用固定一种"的增益（dB）|
|---|---|
| 弱湍流 | +0.27 |
| 中湍流 | +0.48 |
| 强湍流 | +0.40 |

三个场景的 95% 置信区间下界全为正，统计上显著优于"始终用一种"。

**这一部分的对比方法 = 固定导频估计 / 固定盲估计**（"不做切换"的固定版本）。

### 两部分的关系（我们的判断，请老师把关）

我们的倾向：**两部分咬合讲，切换方法是外壳，净增益是数字亮点**。理由：

- **第一部分（净增益 +1.2 dB）是优势的来源**：强湍流下盲估计固有比导频好，我们做了量化和物理归因
- **第二部分（切换方法）是把这个优势落地的工程方案，也是净增益能拿到的前提**：我们实测确认，如果不切换、全程用盲，低信号质量区盲会崩（误码率比导频还差——低 SNR 区导频赢、高 SNR 区盲赢的交叉点真实存在）。所以切换不是锦上添花，是"让系统能用上盲的固有优势"的必要条件
- **这样讲的好处**：贡献干净（切换是我们提出的方法）+ 数字有力（+1.2 dB）+ 诚信守住（诚实标注 +1.2 dB 的来源是盲估计固有性质，切换方法自身的独立增量是 +0.27~0.48 dB）

**标题数字用去导频开销的 +1.2 dB**（强湍流），不用含导频水分的总 +2.5 dB——诚实且不易被一票否决。

> 请老师定：这个"切换外壳 + 净增益亮点"的咬合讲法行不行？还是只卖其中一部分？（见 §5 第 1 问）

## 2. 误码率（BER）曲线的处理（想请老师定，见 §5 第 2 问）

老师之前要求：**有编译码（FEC）的情况下，误码率不能停在 10⁻²，10⁻⁵ 是底线**。我们按这个要求补了高信噪比点（5 seed 探索性补点），结果如下：

| 场景 | 最低 BER（补点后）| 到 10⁻⁵ 了吗 |
|---|---|---|
| 无湍流 | 远超（26 dB+ 全零错）| ✅ |
| 弱湍流 | 远超（40 dB 全零错）| ✅ |
| 中湍流 | 8.3×10⁻⁶（46 dB，刚跨过 10⁻⁵）| ✅ |
| **强湍流（下行）** | **2.0×10⁻⁴（50 dB）** | **❌ 到不了** |
| 强湍流（上行中）| 1.6×10⁻⁴（50 dB）| ❌ 到不了 |
| 强湍流（上行强）| 1.0×10⁻³（50 dB）| ❌ 到不了 |

**为什么强湍流到不了 10⁻⁵**：原以为强湍流有"误码率地板"（deep fade 把误码率卡死），**实测推翻了这个预判**——误码率随信噪比全程单调下降，**没有地板，只是衰减慢**（每 +2 dB 误码率降 ~1.4 倍，而轻湍流降 ~3 倍）。外推到 10⁻⁵ 需要 64~81 dB 信噪比，远超实际系统工作区。

**所以现在的状况**：3 个场景（无湍流/弱/中）的曲线能画到 10⁻⁵ 以下，符合老师要求；3 个强湍流场景画不到，但**这恰恰是 deep fade 现象的可视证据**——强湍流下载波相位恢复的固有难点。配图里强湍流子图上，盲估计贴着理想上界（50 dB 处 NDA/理想 = 1.04），导频退化明显（DA/理想 = 1.99），正好反衬出盲在深衰落区的鲁棒性。

**当前 BER 补点是 5 seed 探索性**（看趋势够），若老师要求正式统计可升级到 30 seed（种子策略已对齐）。

## 4. 新颖性

**单载波载波相位恢复里，导频和盲之间按块硬切换，没有人做过。** 最接近的三类都不是切换：
- **静态比较**（Song 2020）：比较导频 vs 盲后选一个全局用，不切换
- **级联组合**（Moretti 2013 TWC）：导频粗估 + 判决/BPS 细估，两个同时跑，付双倍复杂度
- **单算法内自适应参数**（窗长/环路带宽调参）：单一算法内调参，不跨算法切换

**为什么没有人做**：光纤恒参信道里导频几乎总赢，没有切换的动机。切换机会是 FSO 强湍流特有的（块信噪比大幅波动才有 crossover）。

**线宽敏感性分析**（守诚信，证明 +1.2 dB 不是参数调出来的）：当前激光器线宽 10 kHz 已在盲估计的最优工作区，把线宽加到 500 kHz 盲估计会崩溃（−0.82 dB），说明 +1.2 dB 是物理机制不是调参花招。
