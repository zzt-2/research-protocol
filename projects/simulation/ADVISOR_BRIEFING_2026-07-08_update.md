## 一、一句话现状

我的方法（单载波时域 NDA-ML）**和传统 pilot-aided（DA-ML）比，下行 4 场景省 1.35–2.5 dB、上行 2 场景省 2.5–3.1 dB 功率**（统计显著，这是真增量）；**和经典盲估计 VV/BPS 比，全场景基本持平**（差距 0.006–0.14 dB，统计上接近不可区分）。而且核查还发现：**VV 把滑窗长度从默认 64 调到 16，高相位噪声场景下 VV 反超我的方法 14%–68%**。也就是说，我的方法在估计器精度上不仅没超过经典方法，VV 调参还能赢回来。**唯一真实的增量来自"不用 pilot"这个系统选择，不是估计器算法本身的进步。我想请老师定的是：在这个完整真相下，方向作为学位论文够不够，要不要调整。**

## 二、这一轮做了什么（为什么之前没说清楚）

旧简报（07-06）写的是"赢 BPS、与 VV 持平偏赢"，措辞偏乐观。这一轮（07-07~08）做了三件核查，把真相查清了：

### 2.1 参数统一重跑（D-007）

旧简报的 AWGN 场景沿用了参考论文的参数（25 GBaud / 500 kHz 线宽，OFDM 场景），和我们的湍流场景（2.5 GBaud / 10 kHz，单载波）不一致——同一个"激光线宽"在两条路径里数值差 50 倍，跨场景比较不可信。这一轮统一到单载波参数（2.5 GBaud / 10 kHz，全场景一致），主实验、所有 baseline 对比、线宽扫描全部重跑。

**重跑后主结论不变**：vs DA-ML 的增益稳住甚至略升（AWGN +1.351 dB，下面§三详述）。

### 2.2 发现并核查一个实现 bug（D-008）

我把参考论文（Du 2025, IEEE PTL）的"ML 加权"公式实现错了两个地方：
- 参考论文的 ML 估计用了 |R(k)|² 加权（论文 Eq.16），我实现成等权
- 参考论文升幂前先归一化幅度（论文 Eq.5），我没归一化

这两个 bug 叠加的结果是：**我的"ML"实际上退化成了 VV 的等权 mean-angle 形式**。这就是为啥跟 VV 持平——不是物理巧合，是实现退化成了它的同族。

### 2.3 修对加权后重测（D-009 sandbox 验证）

修对加权之后，三方对照（我的方法-加权版 / 等权版 / VV）跑了线宽扫描（10 kHz–500 kHz）、调制阶数扫描、湍流场景扫描，共 11 个点。结果：

- **加权版 vs 等权版：11 个点全部差距 ≤ 1.7%**——修对加权几乎没区别
- **加权版 vs VV：在 10–100 kHz 区间全部持平（差距 < 5%）**；只有到 200 kHz 以上才拉开（−14% ~ −19%）

也就是说，**在我们这个场景（10 kHz、单载波、(8,8)-16APSK）下，ML 加权这个理论改进物理上看不到收益**。原因是 ML 加权的增益来自样本幅度的不均匀，而低线宽单载波下样本幅度近似均匀，加权退化成等权。

### 2.4 进一步验证两件事（2026-07-08 续）

我自己的判断一开始还不死心，又验证了两件事，结果都坐实了"算法层没真增量"：

**(a) 上行场景对照**：老师 2026-07-07 反馈说上行受湍流影响更大，我当时补跑过上行 vs DA-ML（+2.48/+3.07 dB，旧简报有），但**没对照过 VV/BPS**。这次补上：上行 uplink_moderate / uplink_strong 工作区，NDA-ML vs VV +0.090/+0.119 dB，vs BPS +0.113/+0.141 dB——**仍然持平**，跟下行一致。上行更强的湍流衰落并没有让我的方法拉开经典盲估计。

**(b) VV 滑窗长度 Nw 调优对照**：之前发现"我的方法在高线宽（≥200 kHz）下 BER 比 VV 默认参数低 14%–18%"，一度以为这是真增量。但怀疑可能是 VV 默认参数（Nw=64）太保守，于是扫了 VV 的 Nw（8/16/32/64/128）。**结果**：VV 把 Nw 从 64 调到 16，立刻反超我的方法——200 kHz 时 VV BER 比我的低 14%，500 kHz 时低 **68%**。也就是说之前看到的"segmented 跟踪拉开 VV"**完全是 VV 参数没调好的伪增量**，VV 一调参就赢回来。

这两件事合起来，把我能想到的算法层增量空间（加权 / 块内跟踪 / 上行场景 / 高线宽 niche）**全部堵死了**。结论很硬：**NDA-ML 在估计器精度上跟 VV/BPS 同族持平，VV 调参就赢，没有"超经典方法"的硬增量。**

老师 2026-07-07 反馈触发上行验证。5 种子，工作区（γ_tot ≥ 15 dB）fair gain，数据源 `results/sc_nda_ml_uplink/` + 本轮 sandbox：

|---|---|---|---|---|---|---|

**结论跟下行一致**：NDA-ML vs VV/BPS 持平（< 0.15 dB），vs DA-ML 拉开（+2.5~3.1 dB）。上行更强的湍流衰落没改变这个格局——**频谱效率增量在上下行都成立且更显著**（上行 deep fade 更伤 DA-ML 的 pilot 机制），但估计器精度增量仍然没有。

### 3.5 VV 滑窗参数 Nw 调优对照（关键，防"伪增量"）

这是这一轮最重要的核查。之前一度发现"我的方法在高线宽（≥200 kHz）下 BER 比 VV 默认参数低 14%–18%"，怀疑是我自创的"块内分段跟踪"机制有真增量。但 VV 的滑窗长度 Nw 是可调参数，默认 Nw=64 偏保守。扫 Nw 后（AWGN 18 dB，单 seed 看趋势）：

| 线宽 | 我的 NDA-segmented | VV Nw=64（默认）| **VV Nw=16（调优）** | VV Nw=8 |
|---|---|---|---|---|
| 200 kHz | 4.62e-3 | 5.36e-3（输我 16%）| **3.98e-3（赢我 14%）** | 1.51e-2（输我）|
| 500 kHz | 1.81e-2 | 2.21e-2（输我 22%）| **5.89e-3（赢我 68%）** | 1.50e-2（输我）|

**VV 调到 Nw=16 立刻反超**。也就是说之前看到的"segmented 拉开 VV"完全是 VV 默认参数保守的伪增量，**我的块内分段跟踪机制跟 VV 滑窗本质同类，没真优势**。这把我能想到的"算法层创新"候选（加权 / 分段跟踪 / 高线宽 niche）全部堵死了。

### 3.6 为什么跟 VV 持平（物理原因，不是 bug）

VV（Viterbi-Viterbi 1983）是"升 M 次幂 + 等权 mean-angle"的祖师爷方法。我的 NDA-ML 本质也是"升幂 + mean-angle"，差别只是 ML 理论上该用 |R(k)|² 加权。但：

- **单载波时域 + 低线宽（10 kHz）下，样本幅度近似均匀，ML 加权退化成等权** → 数值上跟 VV 等价
- 只有在 OFDM 频域（参考论文的场景，子载波 SNR 不均匀）或多环幅度离散显著时，加权才有收益

我做了文献核查确认这是**领域共识**，不是我的方法特别差：Rice 等人 2022（IEEE Aerospace）明确写"在高 SNR 下，所有相位误差检测器（包括 ML 和 VV 类）性能趋同"。近年（2020+）单载波 NDA-ML 论文**基本不拿'超过 VV 多少 dB'当卖点**，靠的是 ML 最优性、场景迁移、联合估计、能效等。**而且 §3.5 已经验证：VV 调一下 Nw 就能反超我的方法**——所以"跟 VV 持平"不只是"没赢"，是"VV 调参就赢我们"。这是这一轮最重要的一个硬事实。

## 四、我自己的判断（这次不藏，把最糟的也说清楚）

这一轮把能想到的算法层增量候选（ML 加权、块内分段跟踪、高线宽 niche、上行场景）全部验证完了，**全部堵死**。现在的完整真相是：

**真有的**（稳健，统计显著，跨场景）：
- vs DA-ML 频谱效率增量：下行 +1.35~2.5 dB、上行 +2.5~3.1 dB。这是"不用 pilot"省下 25% overhead 的真实系统收益，DA-ML 的 pilot 在 deep fade 块还会崩，所以湍流越强 NDA 优势越大。
- (8,8)-16APSK + 单载波 NDA-ML + 星地 FSO 湍流的场景组合，文献空白（2020+ 没人做完全一样的）。
- 完整的 FOE+CPE+resolve 流水线在 4+2 场景验证可用。

**没有的**（验证完确认没有）：
- 估计器精度上**没有任何超过经典盲估计 VV/BPS 的硬增量**。全场景持平（0.006~0.14 dB），而且 VV 调 Nw=16 就能反超我们。
- ML 加权（参考论文 B11 的核心创新）在单载波时域**全线无用**（11 点差距 ≤1.7%）。
- 我自创的块内分段跟踪**跟 VV 滑窗本质同类**，VV 调参就赢。

**我的诚实判断**：

按"务实毕业"的标准（之前和老师沟通过的路线：赢传统 baseline 几 dB + 场景迁移就够发），这个方向**现在就够发会议**——主卖点 vs DA-ML 系统增量 +1.35~3.1 dB 是真贡献，VV/BPS 写成"盲估计器类内同档对照"（领域惯例，不是污点）。这条路 D005 务实路线一直成立，不需要新工作量。

但我必须诚实告诉老师一个担心：**如果学位论文的期望是"算法本身有显著创新"**（比如提出新机制、或超过经典方法若干 dB），那在当前场景下做不到——所有算法层增量空间都被堵死了，核心收益来自"去掉 pilot"这个系统选择。这种情况下可能要调整方向，但我备选的几条路（改进 VV 的 LMMSE、Gardner TED 频偏、联合估计）成功率都不高——LMMSE 在低线宽大概率跟加权一样退化（同物理机制），改进 VV 本身也难超 VV 最优。

所以我这次想请老师定的核心问题是：**在"算法层没真增量、唯一卖点是系统层 vs DA-ML"这个完整真相下，这个方向继续往下做（写论文/深化）够不够，还是该调整方向。**
