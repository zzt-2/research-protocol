## 1. 章节叙事大纲 (A+B 框架)

### 1.1 Introduction 叙事线

**问题背景 (2段)**
- LEO 星座规模快速增长（Starlink 4000+, OneWeb 648→规划数千），路由成为瓶颈
- ISL 因轨道力学、硬件故障、天气等因素频繁中断（经验值 5-15%），静态路由（ECMP/SP）无法自适应

**问题定义 (1段)**
- 核心矛盾：路由决策需要在"全局负载感知"和"实时响应"之间取得平衡
  - 全局 TE（如 TELGEN）需要离线求解每个快照，无法应对突发故障
  - 分布式逐跳（如 GRLR）信息局部，无法避免拥塞热点
  - 域间路由（如 DTAR）粒度太粗，域内仍用 SP/ECMP

**研究空白 (1段)**
- 现有 GNN+LEO 路由工作的三个不足：
  1. 无故障弹性验证：多数在无故障/低故障场景测试，未系统验证 0-15% 故障率下的鲁棒性
  2. 无在线逐流决策：per-path 流量分割依赖预计算路径集，per-hop 逐跳无法做多路分流
  3. 无跨规模部署：每星座单独训练，无法零样本部署到不同规模

**本文贡献 (1段)**
- 三级贡献递进：
  1. **故障弹性路由**（主）：GNN per-flow K-path 框架在 0-15% 故障率和 20× 流量突发下，E2E 延迟比 ECMP 低 20%（GNN/ECMP delay = 0.80），MLU 降低 4-13%
  2. **在线逐流决策**（次）：每条流到达时独立路由，单次前向传播（1-2ms CPU），故障响应比 ECMP 重算快 7.7×
  3. **跨规模零样本部署**（辅）：66 星训练 → 48-720 星部署，0.7× 规模 delay 降低 17%，4.4× 规模 delay 降低 75%

### 1.2 System Model 叙事

**星座模型**
- Walker-Delta 物理仿真：alt=550km, inc=86.4°, F=1
- 极地间隙：纬度 > 70° 的 ISL 断开（模拟轨道面间几何不可达）
- ISL 模型：面内链路（固定邻居）+ 面间链路（物理距离加权）
- 训练规模：P=6, S=11 (66 星)；泛化测试：48(P=4,S=12) / 288(P=12,S=24) / 720(P=18,S=40)
- 选择理由：Walker-Delta 是最广泛使用的 LEO 星座拓扑（DTAR/GMR/PRIMAL 均使用）

**流量模型**
- 非均匀热点流量：25% 重型流 + 热点目的地（默认 3 热点 + 10 重型）
- 突发因子：surge_factor ∈ {1, 20}（默认 1.0，鲁棒性测试 20.0）
- 每 episode 40 条流，逐流顺序路由

**故障模型**
- 链路故障率 ∈ {0%, 5%, 8%, 10%, 15%}
- 三种故障模式：random（独立随机）、regional（同一轨道面集中故障）、cascading（级联扩散）
- 故障在 episode 开始时确定，路由过程中固定

**延迟模型**
- E2E 延迟 = Σ(propagation_delay × congestion_factor)，对每条链路：
  - propagation_delay = distance_km / c（光速）
  - congestion_factor = 1/(1 - utilization)，利用率为 1 时封顶为 100×
- **为什么用 E2E delay 而非 MLU ratio 作为主指标**：
  - 文献调研（8 篇）：LEO 路由领域（GRLR, PRIMAL, GNN-MPTE）主流指标为 E2E delay、throughput、packet loss；MLU ratio 仅为互联网 TE 领域（PathGNN, LARRI）使用
  - 纯传播延迟下 GNN 反而比 ECMP 高 20%（GNN 绕路避拥塞），但实际网络中拥塞链路的排队延迟远大于传播延迟差异
- **congestion_factor 的定位**：
  - `1/(1-util)` 不是对物理排队延迟的精确建模（我们的仿真中路由是确定性逐流顺序路由，非泊松到达），而是一个**拥塞惩罚权重**——利用率越高，该链路对 E2E 延迟的贡献越大
  - 选择此函数形式因为它定性反映了真实网络行为：`1/(1-util)` 在 util=0.8 时放大 5×，util=0.95 时放大 20×，高利用率链路的延迟惩罚指数增长
  - 替代方案对比：线性模型 `1 + α·util²` 在 α=1 时 GNN/ECMP delay=1.14（GNN 仍输），说明线性模型不够捕捉拥塞效应对路由决策的区分度

**问题形式化**
- 主优化目标：min E2E delay（传播延迟 × 拥塞惩罚权重）
- 辅助指标：min MLU = max_e (load_e / capacity_e)
- 约束：流完整性（每条流必须从源到目的），链路容量
- 决策：per-flow，从 K 条候选路径中选择一条

### 1.3 Method 叙事

**架构概览（1段 + 图）**
- GAT encoder（L=2 层，H=4 头，d=64）→ 全局链路/节点嵌入
- PathScoringHead：对每条流的 K=4 候选路径，用路径上边嵌入的均值做评分
- PPO 训练，Welford 奖励归一化，增量奖励 r = -(MLU_after - MLU_before)

**设计理由（2段）**
- 为什么 per-flow K-path 而非 per-edge weight：
  - K-path 天然保证路径可达性（候选路径由 BFS 预计算）
  - 离散选择比连续分割更稳定（避免 GMR 的 per-path splitting 不收敛问题）
  - 与 ECMP 的 K 候选路径范式一致，对比公平
- 为什么 GAT 而非 GCN/MPNN：
  - 注意力机制可学习故障链路的权重降低（GCN 等权聚合无法做到）
  - 边特征直接参与消息传递（故障状态、当前负载）
  - DTAR/GRLR 均验证 GAT 在 LEO 路由中优于 GCN

**在线决策流程（1段）**
- 每条流到达 → GNN 一次编码（跨流共享）→ PathScoringHead 独立评分 → 选最高分路径
- 关键：编码一次，评分 F 次（O(L·E·d²) + O(F·K·d)）
- 故障发生时无需重算路径集（候选路径由拓扑确定），只需重新编码

**跨规模泛化机制（1段）**
- GNN 参数与节点/边数无关（shared weights across all nodes/edges）
- 66 星训练的模型直接部署到 48-720 星
- Walker-Delta 族内约束：同 F=1 拓扑结构 + 极地间隙模式
- 不声称"结构泛化"（不同拓扑族需重新训练）

### 1.4 Experiments 叙事

**实验设计（表）**

| 实验 | 目的 | 规模 | 条件 |
|------|------|------|------|
| E01 | 核心优势 | 66 | 8% fault, surge=1 |
| E02 | 无故障基线 | 66 | 0% fault |
| E03 | 突发鲁棒性 | 66 | 8% fault, surge=20 |
| E04-E06 | 跨规模泛化 | 48/288/720 | 8% fault |
| E08 | 故障率消融 | 66 | 0-15% |
| E09 | 流量模式消融 | 66 | 均匀→重型 |
| E10 | GNN 层数 | 66 | L∈{1,2,3} |
| E11 | 注意力头数 | 66 | H∈{2,4,8} |
| E12 | 故障模式对比 | 66 | random/regional/cascading × 4 故障率 |

**核心结果（E01，3 seeds × 800ep）**

| 指标 | GNN | ECMP | MLP | GNN/ECMP | GNN/MLP |
|------|-----|------|-----|----------|---------|
| MLU | 1.378 ± 0.047 | 1.436 | 1.637 | **0.96** | **0.84** |
| E2E delay (ms) | 137 | 171 | 373 | **0.80** | **0.37** |
| CV | 0.855 | 1.028 | 1.035 | — | — |
| Overflow | 2.1% | 2.5% | 4.1% | — | — |

- GNN 的 MLU 改善有限（4%），但 E2E delay 改善显著（20%）
- **关键发现链**：旧拓扑（4-regular 抽象网格）下 GNN/ECMP=0.78，升级到物理仿真拓扑后 MLU 优势缩水到 0.96。根因：极地间隙限制了路由选择空间，ECMP 在规则拓扑上已接近最优。但 GNN 的负载均衡质量（CV 0.85 vs 1.03）远优于 ECMP，这一优势在拥塞延迟维度被放大——高利用率链路的延迟惩罚指数增长，GNN 避免拥塞热点 → delay 大幅下降。
- MLP delay 是 GNN 的 2.7 倍，说明 message passing 对延迟优化的关键作用

**故障激活效应（E02 + E08）**
- E02（无故障）：GNN/ECMP MLU = 1.018，ECMP 略优。无故障时拓扑规则（极地间隙虽存在但固定），ECMP 等价路径机制天然有效，GNN 的自适应能力无用武之地。
- E08（故障率 0-15%）：GNN 在所有故障率下均优于 ECMP（GNN/ECMP 0.87-0.97）。故障打破拓扑规则性 → ECMP 等价路径减少 → GNN 的负载感知选路开始发挥优势。
- 15% 故障率下 GNN/ECMP = 0.866（最大优势），确认故障是 GNN 优势的激活条件。
- E03（surge=20×）：GNN/ECMP = 0.973，极端突发下 GNN 仍保持优势。
- **E02 vs E08@0% 数值差异说明**：E02（GNN/ECMP=1.018）与 E08@0%（GNN/ECMP=0.931）虽同为"无故障"条件，但来自不同实验批次——E02 是核心实验 E01 的对照（同一批 3-seed × 800ep 运行），E08 是故障率扫描实验的 0% 数据点（独立运行序列）。两者的流量随机种子和 episode 数量不同，导致 GNN/ECMP 比值差异。E02 更适合作为"无故障基线"参照，因为它与核心实验 E01 使用完全相同的实验配置和种子。
- **叙事**：这恰好是 Ch3 要解决的问题——不是"GNN 无条件优于 ECMP"，而是"**在链路故障和突发拥塞场景下，GNN 的自适应能力提供了 ECMP 无法实现的延迟优化**"。无故障时 GNN≈ECMP 说明模型没有学到无意义的策略（不会在不需要时过度干预）。

**跨规模泛化（E04-E06）**

| 规模 | GNN MLU | ECMP MLU | GNN/ECMP MLU | GNN delay | ECMP delay | GNN/ECMP delay |
|------|---------|----------|-------------|-----------|------------|----------------|
| 0.7× (48) | 1.508 | 1.644 | **0.917** | 247 | 296 | **0.83** |
| 1.0× (66) | 1.378 | 1.436 | **0.960** | 137 | 171 | **0.80** |
| 4.4× (288) | 4.282 | 4.331 | **0.989** | 1051 | 4222 | **0.25** |
| 10.9× (720) | 5.008 | 4.519 | 1.108 | 507 | 517 | 0.98 |

- MLP 对照：48 节点 MLP(zero-shot) = 1.843（GNN/MLP = 0.82），288 节点 MLP = 4.770（GNN/MLP = 0.90）
- 288 节点：MLU 差距不大（0.989），但 GNN delay 仅为 ECMP 的 25%——负载分布差异在 delay 维度被放大
- 720 节点：10.9× 跨度过大，GNN MLU 反超 ECMP，delay 基本持平。泛化在此规模退化。
- 结论：零样本泛化在 0.7×-4.4× 有效（delay 持续优势），10.9× 退化（需 fine-tune 或增大训练规模）

**故障模式对比（E12，12 组）**
- GNN 在 11/12 组中 MLU 优于 ECMP（唯一失利：cascading 15%，GNN/ECMP = 1.008）
- Regional 模式：GNN 优势最大（0.853-0.909），因区域故障打破 ECMP 的等价路径
- Random 模式：GNN 全面占优（0.884-0.914）
- Cascading 模式：高故障率下 MLU 急剧下降（大量链路中断），GNN/ECMP 接近 1.0

**架构消融（E10-E11）**
- 层数 L∈{1,2,3}：MLU = 1.429 / 1.408 / 1.354。3 层最优（更多消息传递轮次捕获远端信息）。
- 头数 H∈{2,4,8}：MLU = 1.367 / 1.385 / 1.399。2 头略优，架构对超参不敏感（差异 < 4%）。
- 默认配置 L=2, H=4 是合理的折中（训练效率 + 性能）。

### 1.5 Conclusion 叙事

**三句话总结**
1. 提出 GNN per-flow K-path 路由框架，在 Walker-Delta LEO 星座物理仿真中实现故障弹性在线路由，E2E 延迟较 ECMP 降低 20%
2. 故障是 GNN 优势的激活条件：无故障时 GNN ≈ ECMP，有故障时 GNN 在所有故障率和故障模式下全面优于 ECMP（11/12 组）
3. 零样本跨规模部署在 0.7×-4.4× 有效（delay 优势 17%-75%），GNN message passing 的全局聚合能力是关键

**未来工作**
- 非 Walker-Delta 拓扑族的泛化（极地轨道等）
- 10.9× 大跨度泛化的 fine-tune 策略
- 多目标路由（delay + MLU + 能耗）

## 2. DTAR 讨论 (Related Work)

### 定位

DTAR (Zhou 2026, arXiv:2604.12382) 不作为 baseline 直接对比，而是在 Related Work 详细讨论粒度差异。理由：

1. **问题建模不同**：DTAR 解决域间路由（inter-domain），本研究解决全网逐流路由（intra-domain per-flow）。两者不在同一问题空间。
2. **粒度差异**：DTAR 的路由单元是"域"（18 域，288 星），域内仍用最短路径；本研究的路由单元是"流"，直接在全网层面做负载均衡。
3. **强行对比的风险**：DTAR 的域划分 + 域间路由是两阶段方案，直接对比路由阶段不公平（DTAR 的域划分已经做了负载均衡的粗粒度优化），对比整体又混淆了域划分和路由的贡献。

### Related Work 讨论文本

> **域间路由方法**。DTAR [Zhou 2026] 提出两阶段框架：离线 NSGA-II 域划分（双目标：最大化域间流量比、最小化负载偏差）+ 在线 GAT+PPO 域间路由。DTAR 验证了 GNN 在 LEO 域间路由中的有效性，但域内路由仍依赖最短路径，无法实现全网范围的负载均衡。本研究采用的逐流 K-path 路由直接在全网层面决策，避免了域划分引入的粒度损失，更适合链路故障频繁的场景——故障可能发生在任意链路上，域内链路故障无法被域间路由响应。
>
> DTAR 的 action masking（基于物理可达性和跳数约束）和 GAT+LayerNorm+Residual 架构是值得借鉴的设计。本文的 PathScoringHead 通过路径可达性预筛实现了类似的效果：只有 BFS 可达的路径才进入候选集。

### 对比维度表

| 维度 | DTAR | 本文 |
|------|------|------|
| 路由粒度 | 域间（18 域） | 全网逐流 |
| 域内路由 | 最短路径 | N/A（无域划分） |
| 故障处理 | action masking | BFS 候选路径 + GNN 编码 |
| 规模 | 288 星 | 48-720 星（泛化） |
| GNN 架构 | GAT (2L, 4H, d=64) | GAT (2L, 4H, d=64) |
| 训练方式 | PPO | PPO |
| 在线/离线 | 在线 | 在线 |
| 拓扑 | Walker-Delta 仿真 | Walker-Delta 物理仿真（含极地间隙） |

## 3. TELGEN 对比表

### 定位

TELGEN (Zhou 2025, IEEE/ACM ToN) 是最直接的竞品。不回避对比，但强调问题设置的差异而非方法优劣。

### 方法特性对比表

| 维度 | TELGEN [Zhou 2025] | 本文 |
|------|-------------------|------|
| **问题类型** | 流量工程 (TE) | 拥塞感知路由 |
| **决策粒度** | per-path 流量分割 | per-flow 路径选择 |
| **优化方式** | 离线监督学习 | 在线 DRL (PPO) |
| **训练标签** | IPM 最优解 | 增量 MLU 奖励 |
| **网络类型** | 通用（ER/Waxman/ASN） | LEO 星座（Walker-Delta） |
| **时变拓扑** | 静态快照 | 在线适应（故障+突发） |
| **泛化方式** | 跨拓扑族（ER→Waxman） | Walker-Delta 族内 |
| **泛化倍数** | 20× (100→2000 节点) | 6.7× (66→288 节点，有效范围） |
| **泛化 gap** | < 3% optimality gap | GNN/ECMP MLU ≤ 0.989（288 节点） |
| **故障处理** | 无（静态快照） | 0-15% 链路故障，3 种模式 |
| **推理延迟** | 1.52ms (GPU) | 1.2-2.0ms (CPU) |
| **部署模式** | 集中式 SDN | 集中式（可分布式扩展） |
| **参数量** | ~500K (双循环 GCN) | 28,546 (GAT) |
| **训练时间** | 4h (A100) | 22min (RTX 4070) |

### Related Work 讨论文本

> **GNN 规模泛化**。TELGEN [Zhou 2025] 将 TE LP 问题转化为二部图上的 GNN 消息传递，实现了 20× 跨拓扑泛化（optimality gap < 3%），代表了 GNN 规模泛化在 TE 领域的 SOTA。然而，TELGEN 采用静态快照+离线监督学习的范式：(1) 每个拓扑快照需要预计算 IPM 最优解作为标签，在链路频繁故障的 LEO 场景中不现实；(2) 无在线适应能力，无法响应突发流量或实时故障；(3) per-path 流量分割依赖预定义路径集，路径集在拓扑变化时可能失效。本文采用在线 DRL 框架，每条流到达时独立路由，故障信息通过 GNN 边特征实时传播，无需离线预计算或重新训练。

### 差异化论证逻辑

```
TELGEN 的优势（不回避）：
├── 更大的泛化倍数（20× vs 6.7× 有效范围）
├── 更低的泛化 gap（<3% vs ~1% MLU，但 delay 优势更大）
├── 更强的理论保证（对齐 IPM 迭代）
└── 跨拓扑族泛化（ER→Waxman）

本文的差异化（不 claims 方法更优）：
├── 在线 vs 离线：故障和突发时无需重算
├── 逐流 vs 全局：每条流独立路由，天然支持增量部署
├── 轻量 vs 重量：28K 参数 vs 500K，CPU 推理可行
└── LEO 特化 vs 通用：面向卫星场景设计，故障是核心考量

核心论证：不是"比 TELGEN 更好"，而是"解决 TELGEN 未覆盖的在线故障弹性场景"
```

## 4. Baseline 讨论文本

### ECMP

> **等价多路径路由 (ECMP)**。ECMP [Chiesa 2017] 是最广泛使用的负载均衡方法，在等价最短路径间均匀分配流量。ECMP 的优势在于简单和无状态，但其被动等分策略无法感知链路负载差异。在 Walker-Delta 拓扑中，极地间隙限制了路径多样性，ECMP 在故障场景下的等价路径减少更为显著。本文实验表明：(1) 无故障条件下 ECMP 与 GNN 性能接近（GNN/ECMP MLU = 1.018）；(2) 8% 故障率下 GNN 的 E2E 延迟比 ECMP 低 20%（GNN/ECMP delay = 0.80），MLU 低 4%。GNN 的优势来源于故障场景下的自适应路径选择能力。

### MLP (消融对照)

> **MLP 消融对照**。为验证 GNN message passing 的贡献，设计了与 GNN 共享 PPO 训练框架但用 MLP 替代 GAT encoder 的对照。MLP 使用局部特征（源/目的节点 + 1 跳邻居负载 + 路径长度），无法感知全网拓扑。训练在 66 星（800ep），泛化测试在 48-720 星。结果表明：MLP 在训练规模 MLU 落后 GNN 16%（GNN/MLP = 0.84），E2E 延迟是 GNN 的 2.7 倍（GNN/MLP delay = 0.37）。跨规模时 MLP zero-shot 崩溃更严重：48 节点 MLP(zero-shot)/ECMP = 1.12（GNN/ECMP = 0.92）。这证实 GNN 的共享权重机制是跨规模泛化和延迟优化的关键。
