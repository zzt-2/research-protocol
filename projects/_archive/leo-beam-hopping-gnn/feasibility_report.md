# 方向可行性报告 — Beam Hopping + GNN

## 研究方向
多波束LEO卫星Beam Hopping调度中，使用GNN建模波束间空间干扰耦合关系，替代现有DRL方法的扁平MLP编码器。

## A. 结构优势论证

### 核心结构性优势

BH调度的本质是**干扰图约束下的组合优化**：每时隙选择K个波束激活，被激活的波束如果存在空间干扰关系，则互相降低吞吐量。

**简单方法的信息损失场景：**

1. **贪心/启发式（L04图着色, L07势博弈）**：显式建模干扰图拓扑，但无学习能力，需每个快照重解，无法跨场景泛化，计算复杂度高。
2. **扁平MLP（L03 QPLEX, L08 PPO）**：可从数据学习策略，但将N个波束的状态展平为向量——丢失了pairwise干扰拓扑。L08作者自述"cannot capture spatial interference coupling"。当波束数≥19且干扰图非完全图时，MLP无法区分"哪些波束可以安全共激活"。
3. **GNN**：通过消息传递在干扰图上传播信息，每个节点感知邻居状态→自然建模"如果我激活，邻居会受到多少干扰"。

**定量证据：**
- L01（Geng TVT 2025）：同场景（卫星多波束，节点=波束，边=干扰），GNN比扁平FNN **+30%** 数据速率
- L04（WCL 2026）：图论方法接近Gurobi上界→图结构是BH的正确抽象
- L03（TWC 2026）：QPLEX不建模空间关系，作者在conclusion中将此列为future work

**结构性优势条件：** 干扰图为非完全图（波束间干扰非均匀）+ 需求非均匀 + 波束数≥19。信息损失与干扰图"非平凡性"成正比。

### B. 新颖性-可行性解耦

- **新颖性论据**：GNN for BH pattern design = **零篇论文**。经4组关键词检索（Semantic Scholar × 4 + IEEE × 1）+ 双向引用链分析（Gong TWC 2026, Zhang TWC 2025），共53条新增候选，确认零直接竞品。最接近者P1 (Hybrid Graph-RL for Beam Management) 使用Graph-DDPG做波束管理，但仍以RL为主且未涉及BH pattern设计。
- **可行性论据**：GNN在卫星通信相关任务中已有突破性验证：
  - 功率分配：L01 GNN+元学习 +30% over FNN，zero-shot泛化到7/37/61波束
  - 信道+功率分配：L02 超图NN优于pairwise GCN，GRU动态演化
  - 用户调度：L06 3D-GNN接近最优（与WMMSE差距<5%），SPSD理论指导
  - 上述任务与BH共享同一图结构（节点=波束/小区，边=干扰关系），方法论可直接迁移
- **空白原因分析**：双重因素——"没人想到"+"技术使能刚出现"
  - BH研究被DRL社区主导（PPO/QMIX/MADRL是默认选择），DRL研究者天然倾向扁平MLP
  - GNN在卫星通信中是2024-2025年才出现的新方向（L01/L02为首批），与BH的交叉尚未发生
  - 不是"试过效果不好"——没有任何GNN+BH的尝试记录

### C. 仿真条件可行性

GNN 优势的三个前提条件在仿真中均可满足：

1. **非平凡干扰图拓扑**：全频复用 + 真实天线方向图（Bessel/UPA）→ 波束间干扰强度非均匀。L04 核心贡献即揭示"倾斜波束干扰足迹不规则性"，这是 GNN 应利用的典型非平滑信号。
2. **非均匀需求分布**：城市/农村/时变业务（复合泊松）→ 贪心/等分配次优 → GNN 空间感知优势可体现。L01 在 16 种流量分布下均验证 GNN 优势。
3. **波束规模≥19**：MVE 已在 N=19 验证 GNN 收敛时 +16%~+48%；L01 实证 N=19→37→61 均有效。

**"过于平滑"预警**：若仅用自由空间+全向天线，干扰会过于均匀。缓解：必须包含 Bessel 函数天线方向图（L07）或 UPA 阵列响应（L01），确保干扰足迹有空间非均匀性。

**致命信号**：无。

### D. 最小可行实验（MVE）

- **假设**：GNN消息传递在波束干扰图上的结构性先验，使BH调度优于扁平MLP
- **最小实例**：19波束六角形网格（2-ring），K=5激活/时隙，T=5时隙，α=0.5干扰强度。GCN（2层，hidden=32）vs MLP（2层，hidden=128），REINFORCE训练3000 episodes，5个随机种子
- **pass/fail 标准**：GNN平均奖励 ≥ MLP × 1.05（5%提升）
- **结果**：

| Seed | GNN | MLP | Δ | 状态 |
|------|-----|-----|---|------|
| 0 | 12.018 | 8.121 | +48.0% | GNN收敛 |
| 1 | 11.446 | 9.851 | +16.2% | GNN收敛 |
| 2 | 1.326 | 8.143 | -83.7% | GNN崩溃 |
| 3 | 1.497 | 8.795 | -83.0% | GNN崩溃 |
| 4 | 1.131 | 6.295 | -82.0% | GNN崩溃 |

| 方法 | 均值 | 标准差 |
|------|------|--------|
| GNN | 5.483 | 5.106 |
| MLP | 8.241 | 1.159 |
| Greedy | 21.197 | 1.034 |

- **可扩展性测试**：GNN用N=19训练的权重直接zero-shot到N=37（37波束，3-ring六角形，K=8），得分13.970。MLP因固定输入维度无法适配。
- **判定**：**部分通过** — GNN在收敛时（2/5 seeds）显著优于MLP（+16%~+48%），但训练不稳定（3/5 seeds崩溃）。

**不稳定原因分析：**
- REINFORCE的高方差梯度 + GCN参数同时影响所有节点 → 梯度不稳定
- 这是GNN+RL的已知工程问题，文献中的解决方案明确：
  - L01/L02/L06均使用actor-critic框架（非REINFORCE），critic网络降低方差
  - L01额外使用元学习稳定训练
  - PPO的clip机制天然适合GNN策略网络
- 改善路径：实际实现使用PPO/SAC + GNN encoder，可解决此问题

### E. 资源/风险比例

**Baseline 代码可获取性**：全部 4 个 baseline 均无开源代码，需自实现。
- PPO+MLP：PPO 是标准算法（cleanrl 可参考），MDP 设计参考 L08，估计 1-2 周
- 图着色 L04：MCMF+TS+HEAD 算法描述详细，估计 1.5-2 周
- Greedy/EPA：实现极简，1-2 天

**时间投入**：总估计 4-6 周（仿真器 + GNN + PPO + baselines + 实验）。

**贡献**：GNN for BH = 零论文确认的明确空白，高新颖性，投入产出比合理。

**失败时可回收产出**：
- GNN 不优于 MLP → BH 仿真环境 + 条件边界分析（"GNN 在什么条件下对 BH 无效"）
- PPO 训练不稳定 → GNN 模块设计可迁移到其他卫星 RA 任务
- 实验时间不够 → 缩减为 PPO+MLP + Greedy 两个 baseline，产出仍可发表

**致命信号**：无。虽全部 baseline 需自实现，但沉没成本有多条回收路径。

## Go/No-Go 决策

### 4a 决策：Conditional Go（已完成 2026-05-15）

- **决策：Conditional Go**
- **理由**：
  - 维度A（结构优势）：无致命信号。GNN保留干扰图拓扑 vs MLP展平丢失，L01实证+30%
  - 维度B（新颖性-可行性）：无致命信号。零竞品+GNN在卫星RA已有突破+空白原因合理
  - 维度D（MVE）：部分通过。GNN在收敛时+16%~+48%，训练不稳定有明确改善路径（PPO/SAC）
  - GNN zero-shot可扩展性（19→37）已确认，这是MLP无法实现的根本优势
- **条件**：
  1. 实现时必须用actor-critic框架（PPO/SAC），不可用REINFORCE
  2. 在Step 4b中验证GNN训练稳定性
  3. 如4b中GNN训练仍不稳定，重新评估
- **用户确认：** 已确认（2026-05-15）

### 4b 决策：Go（待用户确认）

- **决策：Go**
- **理由**：
  - 维度C（仿真条件）：无致命信号。全频复用+真实天线方向图→非均匀干扰足迹→GNN优势条件充分。"过于平滑"风险可通过Bessel/UPA天线方向图缓解。
  - 维度E（资源风险）：无致命信号。全部baseline需自实现但PPO/Greedy为标准算法；失败时沉没成本有多条回收路径（仿真环境、条件边界分析、GNN模块迁移）。
