## 4. MDP 设计

### 状态空间（每波束 i，共 N 维）

| 维度 | 含义 | 归一化 |
|------|------|--------|
| d_i | 当前需求 | d_i / d_max → [0,1] |
| q_i | 排队积压 | q_i / q_max → [0,1] |
| h_ii | 主瓣信道增益 | dB→线性→log归一化 |
| g_i | 干扰聚合 Σ|h_ij|² | dB→线性→log归一化 |

**图结构**: 邻接矩阵 A（干扰门限），边权重=干扰增益 |h_ij|²

### 动作空间

离散：从 N 个波束中选 K 个激活。实现：N 维 sigmoid → top-K 选择。

### 奖励函数

```
r_t = α · R_throughput + β · R_fairness - γ · P_interference
```

| 项 | 公式 | 范围 | 归一化后 |
|------|------|------|---------|
| R_throughput | Σᵢ min(ŝᵢ, dᵢ) / Σᵢ dᵢ | [0, 1] | [0, 1] |
| R_fairness | (Σᵢ ŝᵢ/dᵢ)² / (K · Σᵢ (ŝᵢ/dᵢ)²) | [0, 1] | [0, 1] |
| P_interference | Σᵢ max(0, SINR_i - SINR_thr) / N | [0, ~0.5] | [0, ~0.5] |

**权重**: α=0.6, β=0.3, γ=0.1

**量级分析**: 三项均在 [0,1] 范围，有效权重比 6:3:1，无单一项独占风险。

## 5. 验证标准

| 验证类型 | 检查项 | 通过条件 |
|---------|--------|---------|
| 解析验证 | 自由空间损耗 L=20log(4πd/λ) | 误差 <0.1dB |
| 解析验证 | Bessel主瓣增益 | 与L07 A_max=48.7dBi 误差 <0.5dB |
| 统计验证 | 需求分布均值/方差 | 复合泊松参数匹配 |
| 退化测试 | 固定需求+固定信道→确定性输出 | 确定性策略下奖励方差=0 |
| 自相关预警 | 信道时序lag-1自相关 | <0.95 |
| MDP试运行 | 随机vs贪心奖励差距 | >10% |
| MDP试运行 | 奖励分解单项占比 | 无单项>95% |
