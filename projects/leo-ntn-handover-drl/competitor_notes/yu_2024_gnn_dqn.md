## 图结构设计

### 图类型
**有向图**。节点 = 卫星 + 虚拟起始节点 (Sat0)。边 = 有向切换关系（从 Sat_i 到 Sat_j 的边表示终端可以从卫星 i 切换到卫星 j，基于重叠服务周期）。

### 节点
- 每个可见卫星是一个节点
- 额外添加一个虚拟起始节点 Sat0，作为所有可能切换路径的起点
- 节点本身不携带特征；特征全部编码在边上

### 边
- **有向边**：从 Sat_i 到 Sat_j 表示终端可从 i 切换到 j
- **边特征**：(传输时延 d_k, 数据速率 r_k, 剩余服务时间 t_k)，零填充到固定大小 N 以保证状态空间维度不变
- **动态性**：拓扑结构每个时隙根据卫星可见性重建，但状态空间大小固定（预定义 N + 零填充）

### 与二部图的区别
- Yu et al. 将卫星建模为图的节点，切换可行性建模为有向边 —— 这是 **路径选择图**（从当前卫星出发选择最优切换路径）
- 不是 UE-卫星二部图匹配问题，而是单用户场景下的序列切换决策问题
- 图的含义是 "切换路径" 而非 "关联关系"

## GNN 架构

### 框架
**MPNN (Message Passing Neural Network)**，但操作在 **边级别**（而非节点级别）。

论文原文："we employ an enhanced MPNN to conduct the message passing process between all edges in the graph"

### 消息函数 M()
- 输入：中心边状态 h_c^k 和邻居边状态 h_e^k
- 实现：全连接网络 (FCN)，接收两条边的状态并输出消息
- M(h_e^k, h_c^k)

### 聚合函数 A()
- **逐元素求和**，对所有邻居边的消息进行聚合
- m^{K+1}(c) = A_{e in N(c)}[M(h_e^k, h_c^k)]

### 更新函数 U()
- **RNN（循环神经网络）**，将边的前一迭代状态和聚合消息结合
- h_c^{k+1} = U[h_e^k, M^{K+1}(c)]
- 输入是边状态的上一轮迭代值 + 当前聚合消息

### GNN 层数
- K 次消息传递迭代（论文未明确给出具体 K 值）

### 读出函数 R()
- O = R(sum_{c in E} h_c)
- 将所有边的最终状态求和，通过全连接 DNN 输出 Q 值估计
- 注意：读出作用于**所有边的状态求和**，而非节点

### 关键设计特点
1. **边级消息传递**：不同于标准 MPNN 在节点间传递消息，Yu et al. 在边之间传递消息
2. **RNN 更新**：使用循环网络而非简单 MLP 来更新边状态，使消息传递过程具有序列记忆能力
3. **全局读出**：所有边状态求和后映射到 Q 值，保持置换不变性

## DRL 接口

### 算法
DQN (Deep Q-Network)

### 状态空间
S(t) = {{d_1, r_1, t_1, padding}, {d_2, r_2, t_2, padding}, ..., {d_k, r_k, t_k, padding}}
- 固定大小，零填充保证维度不变
- 每条边对应一个特征向量（时延、速率、剩余服务时间）

### 动作空间
a(t) in {1, 2, ..., k}，其中 k = 从虚拟起始节点出发的路径数量
- 本质上是选择哪条切换路径

### 奖励函数
R(s, a) = 0.5815 * N(r_i) - 0.1095 * N(d_i) + 0.3090 * N(t_i)
- 权重通过 **AHP（层次分析法）** 确定，非 DRL 学习得到
- N() 为归一化函数
- 三个目标：最大化数据速率 (58.15%)、最小化传输时延 (10.95%)、最大化剩余服务时间 (30.90%)
- **权重固定**：训练过程中不改变

### GNN 在 DRL 中的角色
- GNN 作为 Q 网络的函数逼近器
- 输入：图状态（边特征）→ MPNN 边级消息传递 → 全局读出 → Q 值
- 替代标准 DQN 中的全连接 MLP

## 训练设置

| 超参数 | 值 |
|--------|-----|
| 训练迭代 | 1600 episodes |
| 学习率 | 0.001 |
| 折扣因子 gamma | 0.95 |
| 经验回放 buffer | 4000 |
| Batch size | 32 |
| 优化器 | SGD |
| Epsilon 衰减 | 1.0 → 0.005 |
| 目标网络更新频率 | 每 50 episodes |
| 收敛 | ~1700 episodes |

## 仿真设置

| 参数 | 值 |
|------|-----|
| 卫星数量 | 15 |
| 仿真时长 | 30 min |
| 时隙数 | 60 |
| 轨道高度 | 400-600 km |
| 最小仰角 | 10° |
| 用户场景 | 电力巡检单用户（一个 TA/中继站）|

## 复杂度
- 时间：O(E*K + T*F/5)，E = 边数，K = 消息传递轮数，T = 时间步，F = 特征维度
- 空间：O(E + F)

### 可借鉴点
1. 边级消息传递思路：在切换场景中，切换关系（边）比节点本身携带更多信息
2. AHP 权重确定方法：可作为奖励权重初始化的参考
3. 零填充保持固定状态空间大小的技巧
4. GNN 作为 Q 网络函数逼近器的架构模式

### 局限
1. 单用户场景，无法处理多用户竞争和负载均衡
2. 仿真规模小（15 星）
3. 奖励权重固定，缺乏自适应性
4. DQN 相比 Dueling/DDQN/PPO 在多目标场景下表达能力有限
