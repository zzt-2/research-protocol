# 方向可行性报告

## 研究方向
LEO 巨型星座故障感知抗毁路由——从 GNN 拓扑感知方法 Pivot 至 MARL+课程学习

## A0. 问题-方法适配性预检

### 1. 性能间隙
FCRMJ 在 1-5% 故障率下队列/丢包率优于传统 baseline（Dijkstra/DBPR/CPFAR），但仅用 MLP 无拓扑感知，手工特征在未知故障模式下泛化受限。传统方法在故障场景下性能退化显著，DRL 方法有改进空间。

### 2. 问题结构适配
- 状态空间大（720+ 卫星 × 动态拓扑）✅
- 环境动态复杂（轨道运动 + 故障注入）✅
- 跨场景泛化需求 ✅
- 延迟奖励/长期依赖 ✅

### 3. 跨域成功先例
- GRLR/GraphPR/ADRLRM：GNN+DRL LEO 路由（≥3 篇）
- GDAPS：GNN+MARL SDN 容错路由
- ≥5 篇同类方法在结构相似问题上成功 → 通过

### 4. MDP 非平凡性
S/A/R/P 定义非平凡，最优策略非贪心，状态空间巨大，奖励非稀疏 → 通过

### 5. 负面证据
未发现 GNN+LEO 故障恢复尝试失败的报告。空白性质为"两条活跃研究线尚未交叉" → 通过

**A0 总评：5/5 通过，无致命信号。**

## A. 结构优势论证（GNN 方法 — 已 Pivot）

原始论证：GNN 消息传递自动捕获故障传播模式，优于 FCRMJ 手工 γ 衰减。

**MVE 证伪**：两次实验（18 节点 / 60 节点）均显示 GNN MLU 不优于 MLP+手工特征。
- MVE-1: GNN 差 5.8%
- MVE-2: GNN 差 4.2%

**修正后结论**：在监督式 oracle 模仿 + Dijkstra 路由框架下，GNN 消息传递不提供可测量的路由决策优势。Pivot 至 MARL+课程学习方向。

## B. 新颖性-可行性解耦

- **新颖性**（事实）：GNN+专有故障恢复+LEO 路由 = 方法空白（11 组检索确认）
- **可行性**（预测）：MVE 证伪——GNN 编码器不优于 MLP → 原方法可行性不足
- **空白原因**："没人想到"→ 但 MVE 显示可能是"效果不够好所以不值得"
- **Pivot 后**：MARL+课程学习方向可行性待验证

## D. 最小可行实验（MVE）

### MVE-1（18 节点）
- 假设：GNN 编码器在未见故障模式下路由泛化能力优于 MLP
- 实例：Walker 3×6=18 节点，训练 0-1 故障，测试 2-4+关联故障
- 方法：监督学习（oracle 节点使用量预测 → 边权重 → Dijkstra）
- 结果：GNN MLU 5.337 vs MLP 5.045，GNN 差 5.8%
- **FAIL**

### MVE-2（60 节点）
- 假设：图规模扩大后 GNN 拓扑感知优势显现
- 实例：Walker 6×10=60 节点，训练 0-3 故障，测试 6-12+关联故障
- 结果：GNN MLU 6.529 vs MLP 6.262，GNN 差 4.2%
- 关联故障亮点：GNN Imbalance 2.794 < MLP 2.857，但 MLU 仍输
- **FAIL**

### MVE 结论
两次独立实验一致：GNN 消息传递在路由决策维度不优于 MLP+手工特征。规模从 18→60 节点，差距未缩小反而持续。**致命信号。**

## Go/No-Go 决策
- **决策：Pivot**
- **理由**：MVE 两次失败，GNN 作为核心编码器的假设被证伪。问题空间（故障感知抗毁路由）仍有价值，但方法需调整。
- **Pivot 方向**：MARL+自适应课程学习（分布式多 agent 协调 + 逐步增加故障复杂度）
- **备选**：P2 在线自适应 DRL（Meta-RL / 快速微调）
- **用户确认**：已确认。P1 先行，不行则转 P2。
