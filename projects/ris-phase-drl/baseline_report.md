## 4. 关键发现

### 4.1 DRL 退化为固定策略

**核心发现**：TD3/SAC/DDPG 的确定性评估性能与 Fixed(θ=π) 完全一致：
- TD3 avg=1280.9 ≈ Fixed avg=1292.2 (差距 -0.9%)
- SAC avg=1292.0 ≈ Fixed avg=1292.2 (差距 0.0%)
- DDPG avg=1292.0 ≈ Fixed avg=1292.2 (差距 0.0%)
- 三种 DRL 的 best reward 也与 Fixed best 几乎相同

**结论**：MLP-based DRL 未能学到信道自适应策略。Agent 收敛到输出恒定 action≈0（即 θ≈π），等效于 Fixed baseline。

### 4.2 信道自适应优化的潜力

PSO avg=1553.5 显著优于 Fixed avg=1292.2（+20.2%），证明：
1. 信道自适应的相移优化确实有价值
2. 不同信道实现的最优相移差异显著
3. MLP 架构未能捕获这种映射关系，但优化空间存在

### 4.3 原因分析

DRL 退化的可能原因：
1. **观测空间过大**：obs_dim=2600（Re/Im(H1), Re/Im(H2), cos/sin(θ)），MLP(400,300) 参数量不足以从 2600 维原始信道状态中提取有效特征
2. **Block fading 结构**：每 episode 信道固定，agent 无法通过时序交互"感知"信道变化
3. **LoS 主导**：κ=10dB 时 LoS 分量占 90.9%，最优相移与 LoS 方向强相关，固定策略已接近多数信道实现的最优解
4. **奖励地形**：Rician 信道下 θ=π 附近是平坦高原，梯度信号弱，DRL 缺乏精细调整的动力

### 4.4 研究机会

| 挑战 | 潜在方案 |
|------|---------|
| MLP 无法从原始信道提取特征 | 信道感知架构（如级联信道特征编码器） |
| obs_dim=2600 过大 | 降维：仅传入角度信息 / 信道压缩 / 注意力机制 |
| DRL avg ≈ Fixed avg | 需要架构创新使 DRL 真正学会信道自适应 |
| PSO 作为上界 (+20%) | 目标：DRL 至少达到 PSO 性能，且推理更快 |
