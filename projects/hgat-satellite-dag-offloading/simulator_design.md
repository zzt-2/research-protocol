# 仿真器设计规格

> HGAT 卫星-地面协同边缘计算 DAG 依赖任务卸载
> 参数来源：K2/M01 (TMC 2026) 为主，K3/M06/M08/M09 补充
> 2026-05-12

## 1. 系统模型

四层卫星-地面协同边缘计算架构（K2/M01 §II）：

```
IoTD (任务生成) → UAV (边缘) → LEO (边缘) → CS (云)
  0.8 GHz          3 GHz       4-5 GHz      10 GHz
```

**时间结构**：离散时隙驱动。每个 episode = 一轮 DAG 批次调度（所有子任务完成或超时）。

**决策流程**（参考 M06 逐对决策 + K2/M01 MATS 排序）：
1. 按 ERR 优先级排序就绪子任务（参考 K2/M01 MATS）
2. 构建异构图（任务节点 + 计算节点 + 边）
3. HGAT 编码 → Actor 输出每个 (子任务, 计算节点) pair 的 logit
4. 选择分配，执行，更新状态
5. 重复直到所有子任务分配完毕

### 3.3 信道模型（K2/M01 §II-C + Table III）

| 链路类型 | 带宽 | 路径损耗 | 衰落模型 | 噪声功率 |
|----------|------|---------|---------|---------|
| IoTD-UAV (G2U) | 20 MHz (B^G2U) | 自由空间 ρ₀(d)^-2 | Rician (ξ) | σ² = -100 dBm |
| IoTD-LEO (G2S) | 15 MHz (B^G2S) | 自由空间+大气 | Shadowed-Rician SR(g,Ω) | σ² = -100 dBm |
| UAV-LEO (U2S) | 15 MHz (B^U2S) | 自由空间 | Shadowed-Rician | σ² = -100 dBm |
| LEO-LEO (ISL) | 1 GHz (B_kk') | 自由空间 | — | σ² = -100 dBm |
| LEO-CS | 1 GHz (B_kc) | 固定 | — | — |
| CS (有线) | — | 固定 1 Gbps | — | — |

G2U Rician 衰落（K2/M01 eq.9 区域）：
$\hat{h}_{nm} = \sqrt{\frac{ξ}{ξ+1}\bar{h}_{nm} + \frac{1}{ξ+1}\tilde{h}_{nm}}$，其中 $\bar{h}_{nm}=1$，$\tilde{h}_{nm} \sim \mathcal{CN}(0,1)$

Shadowed-Rician 三种条件（K2/M01 Table IV，MinerU 部分提取 + 原文互补）：
- Light: (b₀, m, Ω) = (0.879, 10.13, 0.001)
- Average: (b₀, m, Ω) = (0.252, 5.21, 0.004)
- Heavy: (b₀, m, Ω) = (0.146, 1.75, 0.025)

> 缺失：Rician K 因子 ξ 论文未给出数值。采用 3GPP TR 38.811 典型值 K=2（地面-低空链路）。G_P=1（天线增益），ζ_B=2（带宽分配系数）。

## 4. 奖励函数设计

### 4.1 从论文提取的奖励结构

| 论文 | 奖励结构 | 归一化 | 权重披露 |
|------|---------|--------|---------|
| K2/M01 | -η_t·T - η_e·E - Σλ_ι·Φ_ι | 未详述 | ❌ η_t, η_e, λ₁-λ₅ 均未给出 |
| M06 | Ĉ(s_t)-Ĉ(s_{t+1}), Ĉ=Σ(w_T·FT+w_E·E) | 贪心下界归一化 | ❌ w_T, w_E 未给出 |
| K3 | λ₃·κ·(ι-L) - λ₁·C - λ₂·K | 各项独立 | ❌ λ 在图片中 |
| M08 | -cost(t), cost=w_d·delay+w_e·energy | [0,1]归一化 | ✅ w_d=w_e=0.5 |
| M09 | η·数据率 + ξ·完成率 + (1-能量) + χ·时间效率 | 归一化 w_i | ❌ 权重未给出 |

K2/M01 完整奖励函数（eq.52，MinerU 提取）：
```
r_i^t = -η_t · T_{i,t} - η_e · E_{i,t} - Σ_{ι=1}^{5} λ_ι · Φ_ι
```
5 个惩罚项 Φ_ι（约束违反度 = max(0, f_ι)）：
- Φ₁: 延迟违反 (T_comp - T_max)
- Φ₂: UAV 计算资源超限 (Σf_m - F_m)
- Φ₃: LEO 计算资源超限 (Σf_k - F_k)
- Φ₄: UAV 速度违反 (ve - ve_max)
- Φ₅: UAV 碰撞违反 (d_min - 距离)

> 本项目仿真器不含 UAV 轨迹优化（UAV 位置固定），Φ₄/Φ₅ 不适用。实际惩罚项仅保留 Φ₁-Φ₃。

### 4.2 本项目奖励设计

采用 K2/M01 的加权成本结构（与主 baseline 一致），辅以 M06 的成本下降思想：

```
R_episode = -(η_t · T_norm + η_e · E_norm + λ_p · P_deadline)
```

各项定义：

| 项 | 公式 | 典型范围（基于 K2/M01 参数） | 归一化后范围 |
|----|------|---------------------------|------------|
| T_norm | 总任务完成延迟 / Σ T_max | 20×(0.5~5)s / 20×55s = [0.18, 1.82] | [0.18, 1.82] |
| E_norm | 总能耗 / E_max | IoTD本地20子任务 ≈ 37.5J / 37.5J | [0, 1.0] |
| P_deadline | Σ max(0, (完成时间-T_max)/T_max) | 0 或 [0.01, 0.5]/子任务 | [0, ~10] |

> E_max = 所有子任务在 IoTD 本地计算的能耗总和（最差情况上界）

### 4.3 权重与量级分析

**默认权重**：η_t=0.4, η_e=0.3, λ_p=0.3

**量级检查**（单 episode，~50 IoTD 各 1 DAG）：
- η_t·T_norm: 0.4 × [0.18, 1.82] ≈ [0.07, 0.73]
- η_e·E_norm: 0.3 × [0, 1.0] ≈ [0, 0.3]
- λ_p·P_deadline: 0.3 × [0, ~10] ≈ [0, 3.0] — 截止时间违约时会主导

**问题**：多 IoTD 累积后 P_deadline 可能远大于 T_norm 和 E_norm，导致奖励被惩罚项主导。

**修正方案**：P_deadline 按子任务数平均：
```
P_deadline = (1/J_total) · Σ max(0, (t_i - T_max_i)/T_max_i)
```
修正后范围 [0, ~0.5]，与 T_norm/E_norm 同量级。

修正后量级检查：
- η_t·T_norm: 0.4 × [0.18, 1.82] ≈ [0.07, 0.73]
- η_e·E_norm: 0.3 × [0, 1.0] ≈ [0, 0.3]
- λ_p·P_avg: 0.3 × [0, 0.5] ≈ [0, 0.15]

三项均在 [0, 0.73] 量级，无单一项独占 >95%。

> **待实现后验证**：Part A-checkpoint（MDP 试运行）将用随机策略和贪心策略验证此量级分析。如果发现失衡，通过调整权重修复。

## 5. 验证标准

### 5.1 解析验证
- [ ] 自由空间路径损耗：L = 32.45 + 20log10(f_GHz) + 20log10(d_km) → 与仿真输出一致
- [ ] LEO 轨道周期：T = 2π√(a³/μ) = 2π√((6771km)³/3.986×10⁵) ≈ 94.6 min (500km)
- [ ] SNR 计算：已知发射功率、距离、带宽 → 与公式计算一致

### 5.2 统计验证
- [ ] Shadowed-Rician 衰落幅度服从对应复合分布（Light/Average/Heavy 三组参数）
- [ ] DAG 出度/入度分布符合 daggen 参数（fat=0.6, density=0.4）
- [ ] IoTD 位置均匀分布在 1×1 km²

### 5.3 退化测试
- [ ] 固定信道（K→∞ 无衰落）→ SNR 仅含路径损耗，确定性输出
- [ ] 固定 DAG（seed 锁定）→ 相同输入产生相同调度轨迹
- [ ] 单类型节点（所有节点同参数）→ HGAT 退化为标准 GAT/GraphSAGE

### 5.4 自相关预警
- [ ] 信道时序 lag-1 自相关 < 0.95（如 >0.95 需引入非平稳特征）

### 5.5 MDP 试运行检查（Part A-checkpoint）
- [ ] 跑 1 episode 随机策略 + 1 episode 贪心策略（最短处理时间优先）
- [ ] 奖励分解：无单一项占总奖励绝对值 >95%
- [ ] 贪心 vs 随机总奖励差距 >10%
- [ ] 关键指标（延迟/能耗/违约率）在贪心和随机策略间有差异
