## 2. B1: +Grid/Fixed 复现报告

### 2.1 实现描述

按 [L01 §III-A: +Grid] 和 [L09 §II-B: Fixed LISLs] 规范实现固定网格拓扑：

- **同轨 ISL ×2**：每颗卫星连接同面相邻前后卫星（环形，永久保持）
- **跨轨 ISL ×2**：每颗卫星连接相邻轨道面中距离最近的 2 颗卫星
- **路由**：Dijkstra 最短路径（传播延迟 + 1ms/hop），与核心方法共用 Router 模块
- **无 setup delay**，无切换成本

代码：`baselines/grid_fixed.py`（~100 行）

### 2.2 拓扑验证

| 指标 | 值 | 期望 |
|------|-----|------|
| 总边数 | 384 | P×SPP(intra) + ~P×SPP(inter) |
| 同轨边 | 192 | P×SPP = 24×8 ✓ |
| 跨轨边 | 192 | ≈ P×SPP ✓ |
| 每星平均度 | 4.00 | ≈ 4 ✓ |

### 2.3 性能结果（24×8, 50 步）

| 指标 | B1 Fixed | Random | Greedy |
|------|----------|--------|--------|
| M1 吞吐量 | 0.048 | 0.004 | 0.054 |
| M3 切换率 | 0.000 | 4.780 | 0.035 |
| M4 阻塞率 | 0.952 | 0.996 | 0.947 |
| M5 公平性 | 0.092 | 0.005 | 0.170 |
| 平均奖励 | 0.048 | -0.386 | -0.024 |

### 2.4 复现判定

- B1 Fixed 结构性优于 Random：吞吐量 +1231% ✓
- B1 Fixed 吞吐量 ≈ Greedy（无切换成本，总奖励更优）✓
- M3 切换率 = 0（固定拓扑特性）✓

**判定：B1 复现成功。** 作为传统方法下限，后续 DRL 方法（核心 GNN-DRL + B2 MADRL）应在吞吐量上超过 B1。

### 2.5 已知限制

1. **低吞吐量 (~5%)**：24×8=192 星规模下所有策略吞吐量均低，因卫星密度不足导致大量流量无法路由。1584 星全规模下预期显著改善
2. **低公平性 (0.09)**：稀疏网格上瓶颈链路造成部分流量完全阻塞，部分流量独占资源

## 3. B2: Wang TCOM MADRL — 待实现

### 3.1 设计规格

详见 `simulator_spec.md` §6.2，关键要素：

| 要素 | 设计 |
|------|------|
| ISL 模式 | 3 固定（2 同轨 + 1 跨轨）+ 1 动态（7 候选选 1） |
| 状态空间 | 邻域负载矩阵 → CS 压缩 → Lin 维向量 |
| 网络架构 | FC: Lin → 512 → 256 → (Advantage 8 + Value 1) |
| 算法 | Double Dueling DQN |
| 动作空间 | {0,1,...,7}（7 候选 + 关闭） |
| 奖励 | 局部负载减少 - β·1(ISL存在) |
| 路由 | Dijkstra（统一路由器，公平对比 [D006]） |
