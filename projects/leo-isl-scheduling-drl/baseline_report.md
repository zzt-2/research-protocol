## 2. B1: +Grid/Fixed 复现报告

### 2.1 实现描述

按 [L01 §III-A: +Grid] 和 [L09 §II-B: Fixed LISLs] 规范实现固定网格拓扑：

- **同轨 ISL ×2**：每颗卫星连接同面相邻前后卫星（环形，永久保持）
- **跨轨 ISL ×2**：每颗卫星连接相邻轨道面中距离最近的 2 颗卫星
- **路由**：Dijkstra 最短路径（传播延迟 + 1ms/hop），与核心方法共用 Router 模块
- **无 setup delay**，无切换成本

代码：`baselines/grid_fixed.py`（~100 行）

### 2.2 拓扑验证（24×8）

| 指标 | 值 | 期望 |
|------|-----|------|
| 总边数 | 384 | P×SPP(intra) + ~P×SPP(inter) |
| 同轨边 | 192 | P×SPP = 24×8 ✓ |
| 跨轨边 | 192 | ≈ P×SPP ✓ |
| 每星平均度 | 4.00 | ≈ 4 ✓ |

### 2.3 性能结果（24×8, 50 步）

| 指标 | B1 Fixed | Random | Greedy |
|------|----------|--------|--------|
| M1 吞吐量 | 0.048 | 0.004 | 0.054 |
| M3 切换率 | 0.000 | 4.780 | 0.035 |
| M4 阻塞率 | 0.952 | 0.996 | 0.947 |
| M5 公平性 | 0.092 | 0.005 | 0.170 |
| 平均奖励 | 0.048 | -0.386 | -0.024 |

### 2.4 复现判定

- B1 Fixed 结构性优于 Random：吞吐量 +1231% ✓
- B1 Fixed 吞吐量 ≈ Greedy（无切换成本，总奖励更优）✓
- M3 切换率 = 0（固定拓扑特性）✓

**判定：B1 复现成功。** 作为传统方法下限，后续 DRL 方法（核心 GNN-DRL + B2 MADRL）应在吞吐量上超过 B1。

### 2.5 已知限制

1. **低吞吐量 (~5%)**：24×8=192 星规模下所有策略吞吐量均低，因卫星密度不足导致大量流量无法路由。1584 星全规模下预期显著改善
2. **低公平性 (0.09)**：稀疏网格上瓶颈链路造成部分流量完全阻塞，部分流量独占资源

## 3. B2: Wang TCOM MADRL 复现报告

### 3.1 实现描述

按 [L09] Wang et al., IEEE TCOM 2024 实现 Double Dueling DQN + "3 固定 + 1 动态" ISL 模式：

- **3 固定 ISL**：2 同轨（相邻前后）+ 1 跨轨（相邻面最近卫星）
- **1 动态 ISL**：从 7 个跨轨候选中选 1 或关闭，DQN 决策
- **网络架构**：Dueling DQN (state → FC 512 → FC 256 → Advantage 8 + Value 1)
- **训练**：Double DQN, ε-greedy (max(1-ep/30, 0.05)), 共享经验池
- **奖励**：局部负载减少 - β·1(动态ISL存在)
- **路由**：Dijkstra（统一路由器 [D006]）

代码：`baselines/wang_madrl.py`（~330 行）

### 3.2 Starlink 适配

| 参数 | 原始 (OneWeb) | 适配后 (Starlink) |
|------|-------------|------------------|
| 总卫星数 | 720 (18×40) | 480 (24×20 测试) |
| 轨道面 | 18 | 24 |

| ISL 最大距离 | 4000 km | 3000 km |

### 3.3 测试规模候选分析

| 星座规模 | 总候选槽位 | 有效候选 | 覆盖率 | 每/星候选 |
|---------|----------|---------|--------|---------|
| 24×8 (192) | 1344 | 192 | 14.3% | ~1 |
| 24×20 (480) | 3360 | 1440 | 42.9% | 3 |

24×8 规模下跨轨候选严重不足（仅 1 个/星），不适合 B2 验证。24×20 有 3 个/星，用于训练测试。

|------|----------|-----------|------------|
| M1 吞吐量 | 0.173 | 0.114 | 0.118 |
| M3 切换率 | 0.000 | 0.000 | 0.000 |
| M4 阻塞率 | 0.827 | 0.886 | 0.882 |
| M5 公平性 | 0.519 | 0.400 | 0.422 |

### 3.5 复现判定

**判定：B2 已实现但测试规模下未优于 B1。**

**原因分析**（[D011]）：

1. **结构性 ISL 差异**：B1 有 4 固定 ISL（2 同轨 + 2 跨轨），B2 仅 3 固定 + 1 动态。B2 少 1 条固定跨轨链路，动态链路需弥补此缺口后才产生净增益
2. **测试规模候选不足**：24×20 仅 3 候选/星（全规模 24×66 预期 >7），DQN 决策空间有限
3. **训练不充分**：50 episodes × 20 步 = 1000 梯度步，L09 原始用 720 星 × 10 步 × 50 episodes = 更多样本
4. **L09 原始优势维度不同**：L09 报告的主要改善是跳数减少和负载均衡，而非原始吞吐量提升

**不阻塞理由**：
- 核心方法（GNN-DRL，2 条全动态 ISL）与 B1 的对比不受 B2 结果影响
- 全规模 (24×66) 训练预期显著改善（候选更丰富 + 更长训练）
- B2 作为中间基线仍有价值：展示 DRL 在受限条件下的表现
- Execute 阶段可在全规模上重新评估 B2
