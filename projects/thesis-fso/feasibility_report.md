## Q12 评估：分治架构（AO 管湍流 + DPLL 管多普勒）→ 联合建模改进

> M = 分治架构（AO 光域管湍流 + DPLL 数字域管多普勒，环路内不含湍流相位）
> C = 星地 LEO 相干下行 + 大气湍流（Gamma-Gamma + 相位畸变）+ Doppler 残频（30-300 MHz）
> A = 分治假设"AO 完全校正 + AGC 恒幅 + DPLL 只管多普勒残频"——湍流相位被推给 AO 不进 PLL 环路传递函数

### A0 §1：性能间隙

- 传统 baseline（Paillier 分治 DPLL）离 oracle 多远？
  - Paillier JLT：湍流致 2.3dB BER penalty（vs AWGN 理论），但这是**幅度衰落**的 penalty，不是**湍流相位**的
  - 湍流相位：Paillier 证明"可忽略"（with vs without φ 曲线重合）
  - 旧 B1 S024：强湍流 KF 距 oracle 有 6dB gap（但弱/中湍流增益消失）
- **性能间隙来源**：[实证] S024 KF 压力测试（强湍流 6dB gap）+ [实证] Paillier JLT（湍流相位 negligible）
- **判定**：性能间隙**在强湍流下存在（6dB），但在弱/中湍流下消失**。间隙是条件性的，不是全局的。

### A0 §5：负面证据搜索

- ✅ **找到失败报告**：旧 B1（S024）就是"用 KF 把湍流纳入同步设计"的直接失败先例
- **失败机制**：B2 消融证明增益来自 KF 跟踪机制而非湍流先验 → "湍流感知"创新点无效
- **Q12 必须解释为什么本研究条件不同**：Q12 用环路传递函数（控制理论）而非 KF，**但物理假设相同**（都假设主动建模湍流相位能带来增益）——除非 Q12 能论证"环路传递函数在强湍流下有 KF 没有的优势"，否则 → **致命信号**

### 维度 A：结构优势论证

- Q12 相比 Paillier 分治 DPLL 的结构性优势在哪？
  - Q12 声称：把 φ_T 纳入环路 H(z) → 在强湍流下减少失锁
  - **但**：旧 B1 用 KF 做同类事被证伪（B2 消融：增益来自跟踪而非湍流先验）
  - Q12 必须论证：环路传递函数纳入 φ_T 比 KF 纳入湍流先验**有本质不同**，否则结构优势声称不成立
- **致命信号**：答不出"环路 H(z) 纳入 φ_T 为什么比 KF 纳入湍流先验本质不同"——两者都假设"主动建模湍流相位带来增益"，物理假设相同，只是数学工具不同。

### 维度 B：新颖性-可行性解耦（**致命**）

1. **新颖性**：领域没人把联合建模做进 DPLL 环路设计（Paillier 用分治+经验性"可忽略"绕过）——✅ 事实成立
2. **可行性**：做了会更好？——**❌ 有强负面证据**
3. **空白原因**：为什么前人没做？
   - 不是"没人想到"——旧 B1（S022）明确想到了"湍流感知 Kalman CPR"
   - 不是"技术限制刚解除"——KF/DPLL 都是成熟工具
   - **是"试过效果不好"**：S024 证伪了"湍流感知带来增益"
   - Paillier 用经验性证明"可忽略"绕过，也是因为"没必要做"
4. **空白零假设检查**（致命）—— 3 个空白存在的结构性原因：
   - **原因1**：湍流残余相位（piston mode）相干时间 ~1ms 远慢于符号率（10 GBaud）→ DPLL 能顺带 track，无需专门联合建模 → **暗示联合建模在结构上冗余**
   - **原因2**：AGC 维持恒幅假设已经把湍流幅度起伏的影响剥离 → 联合建模的"幅度-相位耦合"维度被 AGC 提前消化 → **暗示联合建模的输入信息被 AGC 吸收**
   - **原因3**：AO 校正后残余相位小（flux penalty -4.5dB，piston 是主要残余但量级可控）→ 联合建模的增益空间被 AO 压缩 → **暗示联合建模的增益空间被 AO 吃掉**
   - **3 个原因都暗示方法在结构上可能不适用/冗余** → **升级为致命信号**

## Q12 决策：Kill

**决策依据**：
1. **B1 换皮**（高度同构 + 旧 B1 已被证伪）—— D005"警惕 B1 换皮"纪律直接触发
2. **A0§5 负面证据致命**：找到直接失败先例（S024），Q12 无法论证"本研究条件本质不同"（物理假设相同，仅数学工具不同）
3. **A0§6 先验覆盖致命**：主指标 BER 被 Paillier 分治 DPLL 覆盖 ≥90%
4. **维度 A 结构优势无法论证**：答不出"环路 H(z) 纳入 φ_T 比 KF 纳入湍流先验本质不同"
5. **维度 B 空白零假设致命**：3 个结构性原因都暗示联合建模冗余（piston 慢于符号率/AGC 吸收幅度/AO 压缩相位）
6. **维度 C/E 致命**：强湍流条件已被旧 B1 证伪 + 失败沉没成本无回收价值

**Kill 理由总结**：Q12 的"联合建模进 DPLL 环路"与被证伪的旧 B1（"湍流感知 Kalman CPR"）共享同一物理假设（主动建模湍流相位带来同步增益），只是数学工具不同（控制理论 vs KF）。旧 B1 已用 S024 压力测试证伪该假设（弱/中湍流增益消失 + 强湍流输给最优 Fixed + "湍流感知"核心创新被消融证伪）。Paillier 2020 JLT 独立佐证（湍流相位对载波同步可忽略）。

**诚实预期**：Q12 如果跑 MVE，大概率复现旧 B1 的证伪结果（增益消失），是重复劳动。

**可回收教训**：
1. "把 X 纳入同步算法设计"类方向，必须先验证 X 对同步有实质影响（而非经验性可忽略）
2. 增益归因必须做消融（旧 B1 B2 消融发现增益来自跟踪而非湍流先验）
3. **盲区 A 召回的 Q11/Q12/Q13 三篇都指向"联合建模"gap，但这个 gap 的本质是"Paillier 经验性证明可忽略 + 旧 B1 实验证伪"，不是"没人做"**——块 D 召回纠正了"漏召"，但 Q12 评估揭示了"漏召的方向本身已被证伪"
