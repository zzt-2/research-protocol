## 1. 总判断

把这项工作按三档强度评估，**推荐第二档**。

1. **强独立主方法**——目前**不能**这样包装。原因：面向正式投稿所需的"新颖性闭合
   与直接竞品对照"证据不足。具体地，本研究的目标直接竞品在当前实现中等价于一个
   "对 CMA 输出恒等"的占位，无法支撑"已超越现有直接竞品"的声称；文献检索的新颖性
   收据也没有形成可独立复核的提交闭包。因此不能作为强主方法呈现。

2. **推荐包装（本文档采用）**——一个**低复杂度、塌缩感知、接收机可见的安全归一化
   层**。它可作为：毕业论文中的一个小方法、更大接收机方法中的一个安全组件、或负面
   路线之后的一项正向补充实验。这一档比单纯负面分析更接近可写的方法形态，但证据
   强度仍只是 `LOCAL_SLICE / NONBINDING_DIAGNOSTIC`，不能升级为正式 Go。

3. **保守包装**——仅作为"何时应启动幅度校正"的运行边界与评估洞察使用。即把它的
   价值限定在刻画一个边界条件（正常输出不该被归一化扰动、异常输出需要校正），而不
   给出方法性能声称。

**明确推荐第 2 档。** 它的强项是接收机可见、无发送端信息依赖、零额外迭代开销，且在
当前局部切片上展示了塌缩子集的强恢复和健康子集零最坏退化；它的弱项是证据覆盖窄、
直接竞品未真正实现、新颖性未正式闭合。下文统一按第 2 档（有界包装）的口吻撰写。

## 2. 方法定义

### 2.1 问题

盲均衡（如恒模算法 CMA）在双偏振相干通信中偶尔会让输出星座的幅度发生塌缩：均衡器
收敛后，信号能量整体偏低或某偏振能量偏低，导致判决错误率上升。一种朴素补救是"始终
归一化"——永远把输出幅度拉回目标功率。但这会伤害本来就正常的输出：在健康块上，这种
始终生效的归一化会引入固定的额外退化。**问题因此不是"要不要归一化"，而是"什么时候
才该归一化，且如何归一化得物理正确"**。

### 2.2 核心思想

先用接收端可见的一段已知结构（校准前缀）判别当前输出是否出现塌缩风险；只在判别为
"需要干预"时，才按物理正确的平方根幅度缩放执行恢复；判别为"健康"时保持恒等（输出
完全不变）。这样做的关键在于：健康样本付出零代价（恒等），塌缩样本得到正确恢复
（平方根缩放），且全部判别只依赖接收端能看到的信号，不依赖任何发送端真值。

### 2.3 输入、输出与因果边界

- **输入**：一段调谐好的固定步长盲均衡器（CMA）输出后的双偏振复数流。门控阶段只
  读取 128 个符号的校准前缀；归一化阶段只作用于被评分的后缀（与前缀不重叠）。
- **输出**：与输入同长度的双偏振复数流——健康时逐比特恒等，塌缩时按平方根幅度缩放。
- **因果边界（严格）**：在线运行时**不使用**发送端真值、不使用任何 oracle、不使用
  未来后缀的信息、不存在后缀到门控的反馈。发送端真值仅用于离线生成评价标签，不在
  运行时出现。

### 2.4 公式

记双偏振前缀拼接为
\(z_{\rm prefix}=[z_{x,\rm prefix};\,z_{y,\rm prefix}]\)。先统一计算共享门控特征：

- 平均功率 \(m_2=\operatorname{mean}(|z_{\rm prefix}|^2)\)；
- 展度（变异系数）\(c_v=\operatorname{std}(|z_{\rm prefix}|)/
  (\operatorname{mean}(|z_{\rm prefix}|)+10^{-9})\)。

门控规则（阈值在开发集上冻结，本研究未在测试集上重新调参）：

- 当 \(m_2\ge 0.6\) 且 \(c_v\ge 0.1\) 时，判为**健康**，保持恒等
  \(z'_p=z_p\)；
- 其余情况判为**需要干预**，启用缩放。

对每个偏振 \(p\in\{x,y\}\)，用 10% 截尾均值稳健估计其前缀功率
\(\widehat P_p=\operatorname{trimmean}(|z_{{\rm prefix},p}|^2)\)。取 16QAM 目标平均
功率 \(P_s=\mathbb{E}|s|^2=1\)（按平均功率归一化），则物理正确的复幅度倍数满足
\(|a_p|^2\widehat P_p=P_s\)，故 \(a_p=\sqrt{P_s/\widehat P_p}\)，对后缀施加
\(z'_p=a_p z_p\)。注意是**平方根缩放**而非线性功率比，否则会过校正。

### 2.5 伪代码

```text
输入：双偏振 CMA 后前缀 z_pref_x, z_pref_y（各 128 符号），后缀 z_suf_x, z_suf_y
1  z ← concatenate(z_pref_x, z_pref_y)          # 双偏振统一特征
2  m2 ← mean(|z|^2)
3  cv ← std(|z|) / (mean(|z|) + 1e-9)
4  if m2 ≥ 0.6 and cv ≥ 0.1:
5      return z_suf_x, z_suf_y                    # 健康：逐比特恒等
6  Px ← trimmean(|z_pref_x|^2, 0.1)              # 每偏振稳健功率
7  Py ← trimmean(|z_pref_y|^2, 0.1)
8  ax ← sqrt(1 / Px)  ;  ay ← sqrt(1 / Py)
9  return ax·z_suf_x, ay·z_suf_y                 # 塌缩：平方根幅度缩放
```

### 2.6 复杂度与实现位置

复杂度表述限于：在前缀上做幅值、均值/标准差、排序型截尾均值的若干线性趟扫描；在后缀
上每个样本一次复数标量乘法（或恒等为零开销）。不依赖迭代、矩阵求解或随机数。实现位置
是 CMA 之后、判决之前的无记忆后处理层。**本研究不提供精确 FLOP 计数或硬件时延测量**
（无依据，不臆造）。

### 2.7 与两种朴素方案的机制区别

| 方案 | 健康块行为 | 塌缩块行为 |
|---|---|---|
| 始终归一化 | 始终施加缩放 → 引入固定退化 | 平方根缩放（恢复） |
| 非线性半径重映射 | 始终施加非线性星座映射 | 非线性映射（恢复，但引入映射失真）|
| **本方法（门控 + 平方根缩放）** | **逐比特恒等，零退化** | **平方根缩放（恢复）** |

机制区别的关键在"门控"：恒等分支用逐比特不变换取健康样本零代价，而两种朴素方案都
无法做到这点（它们在健康块上也施加了某种变换）。与非线性半径重映射相比，本方法在塌缩
块上还额外避免了非线性映射可能引入的失真。

## 3. 论文叙事

### 3.1 候选方法名 / 小节标题

### 3.2 中文摘要（问题—机制—收益—边界）

> 盲均衡器收敛后的输出偶发幅度塌缩会推高判决错误率。对健康输出直接施加归一化会引入
> 固定退化，因此问题在于"何时该校正"。我们提出一种接收端可见的安全归一化层：仅用
> 已知的 128 符号校准前缀判别塌缩风险，健康时保持恒等、塌缩时按物理正确的平方根幅度
> 缩放逐偏振恢复，不依赖发送端真值。在一个局部测试切片上，该层在塌缩子集恢复判决
> 错误率约 0.56（10k 自助 95% 区间约 [−0.69, −0.41]），且健康子集最坏退化恰为 0；
> 但这些证据仅限单一切片、单一调制、少量信道与种子，且未闭合正式新颖性与直接竞品
> 对照，故为诊断级而非可泛化结论。

## 5. 不可声称项与升级所需最小证据

### 5.1 目前**不能**写进论文的说法

- "首次提出 / 填补空白 / 解决了盲均衡问题"——新颖性未正式闭合；

- 把 collapse stratum 的 −0.5598 当成"全样本平均收益"——这是条件子集。

### 5.2 若要升级为正式主方法，所需的最小补强（本包只列债，不执行）

1. **重新闭合直接碰撞 / 便宜替代文献链**：把检索、引用链与精读收据整理成可独立复核
   的提交闭包，使新颖性与碰撞判定能被外部核对；
2. **实现真实直接竞品**：用一个真正不同的运行机制替代当前的恒等占位，做公平对照；
3. **在预注册、多信道 / 多长度 / 多调制切片上复核门控与健康保护**：扩展切片并预注册
   通过条件，避免本切片"健康与塌缩罕共现"对判别 CI 的结构性影响；
4. **报告整体分布、失败案例、参数敏感性与计算代价**：给出参数扫描、失败样本剖析与
   （在有依据后）复杂度量化。
