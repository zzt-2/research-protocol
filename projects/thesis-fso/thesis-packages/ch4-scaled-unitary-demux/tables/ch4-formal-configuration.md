# 第四章正式仿真配置候选表

| 配置项 | 取值 | 说明 |
|---|---|---|
| 链路与信号结构 | 双偏振 2×2 相干接收链路 | 每个随机簇内，各方法共享相同信道、导频噪声和载荷噪声 |
| 调制格式 | 双偏振（Dual Polarization, DP）(8,8)-16 阶幅度相位键控（Amplitude and Phase Shift Keying, APSK） | 两个偏振支路采用相同调制格式 |
| 每偏振载荷长度 | 4096 个符号 | 每个随机簇合计评价 32768 bit |
| 信噪比定义 | 每偏振、衰落前、数据符号 $E_s/N_0$ | 横轴范围 5–41 dB，间隔 2 dB |
| 湍流参数 | 弱：$(\alpha,\beta)=(11.6,10.1)$；中等：$(4.0,1.9)$；强：$(4.2,1.4)$ | 各湍流场景独立评价，不跨场景合并性能结论 |
| 导频长度 | 中等湍流：$N_p=2,4,8,16$；弱/强湍流：$N_p=2$ | $N_p$ 表示每偏振导频符号数 |
| 随机总体 | 128 个配对随机簇 | 一个随机簇携带同一场景与导频切片的完整 SNR 曲线 |
| 比特误码率（Bit Error Rate, BER）口径 | 解复用后、载波恢复前、未编码前向纠错（Forward Error Correction, FEC）前 BER | 由整数误码数与总 bit 数汇总，并采用 Jeffreys 修正显示零误码点 |
| 工程参考 BER | $3.8\times10^{-3}$ | 所需信噪比（Signal-to-Noise Ratio, SNR）通过 BER 对数域线性插值得到 |
| 调参奇异值下限 | 中等湍流：$N_p=2$ 时 $\tau=0.5$，$N_p=4,8,16$ 时 $\tau=1.0$；弱/强湍流的 $N_p=2$ 时 $\tau=1.0$ | 参数来自独立调参映射，不用单一 $\tau$ 概括全部正式切片 |
| 非酉失配切片 | 中等湍流、$N_p=2$、25 dB；$\delta=0,0.05,0.1,0.2,0.3,0.4$ | $\delta=0$ 复用主曲线的同一观测，不计为额外独立样本 |
| 章节接口 | 两路解复用输出送往后续每偏振支路载波恢复 | 这里只定义与第三章的模块化接口；未进行第四章与第三章的端到端联合仿真 |

> 注：理想信道状态信息（Channel State Information, CSI）仅用于给出理论参考，不属于可部署接收机对比方法。
