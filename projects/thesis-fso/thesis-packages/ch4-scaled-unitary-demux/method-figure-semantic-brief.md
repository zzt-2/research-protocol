# 第四章方法图语义卡

## 图的唯一任务

用一张图同时交代三件事：接收端如何从短导频提取公共方向；两种结构尺度判据与独立调参基线如何形成各自的解复用矩阵；解复用输出如何作为第三章每偏振载波恢复的输入。图中三条方法支路是并列实验比较，不是在线选择器。

## 必须出现的数学动作

| 环节 | 图内表达 | 语义边界 |
|---|---|---|
| 无约束估计 | `H_LS=Y_p X_p^H(X_p X_p^H)^-1` | 三条支路的共同输入 |
| 方向提取 | `H_LS=U diag(s1,s2)V^H`, `Q=UV^H` | 只提取结构方向 |
| 前向误差尺度 | `g_F=(s1+s2)/2`, `W_F=Q^H/g_F` | 正文主方法 |
| 导频重构尺度 | `W_0=Q^H/s1`, `a=max(0, Re< W_0Y_p,X_p>_F / ||W_0Y_p||_F^2)`, `W_P=aW_0` | 每次观测闭式校准；`a` 不是固定值 |
| 独立调参基线 | `s_i~=max(s_i,tau s1)`, `W_tau=V diag(1/s_i~)U^H` | `tau` 按冻结映射选取，不与两条结构支路共享结果 |
| 载荷处理 | `Z=WY` | `W` 表示当前被比较支路的矩阵 |
| 跨章接口 | `z_x,z_y -> Ch3 每偏振 CPR` | 仅模块接口，未做联合验证 |

## 版式与编码

- 画布约 1200×650；左至右为导频观测、共同方向、三条并列支路、载荷解复用、第三章接口。
- 导频/参数控制使用橙色点划箭头，载荷使用蓝色实线；三条支路用不同边框线型和短标题双重区分。
- 在三条支路旁明确标注“并列实验支路，非运行时切换”。
- 第三章接口放在独立虚线容器内，标注“模块接口；未联合验证”。
- SVG 必须保留可编辑文字；PNG 仅作预览。

## 禁止暗示

- 不画运行时选择器、门控器或由诊断量自动切换方法的逻辑。
- 不画 PDL、PMD、FIR、LDPC、时变 SOP、CFO 或联合载波恢复性能。
- 不把理想 CSI 画成可部署支路。
- 不把导频重构尺度画成独立的结构信道估计器；它校准的是解复用矩阵。
