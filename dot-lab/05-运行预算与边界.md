## 1. 首跑自检（拿到仓库后第一件事，通过才开工）

跨机器确定性对账——防止环境版本差异污染数字：

```bash
# a) 环境对齐（与主线实测版本一致）
pip install "sionna==2.0.1" "numpy==2.5.1" scipy
pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
python -c "import sionna,torch,numpy;print(sionna.__version__,torch.__version__,numpy.__version__)"
# 参考输出：2.0.1 / 2.13.0+cpu / 2.5.1（小版本差异不自动判废，以 b) 对账为准）

# b) 重生成 dev 缓存并复算 B0×20，与仓库锚点逐帧对账
cd projects/simulation/explore/decode-failure-rescue
python generate_llrs.py --split dev    # 重生成 64 帧缓存（seeds 5000-5063，~1 分钟）
python - <<'EOF'
import sys, json, numpy as np
sys.path.insert(0, '.')
from rescue_decoder import RescueDecoder, make_encoder
dec = RescueDecoder(make_encoder())
raw = json.load(open('../../results/decode-failure-rescue/raw_dev.json'))
ref = {f['seed']: f['B0']['info_errors'] for f in raw['frames']}
mism = 0
for seed in sorted(ref):
    f = np.load(f'../../results/decode-failure-rescue/llr_cache/dev/frame_{seed}.npz')
    res = dec.decode(f['llr'][None, :], num_iter=20, alpha=0.75, offset=0.0, trajectory=False)
    ie = int((res['info_bits'][0] != f['truth_info']).sum())
    mism += (ie != ref[seed])
print('mismatch frames:', mism, '/ 64')
EOF
```

**判据：0 失配 → 通过开工；有失配 → 停下，把版本号与失配数记入 RUN-LOG 等用户**（版本差异导致的不一致不要自行改代码"适配"）。

## 3. 资源预算（你的实测：9 核 / ~8GiB 内存 / ~26GiB 磁盘）

- 单轮实验规模参考：2048 帧 × 200 迭代 ≈ 7 分钟 CPU；预计超 30 分钟的实验先砍规模
- 内存：批 256 帧解码约 2GiB；不要并发两个解码进程
- 磁盘：npz 缓存**不 commit**（本地用完即删，seeds 可重生成）；只 commit JSON / md / 代码；工作区保持 >20GiB 可用，低于 10GiB 先清缓存再说话
- 无 GPU：全部实验按 CPU 设计，不需要

## 4. 检查点与恢复（你已验证 SIGTERM + checkpoint 模式）

- 每轮检查点 = 发现卡草稿（哪怕只有一行"正在做 X"）+ RUN-LOG 一行
- 被外部执行器重启后：读 RUN-LOG 最后 10 行接着干（START-HERE §4），不要重新规划
- 长实验（>10 分钟）分批落盘，进程被杀可从最后一批续

## 5. 验收条件（每张发现卡的最低门槛）

- 有数字（哪怕只有 256 帧的初步配对）
- 有一行能重跑的复现命令
- 有基线在场（02 铁律-4）
- 负结果也达标："做了 X，数字 Y，此路不通"就是合格产出

## 6. 停下来等用户的条件（不要硬扛）

- 连续 5 轮全是负结果 → 停，写总结卡（可能需要换打法，不是继续蛮力）
- 出现可写方法章的强候选 → 写成章卡，停
- 首跑自检不过 / 环境损坏 / 磁盘 <10GiB 且清缓存无效 → 停
- 需要付费墙全文 → 登记 `WANTED-PAPERS.md` 后继续干别的，不要干等

## 7. 文献获取协议（对应你的实测缺口）

- 可用：arXiv API、Crossref、搜索工具、PDF/HTML 全文提取（均已验证）
- 离线底座：`search-archive/_index/all-papers.jsonl`（2.17 万条题录+摘要，随仓库提供）；`papers/` 内另有数十篇全文
- Semantic Scholar 限流：间隔 ≥2 分钟重试一次，仍 429 就改用 Crossref/arXiv，不要刷
- 付费墙（IEEE/Springer 等）：登记 `WANTED-PAPERS.md`（DOI + 一句话用途），用户定期人工取回放入 `papers/downloads/<日期>/`，你用 pdftotext 提取（已验证）
- 诚实规则：检索零命中只能说明"该语料+该检索式未命中"，不能写"没人做过"——占位判断的结论句永远带"据所查（arXiv/Crossref/本地库）"
