# 场景事实卡——冻结设定、可复用资产、环境

## 1. 物理与编码设定（全部冻结，改任何一项=换世界）

- 信道：Gamma-Gamma 大气湍流块衰落（三档参数：中 4.0×1.9 / 弱 11.6×10.1 / 强 4.2×1.4）× 连续相位损伤（残余频偏/频率斜率/激光线宽）× Jones SU(2) 双偏振旋转 × AWGN
- 调制：DP-16APSK（非 Gray）
- 码：**5G NR LDPC，BG2，z=104，k=1024，n=1536**（信息 1024，发送 1536）
- 帧结构冻结：4 Walsh 正交导频前导 + 块内导频；**无 CRC**（接受判据只有校验子）
- SNR 工作区：各档湍流下 B0 基线 FER 落在 0.05-0.67 的 SNR 范围（中湍流 11-17dB / 弱 10-14dB / 强 14-18dB 已有实测地形）

## 2. 接收链（T077 冻结链）

导频 LS 解复用 → plain RDE（μ=1e-3）→ 每偏振 DA ML 块相位估计 → 8 歧义消解 → exact-APP 解映射（nominal n0）→ NOMS(α=0.75, offset=0)×20 迭代译码 → 校验子输出。

- Ch3（已完成，不动）：自适应 DA/NDA 载波相位恢复分支选择，CCISP 2026 录用。任何新方法与它保持区分（载波相位恢复是它的领地）。

## 4. 已知场景结构（实测，可直接引用的地形事实）

- 帧质量三段结构：~72-75% 好帧 4-6 迭代收敛 / ~5% 边际帧 20-200 迭代落地 / ~23-27% 深衰死帧 200 迭代仍死
- 20 迭代预算悬崖（非信息悬崖）：悬崖带及以上每条件 40-97 帧在 50-200 迭代落地
