# 模板——发现卡与运行日志

## 发现卡（每轮一张，文件名 `findings/YYYY-MM-DD-<一句话slug>.md`）

```markdown
# <一句话机制标题>

- 日期 / 轮次：
- 状态：正结果 | 负结果 | 做不下去（原因）
- 想法：一句话（什么机制，为什么可能有用）
- 测试：最便宜的可证伪实验是什么，怎么跑的（脚本路径 + seeds）
- 数字：核心指标（含基线对照，标明同帧配对）；结果文件路径
- 判断：值不值得往方法章方向推（一句话理由）
- 下一步（若有）：
```

## 成章卡（强候选专用，写完停下等用户）

```markdown
# <方法名候选>——成章卡

- 问题：M 在 C 条件下因 A 失效（一句话，含场景证据数字）
- 机制：方法做什么，输入/输出是什么（"实时在跑的一节信号处理"自检）
- 与谁比：最强简单基线是谁，数字差多少（配对，CI）
- 消融：拆掉哪个组件会塌（或计划怎么做）
- 预期图：论文里这张图长什么样（轴/曲线/点）
- 风险与边界：什么条件下不成立，哪句必须诚实写
```

## RUN-LOG 行格式（一行一轮）

```
[YYYY-MM-DD HH:MM] 轮次N | 干了啥一句话 | 结果一句话 | 下一步一句话
```
