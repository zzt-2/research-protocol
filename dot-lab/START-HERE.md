# dot 实验室——启动入口（读这一个文件就够开工）

> 这是你在长跑模式下的唯一必读入口。本包由主线蒸馏（2026-09-30），刻意不携带研究历史现场——仓库里其他地方的旧档案不要去翻（见"世界边界"）。
> 编号体系：本包无编号、无治理流程（用户明确豁免）。你就是自由的。

## 0. 你的任务（一句话）

在冻结的星地相干激光通信仿真平台上长期自主探索，为用户的硕士论文找到**可写成方法章的新方法点/新发现**——自由发挥优先，过程从简，测量不造假。

## 1. 世界边界（reading contract）

你的世界 = 以下内容，其他一律不是你的任务输入：

| 允许 | 是什么 |
|---|---|
| `dot-lab/` | 本包全部文件 |
| `projects/simulation/` | 仿真代码与实验资产（复用引擎 + 参考；既有文件只读） |
| `papers/` | 共享文献库（2 万+ 篇带全文/摘要，`papers/_index` 与 `search-archive/_index/all-papers.jsonl` 是索引）——文献检索受限时的离线底座 |
| 你新建的目录 | 你的地盘（新实验放 `projects/simulation/explore/<你的名字>/`，结果放 `projects/simulation/results/<你的名字>/`，笔记放 `dot-lab/findings/`） |

**不要读**：`.sessions/`（历史会话档案，几千个文件，读了会被锚定）、`毕设/`（论文正文现场）、`projects/` 其余项目目录、`search-archive/{日期}/` 原始检索转储。需要知道的历史结论已经压缩成一页：`04-死区与占位.md`。

## 2. 开工三步

1. **配环境**：见 `03-场景与资产.md` §6（装 sionna==2.0.1 等，跑冒烟验证）
2. **读四个短文件**：`01-需求` / `02-规范精简` / `03-场景与资产` / `04-死区与占位`（共约 15 分钟）
3. **启动**：在 `RUN-LOG.md` 写下第一条启动记录，开始第一轮探索

## 3. 工作循环（轻量）

**想法一句话 → 当天可完成的最便宜可证伪测试 → 结果落盘 → 下一轮。**

- 每轮产出一张**发现卡**（模板见 `TEMPLATES.md`），正结果、负结果、做不下去都记——负结果同样值钱
- 每轮结束在 `RUN-LOG.md` 追加一行
- 没有预注册要求、没有编号要求、没有审批流程；唯一不可豁免的是 `02-规范精简.md` 的五条测量铁律

## 4. 中断恢复（长跑必读）

任何新会话/重启后：**先读 `RUN-LOG.md` 最后 10 行 + 最近一张未完成的发现卡，接着干**。不要从头重新规划，不要重读全部文件。

## 5. 产出与交付

- 全部产物进 git；每完成一张发现卡 commit 一次（消息一句话）
- 用户不盯过程，隔段时间看 `dot-lab/findings/`——你的产出 = 可检验的发现卡
- 找到"能撑方法章"的强候选时，写一张**成章卡**（问题定义/机制/数字/与谁比/预期图），停下等用户拍板，不要自动展开写正文

## 6. 不要做

- 不改任何既有代码文件（复用一律只读 import；frozen 模块清单见 03）
- 不执行毁坏性操作（删库、force push、改写 git 历史）
- 没有数字不宣称"有效/无效"；有数字不夸大
- 算力/时间不够时先砍实验规模，不砍记录
