## 2. 状态模型与 joint factor graph

| 维度 | 全文事实 | 指针 |
|---|---|---|
| transmitted signal | LDPC-coded bits 映射到 M-ary complex constellation；r_k=c_k exp(j theta_k)+n_k | :23-28 |
| phase state | **连续 Wiener trajectory**：theta_k=theta_(k-1)+Delta_k，Delta_k 服从零均值 Gaussian，theta_0 uniform | :25-28 |
| discrete slip/change point | **不存在**。模型没有 Bernoulli slip state、jump angle、change-point index 或 piecewise phase-class latent variable；文中 cycle slip 是追踪器漏掉正确 trajectory 的类比/推断失效。 | :26-28,128-130,297-312 |
| pilots | block 起始 preamble + 周期 pilots；论文明确假设用 pilots bootstrap 并维持 tracking | :28 |
| forward/backward messages | p_f(theta_k)、p_b(theta_k) 是逐符号 phase posterior messages；p_d(theta_k) 由 LDPC soft symbol probability P_d(c_k=x) 与 channel likelihood 形成 | :40-51 |
| decoder exchange | channel graph 先计算 P_u(c_k) 给 LDPC；LDPC 的 soft symbol information 再进入 phase recursion，循环迭代 | :45-53 |
| scheduling | 本文算法固定 channel-first 的 forward/backward SPA 调度；正文称一般可有别的 schedule，但这些算法不能采用 | :53 |

这不是“真实相位发生一次离散跳变”的 generative model。它解决的是 Wiener phase-noise 下由 MPSK 对称性、噪声与有限混合阶数造成的多轨迹不确定性和正确分支丢失。

## 3. Multi-modal ambiguity、降阶与 cycle-slip recovery

1. 无 data a-priori 时存在 M 条相隔 2pi/M 的平行 phase trajectories；preamble/pilot 会增强正确分支，远离 known data 时分支可再次出现。split 会增加 mixture component，merge 会减少 component；作者把 split 类比为 PLL 可能 slip 的时点（:126-138）。
2. 每个原 mixture component 经 M 个星座符号扩展为 M×N 个 component，因此每个符号都要 reduction（:142-182）。
3. Algorithm 1 反复选最大权重 lead component，把与它 KL 距离不超过 epsilon 的 components 以 CMVM 合并，直到全部处理；输出阶数随符号自适应，Theorem 5 保证 reduction KL 不超过 epsilon（:221-288）。目标是保留所有 significant trajectories，不是检测一个 jump boundary。
4. Algorithm 2 设最大阶数 L。到达上限后未纳入的剩余 component mass 被丢弃，并以 phi_k^f=(sum retained beta_j)×phi_(k-1)^f 累积“正确 trajectory 仍被保留”的近似概率；backward 方向同理（:297-312）。
5. Algorithm 3 在**预定 pilot 到达时**令 q_f=phi_f p_f+(1-phi_f)/(2pi)：置信度低时让 pilot 从 uniform 部分重新建立 tracking，置信度高时保留原 tracker；这不是从 decoder metric 估计 slip boundary 后 rollback（:314-325）。
6. 送给 LDPC 的 P_u(c_k) 以 phi_k^f、phi_k^b 加权 forward/backward retained/uniform 四种组合，即使单向 recursion 丢轨也尽量利用另一向信息（:327-350）。

## 4. Local-vs-dynamic：为何逐符号 posterior 不等价于局部 repair

| 检查项 | 本文做到什么 | 完整 local chain 缺口 |
|---|---|---|
| temporal resolution | 内部保存逐符号 p_f(theta_k)、p_b(theta_k)，以及 limited-order 时的 phi_k^f、phi_k^b | 没有输出/选择单一 slip/change-point boundary，也没有 boundary accuracy 指标 |
| trigger | 每个符号、每个 joint iteration 固定运行；recovery 在已知 pilot 位置固定执行，phi 只连续加权 | 没有 decoder stall/syndrome/CRC/local metric 的 event trigger、threshold 或 explicit slip flag |
| action | 继续/合并/舍弃 trajectory branches；pilot 时将 tracker 与 uniform 混合后继续递推 | 没有对某个 detected segment/suffix 应用有限 phase-class correction bank |
| decoder work | forward/backward channel SPA 与 LDPC 反复交换整块 soft messages | 没有 rollback 到 boundary、只重算 bounded suffix/segment、只重解 touched codeword 的调度 |
| output | phase messages、symbol LLR 与最终 decoded bits | 没有 boundary、affected interval、selected local correction 或 repaired-segment output |

因此，dynamic Bayesian smoothing 能在内部表达“哪个符号附近出现/丢失分支”，但论文的可部署动作仍是**全程连续 tracking + 周期 pilot re-seeding + 全块 joint iterations**。per-symbol posterior 是状态粒度，不自动推出 detect boundary → bounded segment/suffix rollback/redecode 的动作链。

## 6. Numerical results 与复杂度账本

- 基准：DP（每两个 constellation points 之间 16 个 phase quantization levels）作为最低 PER 近似；BARB 作为低复杂度 comparator。所有仿真 phase state 都是 Wiener process（:371-374）。
- 主 slice：8PSK、LDPC length 4608、rate 0.89、sigma_Delta=0.05 rad/symbol、pilot frequency 0.05。unlimited、limited order 2/3 与 reduced order 3 的 BER/PER 几乎相同并接近 DP；order 1 较差但仍优于 BARB（:374-388）。
- 其他 slice：BPSK/QPSK 用 sigma_Delta=0.1，32PSK 用 0.01；order 2 接近 DP。32PSK 中 BARB 有高 error floor，而 limited order 1 因 pilot-assisted recovery 也几乎达到 DP（:389-410）。
- epsilon=4 的 full algorithm 随 decoder iteration 平均 components 趋近 1；reduced algorithm 用 epsilon=1。epsilon=1/4 在所示 SNR 有相同 PER，epsilon=15 会增加 PER（:410-436）。
- 8PSK complexity table：DP=68,360 MULS + 128 LUT；BARB=61 + 24；reduced order 3 在 iterations 1–4 为 312/292/273/238 MULS、147/134/123/102 LUT（:424-433）。一般式依赖 modulation order M 与平均 mixture order gamma(i)（:352-367）。
- 未报告 wall-clock、memory、throughput、end-to-end latency、Monte Carlo runs/seeds/error bars/CI，也没有与 bounded-local repair 匹配的 decoder-call budget。
