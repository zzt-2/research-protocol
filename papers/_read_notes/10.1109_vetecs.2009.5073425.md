# Read note — Xie 2009

- 题名：Bit-Interleaved LDPC-Coded Modulation with Iterative Demapping and Decoding；title check：PASS。
- DOI/来源：10.1109/VETECS.2009.5073425。
- 源文件路径：papers/doi/10.1109_vetecs.2009.5073425/content.md。
- 发表状态：正式发表。
- 发表渠道：IEEE VTC Spring。
- 年份：2009。
- 核心贡献：量化16/32APSK的 BICM/CM capacity gap，用 LDPC decoder a-priori LLR 回馈 soft demapper 恢复部分独立 demapping 损失。指出 codeword 内 interleaving 形成短环，扩大到8 codewords可再增益。
- 方法概述：候选 symbol likelihood 与同 symbol 其他 bit 的 a-priori LLR 组成 bit LLR；无反馈时退化为 BILCM。
- 实验设置：DVB-S2 LDPC length 64800；rates 2/5、2/3、4/5；8 demap iterations×50 LDPC iterations；AWGN。
- Baseline：BILCM、CM/BICM limits、8PSK/16/32APSK。
- 关键结论：32APSK、8-codeword interleaving 下约0.5 dB（2/3）和0.3 dB（4/5）。
- 与本研究关系：APSK soft-feedback baseline，与 covariance metric 可正交组合。
- 实现关键细节：32APSK radii 2.8/5.3；16APSK 2.7；capacity gap 随 order 增大。
- 适配性：适配 APSK+BICM/LDPC；无 data-dependent covariance、复杂度仅定性。
- 开源代码：无；验证状态：正文完整精读。

## 2026-08-30 C5-0 重读补充

- `source.pdf` 实为31,535-byte IEEE BLIT纯文本，首字节不是 `%PDF-`；title/author/全文完整，但不能称canonical PDF。Eq.(4)只按BLIT文本核对为“likelihood sum由其他bits的decoder a-priori LLR加权”，不把二维排版当canonical typesetting。
- receiver-visible IAO：received (y)+decoder soft-output (L_a) → iterative demapper reweight symbol likelihoods → updated bit LLR → LDPC。没有pilot、residual reliability或noise/LLR calibration estimator。
- 原文明确 (L_a=0) 时退化为traditional independent one-shot demapper（`content.md:120-124`）。加入BILCM-ID arm不会重定义C5-0 B0。
- action作用于decoder a-priori feedback，不是channel/extrinsic LLR scalar；自由度为per-bit/per-outer-iteration，无global/per-frame/per-ring calibration。
- DVB-S2 LDPC length 64800；proposed为8次outer demapping×每次50 LDPC iterations，且1–8 codeword interleaver改变预算。0.5/0.3 dB不能归因于单一scalar原子。
- 对C5-0身份：`background + executable architecture primitive`，不是exact recipe；不能声称首次iterative APSK demapping。DRL字段均 `N/A（传统通信非DRL）`。
