- **核心贡献**：论文为 200G coherent optical TDMA 设计 320-symbol、约 10 ns 的双段 preamble。Preamble A 的两条 frequency tones 用于 burst detection、coarse/fine FOE、one-tap SOP 与 sampling-phase offset (SPO) 初始化，Preamble B 的三组 64-symbol CAZAC 用于 frame synchronization 与 MMSE/ZF channel-estimation initialization；MMSE tap 解的唯一性另作证明。证据：`content.md:50-69,91-107,425-511`。
- **方法概述**：receiver 先在 sliding window 内搜索 Preamble A 的对称频率峰，确认 burst arrival 并作 coarse FOE；恢复 SOP、matched filter/CDC 后，分别用 tone phase 估计 SPO、用周期相位增量估计 fine CFO。SPO 只初始化 Godard timing loop；随后用 Preamble B 的 CAZAC correlation peak 得到 frame synchronization position，再作 MMSE/ZF channel estimation 与 DD-LMS equalization。证据：`content.md:107-114,168-228,233-349`。
- **receiver-visible information**：已知的 Preamble A（X/Y 两偏振上分别位于 `R_s/2`、`R_s/4` 的 128-symbol tones）与 Preamble B（X/Y 不同 seed 的三组 64-symbol CAZAC，符号系数分别 `[1,1,-1]`、`[-1,1,1]`）；payload 每 32 symbols 有一个 CPR pilot。证据：`content.md:91-99`。
- **action/output**：离散 burst-arrival detection；连续 coarse CFO；one-tap SOP/Jones inverse；连续 SPO initial phase；Godard feedback timing correction；连续 fine CFO；离散 frame synchronization position；MIMO equalizer tap coefficients；pilot CPR。证据：`content.md:104-114,119-228,233-349`。
- **时序/处理顺序**：`Preamble A burst detection + coarse FOE → SOP recovery → matched filter/CDC → Preamble A feed-forward SPO initialization + fine FOE → Godard timing recovery/frequency compensation → Preamble B frame synchronization → MMSE/ZF CE → DD-LMS + CPR`。证据：`content.md:107-114,168-228`。
- **exact-action 分类**：`SEQUENTIAL_MODULAR_ESTIMATION_WITH_PARTITIONED_PREAMBLE_REUSE`。SPO、CFO、frame position 分别由 Eq. (5/6)、Eq. (8)、Eq. (9-11) 的不同 metric 输出；正文没有单一 objective、联合搜索空间或一次输出 `(frame index, fractional tau, CFO)` 的 estimator。Preamble A/B 属于同一 designed preamble 总资源，但动作仍分区、分阶段。证据：`content.md:168-228`。
- **failure condition/适用边界**：SOP 与 CFO 会污染 SPO、sync position 和 taps，因此作者用顺序补偿拆耦；`R_s/4` tone 初始化 Godard TED 时还需 fixed phase offset。论文只估计 burst 初始 SPO，不建模 SCO/ppm/drift；离线实验较理想，作者承认实际场景可能需要增加 preamble。证据：`content.md:50,171-183,420`。
- **实验设置**：32 Gbaud PDM-16QAM、Tx RRC roll-off 0.1、90 GSa/s DAC/ADC、20 km SSMF、Tx ECL linewidth <100 kHz；每 frame 含 320 preamble、32400 payload、1046 pilot symbols，burst 约 1.056 us、guard interval 约 45 ns。证据：`content.md:350-369`。
- **使用的 Baseline 方法**：SPO 更新比较“有/无 Preamble-A initial SPO”的 Godard loop；CE 比较 MMSE 与低复杂度 ZF initialization；没有把完整 sequential DSP 与另一套端到端 acquisition pipeline 公平复现比较。证据：`content.md:350-420`。
- **关键结论**：initial SPO 使 Godard loop 在假设 2000-symbol loop delay 下更快收敛；fine FOE 在 `-3` 至 `+3` GHz 输入范围内 absolute error 约不超过 10 MHz；64-symbol CAZAC block 在 ROP `-32 dBm` 时 PMNR 约 15 dB，得到单一明显 synchronization peak。MMSE taps 在高 ROP 优于 ZF，但 20%-OH FEC limit 附近二者相近；考虑 6000-symbol equalizer loop delay 后需额外约 1.5 dB ROP。证据：`content.md:380-407`。
- **与本研究关系**：这是 Q1 当前最强、最直接的廉价顺序 comparator，比 Sun 2025 更明确覆盖 feed-forward fractional SPO、frame synchronization 与 CFO。它占用“一个 compact designed preamble 支撑全部 burst DSP 动作”“preamble-initialized fast timing recovery”以及 integrated Co-BM-DSP 包装；但不占用单一 coupled `(frame,tau,CFO)` estimator。Q1 后续若比较，必须把本链（或等价实现）纳入，不得只对比独立 Gardner/FS/FOE 小模块。
- **实现关键细节**：Preamble A=128 tones；Preamble B=`3×64` CAZAC；总 320 symbols≈10 ns。SPO 公式显式依赖 oversampling rate `K` 与 DFT size `N`；X/Y tones 分别在 16/8 GHz（32 Gbaud）；SPO loop delay 示例 2000 symbols，equalizer loop delay示例 6000 symbols；fine FOE 验证范围 `±3 GHz`。证据：`content.md:91-99,168-197,380-407`。

#### 动作空间

| 类型 | 维度 | 合法动作约束 |
|---|---:|---|
| burst/frame coarse detection | 1 discrete index | 先识别 Preamble-A symmetric tones |
| coarse/fine CFO | 2 sequential scalar estimates | coarse 受 DFT resolution 限制；fine 用 periodic-tone phase slope |
| SOP | `alpha,theta` | `alpha` 由 tone powers；`theta in [0,2pi)` argmax |
| SPO/timing | one scalar initial phase + feedback correction | `R_s/4` tone 对 Godard TED 需 fixed phase offset |
| frame synchronization | one discrete peak index per polarization | Preamble-B CAZAC timing metric maximum |
| channel/equalizer | per-frequency-bin `2x2 W` | MMSE unique-solution design或SOP-recovered ZF approximation |
| coupled `(frame,tau,CFO)` | 0 | 不存在；各量由不同 metric 与顺序模块输出 |
