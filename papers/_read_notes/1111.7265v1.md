# Read note — Szczecinski 2011

- 题名：*Linear Correction of Mismatched L-values in BICM receivers*；title check：PASS（metadata `match`，正文题名见 `papers/arxiv/1111.7265v1/content.md:59`）。
- DOI/来源：arXiv `1111.7265v1`。
- 源文件路径：`papers/arxiv/1111.7265v1/content.md`。
- 发表状态：arXiv v1；正文注明部分工作已投稿 ICC 2012，正式版本未在本任务另行核验。
- 年份：2011。
- 核心贡献：把 mismatched L-value 的线性校准写成 PEP/CGF saddlepoint 问题，并给出校准因子为条件 CGF saddlepoint 两倍的规则。论文同时比较 PEP 型规则与 GMI-optimal scaling，指出二者只在校准后满足 consistency-symmetry 时一致。
- 方法概述：对 decoder 前的 mismatched channel LLR 做正比例缩放；式(12)用 bit-conditioned LLR 分布求 GMI scalar，式(37)用条件 CGF saddlepoint 求 PEP 型 scalar。
- 实验设置：BPSK、Gaussian noise+BPSK interference；rate-1/2 convolutional code+Viterbi 与 rate-3/4 punctured turbo code，块长 1000 bits，turbo 5 iterations；Rayleigh (h_n) 被 receiver 完美知晓。
- 使用的 Baseline 方法：未经校准的同一 mismatched LLR（`alpha=1`）；真实 interference likelihood 的 matched LLR；Gaussian scalar、WLSF、offline GMI scalar。
- 关键结论：soft decoder 对 LLR 可靠度刻度敏感，但正公共 scalar 不改变 uncoded hard sign，亦不改变未量化 ML/Viterbi codeword argmax；异质/per-index scalar 或 iterative decoder 可受益。
- 与本研究关系：C5-0 的 `executable primitive / classical strong neighbor`，不是 APSK/FSO target-scene exact recipe。
- 实现关键细节：interference 模型中式(48)用两次 Newton–Raphson 求根；GMI 数值积分使用 40–100 点 Gauss–Hermite。论文未给 pilot estimator、因果窗口、更新时间或 operational minimum samples。
- 开源代码：未报告。
- 验证状态：2026-08-30 按 T072 从全文重读。

## 公式—输入—动作—输出

- mismatched LLR：式(7) `\tilde l_n=\log[q(y_n,1)/q(y_n,0)]`，`content.md:167-174`。
- GMI scalar：
  \[
  \hat\alpha^{\rm GMI}=\arg\min_\alpha
  \mathbb E_{\tilde L\mid C=0}\!\left[\log_2(1+e^{\alpha\tilde L})\right],
  \tag{12}
  \]
  `content.md:230-245`。需要 bit truth 或 (p_{\tilde L|C})，未知 pdf 时 Monte Carlo 是 offline 标定；原文明确说这排除了 model-based online correction，`content.md:250-254`。
- CGF scalar：式(29)定义条件 CGF，式(37)给 `\hat\alpha_n=2\hat s_n`，`content.md:417-433,518-535`。经验 CGF 仍需 bit-conditioned data；解析求根则要求真实模型参数。
- interference 例：B0 为忽略 interference 的式(45)，matched reference 为式(44)，动作 `\tilde l_n^c=2\hat s y_n` 见式(47)，`content.md:581-622`。

## C5-0 证据边界

- **B0**：同一 mismatched demapper与同一假设参数，`alpha=1`；**B_match/O1**：真实 likelihood，不得混写。
- 支持“scalar correction 是经典数学/模型型可执行原子”，不支持“post-Ch4→Ch3 pilots 已能在线产生该 scalar”；解析例的 (g_n)/SIR 也不能冒充receiver-visible输入。
- 不得声称原创 scalar/GMI/saddlepoint calibration，或把本文模型参数已知的例子改写为 pilot-derived recipe。
