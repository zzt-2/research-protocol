### [L01] Frequency Offset Estimation and Carrier Phase Recovery for High-order QAM Constellations Using the Viterbi-Viterbi Monomial Estimator

- **核心贡献**：论文提出 VVMFOE，把 QPSK phase-increment FOE 扩展到高阶方形 QAM，并以 Viterbi–Viterbi monomial weighting 强化高幅度外圈符号的贡献。论文另提出 VVMPE-ML 两阶段 CPR，以 VVMPE 完成粗相位估计、再以 ML 最近星座点误差完成残差校正，从而避免 BPS stage。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:27-41`（§I）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:145-161`（§III-A/B，Eq. 4）。
- **方法概述**：FOE 先形成相邻接收符号乘积 (x_nx_{n-1}^{*})，其幅度和相位分别为 (r_n=\rho_n\rho_{n-1}) 与 \(\theta_n=\phi_n-\phi_{n-1}\)，再用 VVMPE 对相位增量求均值。CPR Stage 1 直接对逐符号 (x_n=\rho_ne^{j\phi_n}) 使用 VVMPE；Stage 2 对判决星座点与 Stage-1 输出之间的 phase error 做 block averaging 并校正。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:47-55`（§II-A，Eq. 1–2/Fig. 2）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:145-161`（§III-A/B，Eq. 4）。
- **实验设置**：MATLAB 仿真 16/64/256-QAM；FOE 每个信号含 (10^4) symbols，每组 SNR/linewidth 做 (10^3) runs，normalized CFO 扫描 \(\pm0.1\)；CPR 使用 (5\times10^5) 个 differential-encoded symbols。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:77-107`（§II-B）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:157-159`（§III-C）。
- **使用的 Baseline 方法**：
  - classic (l=4) VV4PE phase-increment FOE：论文自实现仿真对照；在所扫区间性能显著弱于最佳 VVMPE exponent。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:109-115`（§II-B，Fig. 3–4）。
  - BPS CPR：论文自实现仿真对照；16-QAM 使用 32 个 test phases，64/256-QAM 使用 64 个 test phases。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:157-185`（§III-C，Fig. 8）。
  - standalone VVMPE-ML without added CFO：用于与串行 VVMFOE+VVMPE-ML 做 matched receiver-level 对照。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:216-232`（§IV，Fig. 9/Table II）。
- **关键结论**：FOE 在论文选定工作区得到约 (10^{-3}) NFE RMS；VVMPE-ML 对 16-QAM 优于 BPS、64-QAM 大致相当、256-QAM 略差。16-QAM 串行 VVMFOE+VVMPE-ML 在 BER (10^{-3}) 和 (1.9\times10^{-2}) 下的 linewidth tolerance 分别为 4.2 MHz 和 8.6 MHz，对应 standalone CPR 的 4.8 MHz 和 9.3 MHz。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:185-191`（§III-C/Table I）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:224-240`（§IV/Table II、§V）。
- **与本研究关系**：直接相关，但科学裁决为 **不是 same-sequence shared implementation**。作者只称两算法共享 monomial-transformation 的基本概念、数字实现“potentially”可共享硬件；原文没有共享节点图、资源计数或综合实现。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:193-216`（§IV）。
- **实现关键细节**：FOE 无歧义范围为 \(\pm1/(8T_s)\)；FOE 对 16/64/256-QAM 采用的最佳 (l) 分别为 9/12/10，而 CPR 分别为 10/11/13；16-QAM、18 dB、normalized linewidth (10^{-5}) 时 Stage-2 block length 示例为 33。证据：`papers/doi/10.1109_csndsp.2014.6923933/content.md:51-55`（§II-A）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:113-117`（§II-B）；`papers/doi/10.1109_csndsp.2014.6923933/content.md:181-183`（§III-C）。
- **适用性分析**：适合用作“VVMPE 同时服务 FOE/CPR”的方法族邻近竞品和串行算法 comparator；不适合直接充当共享计算图实现，因为两阶段输入统计不同、实验最优 (l) 不同，且硬件共享仅为作者未验证的可能性。证据基础：`papers/doi/10.1109_csndsp.2014.6923933/content.md:47-55`（§II-A）、`:151-161`（§III-A）、`:181-195`（§III-C/§IV）。
