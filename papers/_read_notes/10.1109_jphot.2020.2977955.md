## State

N/A as a learning state. Inputs are ideal-time-aligned running sum, next branch, their OSNRs, prescribed loss and an M-symbol block.

## Action

Select minimum M, estimate phase, rotate the next branch and recursively add it in descending OSNR order only when predicted net EGC gain is positive.

## Reward / objective

Reward=N/A. Minimize estimator computation M subject to a prescribed average combining-loss constraint.

## Model assumptions

Ideal time alignment, common narrow-linewidth LO and common phase noise for corresponding symbols, independent circular complex Gaussian ASE, small-angle approximation, block shorter than atmospheric/laser coherence (`content.md:53-57,83-145,225`).

## Network / algorithm

Non-neural serial recursive EGC with an analytic window-size rule.

## Fit analysis

Signature: `{time-aligned fields + running sum + next branch + OSNR + loss target} -> choose M, estimate/rotate phase, positive-gain admission -> coherent running sum + predicted RMSE/loss`. It does not observe synchronization, CE or CPE validity.
