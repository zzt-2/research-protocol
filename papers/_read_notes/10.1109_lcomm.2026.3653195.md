### [L07] A Low-Complexity Carrier Phase Recovery Architecture Using Prefix-Sum and CT-MLE for Coherent Receivers

- **标题自检**：派遣标题 *Low-Complexity Carrier Phase Recovery Architecture Using Prefix-Sum and CT-MLE*；正文首个真实标题见 `papers/doi/10.1109_lcomm.2026.3653195/content.md` §题名 L5。去停用词后 token Jaccard=`10/12=0.833`，`PASS`。
- **DOI/来源**：`10.1109/LCOMM.2026.3653195`。正文 DOI 见 `papers/doi/10.1109_lcomm.2026.3653195/content.md` §首页 L23。
- **源文件路径**：`papers/doi/10.1109_lcomm.2026.3653195/content.md`
- **发表状态**：正式发表；2026-01-08 接收、2026-01-12 在线发表。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §首页 L19。
- **发表渠道**：IEEE Communications Letters；**等级 UNKNOWN（本地证据池无权威分区记录；本轮禁 web，未外推）**。渠道证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md:1`（期刊页眉）。
- **年份/会议**：2026，IEEE Communications Letters, Vol. 30。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §页眉 L1。
- **核心贡献**：论文以 parallel prefix-sum（PPS）对随机散布的 QPSK-like / non-QPSK-like 符号作 location-aware compaction，使后续物理并行度不再按最坏情况配置；再用针对 CT 后 QPSK 判决点的 multiplication-free MLE 替换第二级 VVPE。28 nm 实现中，相对 conventional mVV-CT-VV，estimator core 面积减少 51%、功耗减少 39%，总体性能代价为 0.37 dB。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §I L27-29、§V L199-201。
- **方法概述**：第一级 mVV 从 64-QAM 中选择约 18.75% QPSK-like 符号作 coarse phase estimation，第二级 CT 把星座映射成 QPSK-like 结构后精估计。PPS 双路分别采用低深度 Kogge-Stone 与低面积 Blelloch 网络；第二级 MLE 用 I/Q 加减、符号位、XOR、MUX 和条件反相替代一般复乘。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §II L55-67、§III-B L97-101、§III-C Eq. (7)-(8) L121-157。
- **实验设置**：32 GBaud、64-QAM、32-symbol parallel；两级 averaging window 分别为 4 和 2 个 parallel blocks；以 BER=`1×10^-2` 处 SNR penalty 为指标，使用 bit-true fixed-point simulation。硬件比较统一为 28 nm CMOS、8-bit I/O、`ΔνTs=5×10^-6`、1 GHz。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §IV-A L163、§IV-B L173。
- **使用的 Baseline 方法**：
  - conventional mVV-CT-VV：论文同条件实现的主算法/硬件 baseline。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §II L55-67、§IV-A L169。
  - mVV-CT-MLE：只替换第二级 MLE 的中间消融，用来隔离 MLE 与 PPS 的贡献。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §IV-A L169。
  - BPS：引言中的高性能 benchmark，不是本论文 matched hardware comparison 的主对象。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §I L17。
- **关键结论**：`(P1,P2)=(12,32)` 时性能曲线几乎与 baseline 重合，`P2=12` 时 SNR penalty 仍 `<0.05 dB`。estimator core 面积为 `0.141→0.109→0.069 mm²`，LPR-CPR 功耗由 `65.24→39.92 mW`；含公共开销的 total area/power 为 `0.137 mm²/107 mW`，效率为 `1401.5 Gbps/mm²` 与 `1794.4 Gbps/W`。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §IV-A Fig. 5 L169、§IV-B Fig. 6 L173-175、Table I L189-195。
- **与本研究关系**：方法可借鉴 / explicit-refactor 与 hardware comparator。`[推断]` 它只重构 CPE 内部两级 mVV/CT 数据流，没有 FOE+CPE 两次 M0 次幂，也没有证明跨 FOE/CPE 共享；不得冒充 P1 direct collision。边界依据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §II L43-67、§III-A L69-77。
- **实现关键细节**：32-symbol block 取 `P1=12` 可覆盖 `>99.66%` QPSK-like 数量分布；Kogge-Stone logic depth=`log2 N`，Blelloch=`2log2(N)-2` 且附加延迟被 pipeline slack 隐藏。CT-MLE 的 Eq. (8) 把 correlation 化为 I/Q 符号操纵，硬件只用两条 add/subtract path 与简单逻辑；统一 latency 为 21 cycles。证据：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §III-B L99-113、§III-C Eq. (8)/Fig. 4 L131-157、§IV-B L173。
- **适用性分析**：适用于 64-QAM coherent optical CPR 的显式数据流重构与 ASIC 成本对标；不直接适用于 P1 的 NDA FOE+CPE shared-M0 claim，也未验证 FSO turbulence。证据边界：`papers/doi/10.1109_lcomm.2026.3653195/content.md` §IV-A L163、§III-A L69-77。
