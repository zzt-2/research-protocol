# Flexible Phase Synchronization for Wireless Optical Coherent Communication System With Adaptive Fractionally-Spaced Blind Equalization Combined With Adaptive Kalman Filter

- **源文件路径**：`papers/downloads/2026-07-08/10301506.md`。
- **发表状态**：正式发表；正文给出 2023-10-30 出版日期与 DOI。证据：`papers/downloads/2026-07-08/10301506.md:5-19`。
- **发表渠道**：IEEE Photonics Journal, Vol. 15, No. 6。
- **年份/会议**：2023，IEEE Photonics Journal。
- **核心贡献**：四孔径接收信号在支路频率恢复与定时同步后，作为 fractionally-spaced 输入进入一个联合 FSE-MCMA+DD equalizer；其输出再进入 MEKF/AKF，联合削弱幅度与相位噪声。MCMA/DD 由在线 MSE decision circle 切换，MEKF 相位估计反向辅助 equalizer；CM 或 AR innovation statistics 再更新 measurement-noise variance。证据：`papers/downloads/2026-07-08/10301506.md:115-129,139-179,185-223`。
- **方法概述**：全部四支路样值先共同进入 fractionally-spaced adaptive equalizer，空间分集被吸收到联合 tap adaptation，而非先生成每支路 validity 再做 MRC。equalizer 输出 `y_k` 进入 MEKF/AKF，滤波器的复相位估计用于符号恢复，也以最近 `N=10` 个估计的均值反馈给 equalizer。证据：`papers/downloads/2026-07-08/10301506.md:129,145-185,223`。
- **实验设置**：四孔径、π/4-QPSK、同一 LO；支路间距大于 atmospheric coherent length，使用相互独立 Log-Normal turbulence。每个 SNR 做 20 次 sweep，每次 `2^14` symbols；每 frame 内 fading 固定、frame 间独立变化。证据：`papers/downloads/2026-07-08/10301506.md:57-75,229`。
- **使用的 Baseline 方法**：EGC 后接 VVPE；FSE-MCMA+DD；FSE-MCMA+DD-MEKF；以 transmit symbol 代替 pre-decision 的 IEKF；AKF-CM 与 AKF-AR。证据：`papers/downloads/2026-07-08/10301506.md:249-261,311-319`。
- **关键结论**：相对 EGC+VVPE，FSE-MCMA+DD-MEKF 在文中仿真下报告约 1--2 dB SER/MSE 改善；AKF 将可工作 linewidth 从 MEKF 的约 8 kHz 扩展到 12 kHz，并相对 MEKF 再报告 1--2 dB SER 改善。证据：`papers/downloads/2026-07-08/10301506.md:259-265,309-319,343`。
- **与本研究关系**：`neighbor`，也是必须保留的 estimator-changing comparator。它覆盖“多孔径原始/前端恢复后样值 → joint adaptive taps → combined/equalized stream”，但不覆盖 Q001 的“branch-local validity → bounded reliability/admission/abstention → no-valid flag”。
- **实现关键细节**：FSE tap vector length 为 `l×(L_f+1)`，`L_f=6`；MCMA 与 DD step size 均为 `10^-3`；两者用 MSE decision threshold `d=0.4` 切换，MSE forgetting factor `λ=0.99`；MEKF feedback average `N=10`；MEKF process/measurement noise variance 初值分别 `10^-2/10^-1`。证据：`papers/downloads/2026-07-08/10301506.md:151-179,195`。
- **适配性分析**：
  - 适配点：四孔径 coherent-FSO；receiver-side joint adaptive combining；在 time-varying amplitude/phase impairment 下有状态更新。
  - 不适配点：没有显式 branch-validity observable、per-branch trigger、bounded/shrunk branch weight、admission/abstention 或 no-valid output；其 timing/frequency recovery 已先完成，但没有以这些模块的 lock/confidence 控制支路进入。
