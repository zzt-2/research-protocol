### [Step 3.5] Discrete FRFT-Based Frame and Frequency Synchronization for Coherent Optical Systems

- **标题自检**：metadata 的自动 `title_check=unverifiable`；正文首个 H2 与派遣标题逐词一致，人工 token overlap=`1.0`，`PASS`。证据：`papers/arxiv/1801.01598/content.md:3`。
- **DOI/来源**：DOI `10.1109/LPT.2017.2759584`；arXiv `1801.01598`。
- **源文件路径**：`papers/arxiv/1801.01598/content.md`
- **发表状态/渠道**：正式发表，IEEE Photonics Technology Letters，2017；本地全文为 arXiv manuscript。
- **核心贡献**：论文用两条不同 chirp-rate 的 receiver-known training chirps，在 FRFT 域分别形成相关峰；两个峰移位同时受 time shift 与 CFO 影响，作者通过一个二元线性方程组联合恢复整数 frame offset 与 CFO。该 TS 随后复用于 DD-LMS 自适应均衡。证据：`content.md:7,49-83,95-99`。
- **方法概述**：先在每个候选 block 内对两条 chirp 分别做 fractional cross-correlation 与峰搜索，再把两个峰移位代入 FRFT time/phase-shift 方程；线性求解得到 time shift 与 frequency shift，最后量化为 frame offset 和 CFO。
- **receiver-visible information**：每帧开头的两条已知离散 chirp；两条 chirp 由不同最优 FRFT 角/斜率生成并切片成 4-QAM。接收端在每个偏振支路独立处理。证据：`content.md:49-63,95-99`。
- **action/metric**：对每个 block 与 chirp 计算 fractional-cross-correlation metric
  `R_{ib}(u)=|F_{-pi/2}[(F'_{phi_i}P_{ib})(u)(F'_{phi_i}A_i)^*(u)]|^2`；先取 `u_hat_ib=argmax_u R_ib(u)`，再取 peak 最大的 block `b_hat`，得到两个 peak shift `Delta n_1, Delta n_2`。它们满足 `Delta n_i=Delta t cos(phi_i)+Delta f sin(phi_i)`；解此 2x2 方程后输出 `mu_hat=round(Delta t)+b_hat N_s` 与 `gamma_hat=(Delta f/N_s)R_s`。证据：`content.md:37-83`，公式清晰度由 `source.pdf` 的 Eq. (6)-(13) 复核。
- **output**：一个离散/整数 symbol-domain frame offset `mu_hat` 与一个连续 CFO `gamma_hat`；没有输出 sample-level fractional-symbol timing `tau`，也没有 SCO/drift。证据：`content.md:79-83,97-99`。
- **时序/处理顺序**：`matched RRC -> CD compensation -> downsample to 1 sample/symbol -> FRFT joint frame/CFO synchronization -> DD-LMS polarization demultiplexing/residual CFO/carrier phase`。关键点是 joint synchronizer 的输入已经降为 1 sps。证据：`content.md:95-99`。
- **jointness verdict**：`TRUE_JOINT_INTEGER_FRAME_OFFSET_AND_CFO / NOT_EXACT_Q1_ACTION`。frame offset 与 CFO 由同一对 chirp metrics 的耦合方程共同求解，故不是普通顺序 frame+FOE；但 frame quantity 是 1-sps 下的整数 symbol offset，而不是 Q1 要求的 fractional `tau`。因此不构成单一 objective 同时输出 `(frame index, fractional tau, CFO)` 的 exact collision。
- **Q1 collision**：`NO_EXACT_COLLISION_STRONG_NEIGHBOR`。它占用“同一 receiver-known TS、同一 coupled metric 联合恢复 frame/CFO”的方法先例，Q1 后续必须引用/比较；它没有占用 RRC oversampled sample-level fractional timing 与 frame/CFO 的三参数联合动作。
- **与本研究关系**：直接方法先例/强邻居；不是 Q1 的 task-matched 2019+ baseline，也不是 exact-action collision。
- **实验设置**：32-Gbaud PDM-16QAM Nyquist system；Tx waveform 先上采样到 2 sps 并经 73-tap RRC（roll-off 0.13），但接收同步前下采样到 1 sps；TS length 1024，默认 frame offset 100 symbols、CFO 3 GHz、OSNR 10 dB，每项 1000 trials；laser linewidth 100 kHz。证据：`content.md:91-103`。
- **Baseline**：frame 对比 TS-based Schmidl-Cox；CFO 对比 Zhou TS-based method。论文没有与含 fractional timing 的三参数联合 estimator 比较。证据：`content.md:19-21,103`。
- **关键结论**：TS=1024 时未观察到 timing/frame estimation error，CFO error 约 7 MHz；验证至 `+-5 GHz` CFO 时最大 CFO error 约 11 MHz；相较两项独立 baseline，在低 OSNR 下更稳健。证据：`content.md:101-103,121-131`。
- **实现关键细节**：两条 chirp 用不同 `phi_opt`；默认 `N_s=1024`；离散 FRFT 复杂度为 `O(N log N)`；frame offset 使用 `round(Delta t)+b_hat N_s`，因此不保留 fractional timing。证据：`content.md:35,49-83,101`。
- **failure condition/适用边界**：论文针对 ASE-noise fiber link 和已完成 1-sps decimation 的 burst receiver；没有 Gamma-Gamma fading、fractional sampling phase、SCO/drift 或 oversampled joint-search evidence，不能直接外推为 Q1 exact comparator。

#### 结构化 action contract

| 维度 | 正文事实 | 对 Q1 的含义 |
|---|---|---|
| information | 两条 known chirps；不同 FRFT angle/chirp rate | 同信息源，且两峰共同供参 |
| action | 两个 fractional-correlation peak + 2x2 coupling solve | frame/CFO 是真正 joint action |
| output | integer `mu_hat` + continuous `gamma_hat` | 缺 fractional `tau`，非三参数 exact action |
| timing | CD 后、downsample to 1 sps 后执行 | 不能解决 oversampled sample phase |
| overhead | 默认 TS 1024 symbols | 是强方法邻居，但开销口径须单列 |

#### 状态/动作/目标与建模假设

| 项 | 结构化提取 |
|---|---|
| 状态/输入空间 | `B` 个、每块 `N_s` 个 1-sps received symbols；两条 known chirps 的 FRFT/correlation samples；无统一 normalized state vector。 |
| 动作空间 | 两个 peak indices、一个 block index、连续 `Delta t/Delta f` 解、整数 `mu_hat`、连续 `gamma_hat`；无 fractional `tau` action。 |
| 奖励/目标 | 非学习法，无 reward；局部目标为最大化各 `R_ib(u)`，随后确定性解 2x2 方程，无跨三参数单一 scalar loss。 |
| 建模假设 | burst TS 已知；matched filtering/CD compensation 与 1-sps decimation 已完成；time/frequency shift 可由 FRFT peak displacement 线性表征。 |
| 网络架构 | N/A；离散 FRFT + fractional correlation + argmax + closed-form solve。 |
| 适配性 | 适配 known-preamble frame/CFO jointness；不适配 oversampled fractional timing、SCO/drift、FSO turbulence。 |
