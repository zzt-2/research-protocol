## AMC 关键语义
- deployable action: YES — TX FSO 子载波 m_f-QAM 模式 + RF (m_r-QAM + coding rate r_c per 3GPP TS38.214) MCS + UAV 功率/轨迹；**MCS 切换真实 runtime，闭式 SNR 阈值驱动** [content.md:125,131,397,569]
- CSI: RX 估计 ĥ=h+n, n~N(0,σ_n²/(N·P_t))；**显式 imperfect CSI Gaussian 误差模型 σ²=1/N** [content.md:251]
- decision timescale: per-slot τ=P/T [content.md:137]
- CSI feedback delay: RF μs、FSO ms，论证为远<相干时间（数十 ms）可忽略；**未给具体数值** [content.md:137]
- turbulence: **lognormal** FSO（非 GG）+ 确定性衰减含 pointing（无显式 Farid-Hranilovic PDF）+ RF Nakagami-m [content.md:141,143,171]
- detection: **IM/DD**（强度调制 QAM + photodiode 直接检测，非 coherent）[content.md:115]
- coding/HARQ: **NO** — coding rate r_c 仅作 3GPP MCS 表条目，无 HARQ-IR/RCPC/重传；HARQ 仅 related work [27] 引用 [content.md:125]
- objective: throughput-max s.t. FER≤FER_target + CSI 不确定性鲁棒约束 + UAV 约束 [content.md:191,197]
- baselines: JOMPT-NCU（忽略 CSI 不确定性）、nonadaptive（MCS16/24 固定）、PPO/DQN/random JOMPT [content.md:646,681,699]
- oracle: 隐式 — JOMPT without est errors/perfect CSI 作上界 [content.md:635]
- key numbers: N=1 robust-CU 丢 650Mb/s@0.225W，N=100 gap→0.089Gb/s；adaptive vs nonadaptive MCS16 +0.64Gb/s；DDPG 483Mb/s@0.01W vs DQN 419 vs random 151；robust-CU FER<0.1，NCU FER=0.45/0.28@γ_RF=-7.5/-5dB,N=10 [content.md:627,631,668,681,701]

## 与目标重合/缺失
- 重合: **information uncertainty（Gaussian σ²=1/N）建模高度对齐**、imperfect CSI 下 FER/速率闭式映射 + MCS 切换阈值闭式、DDPG 解混合动作范式、satellite 链路（sat-UAV 段）
- 缺失: **非 coherent**（IM/DD）、**非 GG**（lognormal）、**无 coded chain/HARQ**（coding rate 仅 MCS 表条目）、**非纯星地**（sat-UAV-terrestrial 双跳）
