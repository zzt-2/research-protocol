# Read note — Layton 2018

- 题名：Improved demapping for channels with data-dependent noise；title check：PASS。
- DOI/来源：10.1186/s13638-018-1136-z。
- 源文件路径：papers/doi/10.1186_s13638-018-1136-z/source.md。
- 发表状态：正式发表。
- 发表渠道：EURASIP Journal on Wireless Communications and Networking。
- 年份：2018。
- 核心贡献：以每个星座点独立的二维 Gaussian mean/full covariance 建模数据依赖噪声，把 covariance 同时纳入 Mahalanobis 距离和 determinant normalization。给出 pilot sample covariance 与 blind GMM/EM 两种估计，并在 TWTA residual distortion、phase noise、coded/iterative receiver 中验证最高约 4 dB required-SNR reduction。
- 方法概述：\(p(y|x_k)=[2\pi|\Sigma_k|^{1/2}]^{-1}\exp[-(y-\mu_k)^T\Sigma_k^{-1}(y-\mu_k)/2]\)，bit LLR 对 bit-subsets 求和；pilot 用 unbiased mean/covariance，低样本建议跨 frame 或 shrinkage。
- 实验设置：64/128-APSK、64/128-QAM；约25–26 dB示例；BER target \(10^{-6}\)；pilot sweep、EXIT；AIC 用 \(10^8\) symbols。
- Baseline：circularly symmetric Gaussian/Euclidean demapper；centroid-aware standard demapper。
- 关键结论：distortion-dominated 时获益，thermal-noise-dominated 时趋同；coded gain 依赖 modulation、code threshold、labeling。
- 与本研究关系：C5-1 mandatory full-covariance comparator；原子碰撞，structured estimator 未 exact collision。
- 实现关键细节：full model 7 multiplications vs scalar 4；MATLAB demap time <1% increase，demapper占 receiver <2%；2 turbo iterations 示例成功。
- 适配性：适配 APSK/pilot/full covariance；逐点参数多、causal 时变未定义；启示是 radial/tangential shrinkage。
- 开源代码：无。
- 验证状态：正文完整精读。

## 2026-08-30 C5-0 重读补充

- canonical `source.pdf` 为有效12页PDF；title与 Eq.(6)、(9)–(12) 已同 `source.md` 交叉核对。Eq.(6)/(9)/(10)在PDF第4页，Eq.(11)–(12)在第5页。
- receiver-visible IAO：known APSK pilots及其点身份 → Eq.(11)–(12)逐点估 `mu_k,Sigma_k` → Eq.(10) likelihood → Eq.(6)/(9) APP/extrinsic LLR。120 pilots/point在64阶时约6% overhead；论文没有每帧cadence、tracking latency或 operational minimum samples。
- 自由度约为每点二维centroid+完整2×2 covariance（约 `5M` 实参），不是global/per-frame scalar。它改变 Mahalanobis distance与log determinant，hard decision regions也可改变。
- Layton自身 standard baseline为同样估centroid、但所有点共用constant circular covariance；真实 `p(y|x)`/maximum rate另属 matched-oracle reference。
- 对C5-0身份：`strong neighbor + executable primitive`，**不是 scalar exact recipe**。不支持“首次pilot covariance demapping”或把高维per-point动作冒充低维LLR calibration。
- truth边界：pilots是receiver-visible；oracle covariance NMSE、MI/EXIT积分与仿真SNR属offline evaluation。DRL字段均 `N/A（传统通信非DRL）`。
