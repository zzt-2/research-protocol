### [L02] Simplified Carrier Recovery for Intradyne Optical PSK Receivers in udWDM-PON

- **核心贡献**：论文提出 differential-detection carrier recovery 架构，把 FE 与 PR 都需要的 1-symbol complex correlation 变成单一共享上游节点，以减少 FPGA 算术资源与处理延迟。论文在商用 Virtex-6 FPGA 上以 1.25-Gb/s DPSK、25-km SMF 实时验证，并报告更高的快速 laser-wavelength-drift tolerance。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:47-49`（§I）；`:73-89`（§II，Fig. 2/Table I）；`:177-183`（§IV，Fig. 10）。
- **方法概述**：conventional CR 中，FE 和 PR 分别做 delay-and-multiply correlation；当 CLK recovery 在 CR 之前完成、(P=R_s/R_b=1) 时，两级延迟都成为 (z^{-1})。proposed CR 先每符号计算一次 1-symbol correlation，PR 直接消费该输出，feed-forward differential (m)th-power FE 复用同一输出；CFO 在相关域表现为恒定 \(\Delta\phi\)，故最终 rotator 使用 (e^{-j\Delta\phi}) 而不是 (e^{-jk\Delta\phi})。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:53-77`（§II，Fig. 2a–c）。
- **实验设置**：1.25-Gb/s DPSK、25-km SMF、4-MHz DFB Tx；LO 使用 100-kHz ECL、4-MHz DFB 或 15-MHz DFB；I/Q 经 1-GHz fourth-order Bessel filters 后以 2.5 GSa/s ADC 采样；FPGA 为 8-bit ML605 Xilinx Virtex-6、156.25-MHz process clock。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:91-113`（§III，Fig. 3）。
- **使用的 Baseline 方法**：
  - conventional separated differential (m)th-power FE + differential PR：论文在同一 FPGA 接收链中实现，是 proposed architecture 的 task-matched comparator。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:51-75`（§II，Fig. 2a/b）；`:111-125`（§III/IV）。
  - differential PR without FE：用于测量 CFO tolerance 下界。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:139-149`（§IV，Fig. 8）。
  - 相同 conventional/proposed CR 在不同 linewidth、detuning 与 optical dithering 条件下比较；两架构采用相同最佳 (N=2^8)。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:119-127`（§IV，Fig. 4–5）；`:177-183`（Fig. 10）。
- **关键结论**：proposed CR 的 real adders 减少 23%、real multipliers 减少 25%、总 CR process delay 减少 25%，argument LUT 大小近似不变。conventional/proposed 的静态 BER 基本相同，但 fast optical dithering 的 1-dB tolerance 从 70 kHz 提升到 350 kHz，即 5 倍。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:79-89`（§II，Table I）；`:127-149`（§IV，Fig. 5/8）；`:177-183`（§IV，Fig. 10）。
- **与本研究关系**：直接相关。本文本体已实现 **shared correlation**，不是 shared raised-power；但它同时二手报告 Ferreira et al., OFC 2016 [17] 的架构把 differential (m)th-power FE 与 Viterbi PR 都需要的 (m)th-power 只计算一次并共享。该 [17] 描述与 P1 的 exact action 高碰撞，但正式裁决仍需 primary-source 全文。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:73-75`（§II）；`:237-237`（Reference [17]）。
- **实现关键细节**：共享成立的硬条件是 CLK recovery 已完成且 (P=1)；average block 选择 (N=2^8=256)；argument extraction 用 LUT；(m)th-power FE 的 phase ambiguity 为 \(\pm\pi/m\)，实验用 phase unwrap 展开。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:71-89`（§II）；`:119-125`（§IV，Fig. 4）；`:139-143`（§IV，Fig. 7）。
- **适用性分析**：适合作为“同功能 carrier-recovery 数据流重排 + matched FPGA comparator”的直接工程先例；只适用于先定时、(P=1) 的 differential PSK 路径，不能直接外推为任意 QAM/VV-CPE 的 shared M0-domain 等价证明。证据基础：`papers/doi/10.1109_jlt.2018.2831918/content.md:63-77`（§II）、`:197-203`（§V）。
- **开源代码**：未报告；正文描述 commercial FPGA prototype，但未给 repository。证据：`papers/doi/10.1109_jlt.2018.2831918/content.md:91-115`（§III）；`:255-259`（References/biography 结束，无代码链接）。
