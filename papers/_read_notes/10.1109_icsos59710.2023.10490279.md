- **核心贡献**：为 56-GBaud GEO DP-QPSK feeder link 共同设计 3.6–4.8% overhead frame 和低时延 feed-forward DSP receiver；前端在 2 sps 下顺序完成 coarse CFO、matched filtering、Lee blind timing recovery 与 fractionally-spaced equalization，随后在 1 sps 下做 frame acquisition、data-aided fine CFO 与 pilot-aided CPE。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:40-51,310-370,420-480,629-704`。
- **方法概述**：启动阶段先盲初始化/训练 coarse CFO、timing、adaptive equalizer，再进入 frame acquisition；steady state 中 frame header 每帧支持 Mengali-Morelli fine CFO，pilot blocks 支持 phase tracking。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:358-387,629-704`。
- **receiver-visible information**：启动盲算法只用接收双偏振 samples；frame/fine CFO 使用已知 64-symbol distinct headers；CPE 使用每 248 payload 后的 8 pilots。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:310-348,358-370,619-704`。
- **action**：六候选 coarse CFO 旋转择能量、matched filter、每 5000-symbol block 的 Lee timing estimate + digital interpolation、简化 CMA FSE、双偏振独立 header search、per-frame fine CFO、pilot phase interpolation。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:420-579,607-704`。
- **output**：coarse CFO bin、symbol-epoch corrected 2-sps stream、1-sps polarization-demultiplexed symbols、frame starts、per-frame fine CFO、phase trajectory 与 soft LLR。
- **sample rate / 时序**：架构显式区分 2 sps、1 sps 和 bit-rate；coarse CFO/timing 位于 2-sps path，digital interpolation 后才 downsample 到 1 sps；FSE 吸收 residual fractional delay，frame search 仅处理可能残留的 integer-symbol X-Y skew。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:358-370,420-480,559-579`。
- **实验设置**：56 GBaud DP-QPSK、RRC α=0.1、最低 -6 dB Es/N0、CFO ±5 GHz、clock drift ±30 ppm、linewidth 600 kHz、PDL 5 dB、X-Y skew 0.25 ns；不显式模拟 turbulence trajectory。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:172-205,216-242,245-261`。
- **使用的 Baseline 方法**：DVB-S2/S2X 与 OIF 400ZR 为 system anchors；各 stage 使用 Mengali NDA CFO、Lee timing、modified CMA、Lee 2009 differential frame sync、Mengali-Morelli fine CFO；CPE 对 VV/BPS 与 pilot ML 作取舍。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:274-308,420-480,559-704`。
- **关键结论**：仿真在 -6 dB 与多种 impairment 下以 <5% overhead 完成 acquisition/lock；初始化+锁定通常 <100 μs，frame acquisition 在 -6 dB/5 dB PDL 下 <50 μs。fine CFR 在负 SNR 会因 residual CFO 恶化性能，deep-fade stay-locked/reacquisition 尚待研究。证据：`papers/doi/10.1109_icsos59710.2023.10490279/content.md:380-387,612-649,729-771,779-801`。
- **与本研究关系**：给出真正的 2-sps fractional timing + frame + CFO 完整顺序 comparator，但没有把三者实现为一个 joint estimator/action。
