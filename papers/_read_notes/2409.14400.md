### [L003] Preamble Design for Joint Frame Synchronization, Frequency Offset Estimation, and Channel Estimation in Upstream Burst-mode Detection of Coherent PONs

- **年份/会议**：2025，Journal of Lightwave Technology（正式身份来自本地 metadata）。
- **核心贡献**：论文设计 CAZAC-based TS-B，每个 training unit 由 X/Y 两偏振上的四个变换 CAZAC blocks 与 guard intervals 组成；同一单元可独立支持 frame synchronization、FOE 与 frequency-domain channel estimation，重复 `L` 个单元可用 metric multiplication/averaging 抗噪。FD-CE 利用 CAZAC flat spectrum 估计 RSOP、bandwidth limitation、CD、PMD/DGD 与 PDL 组合形成的 `2×2` transfer matrix，再用 ZF 初始化 FD equalizer，从而减少 LMS convergence 所需 training。证据：`papers/arxiv/2409.14400/content.md` §II L63-257。
- **方法概述**：TS-A 先执行 coarse frame detection 和 Godard clock recovery；TS-B 随后顺序执行 FS（在 `rX,rY,rX+rY,rX-rY` 四路 timing metric 中选 peak 最优者）、FOE（已知 CAZAC 去数据、相关相位增量、X/Y 平均）与 FD-CE/ZF initialization。payload equalizer 由 training-aided LMS 切到 decision-directed LMS，并结合 pilot-aided ML CPR。证据：`content.md` §II/Fig. 1 L41-57、§II-C–F L135-257。
- **实验设置**：15-Gbaud DP-16QAM、RRC roll-off 0.1；最终 `N=64`, `N_GI=2`, `L=2`，总 preamble 272 symbols/18.13 ns。仿真加入 PMD、PDL、RSOP、CD、random delay、FO 和 AWGN；硬件实验用 120 GSa/s AWG、11 km SSMF、100 GSa/s DSO、1550-nm ECL（linewidth <100 kHz）和 `2^15`-symbol payload。证据：`content.md` §III L259-317、§IV L345-367。
- **receiver-visible information**：receiver 知道 TS-A/TS-B preamble。FS 可见 `r'_X,r'_Y,r'_X+r'_Y,r'_X-r'_Y` 四路对称块 timing metrics；FOE 可见已知 CAZAC 去数据后的相位相关；CE 可见两偏振、twofold-upsampled CAZAC 与对应 received sample spectra。证据：`content.md` §II-C–E L135-251。
- **action**：独立 Godard clock recovery 先消除 sampling phase offset；TS-B 再选择 frame peak、估计标量 CFO、估计每个 frequency bin 的 `2×2 H(ω)` 并以 ZF 生成 equalizer coefficients。证据：`content.md` §II/Fig. 1 L43-57、§II-C–E L135-251。
- **output**：clock-corrected samples、TS-B frame index、标量 CFO estimate、frequency-domain `2×2 H(ω)` 与 initialized `W(ω)`，随后输出 LMS/CPR-recovered payload。证据：`content.md` §II L43-57、L193-257。
- **时序/处理顺序**：`TS-A frame detection → Godard clock recovery → TS-B frame synchronization → TS-B FOE → matched filter → TS-B FD-CE/ZF initialization → FD equalizer + pilot CPR/LMS`。论文的 “joint” 指同一 training unit 被多个 DSP 复用，动作模块仍按上述顺序执行。证据：`content.md` §I-II L35-57、L133-205。
- **failure condition/适用边界**：TS-B FS/FOE 假定 sampling phase offset 已由前级 clock recovery 消除，未联合估计 fractional delay；短 FOE training 内 phase noise 近似 constant。单路 timing metric 在特定 RSOP（如 `θ=π/4, α=β`）可被抵消，必须从 X/Y/加/差四路中择优；FOE 为避免 odd-`m` 附加 `π` 相位，使用 two-symbol phase increment，并把 operational range 设为 `(-R_s/4,+R_s/4)`。证据：`content.md` §II L43-57、L145-201。
- **使用的 Baseline 方法**：
  - 2021 JOCN 1792-symbol、2023 JLT 416-symbol、2024 JLT 496-symbol coherent-PON preambles：正文引用其 reported lengths，但没有统一实验复现（`content.md:31-39,447-457`）。
  - ordinary 16QAM training blocks：论文内 self-implemented CE comparator（`content.md:281-291`）。
  - standard equalizer without CE：论文内 self-implemented comparator，先用 100 known blocks 收敛再切 decision-directed（`content.md:317-331,389-393`）。
  - blind fourth-power FOE：实验中用作实际 FO reference，不是完整 pipeline baseline（`content.md:369-375`）。
- **关键结论**：两单元相对一单元的 CE SNR gain 为 1.5 dB，而 2→4 单元仅再增 0.7 dB；两单元时 block length 32→64 增 3.6 dB，64→512 仅增 0.4 dB，故选 64-symbol blocks、2 units。仿真中 FS 在 -3–3 GHz 保持 PMNR>10 dB，FOE 在 -3.5–3.5 GHz 平均 error <3 MHz；实验相对 fourth-power reference 在 -1.5–1.5 GHz 的平均 error within 0.4 MHz。CE equalizer 从首块已收敛，normal equalizer 仿真约需 100 blocks、实验约需 50 blocks。证据：`content.md:283-315,317-331,369-393`。
- **与本研究关系**：oversampled-sync Q1 的近期 task-matched comparator。它已有 RRC、DP-16QAM、短 receiver-known preamble、2-sps CE data 与 frame+CFO；但 fractional timing 由 TS-A/Godard 先消除，TS-B FS→FOE 仍是 sequential actions。它直接约束“共享 preamble”或“重排模块”不能自动称作 sample-level timing/frame/CFO joint action。证据：`content.md:35-57,133-137,227-231`。
- **实现关键细节**：总长度 `N_TS=L×2(N+2N_GI)=272`；payload 每 31 symbols 插一个 pilot，overhead 3.125%；equalizer block length 64、taps 128、50% overlap；FOE operational range `(-R_s/4,+R_s/4)`；短 FOE training 内 phase noise 近似常量。证据：`content.md:39-43,121-133,157-201,253-257,317,345-349,393`。
- **适用性分析**：适配 receiver-known burst acquisition、短 preamble、oversampled coherent DSP 与 frame+CFO comparator；不适配 CFSO turbulence/fade、SCO/drift 或未定时 samples 上的 joint fractional-delay acquisition。其“joint”指 same training unit 被 FS/FOE/CE 共享，不是单一 coupled estimator。证据：`content.md:35-57,133-137,203-231`。

#### 状态/输入空间

| 维度名 | 范围/取值 | 归一化方法 |
|---|---|---|
| FS received samples | `r'_X,r'_Y,r'_X+r'_Y,r'_X-r'_Y` | timing metric 含 normalization power factor；四路择 peak 最优者 |
| TS-B unit | 四个 CAZAC blocks + block 两侧 GI；`L` 个 repeated units | CAZAC constant amplitude/zero autocorrelation/flat spectrum；重复单元 metric multiplication/average |
| FOE input | known CAZAC 去数据后的 X/Y sequences | correlation averaging、two-symbol phase increment、X/Y estimate average |
| CE input | twofold-upsampled known CAZAC spectra 与两偏振 received spectra | `2×2` matrix inversion + ZF-normalized coefficients |
| sampling phase | TS-B 前已经由 Godard clock recovery 消除 | 不作为 TS-B action variable |

证据：`papers/arxiv/2409.14400/content.md` §II L43-57、L119-251（Eq. 14-36）。
