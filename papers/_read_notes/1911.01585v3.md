- 核心贡献：将 PS-BICM 的 prior、extrinsic L-value scaling、auxiliary channel、GMI/NGMI/ASI 与 post-FEC benchmark 统一起来。论文明确了 matched、mismatched和量化场景下指标等价成立/失效的边界，并展示 practical FEC 的 bit mapping dependence。
- 方法概述：posterior L-value 写成 (L^{po}=L^{pr}+sL^{ex})，只缩放 channel/extrinsic部分；纯 SNR mismatch 时理论最优 (s_o=\mathrm{SNR}/\widehat{\mathrm{SNR}})。
- 实验设置：DVB-S2 LDPC 64800 bits、50 BP iterations；32 Gbaud、7 WDM、100 km/span coherent-fiber链路；4% QPSK pilots用于 equalization、CPR和 auxiliary SNR estimate。
- 使用的 Baseline 方法：matched auxiliary channel、不同 pre-FEC metrics与bit mappings；后半仿真假设 approximately matched并取 (s=s_o=s_d=1)。
- 关键结论：prior 不应随 (s) 缩放；式(23)仅适用于 true/assumed channel差别为 SNR；量化/clip 会破坏理想不变性。
- 与本研究关系：`strong neighbor + analytic scaling primitive`，不是 deployable pilot formula。
- 实现关键细节：4% pilots只是插入比例，不是 minimum samples；论文未给 pilot residual→SNR 的 estimator、窗口或 cadence。
- 开源代码：未在正文确认。
- 验证状态：2026-08-30 按 T072 从全文重读。

## 公式—输入—动作—输出

\[
\hat L_i^{po}(y)=L_i^{pr}+s\hat L_i^{ex}(y),
\tag{1}
\]

见 `content.md:148-169`。一般 GMI optimum见式(6)–(8)，`content.md:180-188`；Gaussian auxiliary variance见式(21)–(22)，`content.md:273-290`；纯 SNR mismatch 时

\[
s_o=\frac{\mathrm{SNR}}{\widehat{\mathrm{SNR}}},
\tag{23}
\]

`content.md:291-295`。分子为 true SNR，不能改写为 receiver-visible pilot量。

| 项 | 提取 |
|---|---|
| receiver-visible online input | received symbols与4% QPSK pilots；pilots用于 auxiliary SNR estimate，但公式未给 |
| bit truth / true SNR / offline GMI | 式(23)含 true SNR；GMI/ASI Monte Carlo使用发送 bits（式(51)，`content.md:568-577`） |
| action location | 只缩放 channel/extrinsic LLR；prior保持不变 |
| output | posterior L-value → deinterleaver → SD-FEC decoder |
| causal window / cadence / minimum samples | `UNKNOWN / UNKNOWN / UNKNOWN` |
| freedom | 一个 global scalar；无 per-frame/per-ring/per-bit-channel action |
| hard-decision boundary | uniform prior时正 scaling不改sign；PS时 (L^{pr}+sL^{ex}) 的sign可能变化；量化会破坏理想等价 |
| metric / decoder | GMI/NGMI/ASI/post-FEC BER；有限结构FEC与bit mapping影响benchmark |

## C5-0 证据边界

- **B0**：同一 assumed `SNRhat` 的 mismatched one-shot demapper，`s=1`；后半 nearly matched 仿真更接近 **B_match/O1**，不能冒充 B0。
- 式(23)是 oracle/analytic relation，不是“pilots直接算 (s_o)”；pilot estimator/window/minimum均 `UNKNOWN`。
- claim ceiling：coherent-optical strong neighbor和SNR-only classical scaling，不含 deployable APSK/FSO方法声称。
