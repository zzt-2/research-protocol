# Read note — Wu 2010

- 题名：Adaptive-Normalized/Offset Min-Sum Algorithm；title check：PASS。
- DOI/来源：10.1109/LCOMM.2010.07.100508。
- 源文件路径：papers/doi/10.1109_lcomm.2010.07.100508/content.md。
- 发表状态：正式发表。
- 发表渠道：IEEE Communications Letters。
- 年份：2010。
- 核心贡献：把 check-node syndrome state 引入 NMS/OMS，在 satisfied/unsatisfied check 上切换两组 normalization/offset，抑制不可靠 message。保留 min-sum 数据流和硬件友好性，在两种 LDPC 上接近 SP。
- 方法概述：AN-MS 对 satisfied check 用 \(\mu\)，unsatisfied 用 \(\nu=\mu\eta\)；AO-MS 用 \(\epsilon\) 与 \(\zeta=(1+\rho)\epsilon\)。
- 实验设置：DVB-S2 rate-1/2 length64800、50 iter、8-bit；rate-3/4 length8064、60 iter。
- Baseline：SP、MS/NMS/OMS。
- 关键结论：相对 NMS约0.15 dB、OMS约0.1 dB；距SP约0.1 dB。
- 与本研究关系：C5-2 syndrome-state ancestor。
- 实现关键细节：NMS 27/32；AN (27/32,3/4)；OMS 8/50；AO (8/50,12/50)；shift-add。
- 适配性：低成本但需 syndrome，参数靠 simulation。
- 开源代码：无；验证状态：正文完整精读。
