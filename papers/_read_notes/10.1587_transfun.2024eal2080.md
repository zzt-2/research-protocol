## 标准条目

- **题名**：Reliability-List-Based Check-Belief Propagation Decoding of LDPC Codes。
- **作者**：Zhe Liu、Wu Guan、Ziqin Yan、Liping Liang。
- **DOI/来源**：`10.1587/transfun.2024EAL2080`。
- **源文件路径**：`papers/doi/10.1587_transfun.2024eal2080/content.md`。
- **发表状态**：正式发表。
- **发表渠道**：IEICE Transactions on Fundamentals of Electronics, Communications and Computer Sciences，Vol. E108-A, No. 6。
- **年份**：2025。
- **title identity**：PASS；metadata `title_check=match`、overlap=`0.8888888889`；全文 H1、DOI 与派遣身份一致（`content.md:7-25`）。
- **核心贡献**：论文提出 RL-CBP，用较短的 check-belief reliability list 近似 RBP 的全 residual 调度，只在 list 内选择优先更新的 check node，减少比较开销（`content.md:91-107`）。其将 CBP 的 check-belief 消息传播与动态局部更新顺序结合，仿真报告 BER 接近 RBP、收敛快于 CBP、比较次数低于 RBP（`:109-129,173-203`）。
- **方法概述**：check-belief 是 parity check 满足的后验对数比；调度 reliability 是 check-belief 更新前后的绝对变化量（source.pdf Eq. (1)/(11)；`content.md:53-57,121-129`）。每次从短 list 选最大 reliability check node，更新 B2V、posterior、V2C、C2B 和相邻 list 项。
- **实验设置**：BPSK-AWGN；rate 1/2；码长 2048/8192；regular (3,6) 和指定 irregular LDPC；PEG 构码；最大 50 iterations；最终 `L_total=64`（`:129-145,175`）。
- **使用的 Baseline 方法**：FBP/BP、LBP、RBP、CBP（`:161-187`）。
- **关键结论**：2048 irregular code、BER 约 `1e-5` 时，RL-CBP 相对 CBP/LBP/FBP 约有 `0.06/0.11/0.16 dB` 增益并接近 RBP；平均迭代意义下约为 CBP 两倍收敛速度，与 RBP 相近（`:173-183`）。
- **与本研究关系**：C5-5 direct strong neighbor / primitive overlap；不是外部 predecode reliability→per-codeword `num_iter` 的 exact recipe。
- **实现关键细节**：RBP residual 是消息更新前后幅度差；RL-CBP 每次 check-belief renewal 含 `d_c^j` 次 B2V/V2C/C2B 与 `M·L·(d_v-1)` 次比较；B2V/C2B 各一乘法、V2C 两次加减、list update 一次比较（`:91-97,185-199`）。停止为全部 check-belief 正或达到最大迭代数（`:129`）。
- **适配性分析**：
  - 适配点：直接证明 receiver-computable internal reliability 可驱动 LDPC 局部调度，并给 FBP/LBP/RBP/CBP 及解析操作数口径。
  - 不适配点：输入是 decoder-internal check-belief residual，动作是局部 edge/check-node 顺序；目标 Q-C5-5 输入是当前码字 LLR 派生的 predecode reliability，动作是每码字预译码 cap。
  - 改进/使用边界：只可把 Q-C5-5 定位为 target receiver 上的 LLR-derived reliability budget migration；不得声称首次 reliability-driven LDPC scheduling。
- **decoder output**：变量 posterior 与最终 hard decision；论文指标为 BER、平均迭代与解析复杂度，未报告 FER/P95 latency/API。
- **开源代码**：无公开代码链接；仅 Algorithm 1 伪代码。
- **验证状态**：metadata/content/source.pdf 本地交叉核对；未联网。
- **源质量限制**：`content.md` 丢失部分公式、Algorithm 1 和 Table 1 图像；承重 Eq. (1)/(11) 由 canonical `source.pdf` 核对，精确 list 插入/淘汰和 Table 1 全数值仍 UNKNOWN。

## C5-5 动作与九字段碰撞

- **直接 runtime input**：decoder-internal check-belief residual；receiver-computable，但不是外部 channel/pilot reliability。
- **动作**：局部 check-node/edge 更新次序；不是 predecode cap，也不是码字间预算。
- **stop/budget**：all-positive stop + fixed max 50；reliability 不改 max cap。
- **cost**：解析 updates/operations 与 average iterations；无 equal-total-update 或真实平均/P95 receipt。

| 九字段 | 判定 | 依据 |
|---|---|---|
| target decoder | different | RL-CBP/CBP vs fixed NMS/OMS cap |
| context | different | BPSK-AWGN vs target DP-APSK coherent-FSO |
| receiver-visible input | different | internal check-belief residual vs current-codeword LLR-derived predecode reliability |
| state statistic | different | `abs(Omega_new-Omega_old)` vs codeword reliability bin |
| action | different | select next check node/edge vs select `num_iter` |
| granularity/timing | different | repeated local decisions vs once before decoding |
| update/stop/budget | different | dynamic schedule + fixed cap vs reliability-conditioned cap |
| output/objective | different | BER/average iterations vs bits+BER/FER+avg/P95 cost |
| cost/fairness | different | analytic counts, no equal-update contract |

**碰撞结论**：`STRONG_NEIGHBOR / PRIMITIVE_OVERLAP / NOT_EXACT_COLLISION`。本篇支持 FBP/LBP/RBP/CBP/RL-CBP 邻居与 broad novelty ceiling；不支持 tuned fixed NMS/OMS、CRC early stop、equal-total-update extra-iteration、external reliability LUT、FSO/APSK 收益或首次/SOTA claim。
