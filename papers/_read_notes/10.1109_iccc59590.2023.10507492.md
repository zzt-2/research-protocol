# Read note — Zhao 2023

- 题名：An Improved Syndrome Bit Flipping Decoder with Narrowed Flipping Set for LDPC Codes；title check：PASS。
- DOI/来源：10.1109/ICCC59590.2023.10507492。
- 源文件路径：papers/doi/10.1109_iccc59590.2023.10507492/content.md。
- 发表状态：正式发表。
- 发表渠道：IEEE ICCC。
- 年份：2023。
- 核心贡献：指出低-threshold SBF 连带翻转非错误 bits；用 channel reliability top-\(T_1\) 与随机 \(T_2\) 构成 narrowed set，约束 SBF flipping set。给出包含全部 error bits 的概率与 trial 数关系。
- 方法概述：\(S=S_1\cup S_2\)，只翻 \(S_{SBF}\cap S\)；\(P_\gamma=1-(1-p)^\gamma\)。
- 实验设置：802.3an N=2048,R=.8413，(300,400)；PEGReg504x1008，(400,200)；SBF max200；AWGN/BPSK。
- Baseline：SBF、M-GDBF、S-NGDBF。
- 关键结论：BER \(10^{-6}\) 相对SBF得0.7/1.2 dB；\(\gamma=20\)为折中；低SNR reliability失效。
- 与本研究关系：C5-2 recent reliability-guided representative。
- 实现关键细节：\(\gamma=100\)低SNR约8×复杂度；额外 \(O(t\log t)\) intersection。
- 适配性：需要 soft channel values；低SNR不适配。
- 开源代码：无；验证状态：正文完整精读。
