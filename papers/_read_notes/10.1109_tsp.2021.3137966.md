### [L08] Joint ML/MAP Estimation of the Frequency and Phase of a Single Sinusoid With Wiener Carrier Phase Noise

- **标题自检**：派遣标题展开了实际标题中的 ML/MAP；正文真实标题见 `papers/doi/10.1109_tsp.2021.3137966/content.md` §题名 L5。去停用词 token Jaccard=`7/14=0.500`，`PASS`。
- **DOI/来源**：`10.1109/TSP.2021.3137966`。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §首页 L21。
- **源文件路径**：`papers/doi/10.1109_tsp.2021.3137966/content.md`
- **发表状态**：正式发表；2021-12-19 接收、2021-12-23 在线发表。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §首页 L17。
- **发表渠道**：IEEE Transactions on Signal Processing；**等级 UNKNOWN（本地证据池无权威分区记录；本轮禁 web，未外推）**。渠道证据：`papers/doi/10.1109_tsp.2021.3137966/content.md:1`（期刊页眉）。
- **年份/会议**：2022 卷期，IEEE Transactions on Signal Processing, Vol. 70；online 2021。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §页眉 L1、§首页 L17。
- **核心贡献**：针对 AWGN 与 Wiener carrier phase noise 中的 single sinusoid，论文对 deterministic frequency `ω` 和 initial phase `φ` 作 joint ML，对随机 phase-noise vector `θ` 作 MAP，估计式同时利用 received phase 与 magnitude。论文还推导 CRLB/BCRLB，并将估计器变成 sample-by-sample recursion；每次迭代 `O(1)`、总复杂度 `O(N)`。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §I L43-51、§IV L167-207。
- **方法概述**：将复样本写成 magnitude/unwrapped-phase 形式，用 received magnitude 决定 Gaussian-linearized AOPN variance，并把 Wiener covariance 加入 likelihood；联合求 `ω,φ` 的 ML，再由 conditional Gaussian 求 `θ` 的 MAP。Schur complement 递归更新 covariance inverse 与五个累计统计量，避免每步重新做矩阵逆。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §II L61-93、§III Eqs. (8)-(19) L95-165、§IV Eqs. (21)-(27) L167-213。
- **实验设置**：Monte Carlo `q=10^5`；用 inverse MSE 与 inverse CRLB/BCRLB 比较，扫描 SNR、observation length `N`、phase-noise variance `σp²` 与真实 `ω0/φ0`；主展示多使用 `N=16`。threshold SNR 定义为 inverse-variance curve 距 bound 下降 1 dB 的 SNR。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §VII L393-397、Figs. 1-11 L401-505。
- **使用的 Baseline 方法**：
  - CRLB/BCRLB：ML/MAP 的理论 lower bounds。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §V L225-327。
  - LMMSE-WPA 与 improved Kay estimator：低复杂度传统 frequency estimator。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §VI-B Eq. (54) L359-385、§VII-E L481-493。
  - pure-AWGN ML estimators `[3, Eqs. (16)-(17)]`：直接 estimator mismatch comparator。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §VII-F L495-505。
- **关键结论**：`N=16` 时 joint ML frequency/phase threshold SNR 均约 0 dB；`σp²=10^-2 rad²` 时 MAP threshold 约 5 dB、10 dB 时达到 BCRLB。LMMSE-WPA threshold 约 7 dB；pure-AWGN phase estimator 在 `σp²=10^-2`、SNR=10 dB 时损失约 1.3 dB，在 `σp²=0.1 rad²` 时旧 estimator 距 CRLB 仍约 6 dB。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §VII-C L457-461、§VII-E L481-483、§VII-F L495-505。
- **与本研究关系**：仅供 estimator-changing theory / traditional joint-estimator comparator。`[推断]` 该工作改变 likelihood、phase-noise statistical model 与 estimator target；它不做 Mth-power 去调制，也没有相同 raised-power node 被 FOE/CPE 重复消费，故不是 P1 compute-sharing 或 matched-output conventional refactor。边界证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §III L95-165。
- **实现关键细节**：理论输入为 `|r(k)|` 与 unwrapped `∠r(k)`；未知 amplitude 时可用 noisy magnitude 替代，0 dB 以上精度几乎不变，低于 0 dB 会退化。phase-unwrapping failure 会向后传播；大 `ω0/N/σp²` 时论文建议剔除出现 failure 的 runs。证据：`papers/doi/10.1109_tsp.2021.3137966/content.md` §IV L207-215、§VI-A L329-357、§VII-B L431-449、§VII-D L463-467。
- **适用性分析**：适合说明 joint FOE/phase estimator 可通过改变统计模型获得收益，并提供 `O(N)` recursion 与 MSE bound；不适合充当 modulated-QAM NDA receiver 的同 estimator/shared-M0 comparator，且没有 BER、fixed-point 或硬件资源。证据边界：`papers/doi/10.1109_tsp.2021.3137966/content.md` §II L61-75、§VII L393-509。
- **开源代码**：无；全文未报告 repository/data 链接（全文读取范围 `papers/doi/10.1109_tsp.2021.3137966/content.md` L1-598）。
