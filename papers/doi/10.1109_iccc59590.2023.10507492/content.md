_**Abstract**_ **—In this paper, we propose an improved Syndrome Bit Flipping (SBF) decoding algorithm that utilizes narrowed flipping set. The narrowed flipping set is prone to contain all error bit positions with high probability. To construct the narrowed flipping set, part of its elements are selected according to channel information, and the rest are constructed by random selections. The narrowed flipping set mitigates possible error propagation by avoiding some non-error bits being unnessary flipped, thereby further improving the decoding performance of the original SBF algorithm. The simulation results show that the proposed algorithm can achieve about 1.2 dB bit error rate gain compared with the original SBF algorithm, with a modest increase in computational complexity.** 

_**Index Terms**_ **—Low-density parity-check codes, syndrome bit flipping, narrowed flipping set, error propagation** 

## I. INTRODUCTION 

As an exemplary class of channel coding techniques, lowdensity parity-check (LDPC) code has shown excellent performance in low SNR regions, where the bit-error rate (BER) performance can exponentially decrease with the increase in SNR. However, in high SNR regions, the BER often ceases to decrease exponentially after reaching approximately 10 _[−]_[7] , manifesting a phenomenon known as the error floor [1]. To achieve enhanced decoding performance of LDPC codes, various decoding algorithms have been extensively studied. The two primary categories are the Sum-Product Algorithm (SPA) [2] and Bit Flipping (BF). SPA is sometimes referred to as belief propagation (BP) decoding algorithm, it is based on soft decision, and achieves excellent BER performance. However, it also demands substantial computational resources in its calculation process. 

The BF algorithms have lower algorithmic and hardware complexity compared to SPA algorithm, while the trade-off is that the BER performance is far from optimal. Over the years, various BF algorithms were proposed for making a balance between BER performance and decoding complexity, among which the Gradient Descent Bit Flipping (GDBF) algorithm is a landmark BF algorithm [3]. The performance of the GDBF algorithm outperforms most previously proposed BF algorithms. Moreover, a variant of the GDBF algorithm, known as NGDBF algorithm [4], further improves the BER performance

due to the incorporation of noise perturbations into the energy function. Based on the GDBF and NGDBF algorithms, several enhanced algorithms [5–7] have been proposed, some of which are close to the BP algorithm in terms of BER performance. 

Recently, a novel algorithm named Syndrome Bit Flipping (SBF) was proposed in [8], which is similar to Mulit-Threshold Bit Flipping (MTBF) presented in [9]. SBF exhibits a concise design in both algorithmic structure and hardware architecture. Consequently, SBF decoder is suitable to serve as a postprocessing decoder for other algorithms. During the iterative process of the SBF algorithm, bits with energy functions greater than threshold sequence value are flipped. However, when the values within the threshold sequence are very small, such flipping may lead to the bit-flipping of some non-error bits, causing error propagation. Consequently, this undermines the error-correcting performance of the SBF algorithm. 

To handle this problem and further improve the performance of SBF algorithm, narrowed flipping set are employed in the SBF iteration. The narrowed flipping set successfully avoids some non-error bits being unnessary flipped, resulting in a considerable BER gain. The primary contributions of this paper are summarized as follows: 1. In the SBF algorithm, the narrowed flipping set is introduced to constraint the flipping set found by the original SBF algorithm. 2. Determining the optimal method for selecting narrowed flipping set.

## _A. Error Propagation in SBF_ 

In the SBF algorithm, the flipping set is constructed by _S_ SBF = _{n ∈{_ 1 _. . . N }_ ; _Evn > θk_ ( _ℓ_ ) _}_ . However, when the threshold sequence value is small, such as when _θ_ ( _ℓ_ ) = 0, and there is only one wrong ’1’ variable node _v_ ¯ in the codeword, the existence of _v_ ¯ _i_ results in adjacent check nodes **c** = _{cj}j∈M_ ( _i_ ) being non-satisfied checks. Consequently the 

variable nodes connected with **v** = _{vj}j∈N_ ( **c** ) _\v_ ¯ have _E_ = 1. According to the condition _E > θ_ ( _ℓ_ ), both the **v** with _E_ = 1 and _v_ ¯ are flipped, which causing the error propagation. It is clear that flipping **v** is unnessary. This phenomenon leads to the question of how to effectively constrain the flipping set found by SBF algorithm to reduce the number of non-error bits being unnessary flipped. 

The preceding analysis of the effects of error propagation caused by unnessary bit flipping instructs us to construct a flipping set _S_ that includes the positions of all error bit positions _S_ err and another _n_ non-error bits, and we use _S_ to constrain the flipping set _S_ SBF. Essentially, the original SBF algorithm can be viewed as a circumstance where _S_ contains all the bits in the codeword, then as _n_ decreases, the flipping set _S_ SBF becomes increasingly constrained by _S_ . We use IEEE 802.3an LDPC code [10] with code length _N_ = 2048 and code rate _R_ = 0 _._ 8413 as an illustration, Fig. 1 shows that constraning _S_ SBF resulting in a notable BER gain compared to the SBF algorithm, and BER gain increases as _n_ decreases. Thus constraning _S_ SBF is a viable strategy to optimize the SBF algorithm.

## _C. More Heuristics_ 

Moreover, we discovered that the mechanism of narrowed flipping set is not only applicable to SBF, but also to other multi-bit flipping algorithm based on threshold comparisons, such as MTBF, M-GDBF and M-NGDBF. These algorithms share the same characteristic that during the multi-bit flipping processes, some non-error bits are flipped together with error bits. And varying degrees of BER performance gains can be observed when the NFS mechanism is applied to these algorithms. The NFS mechanism is a cross-validation mechanism - the flipping set is first identified by multi-bit flipping algorithm, then narrowed flipping set filters out some nonerror bits that do not need to flipped. Thereby this mechanism constrains the route of bit flipping, and enhances the decoding performance. However, one limitation of NFS is that at lower SNR, we cannot narrow down the flipping set by selecting the top- _n_ unreliable bit positions, as the distribution of error bit positions in the LDPC code is chaotic under this circumstance. If there exists a method more effective than using channel information to select unreliable bit positions, we believe that the decoding performance of NFS could be further improved. 

## V. CONCLUSION 

In this paper, we proposed an improve SBF algorithm based on narrowed flipping set. Narrowed flipping set is found based on channel information and random selection, and it narrowed the range for bit-flipping in SBF, therefore suppresses error propagation effectively. The NFS-SBF decoding algorithm has been compared with the SBF algorithm and some other 

advanced BF algorithms. The simulation results show that our algorithm outperforms the SBF algorithm, with a modest complexity increasing.
